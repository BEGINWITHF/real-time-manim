# 三维工具函数（three_d_utils）

`mobject/three_d/three_d_utils.py` 是一组模块级工具函数，用来提取 `VMobject` 首/尾角点坐标、渐变起止点与任意锚点处的单位法向量，全部可直接 `from manim import ...`。

这些函数只对**单个三维面片**（一个 `VMobject`）才有意义：传进 `Cube`、`Sphere` 这类 `VGroup` 外壳会退化（角点算回 `ORIGIN`、法向算回 `UP`），要先取 `cube[i]` 这样的子面片再查。

## 首/尾角点与渐变起止点

```python
get_3d_vmob_start_corner(vmob: VMobject) -> Point3D
get_3d_vmob_end_corner(vmob: VMobject) -> Point3D
get_3d_vmob_gradient_start_and_end_points(vmob: VMobject) -> tuple[Point3D, Point3D]
get_3d_vmob_end_corner_index(vmob: VMobject) -> int
```

四个角点/端点查询函数：首角点（`points` 下标恒为 0）与尾角点（下标 `((len(points)-1)//6)*3`）的坐标、该下标本身，以及渐变起止点（就等于首/尾角点，供 `set_stroke`/`set_fill` 渐变用）。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `vmob` | `VMobject` | 必填 | 要查询的三维矢量面片（单个面，不是 `VGroup` 外壳） |

> **返回**：坐标类返回 `Point3D`（`np.ndarray`）；`get_3d_vmob_end_corner_index` 返回 `int` 下标；空 `vmob` 时角点函数返回 `ORIGIN`。另有 `get_3d_vmob_start_corner_index(vmob) -> Literal[0]`，永远返回 0，见页尾"无法演示"。

#### 样例：首尾角点与法向标记

半透明立方体取一个面片，标出它的首角点（红球）、尾角点（黄球），并打印渐变端点与首/尾法向到控制台。

```python
from real_time_manim import ThreeDScene, Cube, Dot3D, Arrow3D, Text, \
    GREEN, GREY_B, RED, YELLOW, UP, DOWN, DEGREES, \
    get_3d_vmob_start_corner, get_3d_vmob_end_corner, \
    get_3d_vmob_end_corner_index, \
    get_3d_vmob_gradient_start_and_end_points, \
    get_3d_vmob_start_corner_unit_normal, get_3d_vmob_end_corner_unit_normal
from real_time_manim.vulkan_bind import MLWindow, Wait

class CornersDemo(ThreeDScene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        self.play = win.play   #move_camera 内部会调 self.play，先接到窗口上
        title = Text("04-corners", font_size=34, color=YELLOW).to_edge(UP)   #样例标题
        self.add_fixed_in_frame_mobjects(title)   #标题钉在屏幕上
        cube = Cube(side_length=2, fill_opacity=0.35, stroke_width=3)   #半透明立方体
        face = cube[0]   #取一个面片（单个 VMobject，这些函数对它才有意义）
        p0 = get_3d_vmob_start_corner(face)   #首角点坐标（下标恒为 0）
        p1 = get_3d_vmob_end_corner(face)   #尾角点坐标
        g0, g1 = get_3d_vmob_gradient_start_and_end_points(face)   #渐变起止点 = 首/尾角点
        n0 = get_3d_vmob_start_corner_unit_normal(face)   #首角点单位法向量
        n1 = get_3d_vmob_end_corner_unit_normal(face)   #尾角点单位法向量
        print("start:", p0, " end idx:", get_3d_vmob_end_corner_index(face), "->", p1)   #控制台输出查询结果
        print("gradient:", g0, g1)   #渐变起止点就是首/尾角点
        print("normals:", n0, n1)   #首/尾角点的单位法向量
        d0 = Dot3D(p0, radius=0.09, color=RED)   #红色小球标出首角点
        d1 = Dot3D(p1, radius=0.09, color=YELLOW)   #黄色小球标出尾角点
        a0 = Arrow3D(p0, p0 + 0.8 * n0, color=GREEN, thickness=0.05)   #首角点法向箭头
        a1 = Arrow3D(p1, p1 + 0.8 * n1, color=GREEN, thickness=0.05)   #尾角点法向箭头
        tag = Text("corners(red/yellow) normals(green)", font_size=24, color=GREY_B).to_edge(DOWN)
        self.add(cube, d0, d1, a0, a1, tag)   #把立方体、角点标记和法向箭头放进场景
        self.set_camera_orientation(phi=65 * DEGREES, theta=-45 * DEGREES)   #摆好斜视角
        win.play(Wait(0.8))   #停 0.8s 看清标记
        self.move_camera(theta=-135 * DEGREES, run_time=1.2)   #带动画环绕 90°
        win.play(Wait(0.4))   #停 0.4s 收工
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：搭一个半透明立方体，`cube[0]` 取它的第一个面片（单个 `VMobject`），查出首角点 `p0`、尾角点 `p1`、渐变起止点和首/尾单位法向并打印到控制台。

画面上用红球标首角点、黄球标尾角点，从两个角点各沿法向引一根绿箭头。环绕 90° 时能看到两根法向箭头始终垂直于面片朝外——这就是"面片局部法向"的直观含义。

<video src="assets/RTM output/04-三维工具函数-corners.mp4" controls width="560"></video>

> 提醒：
>
> - 控制台输出里 `end idx: 6`——尾角点下标是按 `points` 数组算的（`((len-1)//6)*3`），不是面片顶点序号，别拿它当 `faces[6]` 用。
> - 渐变起止点返回的两个坐标与首/尾角点完全相同（`g0 == p0`），它是给"沿首尾方向做渐变着色"这类接口准备的便捷入口。

## 单位法向量查询

```python
get_3d_vmob_unit_normal(vmob: VMobject, point_index: int) -> Vector3D
get_3d_vmob_start_corner_unit_normal(vmob: VMobject) -> Vector3D
get_3d_vmob_end_corner_unit_normal(vmob: VMobject) -> Vector3D
```

按锚点下标查任意位置的单位法向量；首/尾两个封装版等价于固定传 0 / 尾角点下标。法向来自面片该处的三维着色法线，空 `vmob` 时退回 `UP`。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `vmob` | `VMobject` | 必填 | 要查询的单个三维面片 |
| `point_index` | `int` | 必填（仅 `get_3d_vmob_unit_normal`） | 锚点在 `points` 数组里的下标 |

> **返回**：`Vector3D`（单位方向向量 `np.ndarray`）。

#### 样例：`get_3d_vmob_unit_normal`按锚点取法向

取立方体侧面的首 / 中 / 尾三个锚点，各画一根垂直于面片的绿色法向箭头。

```python
from real_time_manim import ThreeDScene, Cube, VGroup, Arrow3D, Text, \
    GREEN, GREY_B, YELLOW, UP, DOWN, DEGREES, \
    get_3d_vmob_end_corner_index, get_3d_vmob_unit_normal
from real_time_manim.vulkan_bind import MLWindow, Wait

class FaceNormalsDemo(ThreeDScene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        self.play = win.play   #move_camera 内部会调 self.play，先接到窗口上
        title = Text("04-face_normals", font_size=34, color=YELLOW).to_edge(UP)   #样例标题
        self.add_fixed_in_frame_mobjects(title)   #标题钉在屏幕上
        face = Cube(side_length=2)[1]   #换一个面片（侧面）来采样多个锚点
        end_idx = get_3d_vmob_end_corner_index(face)   #尾角点在 points 里的下标
        idxs = [0, end_idx // 2, end_idx]   #首 / 中 / 尾三个锚点
        arrows = VGroup()
        for i in idxs:   #在每个锚点处画一根法向箭头
            p = face.points[i]   #锚点坐标
            n = get_3d_vmob_unit_normal(face, i)   #按锚点下标查单位法向量
            arrows.add(Arrow3D(p, p + 0.7 * n, color=GREEN, thickness=0.05))
        tag = Text("normals at idx 0 / %d / %d" % (end_idx // 2, end_idx),   #把三个下标打进标签
                   font_size=24, color=GREY_B).to_edge(DOWN)
        self.add(face, arrows, tag)   #把这个面片和三根箭头放进场景（不用带整只立方体）
        self.set_camera_orientation(phi=65 * DEGREES, theta=-45 * DEGREES)   #摆好斜视角
        win.play(Wait(0.8))   #停 0.8s 看清三根法向箭头
        self.move_camera(theta=-120 * DEGREES, run_time=1.2)   #带动画环绕 90°
        win.play(Wait(0.4))   #停 0.4s 收工
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：只取立方体的一个侧面（不带整只立方体），用 `get_3d_vmob_end_corner_index` 算出尾角点下标，再取首 / 中 / 尾三个锚点，逐个查单位法向并画绿箭头，标签里打出三个下标号。三根箭头都垂直于同一个平面、方向一致，环绕 90° 转到侧面时能确认它们确实"长在面片上"跟着转。

<video src="assets/RTM output/04-三维工具函数-face_normals.mp4" controls width="560"></video>

> 提醒：
>
> - `face.points[i]` 的下标和 `get_3d_vmob_unit_normal` 的 `point_index` 是同一套 `points` 数组下标；越界或传奇数下标（贝塞尔控制点）得到的法向可能没有几何意义。
> - 同一平面片上首/中/尾的法向几乎相同（平面法线恒定），要看法向变化得用曲面片。

无法演示：

- `get_3d_vmob_start_corner_index(vmob) -> Literal[0]`——实现上恒返回 `0`，无参数可调、无画面可变化，控制台里也只是一行 0，不值当出视频。
- 这组函数全部是纯计算（输入 `VMobject`、返回 `ndarray`），画面里的红黄球与绿箭头是把返回值画出来的结果，函数本身不参与渲染。
- 对 `Cube`、`Sphere` 整体这类 `VGroup` 外壳直接调用会退化：`VGroup` 没有自己的 `points`，角点算回 `ORIGIN`、法向算回 `UP`——必须像样例那样先取 `cube[i]` 单个面片。
