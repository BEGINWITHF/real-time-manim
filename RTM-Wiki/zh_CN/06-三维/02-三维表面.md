# 三维表面：Surface、Sphere、Torus

`Surface` 是参数化曲面的通用入口，`Sphere` / `Torus`（以及 [Cone / Cylinder](01b-三维基本体进阶.md)）都是它的子类。本页所有 `Surface` 子类换色都要**构造后 `.set_color(...)`**——`color=` 构造参数会被上游吞掉不生效（详见各小节提醒）。

## Surface

```python
Surface(func: Callable[[float, float], np.ndarray], u_range: tuple[float, float] = (0, 1), v_range: tuple[float, float] = (0, 1), resolution: int | Sequence[int] = 32, surface_piece_config: dict = {}, fill_color: ParsableManimColor = BLUE_D, fill_opacity: float = 1.0, checkerboard_colors: Iterable[ParsableManimColor] | Literal[False] = [BLUE_D, BLUE_E], stroke_color: ParsableManimColor = LIGHT_GREY, stroke_width: float = 0.5, should_make_jagged: bool = False, pre_function_handle_to_anchor_scale_factor: float = 0.00001, **kwargs)
```

用 `func(u, v) -> (x, y, z)` 定义曲面，按棋盘格切成 `resolution` 份面片；配坐标轴时通常写 `lambda u, v: axes.c2p(...)`。

上色常用两个方法：`set_fill_by_checkerboard(*colors, opacity=None)` 按 `(u_index + v_index) % n` 轮流上色，`set_fill_by_value` 按坐标值上渐变色。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `func` | `Callable[[float,float], np.ndarray]` | 必填 | 参数方程，返回 3 维坐标 |
| `u_range` | `tuple[float,float]` | `(0, 1)` | u 的取值区间 |
| `v_range` | `tuple[float,float]` | `(0, 1)` | v 的取值区间 |
| `resolution` | `int \| Sequence[int]` | `32` | int 同时给 u/v；传 `(u_res, v_res)` 分别指定；**不建议**开大——面片数按 `u_res × v_res` 涨，渲染时长跟着涨 |
| `surface_piece_config` | `dict` | `{}` | 每片面片的额外配置 |
| `fill_color` | `ParsableManimColor` | `BLUE_D` | 面片填充色（被 `checkerboard_colors` 覆盖，想用它得先把棋盘格关掉） |
| `fill_opacity` | `float` | `1.0` | 不透明度 |
| `checkerboard_colors` | `Iterable[...] \| False` | `[BLUE_D, BLUE_E]` | 棋盘格交替色；传 `False` 关闭棋盘格 |
| `stroke_color` | `ParsableManimColor` | `LIGHT_GREY` | 每个面片的描边色 |
| `stroke_width` | `float` | `0.5` | 描边宽度 |
| `should_make_jagged` | `bool` | `False` | 把贝塞尔锚点从平滑改成折线（锯齿感） |
| `pre_function_handle_to_anchor_scale_factor` | `float` | `0.00001` | 采样锚点缩放系数（一般不动） |
| `**kwargs` | `Any` | — | 透传给 `VGroup`；`color=` 在这里被吞掉（见提醒） |

#### 样例：`Surface`改动

一条螺旋坡道的参数方程曲面，默认蓝棋盘格；中途 `set_fill_by_checkerboard` 原地换成绿黄配色，再环绕 90°。

```python
import numpy as np

from real_time_manim import ThreeDScene, Surface, Text, \
    GREEN, GREY_B, YELLOW, TAU, UP, DOWN, DEGREES
from real_time_manim.vulkan_bind import MLWindow, Wait

class SurfaceDemo(ThreeDScene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        self.play = win.play   #move_camera 内部会调 self.play，先接到窗口上
        title = Text("02-surface", font_size=34, color=YELLOW).to_edge(UP)   #样例标题
        self.add_fixed_in_frame_mobjects(title)   #标题钉在屏幕上
        surf = Surface(lambda u, v: [v * np.cos(u), v * np.sin(u), u * 0.5],   #螺旋坡道的参数方程
                       u_range=(0, TAU), v_range=(0.3, 1.8),   #u 转一整圈、v 取内外半径
                       resolution=(16, 8))   #低分辨率：控渲染时长，面片也看得清
        self.add(surf)   #把曲面放进场景
        self.set_camera_orientation(phi=60 * DEGREES, theta=-60 * DEGREES)   #摆好斜视角
        win.play(Wait(0.8))   #停 0.8s 看清默认蓝棋盘格
        surf.set_fill_by_checkerboard([GREEN, YELLOW], opacity=0.85)   #方法：原地换棋盘格配色
        win.play(Wait(0.6))   #停 0.6s 看换色效果
        self.move_camera(theta=-150 * DEGREES, run_time=1.2)   #带动画环绕 90°
        win.play(Wait(0.4))   #停 0.4s 收工
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：用 `lambda u, v` 定义一条螺旋坡道——`u` 转一整圈决定方位角、高度按 `u * 0.5` 上升，`v` 决定从内半径 0.3 到外半径 1.8 的"辐条"长度。按 `resolution=(16, 8)` 切成低分辨率面片，面片分块看得清、渲染也快。

先停 0.8 秒展示默认蓝棋盘格，然后 `set_fill_by_checkerboard([GREEN, YELLOW], opacity=0.85)` 原地换成绿黄交替配色，最后环绕 90° 看螺旋的立体形状。

<video src="assets/RTM output/02-三维表面-surface.mp4" controls width="560"></video>

> 提醒：
>
> - `resolution` 是渲染时长的第一杠杆：面片数 = `u_res × v_res`，每片都是独立多边形。示例性曲面 `(16, 8)`（128 片）足够看清结构；默认 `32`（1024 片）会明显变慢。
> - **不要**指望 `Surface(..., color=...)` 换色：`Mobject.__init__` 先应用 `color=`、之后才生成棋盘格面片，颜色被覆盖（上游行为，两引擎一致）；换色用 `set_fill_by_checkerboard(...)` 或 `.set_fill(...)`。

### set_fill_by_value 参数

按坐标值给面上色（渐变），样例未演示（需配 `ThreeDAxes` 反算数据坐标，属进阶用法）：

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `axes` | `ThreeDAxes` | 必填 | 用于把点坐标反算回数据坐标 |
| `colorscale` | `Iterable[颜色] \| Iterable[(颜色, 枢轴值)] \| None` | `None` | 配色；元组形式可自定义枢轴 |
| `axis` | `int` | `2` | 用哪条轴的值上色：0=x，1=y，2=z |
| `colors` | （`**kwargs` 别名） | - | 等价于 `colorscale`，二者只能给一个 |

## Sphere

```python
Sphere(center: Point3DLike = ORIGIN, radius: float = 1, resolution: int | Sequence[int] | None = None, u_range: tuple[float, float] = (0, TAU), v_range: tuple[float, float] = (0, PI), **kwargs)
```

标准球面；改 `u_range`（方位角）/ `v_range`（极角）可裁出球冠、半球等部分球面。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `center` | `Point3DLike` | `ORIGIN` | 球心 |
| `radius` | `float` | `1` | 半径 |
| `resolution` | `int \| Sequence[int] \| None` | `None` → cairo `(24, 12)` | 采样分辨率；同 `Surface`，**不建议**开大 |
| `u_range` | `tuple[float,float]` | `(0, TAU)` | 方位角范围 |
| `v_range` | `tuple[float,float]` | `(0, PI)` | 极角范围（0 = 北极方向）；`v_range=(0, PI/2)` 裁出上半球 |
| `**kwargs` | `Any` | — | 透传给 `Surface`；`color=` 不生效，换色用 `.set_color(...)`（`Dot3D` 内部就是这么做的） |

#### 样例：`Sphere`改动

完整球面 vs `v_range=(0, PI/2)` 裁出的上半球（球冠），环绕 90° 看清裁剪边界。

```python
from real_time_manim import ThreeDScene, Sphere, Text, \
    GREY_B, RED, YELLOW, PI, UP, DOWN, LEFT, RIGHT, DEGREES
from real_time_manim.vulkan_bind import MLWindow, Wait

class SphereDemo(ThreeDScene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        self.play = win.play   #move_camera 内部会调 self.play，先接到窗口上
        title = Text("02-sphere", font_size=34, color=YELLOW).to_edge(UP)   #样例标题
        self.add_fixed_in_frame_mobjects(title)   #标题钉在屏幕上
        full = Sphere(radius=1, resolution=(24, 12))   #完整球面：u 全圈、v 从北极到南极
        full.shift(LEFT * 2.5)   #摆在左侧
        half = Sphere(radius=1, resolution=(24, 12), v_range=(0, PI / 2))   #v_range 裁出上半球
        half.set_color(RED)   #换色：Surface 子类的 “color=” 参数不生效，要构造后 set_color
        half.shift(RIGHT * 2.5)   #摆在右侧
        tag1 = Text("v_range=(0,PI)", font_size=24, color=GREY_B).next_to(full, DOWN)   #左下角标注
        tag2 = Text("v_range=(0,PI/2)", font_size=24, color=GREY_B).next_to(half, DOWN)   #右下角标注
        self.add(full, half, tag1, tag2)   #把两个球面和标签放进场景
        self.set_camera_orientation(phi=65 * DEGREES, theta=-45 * DEGREES)   #摆好斜视角
        win.play(Wait(0.8))   #停 0.8s 看清球冠形状
        self.move_camera(theta=-135 * DEGREES, run_time=1.2)   #带动画环绕 90°
        win.play(Wait(0.4))   #停 0.4s 收工
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：左边放一个完整球面（`v_range` 默认 `(0, PI)`，从北极到南极一整圈）；右边那个只把 `v_range` 收成 `(0, PI/2)`——极角只走到赤道，生成的就是红色上半球（球冠），底部敞口能隐约看到球内。环绕 90° 时裁剪边界（赤道圈）清晰可见。

<video src="assets/RTM output/02-三维表面-sphere.mp4" controls width="560"></video>

> 提醒：`v_range` 的 0 是**北极**方向；`(0, PI/2)` 是上半球，`(PI/2, PI)` 是下半球。`Sphere(..., color=RED)` 不生效（`color=` 被上游吞掉，两引擎一致）——要构造后 `.set_color(RED)`，`Dot3D` 内部就是这么干的。

## Torus

```python
Torus(major_radius: float = 3, minor_radius: float = 1, u_range: tuple[float, float] = (0, TAU), v_range: tuple[float, float] = (0, TAU), resolution: int | tuple[int, int] | None = None, **kwargs)
```

救生圈形状的圆环面；`major_radius` 是环半径，`minor_radius` 是管半径。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `major_radius` | `float` | `3` | 大半径（环半径） |
| `minor_radius` | `float` | `1` | 小半径（管半径） |
| `u_range` | `tuple[float,float]` | `(0, TAU)` | 绕环方向的角度范围（裁一段可得"弯管"） |
| `v_range` | `tuple[float,float]` | `(0, TAU)` | 绕管方向的角度范围（裁一半可得半环管） |
| `resolution` | `int \| tuple[int,int] \| None` | `None` → cairo `(24, 24)` | 采样分辨率；同 `Surface`，**不建议**开大 |
| `**kwargs` | `Any` | — | 透传给 `Surface`；`color=` 不生效，换色用 `.set_color(...)` |

#### 样例：`Torus`改动

整环 vs `v_range=(0, PI)` 裁出的半环管（沿管截面剖开一半），环绕 90° 看清剖面。

```python
from real_time_manim import ThreeDScene, Torus, Text, \
    GREEN, GREY_B, YELLOW, PI, UP, DOWN, LEFT, RIGHT, DEGREES
from real_time_manim.vulkan_bind import MLWindow, Wait

class TorusDemo(ThreeDScene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        self.play = win.play   #move_camera 内部会调 self.play，先接到窗口上
        title = Text("02-torus", font_size=34, color=YELLOW).to_edge(UP)   #样例标题
        self.add_fixed_in_frame_mobjects(title)   #标题钉在屏幕上
        full = Torus(major_radius=1.6, minor_radius=0.5)   #默认整环：环半径 1.6、管半径 0.5
        full.shift(LEFT * 2.5)   #摆在左侧
        half = Torus(major_radius=1.6, minor_radius=0.5, v_range=(0, PI))   #v_range 裁出半环管
        half.set_color(GREEN)   #换色：Surface 子类的 “color=” 参数不生效，要构造后 set_color
        half.shift(RIGHT * 2.5)   #摆在右侧
        tag1 = Text("full ring", font_size=24, color=GREY_B).next_to(full, DOWN)   #左下角标注
        tag2 = Text("v_range=(0,PI)", font_size=24, color=GREY_B).next_to(half, DOWN)   #右下角标注
        self.add(full, half, tag1, tag2)   #把两个圆环面和标签放进场景
        self.set_camera_orientation(phi=60 * DEGREES, theta=-45 * DEGREES)   #摆好斜视角
        win.play(Wait(0.8))   #停 0.8s 看清半环管的剖面
        self.move_camera(theta=-135 * DEGREES, run_time=1.2)   #带动画环绕 90°
        win.play(Wait(0.4))   #停 0.4s 收工
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：左边是缩小后的完整圆环面（环半径 1.6、管半径 0.5）；右边那个 `v_range=(0, PI)` 把绕管方向的角度砍掉一半，绿色的管子沿纵剖面敞开，能看到管壁截面。环绕 90° 转到侧面时两个形状的差异一目了然。

<video src="assets/RTM output/02-三维表面-torus.mp4" controls width="560"></video>

> 提醒：
>
> - `Torus` 的 `u` 是绕环方向、`v` 是绕管方向：裁 `u_range` 得到"弯了一段的管子"，裁 `v_range` 得到"剖开的管子"，别裁反。
> - 默认 `major_radius=3` 比画面还宽，实际用时先按场景缩小。
> - 换色同 `Sphere`：`.set_color(...)` 才有效。

## 深度网格：`MeshBatch`（高级）

`Surface` 的每个面片默认按 painter 顺序绘制。曲面叠到自己、边缘穿过面时，顺序不够用，可以用 `MeshBatch` 把四边形交给 GPU 深度缓冲。

```python
import numpy as np

from real_time_manim import DEGREES, MeshBatch, ThreeDScene
from real_time_manim.vulkan_bind import MLWindow, Wait

class MeshDemo(ThreeDScene):
    def construct(self):
        win = MLWindow(960, 540)   # 创建一个 RTM 窗口
        win.scene = self
        self.set_camera_orientation(phi=58 * DEGREES, theta=0)

        quads = np.array([
            [[-1.5, -1.5, -0.6], [1.5, -1.5, -0.6],
             [1.5, 1.5, -0.6], [-1.5, 1.5, -0.6]],
            [[-0.8, -0.8, 0.6], [0.8, -0.8, 0.6],
             [0.8, 0.8, 0.6], [-0.8, 0.8, 0.6]],
        ], dtype=float)                              # (Q, 4, 3)，世界坐标
        colors = np.array([
            [[0.2, 0.4, 1.0, 1.0]] * 4,
            [[1.0, 0.5, 0.1, 1.0]] * 4,
        ], dtype=np.float32)                         # (Q, 4, 4)，RGBA

        mesh = MeshBatch()
        mesh.append(quads, colors)
        win.set_mesh(mesh)                           # 每帧自动提交
        win.play(Wait(0.8))
        win.close()
```

这块橙色的四边形在 `z = 0.6`，蓝色的在 `z = -0.6`，深度测试会让橙色正确挡住蓝色。换成 `Surface` 时，把每个面片的四个角点放进 `quads` 即可。

### `MeshBatch`

| 成员 | 说明 |
| --- | --- |
| `MeshBatch()` | 空批次 |
| `append(quads, colors)` | 追加四边形；返回自身 |
| `quads` | `(Q, 4, 3)` float，四个角点的世界坐标 |
| `colors` | `(Q, 4, 4)` float，每个角点的 RGBA，范围 0–1 |
| `build_vertices(viewport, width, height)` | 窗口每帧调用，把世界坐标投影成 NDC + 深度；一般不用手动调 |

挂到窗口：

| 方法 | 说明 |
| --- | --- |
| `win.set_mesh(mesh)` | 提交这一帧的网格；`None` 等同于 `clear_mesh()` |
| `win.clear_mesh()` | 摘掉网格，回到纯 painter |

### 限制

- 只接受四边形；三角形请拆成退化四边形，或直接用 `Surface` 的 `MeshBatch` 自动路径。
- 单批上限 `MAX_MESH_VERTS = 262144` 个顶点，约 43690 个四边形。
- `append` 是追加；`win.set_mesh` 每帧提交当前批次，重复调用不会叠加。
- mesh 先画、2D 后画，所以文字、公式、图片永远盖在 mesh 上。
- 半透明交叠仍是近似，没有逐像素排序。
- 相机旋转时每帧在 CPU 重新投影，面数很大时有成本。

### 自动深度（实验性）

RTM 2.0.3 起，符合条件的 `Surface` 可以自动走深度缓冲，不需要手写 `MeshBatch`：

```powershell
$env:RTM_AUTO_DEPTH = "1"
```

条件：3D 相机、顶层 `Surface`、面片不透明、`shade_in_3d=False`、描边与填充同色、画面里没有其他受光 3D 几何。

它解决的是遮挡，不解决逐面 `set_fill` / `set_stroke` 的 Python 开销。面数很大时，逐面改色仍然会慢；需要速度就把颜色更新改成一次数组写入，或使用 `MeshBatch`。
