# 三维基本体（二）：线段、箭头与旋转体

接上页，本页收录带厚度的三维线段 `Line3D`、三维箭头 `Arrow3D`，以及由旋转面生成的 `Cone` / `Cylinder` 两个旋转体。

## Line3D

```python
Line3D(start: Point3DLike = LEFT, end: Point3DLike = RIGHT, thickness: float = 0.02, color: ParsableManimColor | None = None, resolution: int | tuple[int, int] = 24, **kwargs)
```

一段有粗细的圆柱体，用作三维空间中的"线"；`Arrow3D` 是它的子类。类方法 `Line3D.parallel_to(line, point=ORIGIN, length=5)` / `Line3D.perpendicular_to(line, point=ORIGIN, length=5)` 可生成平行/垂直线段。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `start` | `Point3DLike` 或 `Mobject` | `LEFT` | 起点；**能填** `[x, y, z]` 或另一个 mobject（自动取它的中心） |
| `end` | `Point3DLike` 或 `Mobject` | `RIGHT` | 终点 |
| `thickness` | `float` | `0.02` | 圆柱半径（线条粗细）；**能填**任意正数，样例用 `0.06` 放大好观察 |
| `color` | `ParsableManimColor \| None` | `None` | 颜色；`None` 沿用默认白色 |
| `resolution` | `int \| tuple[int,int]` | `24` | int 为采样点数；传 `(u, v)` 同时控制棋盘格数 |
| `**kwargs` | `Any` | — | 透传给 `Cylinder`（`stroke_width`、`fill_opacity`…） |

#### 样例：`Line3D`改动

一条加粗的黄色主线段用 `Create` 逐段画出，两条参照线段分别用 `parallel_to` / `perpendicular_to` 类方法生成，环绕 90° 看清空间关系。

```python
from real_time_manim import ThreeDScene, Line3D, Text, \
    GREY_B, YELLOW, UP, DOWN, DEGREES, Create
from real_time_manim.vulkan_bind import MLWindow, Wait

class Line3DDemo(ThreeDScene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        self.play = win.play   #move_camera 内部会调 self.play，先接到窗口上（本样例的 Create 走 win.play，不需要接线）
        title = Text("01b-line3d", font_size=34, color=YELLOW).to_edge(UP)   #样例标题
        self.add_fixed_in_frame_mobjects(title)   #标题钉在屏幕上
        line = Line3D(start=[-2, -1, 0], end=[2, 1, 1.5], thickness=0.06, color=YELLOW)   #加粗的黄色主线段
        para = Line3D.parallel_to(line, point=[-1, -2.5, 0], length=4)   #过指定点、与主线段平行的线段
        perp = Line3D.perpendicular_to(line, point=[2, -2, 0.75], length=3)   #过指定点、与主线段垂直的线段
        self.add(para, perp)   #先把两条参照线段放进场景
        self.set_camera_orientation(phi=65 * DEGREES, theta=-45 * DEGREES)   #摆好斜视角
        win.play(Create(line), run_time=0.8)   #把主线段逐段画出来
        win.play(Wait(0.5))   #停 0.5s 看清平行/垂直关系
        self.move_camera(theta=-135 * DEGREES, run_time=1.2)   #带动画环绕 90°
        win.play(Wait(0.4))   #停 0.4s 收工
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：先放好两条参照线段——一条用 `Line3D.parallel_to(主线段, point=..., length=4)` 生成（过指定点且与主线段平行），一条用 `perpendicular_to` 生成（互相垂直）。然后 `Create` 把黄色主线段从起点到终点逐段画出来，停 0.5 秒后环绕 90°，从侧面确认三条线段的平行/垂直关系在三维空间里成立。

<video src="assets/RTM output/01b-三维基本体进阶-line3d.mp4" controls width="560"></video>

> 提醒：`Create` 在 RTM 里可用（`Line3D` 支持逐段绘制）。**2026-10-17 实测**：本样例里真正需要 `self.play = win.play` 接线的只有 `move_camera`（它内部会调 `self.play`，不接线环绕就不动）；`Create` 是直接 `win.play(Create(...))` 播的，不经过 `Scene.play`，不接线也能画。默认 `thickness=0.02` 很细，视频里放大到 0.06 才看得清。

## Arrow3D

```python
Arrow3D(start: Point3DLike = LEFT, end: Point3DLike = RIGHT, thickness: float = 0.02, height: float = 0.3, base_radius: float = 0.08, color: ParsableManimColor = WHITE, resolution: int | tuple[int, int] = 24, **kwargs)
```

圆柱杆 + 圆锥箭头组成的三维箭头（`Line3D` 子类），用于坐标轴向量、力/速度方向；`get_end()` 返回箭尖坐标。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `start` | `Point3DLike` | `LEFT` | 起点 |
| `end` | `Point3DLike` | `RIGHT` | 终点（箭头尖端位置） |
| `thickness` | `float` | `0.02` | 杆的半径 |
| `height` | `float` | `0.3` | 箭头圆锥高度；**能填**任意正数 |
| `base_radius` | `float` | `0.08` | 箭头圆锥底面半径 |
| `color` | `ParsableManimColor` | `WHITE` | 整体颜色 |
| `resolution` | `int \| tuple[int,int]` | `24` | 杆的采样数 |
| `**kwargs` | `Any` | — | 透传给 `Line3D`/`Cone` |

#### 样例：`Arrow3D`改动

默认白色箭头对照一个"大箭头锥"的红色箭头（`height=0.6`、`base_radius=0.18`），`get_end()` 读出箭尖坐标做成跟随标注。

```python
from real_time_manim import ThreeDScene, Arrow3D, Text, \
    GREY_B, RED, YELLOW, UP, UR, DEGREES
from real_time_manim.vulkan_bind import MLWindow, Wait

class Arrow3DDemo(ThreeDScene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        self.play = win.play   #move_camera 内部会调 self.play，先接到窗口上
        title = Text("01b-arrow3d", font_size=34, color=YELLOW).to_edge(UP)   #样例标题
        self.add_fixed_in_frame_mobjects(title)   #标题钉在屏幕上
        a = Arrow3D(start=[-2, -1, 0], end=[1.5, 0.5, 1.5])   #默认白色三维箭头
        b = Arrow3D(start=[0, -2.5, 0], end=[-1.5, -2.5, 2], color=RED,   #红色箭头：箭头锥更大
                    thickness=0.08, height=0.6, base_radius=0.18)
        tip = Text("tip=(%.1f, %.1f, %.1f)" % tuple(a.get_end()),   #把箭尖坐标格式化成标注
                   font_size=24, color=GREY_B).next_to(a.get_end(), UR, buff=0.2)   #摆在箭尖旁边
        self.add_fixed_orientation_mobjects(tip)   #只锁朝向：文字正对镜头但留在 3D 空间
        self.add(a, b, tip)   #把两支箭头和标注放进场景
        print("箭尖坐标：", a.get_end())   #控制台也打一份
        self.set_camera_orientation(phi=65 * DEGREES, theta=-60 * DEGREES)   #摆好斜视角
        win.play(Wait(0.8))   #停 0.8s 看清两支箭头
        self.move_camera(theta=-150 * DEGREES, run_time=1.2)   #带动画环绕 90°
        win.play(Wait(0.4))   #停 0.4s 收工
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：放两支三维箭头——白色那支全用默认参数；红色那支把杆加粗（`thickness=0.08`）、箭头锥加大（`height=0.6`、`base_radius=0.18`），一眼能看出箭头锥是可以单独调的。然后 `a.get_end()` 读出白色箭头的箭尖坐标，格式化成文字标注钉在箭尖旁边（`add_fixed_orientation_mobjects` 只锁朝向，文字始终正对镜头）。环绕 90° 时标注跟着箭尖在画面里移动。

<video src="assets/RTM output/01b-三维基本体进阶-arrow3d.mp4" controls width="560"></video>

> 提醒：`end` 是**箭尖**的位置，不是杆的末端——所以箭头锥会有一小截探出 `end` 之外（锥高 `height` 的部分）。想要"从 A 指到 B"就把 `end` 直接填 B 的坐标。

## Cone

```python
Cone(base_radius: float = 1, height: float = 1, direction: Vector3DLike = Z_AXIS, show_base: bool = False, v_range: tuple[float, float] = (0, TAU), u_min: float = 0, checkerboard_colors: Iterable[ParsableManimColor] | Literal[False] = False, **kwargs)
```

由底面半径与高定义的圆锥（`Surface` 子类），锥顶沿 `direction` 方向；`set_direction()` 改朝向，`get_start()/get_end()` 取底心/锥顶。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `base_radius` | `float` | `1` | 底面半径；**能填**任意正数 |
| `height` | `float` | `1` | 从底面到锥顶的高 |
| `direction` | `Vector3DLike` | `Z_AXIS` | 锥顶朝向（会把圆锥旋转到该方向） |
| `show_base` | `bool` | `False` | 是否绘制底面圆盘；**能填** `True` / `False` |
| `v_range` | `tuple[float,float]` | `(0, TAU)` | 方位角范围，可裁出扇形锥（如 `(0, PI)` 半圈） |
| `u_min` | `float` | `0` | 顶点处的半径（>0 得到"截顶"圆台） |
| `checkerboard_colors` | `Iterable[...] \| False` | `False` | 棋盘格配色；`False` 表示用纯色 |
| `**kwargs` | `Any` | — | 透传给 `Surface`（`fill_color`、`resolution`…） |

#### 样例：`Cone`改动

左边标准圆锥加底面圆盘（`show_base=True`），右边演示 `u_min=0.5` 截顶 + `v_range=(0, PI)` 只留半圈的扇形锥。

```python
from real_time_manim import ThreeDScene, Cone, Text, \
    GREEN, GREY_B, YELLOW, PI, UP, DOWN, LEFT, RIGHT, DEGREES
from real_time_manim.vulkan_bind import MLWindow, Wait

class ConeDemo(ThreeDScene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        self.play = win.play   #move_camera 内部会调 self.play，先接到窗口上
        title = Text("01b-cone", font_size=34, color=YELLOW).to_edge(UP)   #样例标题
        self.add_fixed_in_frame_mobjects(title)   #标题钉在屏幕上
        a = Cone(base_radius=1, height=2, show_base=True)   #带底面圆盘的标准圆锥
        a.shift(LEFT * 2.5)   #摆在左侧
        b = Cone(base_radius=1, height=2, u_min=0.5, v_range=(0, PI))   #截顶 + 只留半圈的扇形锥
        b.set_color(GREEN)   #换色：Surface 子类的 “color=” 参数不生效，要构造后 set_color
        b.shift(RIGHT * 2.5)   #摆在右侧
        tag1 = Text("show_base=True", font_size=24, color=GREY_B).next_to(a, DOWN)   #左下角标注
        tag2 = Text("u_min=0.5 v_range=(0,PI)", font_size=24, color=GREY_B).next_to(b, DOWN)   #右下角标注
        self.add(a, b, tag1, tag2)   #把两个圆锥和标签放进场景
        self.set_camera_orientation(phi=65 * DEGREES, theta=-30 * DEGREES)   #摆好斜视角
        win.play(Wait(0.8))   #停 0.8s 看清形态差异
        self.move_camera(theta=-120 * DEGREES, run_time=1.2)   #带动画环绕 90°
        win.play(Wait(0.4))   #停 0.4s 收工
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：左边放一个 `show_base=True` 的标准圆锥（底部多了一块圆盘封口）；右边那个同时改了三处——`u_min=0.5` 把锥顶削平（变成圆台）、`v_range=(0, PI)` 只生成半圈方位角（变成"剖开的半个锥面"）、再用 `.set_color(GREEN)` 换成绿色（`color=` 参数不生效，见下方提醒）。环绕 90° 转到侧面时能看到剖开的截面和削平的顶。

<video src="assets/RTM output/01b-三维基本体进阶-cone.mp4" controls width="560"></video>

> 提醒：`u_min > 0` 会把圆锥从尖顶削成圆台（顶端是个半径 `u_min` 的圆孔）；`v_range` 裁剪后圆锥是"敞开"的，能直接看到内部。`direction` 默认 `Z_AXIS`（锥顶朝上），填 `RIGHT` 就会横过来。换色**不要**写 `Cone(..., color=GREEN)` —— `Surface` 子类在构造时先吞掉 `color=` 再生成面片，颜色不生效（上游行为，两引擎一致）；正确写法是构造后 `.set_color(...)`（如样例），或传 `checkerboard_colors=False, fill_color=...`。

## Cylinder

```python
Cylinder(radius: float = 1, height: float = 2, direction: Vector3DLike = Z_AXIS, v_range: tuple[float, float] = (0, TAU), show_ends: bool = True, resolution: int | tuple[int, int] = (24, 24), **kwargs)
```

以 `direction` 为中轴的圆柱（`Surface` 子类），默认带上下底盖，是 `Line3D` 的基类；`set_direction()`、`add_bases()` 常用。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `radius` | `float` | `1` | 半径 |
| `height` | `float` | `2` | 沿中轴的高度 |
| `direction` | `Vector3DLike` | `Z_AXIS` | 中轴方向；**能填** `Z_AXIS`、`RIGHT` 等方向向量 |
| `v_range` | `tuple[float,float]` | `(0, TAU)` | 方位角范围，可做半圆柱（如 `(0, PI)`） |
| `show_ends` | `bool` | `True` | 是否画上下底盖；**能填** `True` / `False` |
| `resolution` | `int \| tuple[int,int]` | `(24, 24)` | 采样分辨率 |
| `**kwargs` | `Any` | — | 透传给 `Surface` |

#### 样例：`Cylinder`改动

左边默认圆柱（带上下底盖），右边演示 `show_ends=False` + `v_range=(0, PI)` 半圈筒壁 + `direction=RIGHT` 横放。

```python
from real_time_manim import ThreeDScene, Cylinder, Text, \
    GREY_B, RED, YELLOW, PI, UP, DOWN, LEFT, RIGHT, DEGREES
from real_time_manim.vulkan_bind import MLWindow, Wait

class CylinderDemo(ThreeDScene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        self.play = win.play   #move_camera 内部会调 self.play，先接到窗口上
        title = Text("01b-cylinder", font_size=34, color=YELLOW).to_edge(UP)   #样例标题
        self.add_fixed_in_frame_mobjects(title)   #标题钉在屏幕上
        a = Cylinder(radius=0.8, height=2.5)   #默认带上下底盖的圆柱
        a.shift(LEFT * 2.5)   #摆在左侧
        b = Cylinder(radius=0.8, height=2.5, show_ends=False, v_range=(0, PI),   #无底盖 + 半圈筒壁
                     direction=RIGHT)   #中轴改为水平
        b.set_color(RED)   #换色：Surface 子类的 “color=” 参数不生效，要构造后 set_color
        b.shift(RIGHT * 2.5 + UP * 0.4)   #摆在右侧、稍微抬高
        tag1 = Text("show_ends=True", font_size=24, color=GREY_B).next_to(a, DOWN)   #左下角标注
        tag2 = Text("half + no ends + direction", font_size=24, color=GREY_B).next_to(b, DOWN)   #右下角标注
        self.add(a, b, tag1, tag2)   #把两个圆柱和标签放进场景
        self.set_camera_orientation(phi=65 * DEGREES, theta=-45 * DEGREES)   #摆好斜视角
        win.play(Wait(0.8))   #停 0.8s 看清形态差异
        self.move_camera(theta=-135 * DEGREES, run_time=1.2)   #带动画环绕 90°
        win.play(Wait(0.4))   #停 0.4s 收工
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：左边是默认参数的圆柱（`show_ends=True`，上下都有盖，是一根实心管）；右边那个改了三处——`show_ends=False` 去掉底盖、`v_range=(0, PI)` 只留半圈筒壁（变成槽状的半圆柱）、`direction=RIGHT` 把中轴从竖直改成水平横放，再用 `.set_color(RED)` 换成红色。环绕 90° 时能从敞开的一侧看到筒壁内部。

<video src="assets/RTM output/01b-三维基本体进阶-cylinder.mp4" controls width="560"></video>

> 提醒：`direction` 改的是**中轴方向**——填 `RIGHT` 后 `height` 是沿 x 轴量的，别再把它当竖直高度用。`Cylinder` 是 `Line3D` 的基类，所以 `Line3D` 的所有参数（`thickness` 实为 `radius`）都继承自这里。换色同 `Cone`：`color=` 参数不生效（被棋盘格面片覆盖，上游行为），要构造后 `.set_color(...)`。
