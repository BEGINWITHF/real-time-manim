# 三维基本体（一）：面片基类与立方体

三维物体要放进 `ThreeDScene` 并设置相机视角（`set_camera_orientation(phi=..., theta=...)`）才能看出立体效果。本页收录三维矢量面片基类 `ThreeDVMobject` 与三个常用基本体 `Cube` / `Prism` / `Dot3D`。

## ThreeDVMobject

```python
ThreeDVMobject(shade_in_3d: bool = True, **kwargs: Any)
```

`VMobject` 的三维变体，是所有三维矢量面片的基类，会被三维光照着色（正面亮、侧面暗的立体感就来自它）。日常直接用它的子类（`Cube` 面片、`Polygon` 三维化等），很少单独构造。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `shade_in_3d` | `bool` | `True` | 是否参与三维光照着色；`False` 时按普通平面着色（六个面亮度一样，立体感消失） |
| `**kwargs` | `Any` | — | 透传给 `VMobject.__init__`（`stroke_width`、`fill_color` 等） |

> **返回**：无（构造实例）。基类不单独出样例视频，光照效果在下面 `Cube` 样例里直接可见（两个立方体的各面亮度不同）。

## Cube

```python
Cube(side_length: float = 2, fill_opacity: float = 0.75, fill_color: ParsableManimColor = BLUE, stroke_width: float = 0, **kwargs)
```

由 6 个 `Square` 面组成的正方体（`VGroup` 子类），默认半透明蓝色、无描边。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `side_length` | `float` | `2` | 边长；**能填**任意正数 |
| `fill_opacity` | `float` | `0.75` | 填充不透明度（0~1）；改小能看到背面的面 |
| `fill_color` | `ParsableManimColor` | `BLUE` | 填充色；**能填**任意颜色常量或 hex |
| `stroke_width` | `float` | `0` | 面的描边宽度；**能填**任意非负数，默认无描边 |
| `**kwargs` | `Any` | — | 透传给 `VGroup`/`Mobject` |

#### 样例：`Cube`改动

默认参数的半透明蓝立方体，对照一个实心绿、描边加粗的小立方体；`move_camera` 环绕 90° 看到另一侧。

```python
from real_time_manim import ThreeDScene, Cube, Text, \
    BLUE, GREEN, GREY_B, YELLOW, UP, DOWN, RIGHT, DEGREES
from real_time_manim.vulkan_bind import MLWindow, Wait

class CubeDemo(ThreeDScene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        self.play = win.play   #move_camera 内部会调 self.play，先接到窗口上
        title = Text("01-cube", font_size=34, color=YELLOW).to_edge(UP)   #样例标题
        self.add_fixed_in_frame_mobjects(title)   #标题钉在屏幕上，视角怎么转都正对观众
        a = Cube(side_length=2, fill_opacity=0.75, fill_color=BLUE)   #默认参数：边长 2、半透明蓝、无描边
        b = Cube(side_length=1.2, fill_color=GREEN, fill_opacity=1.0, stroke_width=6)   #实心绿、描边加粗
        b.next_to(a, RIGHT, buff=1.2)   #摆在默认立方体右边
        tag1 = Text("default", font_size=26, color=GREY_B).next_to(a, DOWN)   #左下角标注
        tag2 = Text("solid + stroke", font_size=26, color=GREY_B).next_to(b, DOWN)   #右下角标注
        self.add(a, b, tag1, tag2)   #把两个立方体和标签放进场景
        self.set_camera_orientation(phi=65 * DEGREES, theta=-45 * DEGREES)   #摆好斜视角
        win.play(Wait(0.8))   #停 0.8s 看清立体效果
        self.move_camera(theta=-135 * DEGREES, run_time=1.4)   #带动画环绕 90°，看到另一侧
        win.play(Wait(0.4))   #停 0.4s 收工
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：先开一个 RTM 窗口、把场景绑上去，并把样例标题钉在屏幕上。然后放两个立方体——左边是默认参数（边长 2、半透明蓝、无描边），右边是改过参数的（边长 1.2、实心绿、描边 6），各配一行地面标注。`set_camera_orientation` 一帧摆到斜视角停 0.8 秒，再 `move_camera` 带动画环绕 90°，能看到立方体的侧面在转动中明暗变化（这就是三维光照着色在起作用）。

<video src="assets/RTM output/01-三维基本体-cube.mp4" controls width="560"></video>

> 提醒：`move_camera` 内部会调 `self.play`，RTM 里必须先写 `self.play = win.play`，否则镜头不动。`Cube` 默认 `fill_opacity=0.75` 半透明，能隐约看到背面的面；想要实心就填 `1.0`。标签是普通 3D 文本（贴在地面上），会跟着视角倾斜，这正是它们处在三维空间里的证据。

## Prism

```python
Prism(dimensions: Vector3DLike = [3, 2, 1], **kwargs)
```

`Cube` 的推广，按 `[x, y, z]` 三边长拉伸得到的长方体。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `dimensions` | `Vector3DLike` | `[3, 2, 1]` | 三边长 `[x, y, z]`；**能填**任意三个正数 |
| `**kwargs` | `Any` | — | 同 `Cube`（`fill_color`、`fill_opacity`、`stroke_width`…） |

#### 样例：`Prism`改动

默认 `[3, 2, 1]` 的扁长方体，对照一个 `[1, 1, 3]` 的瘦高红棱柱，环绕 90° 看清三边比例。

```python
from real_time_manim import ThreeDScene, Prism, Text, \
    GREY_B, RED, YELLOW, UP, DOWN, RIGHT, DEGREES
from real_time_manim.vulkan_bind import MLWindow, Wait

class PrismDemo(ThreeDScene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        self.play = win.play   #move_camera 内部会调 self.play，先接到窗口上
        title = Text("01-prism", font_size=34, color=YELLOW).to_edge(UP)   #样例标题
        self.add_fixed_in_frame_mobjects(title)   #标题钉在屏幕上
        a = Prism(dimensions=[3, 2, 1])   #默认三边长 [x, y, z] = [3, 2, 1]
        b = Prism(dimensions=[1, 1, 3], fill_color=RED, fill_opacity=0.6)   #瘦高的红色棱柱
        b.next_to(a, RIGHT, buff=1.2)   #摆在默认棱柱右边
        tag1 = Text("[3, 2, 1]", font_size=26, color=GREY_B).next_to(a, DOWN)   #左下角标注
        tag2 = Text("[1, 1, 3]", font_size=26, color=GREY_B).next_to(b, DOWN)   #右下角标注
        self.add(a, b, tag1, tag2)   #把两个棱柱和标签放进场景
        self.set_camera_orientation(phi=65 * DEGREES, theta=-60 * DEGREES)   #摆好斜视角
        win.play(Wait(0.8))   #停 0.8s 看清三边长差异
        self.move_camera(theta=-150 * DEGREES, run_time=1.4)   #带动画环绕 90°
        win.play(Wait(0.4))   #停 0.4s 收工
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：放两个棱柱——左边是默认的 `[3, 2, 1]`（宽而扁），右边传 `[1, 1, 3]` 并换成半透明红色（又细又高），地面各有一行边长标注。摆好斜视角停 0.8 秒后环绕 90°，转到侧面时能清楚看到 `[1, 1, 3]` 那根"高柱子"竖在那。

<video src="assets/RTM output/01-三维基本体-prism.mp4" controls width="560"></video>

> 提醒：`Prism` 只是把 `Cube` 按三边缩放，`dimensions` 顺序是 `[x, y, z]`（z 是竖直方向），别写反。填 `[1, 1, 1]` 就是一个边长 1 的 `Cube`。

## Dot3D

```python
Dot3D(point: Point3D = ORIGIN, radius: float = DEFAULT_DOT_RADIUS, color: ParsableManimColor = WHITE, resolution: int | tuple[int, int] | None = (8, 8), **kwargs)
```

`Sphere` 的特化，低分辨率小球，用于三维空间中标记点（等价二维的 `Dot`）。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `point` | `Point3D` | `ORIGIN` | 球心位置；**能填** `[x, y, z]` 或 `UR` 这类方向向量 |
| `radius` | `float` | `DEFAULT_DOT_RADIUS`（0.08） | 半径；**能填**任意正数，样例用 `0.4` / `0.5` 放大好观察 |
| `color` | `ParsableManimColor` | `WHITE` | 颜色 |
| `resolution` | `int \| tuple[int,int] \| None` | `(8, 8)` | u/v 采样数，越大越圆滑越慢；样例用 `(4, 2)` 对比棱角感 |
| `**kwargs` | `Any` | — | 透传给 `Sphere` |

#### 样例：`Dot3D`改动

三个放大的小球：大红球标记一个点，两个绿球分别用极低分辨率 `(4, 2)` 和默认 `(8, 8)` 对比圆滑度。

```python
from real_time_manim import ThreeDScene, Dot3D, Text, \
    GREEN, GREY_B, RED, YELLOW, UP, DOWN, LEFT, RIGHT, UR, DEGREES
from real_time_manim.vulkan_bind import MLWindow, Wait

class Dot3DDemo(ThreeDScene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        self.play = win.play   #move_camera 内部会调 self.play，先接到窗口上
        title = Text("01-dot3d", font_size=34, color=YELLOW).to_edge(UP)   #样例标题
        self.add_fixed_in_frame_mobjects(title)   #标题钉在屏幕上
        big = Dot3D(2 * UR, radius=0.5, color=RED)   #大号红球标记一个三维点
        rough = Dot3D(LEFT * 2.5 + DOWN, radius=0.4, color=GREEN, resolution=(4, 2))   #极低分辨率：棱角分明
        smooth = Dot3D(RIGHT * 2.5 + DOWN, radius=0.4, color=GREEN)   #默认 (8, 8)：圆滑一些
        tag1 = Text("res=(4,2)", font_size=26, color=GREY_B).next_to(rough, DOWN)   #左下角标注
        tag2 = Text("default (8,8)", font_size=26, color=GREY_B).next_to(smooth, DOWN)   #右下角标注
        self.add(big, rough, smooth, tag1, tag2)   #把三个小球和标签放进场景
        self.set_camera_orientation(phi=60 * DEGREES, theta=-45 * DEGREES)   #摆好斜视角
        win.play(Wait(0.8))   #停 0.8s 对比分辨率
        self.move_camera(theta=-135 * DEGREES, run_time=1.4)   #带动画环绕 90°
        win.play(Wait(0.4))   #停 0.4s 收工
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：在三维空间放三个放大的小球——右上方一个大红球（`radius=0.5`）演示按坐标标记点；下方左右各一个绿球，左边用 `resolution=(4, 2)`（面数极少、棱角分明），右边用默认 `(8, 8)`（明显更圆滑）。环绕 90° 时能看到低分辨率球的"多边形棱"和高分辨率球的平滑表面对比。

<video src="assets/RTM output/01-三维基本体-dot3d.mp4" controls width="560"></video>

> 提醒：`Dot3D` 默认 `radius=0.08` 非常小，视频里为了看清才放大到 0.4~0.5；真实标记点时配合场景尺度选半径。`resolution` 越低越省渲染时间，标记用途够用就行。
