# 多面体：Polyhedron 家族与凸包

所有多面体都继承 `Polyhedron`（`VGroup`）：内部是 `.faces` 面片，加上顶点为 `Dot3D` 的 `.graph`，两者靠 updater 联动——拖动 `polyhedron.graph[v]` 顶点，整个立体跟着形变。

本页收录自定义多面体 `Polyhedron`、四种柏拉图立体 `Tetrahedron` / `Octahedron` / `Icosahedron` / `Dodecahedron`，以及自动求凸包的 `ConvexHull3D`。

## Polyhedron

```python
Polyhedron(vertex_coords: Point3DLike_Array, faces_list: list[list[int]], faces_config: dict[str, str | int | float | bool] = {}, graph_config: dict[str, Any] = {})
```

按"顶点坐标表 + 面索引表"定义的凸多面体（OFF 文件的思路）：每个面的顶点按列表顺序首尾自动闭合。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `vertex_coords` | `Point3DLike_Array` | 必填 | 顶点坐标列表，下标即顶点号 |
| `faces_list` | `list[list[int]]` | 必填 | 每个面由哪些顶点下标构成 |
| `faces_config` | `dict` | `{}` | 面片 `Polygon` 的构造参数，默认已注入 `{"fill_opacity": 0.5, "shade_in_3d": True}` |
| `graph_config` | `dict` | `{}` | 顶点 `Graph` 的构造参数，默认已注入 `{"vertex_type": Dot3D, "edge_config": {"stroke_opacity": 0}}` |

> **返回**：无（构造实例）。可直接访问 `.faces`（面片 `VGroup`）与 `.graph`（`Graph`），另有 `.layout`、`.edges`。

#### 样例：`Polyhedron`改动

手写一个 5 顶点四棱锥（4 个侧面 + 1 个底面），第 3 个侧面染黄、锥顶染红，再用 `graph[4].animate` 拖动锥顶——updater 带整个立体形变。

```python
from real_time_manim import ThreeDScene, Polyhedron, Text, \
    BLUE, GREY_B, RED, YELLOW, UP, DOWN, LEFT, DEGREES
from real_time_manim.vulkan_bind import MLWindow, Wait

class PolyhedronDemo(ThreeDScene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        self.play = win.play   #保险接线：animate 由 win.play 直接播（move_camera 等场景方法才真会调 self.play）
        title = Text("03-polyhedron", font_size=34, color=YELLOW).to_edge(UP)   #样例标题
        self.add_fixed_in_frame_mobjects(title)   #标题钉在屏幕上
        pyramid = Polyhedron(
            vertex_coords=[[1, 1, 0], [1, -1, 0], [-1, -1, 0], [-1, 1, 0], [0, 0, 2]],   #4 个底面顶点 + 1 个锥顶
            faces_list=[[0, 1, 4], [1, 2, 4], [2, 3, 4], [3, 0, 4], [0, 1, 2, 3]],   #4 个侧面 + 1 个底面
            faces_config={"fill_opacity": 0.6, "fill_color": BLUE},   #面片配置：半透明蓝
        )
        pyramid.shift(LEFT * 2)   #整体左移，给形变留出空间
        pyramid.faces[2].set_color(YELLOW)   #给第 3 个面（侧面）换个颜色
        pyramid.graph[4].set_color(RED)   #给锥顶顶点上色
        print("面片数：", len(pyramid.faces), "顶点数：", len(pyramid.graph))   #控制台确认结构
        tag = Text("faces[2] / graph[4]", font_size=24, color=GREY_B).next_to(pyramid, DOWN)
        self.add(pyramid, tag)   #把棱锥和标签放进场景
        self.set_camera_orientation(phi=65 * DEGREES, theta=-45 * DEGREES)   #摆好斜视角
        win.play(Wait(0.8))   #停 0.8s 看清上色的面和顶点
        win.play(pyramid.graph[4].animate.shift(DOWN + RIGHT * 0.5), run_time=1.0)   #拖动锥顶：updater 带动整个立体形变
        win.play(Wait(0.4))   #停 0.4s 收工
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：先按顶点表和面表搭一个半透明蓝的四棱锥，左移留出形变空间；`faces[2]` 染黄、`graph[4]`（锥顶）染红并打印面片/顶点数确认结构。摆好斜视角停 0.8 秒后，用 `graph[4].animate.shift(...)` 把锥顶往右下拖 1 秒——因为面片由 updater 跟着顶点走，整个棱锥会实时塌成一个歪斜的锥。

<video src="assets/RTM output/03-多面体-polyhedron.mp4" controls width="560"></video>

> 提醒：
>
> - **2026-10-17 实测**：`graph[4].animate.shift(...)` 这类 `.animate` 动画由 `_AnimationBuilder` 构建、直接 `win.play(builder)` 播放，**不**回调 `self.play`——首行的 `self.play = win.play` 属保险接线（真正会调 `self.play` 的是 `move_camera` 这类场景方法，本样例没用到）。
> - `faces_list` 里的下标对应 `vertex_coords` 的顺序，写错会得到穿插的烂面。
> - `fill_color` 走 `faces_config`（`Polygon` 的参数），不走 `set_color` 那条 Surface 的坑。

## Tetrahedron / Octahedron / Icosahedron / Dodecahedron

```python
Tetrahedron(edge_length: float = 1, **kwargs)
Octahedron(edge_length: float = 1, **kwargs)
Icosahedron(edge_length: float = 1, **kwargs)
Dodecahedron(edge_length: float = 1, **kwargs)
```

四种柏拉图立体（4 / 8 / 20 / 12 面），都是 `Polyhedron` 的预设，同样支持 `.graph`、`.faces` 访问与顶点形变。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `edge_length` | `float` | `1` | 棱长 |
| `**kwargs` | `Any` | — | 透传给 `Polyhedron`（`faces_config`、`graph_config`…） |

#### 样例：四种柏拉图立体

正四面体 / 正八面体 / 正二十面体 / 正十二面体排成一行，给八面体的一个顶点染红、一个面染黄，环绕 90° 看清四种外形。

```python
from real_time_manim import ThreeDScene, VGroup, Tetrahedron, Octahedron, \
    Icosahedron, Dodecahedron, Text, \
    GREY_B, RED, YELLOW, UP, DOWN, RIGHT, DEGREES
from real_time_manim.vulkan_bind import MLWindow, Wait

class PlatonicDemo(ThreeDScene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        self.play = win.play   #move_camera 内部会调 self.play，先接到窗口上
        title = Text("03-platonic", font_size=34, color=YELLOW).to_edge(UP)   #样例标题
        self.add_fixed_in_frame_mobjects(title)   #标题钉在屏幕上
        solids = VGroup(
            Tetrahedron(edge_length=1),      #4 面正四面体
            Octahedron(edge_length=1),       #8 面正八面体
            Icosahedron(edge_length=0.9),    #20 面正二十面体
            Dodecahedron(edge_length=0.7),   #12 面正十二面体
        ).arrange(RIGHT, buff=1.2)   #从左到右排成一行
        solids.to_edge(DOWN, buff=1.4)   #整体下沉一点，给标题留位
        octa = solids[1]   #取正八面体演示访问
        octa.graph[0].set_color(RED)   #给一个顶点上色（graph 是顶点 Graph）
        octa.faces[2].set_color(YELLOW)   #给一个面上色（faces 是面片 VGroup）
        tag = Text("tetra / octa / icosa / dodeca", font_size=24, color=GREY_B).next_to(solids, DOWN)
        self.add(solids, tag)   #把四个立体和标签放进场景
        self.set_camera_orientation(phi=65 * DEGREES, theta=-30 * DEGREES)   #摆好斜视角
        win.play(Wait(0.8))   #停 0.8s 看清四个立体
        self.move_camera(theta=-120 * DEGREES, run_time=1.4)   #带动画环绕 90°
        win.play(Wait(0.4))   #停 0.4s 收工
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：把四个柏拉图立体按棱长从大到小排成一行放在画面下方，逐个加上地面标签；再取第二个（正八面体）演示结构访问——`graph[0]` 的顶点染红、`faces[2]` 的面染黄。斜视角停 0.8 秒后环绕 90°，能看到正二十面体接近球形、正十二面体的大五边形面在转动中的明暗变化。

<video src="assets/RTM output/03-多面体-platonic.mp4" controls width="560"></video>

> 提醒：四种立体的 `edge_length` 相同时视觉大小差很多（顶点数不同），样例里递减着排才协调。`graph` 是 `Graph`、`faces` 是 `VGroup`，按数字下标访问即可；顶点默认是 `Dot3D`，边默认无描边（`stroke_opacity: 0`），所以上色只看点和面。

## ConvexHull3D

```python
ConvexHull3D(*points: Point3D, tolerance: float = 1e-5, **kwargs)
```

给一组三维点，自动求凸包包成 `Polyhedron`（顶点 + 面 + 棱边全算好），用于"散点围出的形体"可视化。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `*points` | `Point3D` | 必填 | 参与求凸包的点（位置传参，不用列表） |
| `tolerance` | `float` | `1e-5` | quickhull 的数值容差 |
| `**kwargs` | `Any` | — | 透传给 `Polyhedron`（`faces_config`、`graph_config`…） |

#### 样例：`ConvexHull3D`求凸包

6 个散点（小红球标出），自动求出半透明绿凸包包住它们，环绕 90° 看清包络形状。

```python
from real_time_manim import ThreeDScene, ConvexHull3D, VGroup, Dot3D, Text, \
    GREEN, GREY_B, RED, YELLOW, UP, DOWN, DEGREES
from real_time_manim.vulkan_bind import MLWindow, Wait

class HullDemo(ThreeDScene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        self.play = win.play   #move_camera 内部会调 self.play，先接到窗口上
        title = Text("03-hull", font_size=34, color=YELLOW).to_edge(UP)   #样例标题
        self.add_fixed_in_frame_mobjects(title)   #标题钉在屏幕上
        pts = [[1.9, 0.4, -1.5], [-0.9, 1.2, 0.6], [0.4, 0.4, -1.8],   #6 个三维点
               [-1.5, -0.8, -0.5], [0.8, -1.4, 0.9], [-0.2, 0.1, 2.0]]
        hull = ConvexHull3D(*pts, faces_config={"fill_opacity": 0.4, "fill_color": GREEN})   #自动求凸包成多面体
        dots = VGroup(*[Dot3D(p, radius=0.08, color=RED) for p in pts])   #原始点用小红球标出
        tag = Text("ConvexHull3D(*points)", font_size=24, color=GREY_B).to_edge(DOWN)
        self.add(hull, dots, tag)   #把凸包、点和标签放进场景
        self.set_camera_orientation(phi=65 * DEGREES, theta=-45 * DEGREES)   #摆好斜视角
        win.play(Wait(0.8))   #停 0.8s 看清凸包包络
        self.move_camera(theta=-135 * DEGREES, run_time=1.4)   #带动画环绕 90°
        win.play(Wait(0.4))   #停 0.4s 收工
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：在空间里散布 6 个点并用小红球标出来，`ConvexHull3D(*pts)` 一键求出包住所有点的凸包（半透明绿，能看到内部的红点），配一行地面标注。斜视角停 0.8 秒后环绕 90°，转到侧面能看到凸包"贴着"最外围的点鼓出来，落在内部的点被包在半透明面片后面。

<video src="assets/RTM output/03-多面体-hull.mp4" controls width="560"></video>

> 提醒：
>
> - `ConvexHull3D` 是位置传参（`ConvexHull3D(*pts)`），不要传一个列表进去。
> - 点数少于 4 个或全部共面时求不出体，会退化；`tolerance` 默认即可，数值病态的点集才需要调。
