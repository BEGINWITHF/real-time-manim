# 第一个场景

写一个普通的 Manim `Scene`，在 `construct()` 里开窗、绑定场景、播动画、关窗，即可实时预览并一键录制成 MP4。

## 参数

RTM 最小程序模板涉及的接口（来自 README 的 Quick start / Core concepts）：

| 参数                                | 类型         | 默认值          | 说明                                                                            |
| --------------------------------- | ---------- | ------------ | ----------------------------------------------------------------------------- |
| `MLWindow(w, h)`                  | `int, int` | `1920, 1080` | 打开一个实时 Vulkan 窗口，这里是 `960×540` / `1280×720`                                   |
| `win.scene`                       | `Scene`    | `None`       | 把当前 Manim 场景绑定给窗口（`win.scene = self`）                                         |
| `win.play(*animations, **kwargs)` | 动画         | —            | 播放任意受支持的动画；play 级关键字**只认 `run_time`、`rate_func`，以及 `path_arc` / `path_arc_axis` / `path_arc_centers` / `path_func`**（`path_*` 走 manim `compile_animations` 的 setattr 语义，见 `01-场景与相机/专用场景/05-线性变换场景.md`），`lag_ratio` 等其余关键字会被打印 `[RTM] play(): unsupported keyword(s) ... ignored` 警告并忽略（`window/play.py::SUPPORTED_PLAY_KWARGS`） |
| `win.close()`                     | —          | —            | 关闭窗口，结束渲染                                                                     |
| `fast_record_scene(Hello)`        | `Scene` 子类 | —            | 整段场景录制到 `~/Downloads/output.mp4`，录制自动包住场景起止，之后清理临时 `media/`                   |

## 示例

```python
from real_time_manim import Scene, Square, BLUE
from real_time_manim.vulkan_bind import MLWindow, Create, Wait
from real_time_manim.record import fast_record_scene

class Hello(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        sq = Square(side_length=1.5, color=BLUE).set_fill(BLUE, 0.6)   #创建一个 “Square” Mobject，名为 “sq”
        win.play(Create(sq), run_time=1.0)   #对 “sq” 使用 “Creat” 动画，动画用 1s 完成
        win.play(Wait(0.5))   #进行 0.5s 的等待
        win.close()   #关闭 RTM 窗口

fast_record_scene(Hello)   #保存由 RTM 渲染的视频
```
