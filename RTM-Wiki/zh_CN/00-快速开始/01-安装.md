# 安装 real-time-manim

RTM 以 pip 库的形式安装；它没有 `manim` 命令行，安装完成后直接在 Python 脚本里用 `MLWindow` 实时渲染或录制视频。

> **不需要单独安装 ManimCE，也不需要 `import manim`**：RTM 自带它驱动的那份 ManimCE（`real_time_manim/manim/`），`import real_time_manim` 会把整个 ManimCE 命名空间（`Scene`、所有 mobject、所有动画、颜色、速率函数……）一起导出，直接 `from real_time_manim import ...` 即可。旧代码里的 `from manim import ...` 也仍然可用，拿到的是同一批类。
>
> **例外**：若进程里**先** `import manim`，则 `manim` 沿用那份外部副本并在版本不符时打印 `RuntimeWarning`，此时类身份与 RTM 内置的那份不同——先 `import real_time_manim` 即可。
>
> 版本对照：内置 ManimCE **0.21.0**（`real_time_manim.MANIM_BUNDLE_VERSION`，MIT，见仓库 `UPSTREAM.md`），项目版本 **2.0.0**（`pyproject.toml`）。

## 参数

安装方式与运行时依赖（来自 README 的 Install 一节）：

| 参数         | 类型        | 默认值           | 说明                                                                           |
| ---------- | --------- | ------------- | ---------------------------------------------------------------------------- |
| Python     | 版本        | 3.11+         | 运行 RTM 的最低 Python 版本                                                         |
| 平台         | 系统        | Windows 10/11 | wheel 自带 `vulkan_core.dll` 与窗口图标，无需单独构建                                      |
| macOS 前置步骤 | shell 命令  | —             | `brew install molten-vk` + `bash native/build_mac.sh`，生成 `vulkan_core.dylib` |
| Vulkan 驱动  | GPU/驱动    | —             | 运行时必需：需要支持 Vulkan 的 GPU 与驱动                                                  |
| `ffmpeg`   | PATH 中的命令 | —             | 只有想录制视频时才必需                                                                  |

## 示例

Windows 一键安装：

```bash
pip install real-time-manim
```

可选：Typst 排版后端（`MathTex` 自动路由 Typst 编译所必需，见 [10-Typst](../04-图形与文本/10-Typst.md)）：

```bash
pip install "real-time-manim[typst]"   # = pip install "typst>=0.14"
```

macOS 先构建原生库再安装：

```bash
brew install molten-vk          # MoltenVK provides the Vulkan layer on macOS
bash native/build_mac.sh        # -> dist/release/vulkan_core.dylib
pip install real-time-manim
```

安装后验证（能导入即成功）：

```python
from real_time_manim.vulkan_bind import MLWindow, Create, Wait
from real_time_manim.record import fast_record_scene
```
