# 沿路径移动与同态变换（MoveAlongPath / Homotopy）

手册「7.2 沿路径移动」「7.3 同态变换（逐点函数驱动）」的主力两条：一个让对象沿矢量路径按比例前进，一个用 `(x, y, z, t) -> (x', y', z')` 逐点重映射整个形状。两个类均实测可渲（走 RTM 自有实现），两条样例各自成片。同节其余三个类见 [02b-同态变换其余类](02b-同态变换其余类.md)。

## 参数

### MoveAlongPath

```python
MoveAlongPath(mobject, path, suspend_mobject_updating=False, **kwargs)
```

继承 `MoveAlongPath(Animation)`，来源 `animation/movement.py`。让对象沿另一条 VMobject 的**路径按比例前进**（每帧取 `path.point_from_proportion(rate_func(alpha))` 并 `move_to`），是"点走轨迹""物体沿曲线运动"的标准解。注意：只移动位置，不改变朝向。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `Mobject` | — | 移动的对象 |
| `path` | `VMobject` | — | 路径。**只能填** 矢量对象：`Line`、`Arc`、`Circle`、自定义 `VMobject`… |
| `suspend_mobject_updating` | `bool` | `False` | 是否挂起 updater（路径需要 updater 时保持 `False`；路径无 updater 时 True/False 画面一致） |
| `**kwargs` | `Any` | — | `Animation` 通用参数（`run_time`、`rate_func`、`lag_ratio`…） |

> **返回**：`Animation`（交给 `play` 播放）。

#### 样例：橙点沿画出来的圆轨迹走一圈

灰色圆路径先画出来（轨迹看得见），橙点沿它匀速走一整圈。

```python
from real_time_manim import Scene, Text, Circle, Dot, GREY_B, ORANGE, YELLOW, UP, DOWN, \
    Create, FadeIn, Write, linear
from real_time_manim.vulkan_bind import MLWindow, MoveAlongPath, Wait

class MoveAlongPathDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("02-MoveAlongPath", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        sig = Text("MoveAlongPath(dot, path, run_time=2.0, rate_func=linear)",
                   font_size=30, color=GREY_B).next_to(title, DOWN, buff=0.4)   #签名标签
        path = Circle(radius=1.9, color=GREY_B).shift(DOWN * 0.9)   #灰色圆形路径
        dot = Dot(radius=0.14, color=ORANGE).move_to(path.point_from_proportion(0.0))   #起点上的橙点
        win.play(FadeIn(sig, shift=DOWN), FadeIn(dot), run_time=0.4)   #标签与点淡入
        win.play(Create(path, run_time=0.8, rate_func=linear))   #把路径画出来（轨迹可见）
        win.play(MoveAlongPath(dot, path, run_time=2.0, rate_func=linear))   #参数 “path / run_time / rate_func”
        win.play(Wait(0.6))   #停留看结果
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：先用 `Create` 把灰色圆路径本身画出来，橙点 `MoveAlongPath(dot, path, run_time=2.0, rate_func=linear)` 每帧取 `path.point_from_proportion(alpha)` 把自己挪到轨迹上——只移动位置、不改朝向；`rate_func=linear` 让整圈走得均匀。

<video src="assets/RTM output/02-沿路径与同态变换-movealongpath.mp4" controls width="560"></video>

> 提醒：`rate_func` 直接决定沿路径的速度曲线，`linear` 才是匀速、`smooth` 会两头慢中间快；路径形状变了下次取点也跟着变，所以路径适合做成可见的轨迹线。

### Homotopy

```python
Homotopy(homotopy, mobject, run_time=3, apply_function_kwargs=None, **kwargs)
```

继承 `Homotopy(Animation)`，来源 `animation/movement.py`。按你给的函数 `(x, y, z, t) -> (x', y', z')` **逐点重映射**整个形状，`t` 从 0 到 1。用它可以做"方块被推成波浪""黏液流动"这类整体连续变形。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `homotopy` | `Callable[[float, float, float, float], tuple]` | — | 输入旧坐标与时间，输出新坐标。**能填** 任意四参函数（如 `lambda x, y, z, t: (x, y + .3*np.sin(x+2*PI*t), z)`） |
| `mobject` | `Mobject` | — | 被变形对象（每帧从起点副本重算） |
| `run_time` | `float` | `3` | 时长（秒） |
| `apply_function_kwargs` | `dict \| None` | `None` | 透传给 `Mobject.apply_function` 的参数（如 `about_point` / `about_edge`）。已接收并透传（2026-10-16 补全，测试 `tests/test_gap_transform_motion.py`）：非法键构造期抛 `TypeError`；不传时行为与旧版逐位相同 |
| `**kwargs` | `Any` | — | `Animation` 通用参数（`rate_func`…） |

> **返回**：`Animation`（交给 `play` 播放）。

#### 样例：矩形被逐点重映射成波浪带

黄矩形在 2 秒里被 `wave(x, y, z, t)` 逐帧重映射成起伏的波浪带。

```python
import numpy as np

from real_time_manim import Scene, Text, Rectangle, GREY_B, YELLOW, UP, DOWN, \
    FadeIn, Write, linear
from real_time_manim.vulkan_bind import MLWindow, Homotopy, Wait

class HomotopyDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("02-Homotopy", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        sig = Text("Homotopy(wave, rect, run_time=2.0, rate_func=linear)",
                   font_size=30, color=GREY_B).next_to(title, DOWN, buff=0.4)   #签名标签
        rect = Rectangle(width=4.4, height=1.6, color=YELLOW).set_fill(YELLOW, 0.35).shift(DOWN * 1.2)   #黄色矩形
        win.play(FadeIn(sig, shift=DOWN), FadeIn(rect), run_time=0.4)   #标签与矩形淡入

        def wave(x, y, z, t):   #参数 “homotopy”：(x, y, z, t) -> (x', y', z')
            return (x, y + 0.45 * np.sin(2.2 * x + 2.0 * np.pi * t), z)

        win.play(Homotopy(wave, rect, run_time=2.0, rate_func=linear))   #参数 “homotopy / run_time / rate_func”
        win.play(Wait(0.6))   #停留看结果
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：`Homotopy(wave, rect, run_time=2.0, rate_func=linear)` 在 2 秒里逐帧按 `wave(x, y, z, t)` 重映射矩形的每个顶点——`y` 方向叠加随 `x` 和时间变化的正弦，矩形就变成一条来回起伏的波浪带；`t` 从 0 走到 1，函数里没有残留位移，结束时恢复原状。

<video src="assets/RTM output/02-沿路径与同态变换-homotopy.mp4" controls width="560"></video>

> 提醒：`Homotopy` 每帧从**起点副本**重算，别指望它结束后"停在中间态"；想要平滑版（每帧 `make_smooth()`）见 [02b-同态变换其余类](02b-同态变换其余类.md) 的 `SmoothedVectorizedHomotopy`。
