# 同态变换其余类：Smoothed / Complex / PhaseFlow

手册「7.3 同态变换」中除 `Homotopy` 之外的三个类——平滑版逐点重映射、复变函数驱动、向量场累积位移。三个类均实测可渲（签名照抄手册、来源 `animation/movement.py`），三条样例各自成片；其中 `SmoothedVectorizedHomotopy` 在纯命令行渲染下需要上游 bug 绕法（见样例与提醒）。

## 参数

### SmoothedVectorizedHomotopy

```python
SmoothedVectorizedHomotopy(homotopy, mobject, run_time=3, apply_function_kwargs=None, **kwargs)
```

继承 `SmoothedVectorizedHomotopy(Homotopy)`（**无自有 `__init__`**，签名完全继承自 `Homotopy`），来源 `animation/movement.py`（无 docstring，依据源码整理）。同 `Homotopy`，但每帧对结果调用 `make_smooth()`，保证曲线平滑（只适用于 `VMobject`，否则 `assert` 失败）。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `homotopy` | `Callable[[float, float, float, float], tuple]` | — | 输入旧坐标与时间，输出新坐标（同 `Homotopy`）。**能填** 任意四参函数 |
| `mobject` | `Mobject` | — | 被变形对象，**必须是 `VMobject`**（矢量对象） |
| `run_time` | `float` | `3` | 时长（秒） |
| `apply_function_kwargs` | `dict \| None` | `None` | 透传给 `Mobject.apply_function` 的参数。已修复（2026-10-16，测试 `tests/test_gap_transform_motion.py`）：真因是上游 `VMobject.apply_function` 声明了 `about_point` / `about_edge` 却不传给父类（0.19–0.21 皆然），RTM 在内嵌副本最小改 1 行 + 幂等运行时补丁（对已 import 的外部 manim 同样生效） |
| `**kwargs` | `Any` | — | `Animation` 通用参数（`rate_func`…） |

> **返回**：`Animation`（交给 `play` 播放）。

#### 样例：圆被平滑压扁再拉伸

蓝圆被 `squash(x, y, z, t)` 逐点映射：x 方向随 `t` 拉长、y 方向压扁，轮廓始终平滑。

```python
from real_time_manim import Scene, Text, VGroup, Circle, BLUE, GREY_B, YELLOW, UP, DOWN, \
    FadeIn, SmoothedVectorizedHomotopy, Write, linear
from real_time_manim.vulkan_bind import MLWindow, Wait

class SmoothedHomotopyDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("02b-SmoothedVectorizedHomotopy", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        l1 = Text("SmoothedVectorizedHomotopy(squash, c, run_time=1.8,", font_size=30, color=GREY_B)
        l2 = Text("                            rate_func=linear)", font_size=30, color=GREY_B)
        sig = VGroup(l1, l2).arrange(DOWN, buff=0.06).next_to(title, DOWN, buff=0.4)   #签名标签
        c = Circle(radius=1.0, color=BLUE).set_fill(BLUE, 0.4).shift(DOWN * 1.5)   #蓝色圆
        win.play(FadeIn(sig, shift=DOWN), FadeIn(c), run_time=0.4)   #标签与圆淡入

        def squash(x, y, z, t):   #参数 “homotopy”：x 拉长、y 压扁
            return (x * (1.0 + 0.9 * t), y * (1.0 - 0.45 * t), z)

        win.play(SmoothedVectorizedHomotopy(squash, c, run_time=1.8, rate_func=linear))
        win.play(Wait(0.6))   #停留看结果
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：`squash(x, y, z, t)` 把每个点映射成 `(x*(1+0.9t), y*(1-0.45t))`——1.8 秒里蓝圆一边横向拉长到 1.9 倍、一边压到一半高；`SmoothedVectorizedHomotopy` 每帧对结果再调 `make_smooth()`，所以拉伸过程中轮廓始终是平滑曲线，不会出现折角。

> 提醒：上游 manim 0.21 的 `SmoothedVectorizedHomotopy.interpolate_submobject` 用到 `VMobject` 却没导入，纯 manim 下第一次插值就 `NameError`；补一句 `movement.VMobject = VMobject` 即可（RTM 的 `compat.py` 已内置这个修复，样例正常出片）。

### ComplexHomotopy

```python
ComplexHomotopy(complex_homotopy, mobject, **kwargs)
```

继承 `ComplexHomotopy(Homotopy)`，来源 `animation/movement.py`。用复变函数 `C × [0,1] -> C` 描述变形：内部把 `(x, y)` 看作复数 `z`，算出 `complex_homotopy(complex(x, y), t)` 后再取实部虚部（`z` 坐标不变）。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `complex_homotopy` | `Callable[[complex, float], complex]` | — | 输入复数与时间，输出新复数。**能填** 如 `lambda z, t: z * np.exp(1j * t * PI / 2)`（复平面旋转） |
| `mobject` | `Mobject` | — | 被变形对象 |
| `**kwargs` | `Any` | — | `Homotopy` 的 `run_time=3`、`apply_function_kwargs` 与 `Animation` 通用参数 |

> **返回**：`Animation`（交给 `play` 播放）。

#### 样例：复平面乘 e^(i·t·π/2) 原地转 90°

红方块的每个点当复数处理，乘上旋转因子后原地转 90°。

```python
import numpy as np

from real_time_manim import Scene, Text, VGroup, Square, RED, GREY_B, YELLOW, UP, DOWN, \
    ComplexHomotopy, FadeIn, Write
from real_time_manim.vulkan_bind import MLWindow, Wait

class ComplexHomotopyDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("02b-ComplexHomotopy", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        l1 = Text("ComplexHomotopy(lambda z, t: z*e^(i*t*PI/2), sq,", font_size=30, color=GREY_B)
        l2 = Text("                run_time=1.8)", font_size=30, color=GREY_B)
        sig = VGroup(l1, l2).arrange(DOWN, buff=0.06).next_to(title, DOWN, buff=0.4)   #签名标签
        sq = Square(side_length=1.6, color=RED).set_fill(RED, 0.4).shift(DOWN * 1.5)   #红色方块
        win.play(FadeIn(sig, shift=DOWN), FadeIn(sq), run_time=0.4)   #标签与方块淡入
        win.play(ComplexHomotopy(lambda z, t: z * np.exp(1j * t * np.pi / 2), sq,   #参数 “complex_homotopy”（复平面旋转）
                                 run_time=1.8))
        win.play(Wait(0.6))   #停留看结果
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：`lambda z, t: z * np.exp(1j * t * np.pi / 2)` 就是"复数乘一个模长为 1、辐角随 `t` 从 0 涨到 π/2 的数"——几何上等于把每个点绕原点逆时针转 90°。1.8 秒里红方块原地转完 90°，`z` 坐标（垂直纸面方向）不受影响。

### PhaseFlow

```python
PhaseFlow(function, mobject, virtual_time=1, suspend_mobject_updating=False,
          rate_func=linear, **kwargs)
```

继承 `PhaseFlow(Animation)`，来源 `animation/movement.py`（无 docstring，依据源码整理）。按向量场 `function(point) -> velocity` **逐帧累积位移**（每帧位移 `Δ = virtual_time * (rate_func(a2) - rate_func(a1)) * function(p)`），让形状沿相流运动。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `function` | `Callable[[np.ndarray], np.ndarray]` | — | 向量场：输入点，输出速度。**能填** 如 `lambda p: np.array([-p[1], p[0], 0])`（绕原点旋转场） |
| `mobject` | `Mobject` | — | 被推动的对象 |
| `virtual_time` | `float` | `1` | 位移倍率 |
| `suspend_mobject_updating` | `bool` | `False` | 是否挂起 updater（无 updater 的场景里 True/False 画面一致） |
| `rate_func` | `Callable` | `linear` | 进度函数 |
| `**kwargs` | `Any` | — | `Animation` 通用参数 |

> **返回**：`Animation`（交给 `play` 播放）。

#### 样例：点被向量场推着绕中心画弧

灰点在旋转向量场里被推着绕左下方的中心点画一段弧。

```python
import numpy as np

from real_time_manim import Scene, Text, VGroup, Dot, GREY_B, YELLOW, LEFT, UP, DOWN, \
    FadeIn, PhaseFlow, Write, linear
from real_time_manim.vulkan_bind import MLWindow, Wait

class PhaseFlowDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("02b-PhaseFlow", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        l1 = Text("PhaseFlow(lambda p: [-p[1]-1.3, p[0], 0], dot,", font_size=30, color=GREY_B)
        l2 = Text("          virtual_time=1.2, run_time=2.0, rate_func=linear)", font_size=28, color=GREY_B)
        sig = VGroup(l1, l2).arrange(DOWN, buff=0.06).next_to(title, DOWN, buff=0.4)   #签名标签
        dot = Dot(radius=0.13, color=GREY_B).shift(LEFT * 1.9 + DOWN * 1.3)   #被向量场推动的点
        center = Dot(radius=0.06, color=GREY_B).shift(DOWN * 1.3)   #向量场的旋转中心
        win.play(FadeIn(sig, shift=DOWN), FadeIn(VGroup(dot, center)), run_time=0.4)   #标签与点淡入
        win.play(PhaseFlow(lambda p: np.array([-p[1] - 1.3, p[0], 0.0]), dot,   #参数 “function”（向量场）
                           virtual_time=1.2, run_time=2.0, rate_func=linear))   #参数 “virtual_time / run_time / rate_func”
        win.play(Wait(0.6))   #停留看结果
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：向量场 `lambda p: [-p[1]-1.3, p[0], 0]` 是"绕点 `(-1.3, 0)` 逆时针旋转"的场——`PhaseFlow` 每帧按当前速度积分一小步，灰点就被推着绕下方那个灰点中心画弧；`virtual_time=1.2` 是步长倍率（越大跑得越快），`rate_func=linear` 让整段匀速。
