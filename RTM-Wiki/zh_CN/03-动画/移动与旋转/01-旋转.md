# 旋转动画：Rotate 与 Rotating

手册「7.1 旋转」的两个类：`Rotate` 是**一次性**把对象转 `angle`（RTM 自有版给显式轴心/非 z 轴时逐帧烘焙真实旋转），`Rotating` 是"每帧真的转过去"的连续转动。两个类均实测可渲（`Rotate`/`Rotating` 走 RTM 自有实现），三条样例各自成片。

## 参数

### Rotate

```python
Rotate(mobject, angle=PI, axis=OUT, about_point=None, about_edge=None, **kwargs)
```

继承 `Rotate(Animation)`（RTM 自有实现，`real_time_manim/animations/rotate.py`；**不是** `Transform` 子类）。**一次性**把对象旋转 `angle` 弧度（默认 `PI`）：RTM 走的是**逐帧烘焙**——给了显式 `about_point`/`about_edge`（或非 z 轴）时，每帧对点集做真实旋转/绕轴心公转，终态与 CE 逐点一致；只绕自身中心且轴 ∥ z 时沿用渲染端的标量绘制通道（最省）。`about_point` 未给时用对象中心，`about_edge` 可用包围盒的边当旋转中心（如 `about_edge=UP`）。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `Mobject` | — | 被旋转对象 |
| `angle` | `float` | `PI` | 旋转角（弧度）。**能填** `PI`、`2*PI/3`、`90 * DEGREES` 这类弧度值 |
| `axis` | `Vector3DLike` | `OUT` | 旋转轴（2D 即 z 轴）。已接收（2026-10-16 补全，测试 `tests/test_gap_transform_motion.py`）：轴 ∥ ±z 时沿用标量绘制通道并按轴符号翻转角度（`axis=IN` 反向转，此前完全无效），其他轴走每帧 3D Rodrigues 旋转（2D 场景体现为透视压缩，3D 场景为完整旋转）。**用法提醒**：`axis` 本是 3D 参数，2D 里改它通常无可见效果（∥z 时等价镜像/反向） |
| `about_point` | `Point3DLike \| None` | `None` | 旋转中心；`None` 用 `mobject.get_center()`；**能填** 坐标点 |
| `about_edge` | `Vector3DLike \| None` | `None` | `about_point` 为 `None` 时可用包围盒边代替中心（如 `UP`）。已接收（2026-10-16 补全）：优先级 `about_point` > `about_edge`（取 `get_critical_point(about_edge)`）> 都不给则保持默认自身中心 |
| `**kwargs` | `Any` | — | `Animation` 通用参数（`run_time`、`rate_func`…）。RTM 自有 `Rotate` 并非 `Transform` 子类，`path_arc`/`path_func` 两个 kwarg 在 `Rotate` 上仍被吞——圆弧路径要走 `Transform` 才有（见[Transform 核心](../变换/01-Transform核心.md)） |

> **返回**：`Animation`（交给 `play` 播放）。

#### 样例：绕橙色定点转 120°

橙点是旋转中心，蓝方块绕它转 120°；`rate_func=smooth` 缓入缓出。

```python
from real_time_manim import Scene, Text, VGroup, Square, Dot, BLUE, GREY_B, ORANGE, YELLOW, \
    UP, DOWN, RIGHT, ORIGIN, PI, FadeIn, Write, smooth
from real_time_manim.vulkan_bind import MLWindow, Rotate, Wait

class RotateDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("01-Rotate", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        l1 = Text("Rotate(sq, angle=2*PI/3, about_point=PIVOT,", font_size=30, color=GREY_B)
        l2 = Text("         run_time=1.6, rate_func=smooth)", font_size=30, color=GREY_B)
        sig = VGroup(l1, l2).arrange(DOWN, buff=0.06).next_to(title, DOWN, buff=0.4)   #签名标签
        pivot = Dot(point=ORIGIN + DOWN * 1.4, radius=0.09, color=ORANGE)   #旋转中心点
        sq = Square(side_length=1.3, color=BLUE).set_fill(BLUE, 0.5).move_to(pivot.get_center() + RIGHT * 2.6)   #蓝色方块
        win.play(FadeIn(sig, shift=DOWN), FadeIn(VGroup(pivot, sq)), run_time=0.4)   #标签与图形淡入
        win.play(Rotate(sq, angle=2 * PI / 3, about_point=pivot.get_center(),   #参数 “angle / about_point”
                        run_time=1.6, rate_func=smooth))                        #参数 “run_time / rate_func”
        win.play(Wait(0.6))   #停留看结果
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：RTM 自有 `Rotate` 在给了显式 `about_point` 时**逐帧烘焙**真实旋转——蓝方块的每个点都绕橙点公转 120°；`about_point` 没给时才退回绕对象自身中心转。转 120° 用 1.6 秒，`rate_func=smooth` 缓入缓出。

<video src="assets/RTM output/01-旋转-rotate.mp4" controls width="560"></video>

> 提醒：`Rotate` 转的是**插值终态**——但 RTM 自有版在给了显式 `about_point`/`about_edge`（样例就是）时**逐帧烘焙**真实旋转/公转，终态与 CE 逐点一致；只绕自身中心且轴 ∥ z 时才走渲染端的标量通道。`axis`/`about_edge` 在 RTM 侧已接线（形参表已标，测试 `tests/test_gap_transform_motion.py`）——2D 里 `axis` 只在 ∥ ±z 时有可见效果（`axis=IN` 即反向转），想要"每帧真的转过去"的连续转动仍看下方 `Rotating` 的两条样例。

### Rotating

```python
Rotating(mobject, angle=TAU, axis=None, about_point=None, about_edge=None,
         run_time=5, rate_func=linear, **kwargs)
```

继承 `Rotating(Animation)`（**不是** `Rotate` 的子类、也**不是** `Transform` 子类），来源 `real_time_manim/animations/rotating.py`。**连续转动**动画：每帧都把对象重置为起始状态再转 `rate_func(alpha)*angle`（给了显式 `about_point`/`about_edge` 或非 z 轴时逐帧烘焙真实 3D/绕轴心旋转），因此是"真的转过去"，不会因为插值而走样；默认转一整圈、5 秒、匀速，适合转齿轮、指针、3D 物体。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `Mobject` | — | 被旋转对象 |
| `angle` | `float` | `TAU` | 旋转总角度（弧度）。**能填** `TAU`、`180 * DEGREES`、`PI`… |
| `axis` | `Vector3DLike \| None` | **`None`** | RTM 自有版签名默认值是 **`None`**（语义等价 `OUT`：`_is_3d_axis()` 判定 `None` 即非 3D 轴，`interpolate` 里按 `OUT` 处理）；**ManimCE 版签名默认值写的是 `OUT`**——两版行为一致，只是默认值写法不同。**能填** `OUT`（正转）、`IN`（2D 画面反向转） |
| `about_point` | `Point3DLike \| None` | `None` | 旋转中心；`None` 用对象中心。传显式值时逐帧烘焙真实公转 |
| `about_edge` | `Vector3DLike \| None` | `None` | `about_point` 为 `None` 时用包围盒边当轴心（如 `UP` = 上边缘当铰链） |
| `run_time` | `float` | `5` | 总时长（秒） |
| `rate_func` | `Callable` | `linear` | 进度函数。**能填** `linear`（匀速）、`rush_into`、`smooth`… |
| `**kwargs` | `Any` | — | `Animation` 通用参数。非 `Transform` 子类，`path_arc`/`path_func` 传了被吞、无效 |

> **返回**：`Animation`（交给 `play` 播放）。

#### 样例：axis=IN 让 2D 画面反向转

金色箭头用 `Rotating` 连续转 180°，`axis=IN` 让 2D 画面上的转向反过来。

```python
from real_time_manim import Scene, Text, VGroup, Arrow, GOLD, GREY_B, YELLOW, UP, DOWN, \
    RIGHT, ORIGIN, IN, DEGREES, FadeIn, Write, linear
from real_time_manim.vulkan_bind import MLWindow, Rotating, Wait

class RotatingAxisDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("01-RotatingAxis", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        l1 = Text("Rotating(arrow, angle=180*DEGREES, axis=IN,", font_size=30, color=GREY_B)
        l2 = Text("          run_time=1.4, rate_func=linear)", font_size=30, color=GREY_B)
        sig = VGroup(l1, l2).arrange(DOWN, buff=0.06).next_to(title, DOWN, buff=0.4)   #签名标签
        arrow = Arrow(ORIGIN, RIGHT * 2.0, buff=0, color=GOLD).shift(DOWN * 1.6)   #金色箭头
        win.play(FadeIn(sig, shift=DOWN), FadeIn(arrow), run_time=0.4)   #标签与箭头淡入
        win.play(Rotating(arrow, angle=180 * DEGREES, axis=IN,   #参数 “angle / axis=IN”（2D 画面反向转）
                          run_time=1.4, rate_func=linear))       #参数 “run_time / rate_func”
        win.play(Wait(0.6))   #停留看结果
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：`Rotating` 每帧把对象重置为起始状态再转 `rate_func(alpha)*angle`——是"真的转过去"，不会因为插值而走样；`linear` 匀速。同一个 `angle=180*DEGREES`，`axis` 从默认 `OUT` 换成 `IN`，2D 画面上转向就相反。

#### 样例：about_edge 以上边缘当铰链翻 90°

青色三角以上边缘为铰链翻转 90°。

```python
from real_time_manim import Scene, Text, VGroup, Triangle, TEAL, GREY_B, YELLOW, UP, DOWN, \
    DEGREES, FadeIn, Write, rush_into
from real_time_manim.vulkan_bind import MLWindow, Rotating, Wait

class RotatingEdgeDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("01-RotatingEdge", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        l1 = Text("Rotating(tri, angle=90*DEGREES, about_edge=UP,", font_size=30, color=GREY_B)
        l2 = Text("           run_time=1.6, rate_func=rush_into)", font_size=30, color=GREY_B)
        sig = VGroup(l1, l2).arrange(DOWN, buff=0.06).next_to(title, DOWN, buff=0.4)   #签名标签
        tri = Triangle(color=TEAL).scale(1.1).set_fill(TEAL, 0.5).shift(DOWN * 2.0)   #青色三角
        win.play(FadeIn(sig, shift=DOWN), FadeIn(tri), run_time=0.4)   #标签与三角淡入
        win.play(Rotating(tri, angle=90 * DEGREES, about_edge=UP,   #参数 “about_edge=UP”（上边缘当铰链）
                          run_time=1.6, rate_func=rush_into))       #参数 “run_time / rate_func”
        win.play(Wait(0.6))   #停留看结果
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：`about_edge=UP` 在 `about_point` 未给时用包围盒上边当轴心——三角形像挂在上边缘的铰链一样甩过去；`rate_func=rush_into` 先慢后快，收尾干脆。
