# 特殊出场：Broadcast

手册「7.4 特殊出场」本节仅收录 `Broadcast` 一个类：从焦点逐圈扩散发射副本的雷达/声纳波纹效果。实测可渲——`Broadcast` 不在 RTM 自有动画导出清单里，样例用 manim 本体的 `Broadcast` 经 RTM 时间轴渲染，配合 RTM 的 `_spec.Broadcast` 补丁生效；两组调参各自成片。

## 参数

### Broadcast

```python
Broadcast(mobject, focal_point=ORIGIN, n_mobs=5, initial_opacity=1, final_opacity=0,
          initial_width=0.0, remover=True, lag_ratio=0.2, run_time=3, **kwargs)
```

继承 `Broadcast(LaggedStart) ← AnimationGroup`，来源 `animation/specialized.py`。从 `focal_point` 出发**逐圈扩散发射** `n_mobs` 个该形状的副本：每个副本从 `initial_width` 宽度 `Restore` 回原始大小，同时透明度从 `initial_opacity` 变到 `final_opacity`。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `Mobject` | — | 被广播的形状（内部复制 `n_mobs` 份，原件不受影响）。**能填** `Circle`、`Dot` 等任意矢量对象 |
| `focal_point` | `Sequence[float]` | `ORIGIN` | 发射中心。**能填** 坐标点——关键字与位置传值均严格生效（2026-10-16 修复，显式 `focal_point=ORIGIN` 即得手册语义，`Broadcast(mob, ORIGIN, 3)` 位置传参也不再 `TypeError`）。不传时 RTM 补丁仍取 mobject 中心（既有差异，不改默认以保持既有渲染不变；样例两条都显式传） |
| `n_mobs` | `int` | `5` | 副本数量 |
| `initial_opacity` | `float` | `1` | 起始不透明度（0~1） |
| `final_opacity` | `float` | `0` | 结束不透明度（0~1） |
| `initial_width` | `float` | `0.0` | 起始宽度（`0` 即从点开始，`0.2` 起步就是个小圈） |
| `remover` | `bool` | `True` | 播完移除副本 |
| `lag_ratio` | `float` | `0.2` | 圈与圈的错峰比例（越大越"一个接一个"） |
| `run_time` | `float` | `3` | 总时长 |
| `**kwargs` | `Any` | — | 透传给 `LaggedStart`/`AnimationGroup`（如 `rate_func`） |

> **返回**：`Animation`（交给 `play` 播放）。依赖 `LaggedStart`——RTM 同样用 manim 本体类渲染（见[组合编排](../组合编排/01-AnimationGroup与错峰.md)的实测）。

#### 样例：6 圈雷达波从焦点扩散到透明

青色圆环被复制 6 份，从小圈错峰放大并淡出，画面上就是一圈圈往外扩散的波。

```python
from real_time_manim import Scene, Text, VGroup, Circle, Dot, TEAL_A, GREY_B, YELLOW, UP, \
    DOWN, Broadcast, FadeIn, Write, smooth
from real_time_manim.vulkan_bind import MLWindow, Wait

class BroadcastDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("03-Broadcast", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        l1 = Text("Broadcast(ring, focal_point=ORIGIN, n_mobs=6,", font_size=30, color=GREY_B)
        l2 = Text("           initial_opacity=1.0, final_opacity=0.0, initial_width=0.2,", font_size=28, color=GREY_B)
        l3 = Text("           lag_ratio=0.3, run_time=2.4)", font_size=30, color=GREY_B)
        sig = VGroup(l1, l2, l3).arrange(DOWN, buff=0.06).next_to(title, DOWN, buff=0.4)   #签名标签
        focal = Dot(point=DOWN * 1.4, radius=0.07, color=TEAL_A)   #发射中心
        ring = Circle(radius=2.0, color=TEAL_A).move_to(focal)   #被广播的圆环
        win.play(FadeIn(sig, shift=DOWN), FadeIn(focal), run_time=0.4)   #标签与焦点淡入
        win.play(Broadcast(ring, focal_point=focal.get_center(), n_mobs=6,   #参数 “focal_point / n_mobs”
                           initial_opacity=1.0, final_opacity=0.0, initial_width=0.2,   #参数 “opacity / initial_width”
                           lag_ratio=0.3, run_time=2.4))   #参数 “lag_ratio / run_time”
        win.play(Wait(0.6))   #停留看结果
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：在画面下方的青色焦点上放一个大圆环，`Broadcast` 把它复制 6 份，每份从 `initial_width=0.2` 的小圈按 `lag_ratio=0.3` 错峰放大回原尺寸，同时不透明度从 1 淡到 0——画面上就是一圈圈往外扩散的雷达波；`remover=True` 播完把副本收掉，最后只剩焦点。

<video src="assets/RTM output/03-特殊出场-broadcast.mp4" controls width="560"></video>

> 提醒：`focal_point` 不传时默认仍是 mobject 中心（RTM 既有差异，保持既有渲染不变），**显式传**才与手册语义一致——现在关键字与位置传值都严格生效（样例两条都关键字显式传了）。

#### 样例：换焦点、减圈数、收尾半透明的对比组

第二组参数：4 圈、起步更宽、收尾停在 40% 不透明度、错峰更开、`rate_func=smooth`。

```python
from real_time_manim import Scene, Text, VGroup, Circle, Dot, TEAL_A, GREY_B, YELLOW, LEFT, \
    UP, DOWN, Broadcast, FadeIn, Write, smooth
from real_time_manim.vulkan_bind import MLWindow, Wait

class BroadcastTunedDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("03-BroadcastTuned", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        l1 = Text("Broadcast(ring, focal_point=SPOT, n_mobs=4,", font_size=30, color=GREY_B)
        l2 = Text("           initial_opacity=0.9, final_opacity=0.4, initial_width=0.5,", font_size=28, color=GREY_B)
        l3 = Text("           lag_ratio=0.5, run_time=2.2, rate_func=smooth)", font_size=30, color=GREY_B)
        sig = VGroup(l1, l2, l3).arrange(DOWN, buff=0.06).next_to(title, DOWN, buff=0.4)   #签名标签
        spot = Dot(point=LEFT * 2.6 + DOWN * 1.4, radius=0.09, color=GREY_B)   #新的发射中心
        ring = Circle(radius=1.5, color=TEAL_A).move_to(spot)   #更小的圆环
        win.play(FadeIn(sig, shift=DOWN), FadeIn(spot), run_time=0.4)   #标签与焦点淡入
        win.play(Broadcast(ring, focal_point=spot.get_center(), n_mobs=4,   #参数 “n_mobs=4”（圈数更少）
                           initial_opacity=0.9, final_opacity=0.4, initial_width=0.5,   #参数 “opacity / initial_width”（收尾半透明）
                           lag_ratio=0.5, run_time=2.2, rate_func=smooth))   #参数 “lag_ratio / rate_func”
        win.play(Wait(0.6))   #停留看结果
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：焦点换到画面左侧的灰点、圆环半径改 1.5，参数整组换掉——只有 4 圈、起步就有半圈宽（`initial_width=0.5`）、收尾停在 40% 不透明度、错峰拉开到 `lag_ratio=0.5`、`rate_func=smooth`：波纹更少、更慢、更"虚"。两条样例并排看，就是上面参数表里每个参数各自的作用。

无法演示：`Broadcast` 的 `remover` —— 无视频：播完移除的是内部副本，`final_opacity=0` 时画面上无法区分。手册本节没有其他条目。

> **2026-10-16 更新**：`focal_point` 默认仍是 mobject 中心（RTM 既有差异，不改默认以保持既有渲染不变），但显式传值现在严格生效——关键字 `focal_point=ORIGIN` 可得手册语义，位置传参 `Broadcast(mob, ORIGIN, 3)` 也不再直接 `TypeError`（此前崩溃）。
