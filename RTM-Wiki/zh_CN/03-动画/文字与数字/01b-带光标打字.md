# 带光标打字：TypeWithCursor / UntypeWithCursor

逐字打字时末尾跟一个光标 mobject 的打字机效果，及其倒放版。

## 参数

### `TypeWithCursor 

```python
TypeWithCursor(text, cursor, buff=0.1, keep_cursor_y=True, leave_cursor_on=True,
               time_per_char=0.1, run_time=None, **kwargs)
```

逐字打字的同时**末尾跟一个光标**，光标随已打出的字符不断右移（`buff` 控制间距），播完可选择留下或隐藏光标。常与 `Blink` 组合成完整输入效果（见 [01-强调与闪烁](../强调与提示/01-强调与闪烁.md)）。

**继承** `TypeWithCursor(ShowIncreasingSubsets) ← Animation`。`run_time=None` 时按 `time_per_char × 字符数` 自动算（样例注释里的 0.14×9=1.26s 就是它）。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `text` | `Text` | — | 被输入的文本 |
| `cursor` | `Mobject` | —（必填，无默认） | 光标（如一个细矩形/下划线），动画期间会被临时摆位 |
| `buff` | `float` | `0.1` | 光标与最后一个字符的间距 |
| `keep_cursor_y` | `bool` | `True` | `True` 光标 y 坐标保持为整段文本中心，否则跟随当前字符中心 |
| `leave_cursor_on` | `bool` | `True` | 动画结束后是否保留光标（`False` 则隐藏） |
| `time_per_char` | `float` | `0.1` | 每字符间隔（同时决定 `run_time=None` 时的自动时长） |
| `run_time` | `float \| None` | `None`（→ `time_per_char × 字符数`） | 显式传则覆盖自动值 |
| `rate_func` | `Callable` | `smooth`（`Animation` 默认） | RTM 自有版**没有** CE `AddTextLetterByLetter` 的 `linear` 默认 |
| `reverse_rate_function` | `bool` | `False` | 反向（经 `**kwargs` 转给 `Animation`，**不是显式形参**） |
| `introducer` | `bool` | `False`（`Animation` 默认） | RTM 自有版**未固定**（走 `Animation` 默认 `False`、可显式传 `True`，样例就是这么做的）
| `**kwargs` | — | — | `Animation` 通用参数（`suspend_mobject_updating`…）。RTM 版没有 CE `AddTextLetterByLetter` 的 `int_func` / `suspend_mobject_updating=False` 那套默认 |

> **返回**：`TypeWithCursor` 实例。

一行上手：

```python
text = Text("Inserting", color=PURPLE).scale(1.5).to_edge(LEFT)
cursor = Rectangle(color=GREY_A, fill_color=GREY_A, fill_opacity=1,
                   height=1.1, width=0.5).move_to(text[0])
win.play(TypeWithCursor(text, cursor))
win.play(Blink(cursor, blinks=2))
```

### `UntypeWithCursor` 

```python
UntypeWithCursor(text, cursor, buff=0.1, keep_cursor_y=True, leave_cursor_on=True,
                 time_per_char=0.1, run_time=None, **kwargs)
```

带光标的**倒打字**（字符从末尾依次消失，光标跟随），播完移出场景——用于"删掉这段输入"的镜头。**继承** `UntypeWithCursor(Animation)`。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `text` | `Text` | — | 被逐字删除的文本 |
| `cursor` | `VMobject` | —（**必填，无默认**） | RTM 自有版 `cursor` 是**第二个位置必填参数**、没有 `None` 默认
| `buff` | `float` | `0.1` | 光标与末字符间距 |
| `keep_cursor_y` | `bool` | `True` | 锁定光标 y |
| `leave_cursor_on` | `bool` | `True` | 播完是否保留光标 |
| `time_per_char` | `float` | `0.1` | 每字符间隔 |
| `run_time` | `float \| None` | `None`（→ `time_per_char × 字符数`） | 显式传则覆盖自动值 |
| `reverse_rate_function` / `remover` | — | — | RTM 自有版**没有这两个形参**（也没有 `introducer`）；倒放方向是类内写死的（`index = n - floor(alpha*n)`），`remover`/`introducer` 要传只能进 `**kwargs` 转给 `Animation`，且 `clean_up_from_scene` 是基类 `pass`、播完并不真的摘场景。ManimCE 版才有这两个显式形参 |
| `**kwargs` | — | — | `Animation` 通用参数（`rate_func` 等） |

> **返回**：`UntypeWithCursor` 实例。

一行上手：

```python
text = Text("Deleting", color=PURPLE).scale(1.5).to_edge(LEFT)
cursor = Rectangle(color=GREY_A, fill_color=GREY_A, fill_opacity=1,
                   height=1.1, width=0.5).move_to(text[0])
self.add(text)
win.play(UntypeWithCursor(text, cursor))
```

#### 样例：TypeWithCursor / UntypeWithCursor 逐项演示

本页成片按 TypeWithCursor（含打完光标闪两下）→ UntypeWithCursor 的顺序各演示一段，参数逐条标在画面里。

```python
import os

from real_time_manim import (
    GREEN,
    GREY_B,
    PURPLE,
    RED,
    DOWN,
    UP,
    Rectangle,
    Scene,
    Text,
    VGroup,
)
from real_time_manim.vulkan_bind import (
    MLWindow,
    Blink,
    FadeIn,
    FadeOut,
    TypeWithCursor,
    UntypeWithCursor,
    Wait,
    Write,
)
from real_time_manim.record import fast_record_scene  # noqa: F401  文件末尾 __main__ 使用


class Page_01b_带光标打字(Scene):
    def construct(self):
        win = MLWindow(1280, 720, hidden=True)   # 参数 w=1280 / h=720 / hidden=True
        win.scene = self                          # 参数 win.scene

        title = Text("TypeWithCursor / UntypeWithCursor",
                     font_size=34, color=GREEN).to_edge(UP)   #标题只用 ASCII：两引擎字体回退才稳
        win.play(Write(title), run_time=0.85)

        # —— 步骤 1：TypeWithCursor(text, cursor, buff, keep_cursor_y,
        #                           leave_cursor_on, time_per_char, ...) ——
        s1a = Text("TypeWithCursor(txt, cursor,", font_size=28, color=GREY_B)
        s1b = Text("    buff=0.12, keep_cursor_y=True, leave_cursor_on=True,",
                   font_size=28, color=GREY_B)
        s1c = Text("    time_per_char=0.14, reverse_rate_function=False,",
                   font_size=28, color=GREY_B)
        s1d = Text("    introducer=True)", font_size=28, color=GREY_B)
        sig1 = VGroup(s1a, s1b, s1c, s1d).arrange(DOWN, buff=0.08).next_to(title, DOWN, buff=0.3)
        txt01 = Text("Inserting", color=PURPLE, font_size=52).next_to(sig1, DOWN, buff=0.6)
        cur01 = Rectangle(color=RED, fill_color=RED, fill_opacity=1,   # 光标颜色：创建 cursor 时给
                          height=1.0, width=0.14).move_to(txt01[0])
        win.play(FadeIn(sig1, shift=DOWN), run_time=0.45)
        win.play(
            TypeWithCursor(
                txt01,                                # 参数 text ✓
                cur01,                                # 参数 cursor ✓（细矩形光标，RED）
                buff=0.12,                            # 参数 buff=0.12 ✓（默认 0.1：光标与末字符间距）
                keep_cursor_y=True,                   # 参数 keep_cursor_y=True ✓（y 锁在整段中心）
                leave_cursor_on=True,                 # 参数 leave_cursor_on=True ✓（播完留下光标）
                time_per_char=0.14,                   # 参数 time_per_char=0.14 ✓（默认 0.1）
                reverse_rate_function=False,          # 参数 reverse_rate_function=False ✓
                introducer=True,                      # 参数 introducer=True ✓（播前加入场景）
            ),
            Wait(1.6),                                # 比自动 run_time(=0.14*9=1.26s) 略长，末帧 alpha 才到 1
        )
        win.play(                                     # 页面示例：打完让光标闪两下
            Blink(
                cur01,                                # 参数 mobject ✓
                time_on=0.3,                          # 参数 time_on=0.3 ✓
                time_off=0.3,                         # 参数 time_off=0.3 ✓
                blinks=2,                             # 参数 blinks=2 ✓
            ),
            run_time=1.2,
        )
        win.play(FadeOut(sig1), FadeOut(txt01), FadeOut(cur01), run_time=0.5)

        # —— 步骤 2：UntypeWithCursor(text, cursor, ..., reverse_rate_function=True,
        #                             introducer=False, remover=True) ——
        s2a = Text("UntypeWithCursor(txt, cursor,", font_size=28, color=GREY_B)
        s2b = Text("    buff=0.12, keep_cursor_y=True, leave_cursor_on=True,",
                   font_size=28, color=GREY_B)
        s2c = Text("    time_per_char=0.14, reverse_rate_function=True,",
                   font_size=28, color=GREY_B)
        s2d = Text("    introducer=False, remover=True)", font_size=28, color=GREY_B)
        sig2 = VGroup(s2a, s2b, s2c, s2d).arrange(DOWN, buff=0.08).next_to(title, DOWN, buff=0.3)
        txt02 = Text("Deleting", color=PURPLE, font_size=52).next_to(sig2, DOWN, buff=0.6)
        cur02 = Rectangle(color=RED, fill_color=RED, fill_opacity=1,
                          height=1.0, width=0.14).move_to(txt02[0])
        win.play(FadeIn(sig2, shift=DOWN), run_time=0.45)
        self.add(txt02, cur02)                        # 参数 introducer=False → 先手动放进场景
        win.play(
            UntypeWithCursor(
                txt02,                                # 参数 text ✓
                cur02,                                # 参数 cursor ✓
                buff=0.12,                            # 参数 buff ✓（继承 TypeWithCursor）
                keep_cursor_y=True,                   # 参数 keep_cursor_y ✓
                leave_cursor_on=True,                 # 参数 leave_cursor_on ✓
                time_per_char=0.14,                   # 参数 time_per_char=0.14 ✓
                reverse_rate_function=True,           # 参数 reverse_rate_function=True ✓（与父类 False 不同）
                introducer=False,                     # 参数 introducer=False ✓（与父类 True 不同）
                remover=True,                         # 参数 remover=True ✓（播完移出场景）
            ),
            Wait(1.6),                                # 同上：把时长撑开，末帧 alpha 才到 1
        )
        win.play(FadeOut(sig2), run_time=0.5)
        win.play(Wait(0.3))

        win.play(FadeOut(title), run_time=0.5)
        win.close()
```

这段代码在做什么：两段演示，一段正打字、一段倒着删。

- 第一段是打字机：红色细矩形光标贴在 "Inserting" 开头，`TypeWithCursor` 按 `time_per_char=0.14` 逐字打出、光标跟着往右走（`buff=0.12` 留缝），打完光标留下（`leave_cursor_on=True`）再 `Blink` 闪两下；`Wait(1.6)` 把这一拍撑过自动时长（0.14×9=1.26s），保证最后一帧进度到 1。
- 第二段倒放："Deleting" 和光标先 `self.add` 进场景（`introducer=False`），`UntypeWithCursor` 从末尾逐字删掉、光标跟着回收，播完整段移出场景。

> 提醒：
>
> - 光标就是个普通 mobject，**颜色/粗细在创建时给**（样例用红色细矩形），动画签名里没有颜色参数。
> - `UntypeWithCursor` 的 `introducer` 在 RTM 自有版里**不是显式形参**（经 `**kwargs` 进 `Animation`，默认 `False`）——不先 `self.add(text, cursor)`，对象不在场景里，动画空转。
> - 想让打字节奏确定，别在 play 级再给 `run_time` 压缩 `Blink` 这类自带总时长的动画：两边对"压缩短语义"的处理不同，闪烁相位会错开（样例里 `Blink(..., run_time=1.2)` 就是这种情况，见对照说明）。

无法演示：

- 光标的"颜色"不在动画签名里 —— `cursor` 就是一个 mobject，颜色在创建矩形时给（样例用 RED，页面示例用 GREY_A）。
- `UntypeWithCursor(reverse_rate_function=...)` / `(remover=...)` —— RTM 自有版**无这两个形参**（倒放写死在类里，`remover` 即便传了也不摘场景）。
- `**kwargs` 其余通用参数无可视效果。
