# 逐字出现与消失：AddTextLetterByLetter 等

按字符逐个显示/隐藏 `Text` 的三个动画类。`AddTextLetterByLetter`、`RemoveTextLetterByLetter` 已渲染验证（两引擎逐帧对齐）；`AddTextWordByWord` 是上游坏实现，不建议用（见下）。带光标的打字机效果见 [01b-带光标打字](01b-带光标打字.md)；`Write`/`Unwrite` 是"整笔写出/擦除"，属于创建与擦除篇，见 [Create 与画线族](../创建与擦除/01-Create与画线族.md)、[反向擦除](../创建与擦除/02-反向擦除.md)，本页不展开。

## 参数

### `AddTextLetterByLetter` 

```python
AddTextLetterByLetter(text, suspend_mobject_updating=False, int_func=np.ceil,
                      rate_func=linear, time_per_char=0.1, run_time=None,
                      reverse_rate_function=False, introducer=True, **kwargs)
```

让 `Text` **一个字母一个字母地蹦出来**（按字符逐个显示而非平滑淡入），`time_per_char` 控制打字速度。`run_time` 不传时自动算成 `max(1/帧率, time_per_char) * 字符数`。**只支持 `Text`，不支持 `MathTex`**；空文本抛 `ValueError`。**继承** `AddTextLetterByLetter(ShowIncreasingSubsets)` ← `Animation`。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `text` | `Text` | — | 要逐字显示的文本（必须非空） |
| `suspend_mobject_updating` | `bool` | `False` | 是否挂起 updater |
| `int_func` | `Callable` | `np.ceil` | 进度取整函数（`ceil` = 到达即显示） |
| `rate_func` | `Callable` | `linear` | 匀速打字 |
| `time_per_char` | `float` | `0.1` | 每个字符的最短显示间隔（秒） |
| `run_time` | `float \| None` | `None` | 不传则自动 = `max(1/frame_rate, time_per_char) * len(text)` |
| `reverse_rate_function` | `bool` | `False` | `True` 时倒着收 |
| `introducer` | `bool` | `True` | 播放前加入场景 |
| `**kwargs` | — | — | `ShowIncreasingSubsets`/`Animation` 通用参数 |

> **返回**：`AddTextLetterByLetter` 实例。

一行上手：

```python
t = Text("Typing...", font_size=48)
win.play(AddTextLetterByLetter(t, time_per_char=0.15))
```

### `RemoveTextLetterByLetter` 

```python
RemoveTextLetterByLetter(text, suspend_mobject_updating=False, int_func=np.ceil,
                         rate_func=linear, time_per_char=0.1, run_time=None,
                         reverse_rate_function=True, introducer=False, remover=True, **kwargs)
```

父类的倒放——**一个字母一个字母地消失**，播完从场景移除。参数与父类唯一不同的是默认值，已在签名中体现。**继承** `RemoveTextLetterByLetter(AddTextLetterByLetter)`。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `text` | `Text` | — | 被逐字移除的文本 |
| `suspend_mobject_updating` | `bool` | `False` | 是否挂起 updater |
| `int_func` | `Callable` | `np.ceil` | 进度取整函数 |
| `rate_func` | `Callable` | `linear` | 匀速 |
| `time_per_char` | `float` | `0.1` | 每字符间隔（秒） |
| `run_time` | `float \| None` | `None` | 同父类自动计算 |
| `reverse_rate_function` | `bool` | `True` | 倒着播（与父类的 `False` 不同） |
| `introducer` | `bool` | `False` | 播放前不加入场景（与父类的 `True` 不同） |
| `remover` | `bool` | `True` | 播完从场景移除 |
| `**kwargs` | — | — | `ShowIncreasingSubsets`/`Animation` 通用参数 |

> **返回**：`RemoveTextLetterByLetter` 实例。

一行上手：

```python
t = Text("Vanishing")
self.add(t)
win.play(RemoveTextLetterByLetter(t))
```

### `AddTextWordByWord`（上游坏实现，不建议用）

```python
AddTextWordByWord(text_mobject, run_time=None, time_per_char=0.06, **kwargs)
```

本意是"一个词一个词地出现"，但上游源码标注 `# TODO, this is broken...`、docstring 也写明 *currently broken*：对普通 `Text` 切词为空，渲出来是静止画面——同样结果，属上游 bug 而非 RTM 缺口。**不建议在新脚本里使用**；需要逐词效果请用 `Text` 的行级切片 + `LaggedStart(FadeIn)`。**继承** `AddTextWordByWord(Succession)`。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `text_mobject` | `Text` | — | 被逐词显示的文本 |
| `run_time` | `float \| None` | `None` | 总时长（不传按内部序列计算） |
| `time_per_char` | `float` | `0.06` | 每词间隔 |
| `**kwargs` | — | — | `Succession`/`AnimationGroup` 通用参数 |

> **返回**：`AddTextWordByWord` 实例（不建议构造）。

#### 样例：AddTextLetterByLetter / RemoveTextLetterByLetter 逐项演示

本页成片按 AddTextLetterByLetter → RemoveTextLetterByLetter 的顺序各演示一段，参数逐条标在画面里。

```python
import os

import numpy as np
from real_time_manim import (
    BLUE,
    GREEN,
    GREY_B,
    RED,
    DOWN,
    UP,
    AddTextLetterByLetter,
    RemoveTextLetterByLetter,
    Scene,
    Text,
    VGroup,
    linear,
)
from real_time_manim.vulkan_bind import (
    MLWindow,
    FadeIn,
    FadeOut,
    Wait,
    Write,
)
from real_time_manim.record import fast_record_scene  # noqa: F401  文件末尾 __main__ 使用


class Page_01_逐字出现与消失(Scene):
    def construct(self):
        win = MLWindow(1280, 720, hidden=True)   # 参数 w=1280 / h=720 / hidden=True
        win.scene = self                          # 参数 win.scene

        title = Text("AddTextLetterByLetter / RemoveTextLetterByLetter",
                     font_size=34, color=GREEN).to_edge(UP)   #标题只用 ASCII：两引擎字体回退才稳
        win.play(Write(title), run_time=0.85)

        # —— 步骤 1：AddTextLetterByLetter(...) ——
        s1a = Text("AddTextLetterByLetter(txt, suspend_mobject_updating=False,",
                   font_size=28, color=GREY_B)
        s1b = Text("    int_func=np.ceil, rate_func=linear, time_per_char=0.25,",
                   font_size=28, color=GREY_B)
        s1c = Text("    run_time=2.4, reverse_rate_function=False, introducer=True)",
                   font_size=28, color=GREY_B)
        sig1 = VGroup(s1a, s1b, s1c).arrange(DOWN, buff=0.08).next_to(title, DOWN, buff=0.4)
        a01 = Text("Typing...", font_size=50, color=BLUE).next_to(sig1, DOWN, buff=0.9)
        win.play(FadeIn(sig1, shift=DOWN), run_time=0.45)
        win.play(
            AddTextLetterByLetter(
                a01,                                   # 参数 text ✓（只支持 Text）
                suspend_mobject_updating=False,        # 参数 suspend_mobject_updating=False ✓
                int_func=np.ceil,                      # 参数 int_func=np.ceil ✓（到达即显示）
                rate_func=linear,                      # 参数 rate_func=linear ✓（匀速打字）
                time_per_char=0.25,                    # 参数 time_per_char=0.25 ✓（默认 0.1）
                run_time=2.4,                          # 参数 run_time=2.4 ✓（不传则按字符数自动算）
                reverse_rate_function=False,           # 参数 reverse_rate_function=False ✓
                introducer=True,                       # 参数 introducer=True ✓（播前加入场景）
            ),
        )
        win.play(Wait(0.3))
        win.play(FadeOut(sig1), FadeOut(a01), run_time=0.45)

        # —— 步骤 2：RemoveTextLetterByLetter(...) ——
        s2a = Text("RemoveTextLetterByLetter(txt, suspend_mobject_updating=False,",
                   font_size=28, color=GREY_B)
        s2b = Text("    int_func=np.ceil, rate_func=linear, time_per_char=0.2,",
                   font_size=28, color=GREY_B)
        s2c = Text("    run_time=2.0, reverse_rate_function=True, introducer=False,",
                   font_size=28, color=GREY_B)
        s2d = Text("    remover=True)", font_size=28, color=GREY_B)
        sig2 = VGroup(s2a, s2b, s2c, s2d).arrange(DOWN, buff=0.08).next_to(title, DOWN, buff=0.4)
        b01 = Text("Vanishing", font_size=50, color=RED).next_to(sig2, DOWN, buff=0.7)
        win.play(FadeIn(sig2, shift=DOWN), run_time=0.45)
        self.add(b01)                                  # 参数 introducer=False → 先手动放进场景
        win.play(
            RemoveTextLetterByLetter(
                b01,                                   # 参数 text ✓
                suspend_mobject_updating=False,        # 参数 suspend_mobject_updating=False ✓
                int_func=np.ceil,                      # 参数 int_func=np.ceil ✓
                rate_func=linear,                      # 参数 rate_func=linear ✓
                time_per_char=0.2,                     # 参数 time_per_char=0.2 ✓
                run_time=2.0,                          # 参数 run_time=2.0 ✓
                reverse_rate_function=True,            # 参数 reverse_rate_function=True ✓（与父类 False 不同）
                introducer=False,                      # 参数 introducer=False ✓（与父类 True 不同）
                remover=True,                          # 参数 remover=True ✓（播完移出场景）
            ),
        )
        win.play(FadeOut(sig2), run_time=0.45)
        win.play(Wait(0.3))

        win.play(FadeOut(title), run_time=0.5)
        win.close()
```

这段代码在做什么：先写标题，然后两段打字演示。第一段：蓝色 "Typing..." 按 `time_per_char=0.25` 一个字符一个字符蹦出来（`run_time=2.4` 覆盖自动时长）；第二段：红色 "Vanishing" 先 `self.add` 进场景（`introducer=False` 不会自动引入），再按 `reverse_rate_function=True` 从末尾一个字符一个字符消失，`remover=True` 播完整段文字移出场景。控制台跑完可以数一下：两段的字符数 × `time_per_char` 就是各自节奏。

<video src="assets/RTM output/01-逐字出现与消失.mp4" controls width="560"></video>

> 提醒：`RemoveTextLetterByLetter` 默认 `introducer=False`——**不先 `self.add(...)` 的话对象根本不在场景里**，动画空转；父类 `AddTextLetterByLetter` 则相反（`introducer=True` 自动引入）。两个类都**只支持 `Text`**，喂 `MathTex` 会出问题；`run_time` 想要"匀速打字"就按 `time_per_char * 字符数` 给足，给短了字符会挤在一起蹦。
