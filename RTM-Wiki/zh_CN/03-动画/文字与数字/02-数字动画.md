# 数字动画：ChangingDecimal / ChangeDecimalToValue

驱动 `DecimalNumber` 显示值变化的两个动画类——一个按任意函数取值，一个从当前值线性跳到目标值。

## 参数

### `ChangingDecimal` 

```python
ChangingDecimal(decimal_mob, number_update_func, suspend_mobject_updating=False, **kwargs)
```

按你给的函数 `f(alpha) -> 数值` 连续改变 `DecimalNumber` 显示的数（每帧 `set_value(f(rate_func(alpha)))`），可做任意时间-数值映射。非 `DecimalNumber` 输入抛 `TypeError`。**继承** `ChangingDecimal(Animation)`。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `decimal_mob` | `DecimalNumber` | — | 被动画的数字对象（必须是 `DecimalNumber`） |
| `number_update_func` | `Callable[[float], float]` | — | 输入进度 `alpha`，返回要显示的数值 |
| `suspend_mobject_updating` | `bool` | `False` | 是否挂起 updater（默认不挂起，便于与 `ValueTracker` 共存） |
| `**kwargs` | … | — | `Animation` 通用参数（`run_time`、`rate_func`…） |

> **返回**：`ChangingDecimal` 实例。

一行上手：

```python
number = DecimalNumber(0)
self.add(number)
win.play(ChangingDecimal(number, lambda a: 5 * a, run_time=3))
win.play(Wait(1))
```

### `ChangeDecimalToValue` 

```python
ChangeDecimalToValue(decimal_mob, target_number, **kwargs)
```

把 `DecimalNumber` **从当前值线性插值到目标值**（内部 `lambda a: interpolate(start, target, a)`），是最常用的"计数器跳到 X"写法。**继承** `ChangeDecimalToValue(ChangingDecimal)`。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `decimal_mob` | `DecimalNumber` | — | 被动画的数字对象 |
| `target_number` | `int` | — | 目标值；源码标注 `int`，实际走 `interpolate`，传浮点同样可用 |
| `**kwargs` | … | — | `ChangingDecimal` 的 `suspend_mobject_updating=False` 与 `Animation` 通用参数（如 `run_time=3`） |

> **返回**：`ChangeDecimalToValue` 实例。

一行上手：

```python
number = DecimalNumber(0)
self.add(number)
win.play(ChangeDecimalToValue(number, 10, run_time=3))
```

> 经验：要**长期**跟随 `ValueTracker` 显示数值，用 updater 更合适：`number.add_updater(lambda n: n.set_value(tracker.get_value()))`——本页成片第三段就是它。
>
> 手册本节只收录上述两个类。RTM 另导出 `TextDecimalNumber`（已支持，`real_time_manim.animations.text`），手册未收录其签名，本页不展开。

#### 样例：ChangingDecimal / ChangeDecimalToValue / ValueTracker 跟随

本页成片按 ChangingDecimal → ChangeDecimalToValue → ValueTracker+updater 的顺序各演示一段，参数逐条标在画面里。

```python
import os

from real_time_manim import (
    BLUE,
    GREEN,
    GREY_B,
    RED,
    DOWN,
    UP,
    ChangeDecimalToValue,
    ChangingDecimal,
    DecimalNumber,
    Scene,
    Text,
    ValueTracker,
    VGroup,
    linear,
)
from real_time_manim.vulkan_bind import (
    MLWindow,
    FadeIn,
    FadeOut,
    Wait,
    Write,
)
from real_time_manim.record import fast_record_scene  # noqa: F401  文件末尾 __main__ 使用


class Page_02_数字动画(Scene):
    def construct(self):
        win = MLWindow(1280, 720, hidden=True)   # 参数 w=1280 / h=720 / hidden=True
        win.scene = self                          # 参数 win.scene

        title = Text("ChangingDecimal / ChangeDecimalToValue",
                     font_size=34, color=GREEN).to_edge(UP)   #标题只用 ASCII：两引擎字体回退才稳
        win.play(Write(title), run_time=0.85)

        # —— 步骤 1：ChangingDecimal(decimal_mob, number_update_func, ...) ——
        s1a = Text("ChangingDecimal(num, lambda a: 5 * a,", font_size=30, color=GREY_B)
        s1b = Text("    suspend_mobject_updating=False, run_time=2.4,", font_size=30, color=GREY_B)
        s1c = Text("    rate_func=linear)", font_size=30, color=GREY_B)
        sig1 = VGroup(s1a, s1b, s1c).arrange(DOWN, buff=0.08).next_to(title, DOWN, buff=0.4)
        n01 = DecimalNumber(0, num_decimal_places=2, color=BLUE).next_to(sig1, DOWN, buff=0.9)
        win.play(FadeIn(sig1, shift=DOWN), run_time=0.45)
        self.add(n01)
        win.play(
            ChangingDecimal(
                n01,                                  # 参数 decimal_mob ✓（必须是 DecimalNumber）
                lambda a: 5 * a,                      # 参数 number_update_func ✓：f(alpha) -> 数值
                suspend_mobject_updating=False,       # 参数 suspend_mobject_updating=False ✓（可与 ValueTracker 共存）
                run_time=2.4,                         # 参数 **kwargs：run_time=2.4 ✓
                rate_func=linear,                     # 参数 **kwargs：rate_func=linear ✓
            ),
        )
        win.play(Wait(0.4))
        win.play(FadeOut(sig1), FadeOut(n01), run_time=0.45)

        # —— 步骤 2：ChangeDecimalToValue(decimal_mob, target_number, ...) ——
        s2a = Text("ChangeDecimalToValue(num, target_number=10,",
                   font_size=30, color=GREY_B)
        s2b = Text("    run_time=2.4, rate_func=linear,", font_size=30, color=GREY_B)
        s2c = Text("    suspend_mobject_updating=False)", font_size=30, color=GREY_B)
        sig2 = VGroup(s2a, s2b, s2c).arrange(DOWN, buff=0.08).next_to(title, DOWN, buff=0.4)
        n02 = DecimalNumber(0, num_decimal_places=2, color=RED).next_to(sig2, DOWN, buff=0.9)
        win.play(FadeIn(sig2, shift=DOWN), run_time=0.45)
        self.add(n02)
        win.play(
            ChangeDecimalToValue(
                n02,                                  # 参数 decimal_mob ✓
                10,                                   # 参数 target_number=10 ✓（源码标 int，浮点同样可用）
                run_time=2.4,                         # 参数 **kwargs：run_time=2.4 ✓
                rate_func=linear,                     # 参数 **kwargs：rate_func=linear ✓
                suspend_mobject_updating=False,       # 参数 **kwargs：继承 ChangingDecimal ✓
            ),
        )
        win.play(Wait(0.3))
        win.play(FadeOut(sig2), FadeOut(n02), run_time=0.45)

        # —— 步骤 3：页面「经验」——长期跟随用 ValueTracker + updater ——
        s3a = Text("tracker = ValueTracker(0)", font_size=30, color=GREY_B)
        s3b = Text("num.add_updater(lambda n: n.set_value(tracker.get_value()))",
                   font_size=30, color=GREY_B)
        s3c = Text("win.play(tracker.animate.set_value(7.5), run_time=2)",
                   font_size=30, color=GREY_B)
        sig3 = VGroup(s3a, s3b, s3c).arrange(DOWN, buff=0.08).next_to(title, DOWN, buff=0.4)
        tracker = ValueTracker(0)
        n03 = DecimalNumber(0, num_decimal_places=1, color=GREEN).next_to(sig3, DOWN, buff=0.9)
        n03.add_updater(lambda n: n.set_value(tracker.get_value()))
        win.play(FadeIn(sig3, shift=DOWN), run_time=0.45)
        self.add(n03)
        win.play(tracker.animate.set_value(7.5), run_time=2, rate_func=linear)
        n03.clear_updaters()
        win.play(FadeOut(sig3), FadeOut(n03), run_time=0.5)
        win.play(Wait(0.3))

        win.play(FadeOut(title), run_time=0.5)
        win.close()
```

这段代码在做什么：三段都是"数字在变"。

- 第一段：蓝色 `DecimalNumber` 用 `ChangingDecimal` 按 `lambda a: 5 * a` 从 0.00 匀速爬到 5.00（`rate_func=linear`，2.4 秒）。
- 第二段：红色数字用 `ChangeDecimalToValue` 从当前值直线跳到 10.00。
- 第三段演示长期跟随的写法——`ValueTracker` 从 0 推到 7.5，`num.add_updater(...)` 让绿色数字每帧读它的值（播完 `clear_updaters()` 解绑）。

前两段是"一次性"动画，第三段是"绑定关系"，这是本页最实用的一条经验。

> 提醒：
>
> - `ChangingDecimal`/`ChangeDecimalToValue` 只吃 `DecimalNumber`，喂别的类型抛 `TypeError`。
> - 它们是**一次性**动画：播完数字就停在终点，别指望继续跟随。
> - 要"数字一直跟着某个量"，用第三段的 `add_updater` 写法，并记得解绑前 `clear_updaters()`；否则后续 `FadeOut` 等操作还会被 updater 拉回旧值。
