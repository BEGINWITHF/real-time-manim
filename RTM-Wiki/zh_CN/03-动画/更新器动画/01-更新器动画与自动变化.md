# 更新器动画与更新工具：UpdateFromFunc 等

这三个动画类都在播放期间用每帧回调驱动对象状态。

它们来自 manim 自己的 `animation/updaters/update.py`——不在 RTM 的 `vulkan_bind` 导出清单里，但 RTM 的渲染钩子照常接管。已渲染验证，两引擎逐帧对齐。

12.1 更新工具函数与自动变化对象见 [01b-更新工具与自动变化](01b-更新工具与自动变化.md)。

## 参数

### `UpdateFromFunc` 

```python
UpdateFromFunc(mobject, update_function, suspend_mobject_updating=False, **kwargs)
```

播放期间**每帧调用 `update_function(mobject)`** 驱动对象状态，适合"一个对象的状态依赖另一个正在运动的对象"的场景（例：一条线始终连接两个移动的点）。

它的 `rate_func` 不会传给函数，做什么由函数自己决定。**继承** `UpdateFromFunc(Animation)`。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `Mobject` | — | 被驱动的对象 |
| `update_function` | `Callable[[Mobject], Any]` | — | 每帧调用，参数就是该 mobject |
| `suspend_mobject_updating` | `bool` | `False` | 是否挂起它自带的 updater（**保持 `False`** 才能与本动画并存） |
| `**kwargs` | … | — | `Animation` 通用参数（`run_time` 必须显式给，否则 1 秒后停止调用） |

> **返回**：`UpdateFromFunc` 实例。

一行上手：

```python
dot = Dot()
label = Text("hi").next_to(dot, UP)
self.add(dot, label)
win.play(dot.animate.shift(RIGHT * 3),
          UpdateFromFunc(label, lambda l: l.next_to(dot, UP), run_time=3),
          rate_func=linear)
```

### `UpdateFromAlphaFunc` 

```python
UpdateFromAlphaFunc(mobject, update_function, suspend_mobject_updating=False, **kwargs)
```

同上，但回调多收一个**进度参数**：`update_function(mobject, rate_func(alpha))`。`alpha` 从 0 到 1 单调前进，适合"按进度插值到某个状态"。**继承** `UpdateFromAlphaFunc(UpdateFromFunc)`——**无自己的 `__init__`**，只重写了插值方式。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `Mobject` | — | 被驱动的对象 |
| `update_function` | `Callable[[Mobject, float], Any]` | — | 第二参数为经 `rate_func` 处理的进度 |
| `suspend_mobject_updating` | `bool` | `False` | 是否挂起自带 updater |
| `**kwargs` | … | — | `Animation` 通用参数 |

> **返回**：`UpdateFromAlphaFunc` 实例。

一行上手：

```python
sq = Square()
self.add(sq)
win.play(UpdateFromAlphaFunc(sq, lambda m, a: m.set_fill(RED, opacity=a), run_time=2))
```

### `MaintainPositionRelativeTo` 

```python
MaintainPositionRelativeTo(mobject, tracked_mobject, **kwargs)
```

播放期间保持 `mobject` 与 `tracked_mobject` 之间**开始时的相对位移**不变：后者动，前者跟。无 docstring，依据源码整理。**继承** `MaintainPositionRelativeTo(Animation)`。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `Mobject` | — | 跟随者 |
| `tracked_mobject` | `Mobject` | — | 被跟随者 |
| `**kwargs` | … | — | `Animation` 通用参数 |

> **返回**：`MaintainPositionRelativeTo` 实例。

一行上手：

```python
a, b = Dot(LEFT * 2), Dot(RIGHT * 2)
self.add(a, b)
win.play(a.animate.shift(UP * 2), MaintainPositionRelativeTo(b, a, run_time=2))
```

#### 样例：UpdateFromFunc / UpdateFromAlphaFunc / MaintainPositionRelativeTo 逐项演示

本页成片按 UpdateFromFunc → UpdateFromAlphaFunc → MaintainPositionRelativeTo 的顺序各演示一段，参数逐条标在画面里。

```python
import os

from real_time_manim import (
    GREEN,
    GREY_B,
    PURPLE,
    RED,
    DOWN,
    LEFT,
    RIGHT,
    UP,
    Dot,
    Scene,
    Square,
    Text,
    UpdateFromAlphaFunc,
    UpdateFromFunc,
    MaintainPositionRelativeTo,
    VGroup,
    linear,
)
from real_time_manim.vulkan_bind import (
    MLWindow,
    FadeIn,
    FadeOut,
    Write,
)
from real_time_manim.record import fast_record_scene  # noqa: F401  文件末尾 __main__ 使用


class Page_01_更新器动画与自动变化(Scene):
    def construct(self):
        win = MLWindow(1280, 720, hidden=True)   # 参数 w=1280 / h=720 / hidden=True
        win.scene = self                          # 参数 win.scene

        title = Text("UpdateFromFunc / UpdateFromAlphaFunc / MaintainPositionRelativeTo",
                     font_size=24, color=GREEN).to_edge(UP)   #标题只用 ASCII：两引擎字体回退才稳
        win.play(Write(title), run_time=0.85)

        # —— 步骤 1：UpdateFromFunc(mobject, update_function, suspend..., run_time) ——
        s1a = Text("UpdateFromFunc(label, lambda l: l.next_to(dot, UP),",
                   font_size=28, color=GREY_B)
        s1b = Text("    suspend_mobject_updating=False, run_time=2.4)",
                   font_size=28, color=GREY_B)
        sig1 = VGroup(s1a, s1b).arrange(DOWN, buff=0.08).next_to(title, DOWN, buff=0.4)
        dot = Dot(radius=0.12, color=RED).next_to(sig1, DOWN, buff=1.1).shift(LEFT * 3.5)
        label = Text("hi", font_size=40, color=RED).next_to(dot, UP, buff=0.3)
        win.play(FadeIn(sig1, shift=DOWN), run_time=0.45)
        self.add(dot, label)
        win.play(                                    # 参数 mobject=dot + 每帧驱动 label
            dot.animate.shift(RIGHT * 7),
            UpdateFromFunc(
                label,                               # 参数 mobject ✓
                lambda l: l.next_to(dot, UP),        # 参数 update_function ✓（每帧调用）
                suspend_mobject_updating=False,      # 参数 suspend_mobject_updating=False ✓
                run_time=2.4,                        # 参数 **kwargs：run_time=2.4 ✓（必须显式给）
            ),
            rate_func=linear,
        )
        win.play(FadeOut(sig1), FadeOut(dot), FadeOut(label), run_time=0.45)

        # —— 步骤 2：UpdateFromAlphaFunc(mobject, update_function, ...) ——
        s2a = Text("UpdateFromAlphaFunc(sq, lambda m, a: m.set_fill(RED, opacity=a),",
                   font_size=26, color=GREY_B)
        s2b = Text("    suspend_mobject_updating=False, run_time=2.0)",
                   font_size=26, color=GREY_B)
        sig2 = VGroup(s2a, s2b).arrange(DOWN, buff=0.08).next_to(title, DOWN, buff=0.4)
        sq = Square(side_length=2.0, color=GREEN).next_to(sig2, DOWN, buff=0.6)
        win.play(FadeIn(sig2, shift=DOWN), run_time=0.45)
        self.add(sq)
        win.play(
            UpdateFromAlphaFunc(
                sq,                                   # 参数 mobject ✓
                lambda m, a: m.set_fill(RED, opacity=a),   # 参数 update_function ✓（多收一个进度参数）
                suspend_mobject_updating=False,       # 参数 suspend_mobject_updating=False ✓
                run_time=2.0,                         # 参数 **kwargs：run_time=2.0 ✓
            ),
        )
        win.play(FadeOut(sig2), FadeOut(sq), run_time=0.45)

        # —— 步骤 3：MaintainPositionRelativeTo(mobject, tracked_mobject, **kwargs) ——
        s3a = Text("MaintainPositionRelativeTo(b, a, run_time=2.2)",
                   font_size=30, color=GREY_B)
        sig3 = s3a.next_to(title, DOWN, buff=0.4)
        a = Dot(radius=0.14, color=GREEN).next_to(sig3, DOWN, buff=1.1).shift(LEFT * 2)
        b = Dot(radius=0.14, color=PURPLE).next_to(a, RIGHT, buff=1.2)
        win.play(FadeIn(sig3, shift=DOWN), run_time=0.45)
        self.add(a, b)
        win.play(                                    # 参数 mobject=b / tracked_mobject=a
            a.animate.shift(RIGHT * 2.5 + DOWN * 0.9),
            MaintainPositionRelativeTo(
                b,                                   # 参数 mobject（跟随者）✓
                a,                                   # 参数 tracked_mobject（被跟随者）✓
                run_time=2.2,                        # 参数 **kwargs：run_time=2.2 ✓
            ),
            rate_func=linear,
        )
        win.play(FadeOut(sig3), FadeOut(a), FadeOut(b), run_time=0.5)

        win.play(FadeOut(title), run_time=0.5)
        win.close()
```

这段代码在做什么：三段都是"每帧回调"。

- 第一段：红点从左往右走 7 个单位，`UpdateFromFunc` 让 "hi" 标签每帧重新 `next_to(dot, UP)` 贴着它走——回调只收对象，干什么由它自己决定。
- 第二段：绿方块用 `UpdateFromAlphaFunc` 按进度 `a` 把填充改成红色（`opacity=a` 从透明渐显到实心）。
- 第三段：绿点动，紫点用 `MaintainPositionRelativeTo` 保持初始相对位移跟着走。

三段回调都是 `suspend_mobject_updating=False`，与对象自带 updater 并存。

> 提醒：
>
> - `UpdateFromFunc` 的 `run_time` **必须显式给**。不给的话，内部默认 1 秒就停止调用回调，你的对象会停在半路。
> - `suspend_mobject_updating` 保持 `False`。传 `True` 会把对象自带的 updater 一起挂起，"每帧驱动"就断了。
> - `UpdateFromAlphaFunc` 的回调多收一个进度参数（已经过 `rate_func` 处理），写错签名会在第一帧就抛异常。
