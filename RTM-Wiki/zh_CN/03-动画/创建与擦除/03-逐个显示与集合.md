# 逐个显示子对象：ShowIncreasingSubsets / ShowSubmobjectsOneByOne / SpiralIn

这一节讲"逐个显示子对象"收录的三个类，它们都作用于容器的每个子对象：

- `ShowIncreasingSubsets`：一个接一个蹦出，且之前的都留下。
- `ShowSubmobjectsOneByOne`：同一时刻只显示一个。
- `SpiralIn`：沿螺旋轨迹飞入。

## 参数

### `ShowIncreasingSubsets`

```python
ShowIncreasingSubsets(group, suspend_mobject_updating=False, int_func=np.floor,
                      reverse_rate_function=False, **kwargs)
```

继承 `ShowIncreasingSubsets(Animation)`。它按节拍**一个接一个显示子对象，且之前显示的都留在屏幕上**（透明度从 0 跳到 1，是"逐个蹦出"而不是淡入）。

**注意**：构造时就会立刻把所有子对象 `set_opacity(0)`，所以要么先 `self.add(group)` 再构造，要么确保它只在 `play` 时才进场景。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `group` | `Mobject` | —（必填） | 被逐个显示的容器（`VGroup` 等） |
| `suspend_mobject_updating` | `bool` | `False` | **不建议改**：默认不挂起 updater（透明度由外部控制） |
| `int_func` | `Callable` | `np.floor` | 把连续进度取整成"已显示个数"的函数。**能填** `np.floor`/`np.ceil`/自定义可调用 |
| `reverse_rate_function` | `bool` | `False` | `True` 时倒着收（从全部显示到逐个消失） |
| 其余 | — | — | `Animation` 通用参数（`lag_ratio` 在此类中由 `int_func` 代替发挥作用） |

> **返回**：`ShowIncreasingSubsets` 实例。

#### 样例：四个形状按节拍逐个蹦出，之前的都留下

一行四个形状先 `self.add` 进场景，再把五个参数逐个点名——`int_func=np.floor` 把进度取整成"已显示个数"，形状一个接一个蹦出且都留在屏幕上。

```python
import numpy as np
from real_time_manim import Scene, Text, VGroup, Circle, Square, Triangle, BLUE, \
    GREEN, GREY_B, ORANGE, RED, YELLOW, UP, DOWN, RIGHT, FadeIn, \
    ShowIncreasingSubsets, Write
from real_time_manim.vulkan_bind import MLWindow, Wait

class IncreasingSubsetsDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("03-ShowIncreasingSubsets", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        l1 = Text("ShowIncreasingSubsets(group, suspend_mobject_updating=False,",
                  font_size=30, color=GREY_B)
        l2 = Text("    int_func=np.floor, reverse_rate_function=False)",
                  font_size=30, color=GREY_B)
        lab1 = VGroup(l1, l2).arrange(DOWN, buff=0.06).next_to(title, DOWN, buff=0.4)   #两行签名标签
        g1 = VGroup(Circle(radius=0.35, color=BLUE),
                    Square(side_length=0.9, color=GREEN),
                    Triangle(color=ORANGE).scale(0.6),
                    Circle(radius=0.35, color=RED),
                    ).arrange(RIGHT, buff=0.7).next_to(lab1, DOWN, buff=0.6)   #被逐个显示的四个形状
        win.play(FadeIn(lab1, shift=DOWN), run_time=0.4)   #标签从下方淡入
        self.add(g1)   #构造时就把子对象 set_opacity(0)，先加入场景
        win.play(
            ShowIncreasingSubsets(                  #参数 “group”
                g1,
                suspend_mobject_updating=False,     #参数 “suspend_mobject_updating”
                int_func=np.floor,                  #参数 “int_func”：已显示个数取整
                reverse_rate_function=False,        #参数 “reverse_rate_function”
                run_time=2.0,                       #参数 “run_time”
            ),
            run_time=2.0,
        )
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：四个形状排好行，`self.add(g1)` 先把它们放进场景（构造 `ShowIncreasingSubsets` 时它就把子对象 `set_opacity(0)` 了），再 `ShowIncreasingSubsets(g1, suspend_mobject_updating=False, int_func=np.floor, reverse_rate_function=False, run_time=2.0)` 按节拍播。`int_func=np.floor` 把连续进度取整成"已显示个数"，形状一个接一个蹦出来，之前蹦出的都留在屏幕上。

<video src="assets/RTM output/03-逐个显示与集合-increasing_subsets.mp4" controls width="560"></video>

> 提醒：`ShowIncreasingSubsets` 构造时就把所有子对象 `set_opacity(0)`——样例里 `self.add(g1)` 那行就是"先加场景、再播动画"的用意，漏了这行对象上屏就是隐身状态。

### `ShowSubmobjectsOneByOne`

```python
ShowSubmobjectsOneByOne(group, int_func=np.ceil, **kwargs)
```

继承 `ShowSubmobjectsOneByOne(ShowIncreasingSubsets) ← Animation`。它与 `ShowIncreasingSubsets` 相反——**同一时刻只显示一个**子对象，前面的自动隐藏（"轮流闪现"）。构造时会把传入的可迭代对象包成 `Group`。这个类不在 RTM 导出清单中，随自带 ManimCE 从 `real_time_manim` 导入，实测可播。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `group` | `Iterable[Mobject]` | —（必填） | 子对象可迭代容器（内部转成 `Group`） |
| `int_func` | `Callable` | `np.ceil` | 进度取整函数。**能填**同上 |
| 其余 | — | — | 继承 `ShowIncreasingSubsets` 的 `suspend_mobject_updating=False`、`reverse_rate_function=False` 与 `Animation` 通用参数 |

> **返回**：`ShowSubmobjectsOneByOne` 实例。

#### 样例：同一时刻只亮一个，四个形状轮流闪现

同一批形状换成 `ShowSubmobjectsOneByOne(g2, int_func=np.ceil, run_time=2.0)`——`int_func=np.ceil` 与上一个正好相反，同一时刻只亮一个、前面的自动隐藏。同样先 `self.add` 再播。

```python
import numpy as np
from real_time_manim import Scene, Text, VGroup, Circle, Square, Triangle, BLUE, \
    RED, YELLOW, GREEN, GREY_B, UP, DOWN, RIGHT, FadeIn, \
    ShowSubmobjectsOneByOne, Write
from real_time_manim.vulkan_bind import MLWindow, Wait

class OneByOneDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("03-ShowSubmobjectsOneByOne", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        l3 = Text("ShowSubmobjectsOneByOne(group, int_func=np.ceil, run_time=2.0)",
                  font_size=30, color=GREY_B).next_to(title, DOWN, buff=0.4)   #签名标签
        g2 = VGroup(Circle(radius=0.35, color=YELLOW),
                    Square(side_length=0.9, color=RED),
                    Triangle(color=BLUE).scale(0.6),
                    Circle(radius=0.35, color=GREEN),
                    ).arrange(RIGHT, buff=0.7).next_to(l3, DOWN, buff=0.6)   #轮流闪现的四个形状
        win.play(FadeIn(l3, shift=DOWN), run_time=0.4)   #标签从下方淡入
        self.add(g2)   #构造时就置 0，先加入场景
        win.play(
            ShowSubmobjectsOneByOne(                #参数 “group”
                g2,
                int_func=np.ceil,                   #参数 “int_func”：取整函数
                run_time=2.0,                       #参数 “run_time”
            ),
            run_time=2.0,
        )
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：同一批形状换成 `ShowSubmobjectsOneByOne(g2, int_func=np.ceil, run_time=2.0)`。`int_func=np.ceil` 把进度一取整就是"当前该亮第 N 个"，同一时刻只亮一个子对象、前面的自动隐藏，四个形状轮流闪现。它继承 `ShowIncreasingSubsets`，构造时同样把子对象置 0，所以前面也要 `self.add(g2)`。

> 提醒：`ShowSubmobjectsOneByOne` 不在 RTM 导出清单里，从 `real_time_manim` 导入（见代码块），实测可播；`int_func` 换成别的可调用函数，取整规则就跟着换。

### `SpiralIn`

```python
SpiralIn(shapes, scale_factor=8, fade_in_fraction=0.3, **kwargs)
```

继承 `SpiralIn(Animation)`。`shapes` 的**每个子对象**从"以整体中心为基准放大 `scale_factor` 倍的位置"沿**螺旋轨迹**飞入到位，同时在前 `fade_in_fraction` 的进度里淡入，适合作为一组图形的花式出场。

**坑**：构造函数**会立刻移动子对象**（把它们搬到螺旋起点），所以不要提前 `self.add(shapes)`。本页 demo 从 `real_time_manim` 顶层导入，因此能以 introducer 身份在播放时进入场景。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `shapes` | `Mobject` | —（必填） | 被动画的容器；**每个子对象单独飞入** |
| `scale_factor` | `float` | `8` | 起始位置相对整体中心的外扩倍数。**能填**任意正数（越大飞得越远） |
| `fade_in_fraction` | `float` | `0.3` | 前多少进度用于淡入。**能填** `0`~`1` |
| `introducer` | `bool` | `False` | RTM 自有版**可传**（走 `Animation` 默认 `False`、显式传 `True` 生效）
| 其余 | — | — | `Animation` 通用参数 |

> **返回**：`SpiralIn` 实例。

#### 样例：四个形状沿螺旋轨迹飞入到位

`samples` 里 `scale_factor=6` 非默认（默认 8），`fade_in_fraction=0.3` 前 30% 同时淡入；这一段**不**提前 `self.add`。

```python
from real_time_manim import Scene, Text, VGroup, Circle, Square, Triangle, BLUE, \
    GREEN, GREY_B, ORANGE, RED, YELLOW, UP, DOWN, RIGHT, FadeIn, SpiralIn, \
    Write
from real_time_manim.vulkan_bind import MLWindow, Wait

class SpiralInDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("03-SpiralIn", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        l5 = Text("SpiralIn(shapes, scale_factor=6, fade_in_fraction=0.3,",
                  font_size=30, color=GREY_B)
        l6 = Text("        run_time=1.8)",
                  font_size=30, color=GREY_B)
        lab3 = VGroup(l5, l6).arrange(DOWN, buff=0.06).next_to(title, DOWN, buff=0.4)   #两行签名标签
        g3 = VGroup(Circle(radius=0.4, color=GREEN),
                    Square(side_length=1.0, color=BLUE),
                    Triangle(color=RED).scale(0.7),
                    Circle(radius=0.4, color=ORANGE),
                    ).arrange(RIGHT, buff=0.7).next_to(lab3, DOWN, buff=0.6)   #沿螺旋飞入的四个形状
        win.play(FadeIn(lab3, shift=DOWN), run_time=0.4)   #标签从下方淡入
        #不提前 add：SpiralIn 构造时把子对象搬到螺旋起点，以 introducer 身份进场景
        win.play(
            SpiralIn(g3,                            #参数 “shapes”
                     scale_factor=6,                #参数 “scale_factor”：非默认 8
                     fade_in_fraction=0.3,          #参数 “fade_in_fraction”
                     run_time=1.8),                 #参数 “run_time”
            run_time=1.8,
        )
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：`SpiralIn(g3, scale_factor=6, fade_in_fraction=0.3, run_time=1.8)` 让四个形状各自从"以整体中心为基准外扩 6 倍"的位置沿螺旋轨迹飞入到位，前 30% 的进度里同时淡入。注意这一段没有提前 `self.add`——`SpiralIn` 构造时就把子对象搬到了螺旋起点，让它以 introducer 身份在播放时进场景。

<video src="assets/RTM output/03-逐个显示与集合-spiral_in.mp4" controls width="560"></video>

> 提醒：`SpiralIn` 和前两个正相反——**不要**提前 `self.add`（构造时它会把子对象搬到螺旋起点，提前加会把起点位置直接摆上屏）。

无法演示：

- `introducer`：RTM 自有 `SpiralIn` **可传**；`ShowIncreasingSubsets` 无该形参，两版一致。
- mobject 类型校验：RTM 自有版不做类型校验。
