# 反向擦除：Uncreate / Unwrite / Add

这一节讲"反向擦除"收录的类：

- `Uncreate`：`Create` 的倒放。
- `Unwrite`：模拟手擦文字。
- `Add`："放进场景"的动画版——它不擦东西，但和上面两个一样靠动画控制对象进出场景，还能排进时间轴。

## 参数

### `Uncreate` 

```python
Uncreate(mobject, run_time=1.0, lag_ratio=1.0, remover=True,
         rate_func=None, reverse_rate_function=True, **kwargs)
```

继承 `Uncreate(Create)`。它是 `Create` 的倒放：把已经画好的对象**沿笔画倒着擦掉**，并默认在结束后把对象从场景移除。与 `FadeOut` 的区别在于：它是"逆向重画"，会露出笔画路径；`FadeOut` 则是整体透明度渐隐。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `VMobject` | —（必填） | 要擦掉的矢量对象 |
| `reverse_rate_function` | `bool` | `True` | 倒放。2026-10-16 起默认走 CE 的 `smooth(1-t)` 曲线（该形参显式可传），不再是线性倒放 |
| `remover` | `bool` | `True` | 播完从场景移除；**不建议改**成 `False`（擦完了还留在场景里通常不是你要的） |
| `introducer` | `bool` | `False` | RTM 版**可传**（走 `Animation` 默认 `False`，显式传 `True` 生效）
| `run_time` / `lag_ratio` | `float` | `1.0` / `1.0` | 与 `Create` 同默认 |
| 其余 | — | — | `Create`/`Animation` 通用参数（`rate_func=smooth` 等） |

> **返回**：`Uncreate` 实例。

#### 样例：先画后擦，沿笔画倒着擦掉

先用 `Create` 把蓝方块画好，再把 `Uncreate` 五个参数逐个点名倒放擦除，播完移出场景。

```python
from real_time_manim import Scene, Text, Square, VGroup, BLUE, YELLOW, GREY_B, UP, DOWN, \
    smooth, Create, FadeIn, Uncreate, Write
from real_time_manim.vulkan_bind import MLWindow, Wait

class UncreateDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("02-Uncreate", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        l1 = Text("Uncreate(mobject, reverse_rate_function=True, remover=True,",
                  font_size=30, color=GREY_B)
        l2 = Text("         lag_ratio=1.0, run_time=1.2, rate_func=smooth)",
                  font_size=30, color=GREY_B)
        lab1 = VGroup(l1, l2).arrange(DOWN, buff=0.06).next_to(title, DOWN, buff=0.4)   #两行 “Uncreate” 签名标签
        sq = Square(side_length=1.6, color=BLUE).next_to(lab1, DOWN, buff=0.6)   #先画后擦的蓝方块
        win.play(FadeIn(lab1, shift=DOWN), run_time=0.4)   #标签从下方淡入
        win.play(Create(sq, run_time=1.0), run_time=1.0)   #先把方块画好
        win.play(
            Uncreate(sq,                            #参数 “mobject”
                     reverse_rate_function=True,    #参数 “reverse_rate_function”：倒放
                     remover=True,                  #参数 “remover”：擦完移出场景
                     lag_ratio=1.0,                 #参数 “lag_ratio”
                     run_time=1.2,                  #参数 “run_time”
                     rate_func=smooth),             #参数 “rate_func”
            run_time=1.2,
        )
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：先 `Create(sq, run_time=1.0)` 把蓝方块画完整，再 `Uncreate(sq, reverse_rate_function=True, remover=True, lag_ratio=1.0, run_time=1.2, rate_func=smooth)` 沿着同一笔画倒着往回擦——画面上是"一笔一笔消失"，擦完整块移出场景。倒放是 `reverse_rate_function=True` 给的（默认就是它，这里逐个点名只为看清楚）。

### `Unwrite` 

```python
Unwrite(mobject, rate_func=linear, reverse=True, run_time=1.0, **kwargs)
```

继承 `Unwrite(Write) ← DrawBorderThenFill(Animation)`。它模拟"手擦掉"文字/图形：画面**从完整 → 消失**（`_apply_two_phase` 里手工算 `rate_func(1 - sub_alpha)`）。

`reverse` 只决定**从哪一头开始擦**——`True`（默认）先擦最后一个子对象，`False` 从第一个子对象开始擦。`run_time` **显式默认 `1.0`**（RTM 版不走 `Write` 的"按长度自动取值"），`lag_ratio` 未传时仍按 `min(4/length, 0.2)` 自动取。

继承来的 `DrawBorderThenFill.interpolate` **会读 `reverse_rate_function`**（先翻转 `alpha` 再交给上面的倒转计算），所以传 `True` 会把画面再倒一次。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `VMobject` | —（必填） | 被擦除的对象 |
| `rate_func` | `Callable` | `linear` | **不建议改**：匀速擦除最符合"手擦"直觉 |
| `reverse` | `bool` | `True` | `True`：从最后一个子对象开始擦；`False`：从第一个开始。RTM 版 `reverse` **不再连带 `remover`**（`remover` 见下一行） |
| `run_time` | `float` | `1.0` | **能填**任意正数。RTM 版**默认值写死 `1.0`**，不按长度自动取 |
| `lag_ratio` | `float \| None` | `None`（→ 自动） | **能填** `0`~`1`；不传自动取 `min(4/max(1,length), 0.2)` |
| `remover` | `bool` | `False` | RTM 版**默认恒为 `False`**，且**不再随 `reverse` 联动**。RTM 侧把笔画/子对象进度置 0 让它看不见，但 `Unwrite` 没有自己的 `clean_up_from_scene`（基类是 `pass`），所以**播完不从场景摘除**——即便显式传 `remover=True` 也摘不掉，只是属性值变了 |
| `reverse_rate_function` | `bool` | `False` | 实测**有效**（继承的 `DrawBorderThenFill.interpolate` 会先按它翻转 `alpha` 再交给倒转计算）：默认 `False` = 从完整擦到消失；传 `True` 等于再倒一次、画面变回"从无到有"。RTM 自有版默认 `False`、ManimCE 版默认 `True`（两版默认值相反）；本页 `unwrite` 成片用的是**顶层导入的 CE 版**（见上方"导入"提醒），所以与 CE 逐帧对齐，不代表 RTM 自有版的中间帧也逐帧一致 |
| 其余 | — | — | `Write`/`DrawBorderThenFill`/`Animation` 通用参数 |

> **返回**：`Unwrite` 实例。

#### 样例：linear 匀速手擦，reverse=False 从头擦

先写出 "Goodbye Manim"，再用非默认的 `reverse=False` 从第一个字母开始手擦，`run_time`/`lag_ratio` 显式覆盖自动值。

```python
from real_time_manim import Scene, Text, VGroup, GREEN, YELLOW, GREY_B, UP, DOWN, \
    linear, FadeIn, Unwrite, Write
from real_time_manim.vulkan_bind import MLWindow, Wait

class UnwriteDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("02-Unwrite", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        l3 = Text("Unwrite(vmobject, rate_func=linear, reverse=False,",
                  font_size=30, color=GREY_B)
        l4 = Text("        run_time=1.4, lag_ratio=0.2)",
                  font_size=30, color=GREY_B)
        lab2 = VGroup(l3, l4).arrange(DOWN, buff=0.06).next_to(title, DOWN, buff=0.4)   #两行 “Unwrite” 签名标签
        txt = Text("Goodbye Manim", font_size=44, color=GREEN).next_to(lab2, DOWN, buff=0.6)   #先写后擦的字
        win.play(FadeIn(lab2, shift=DOWN), run_time=0.4)   #标签从下方淡入
        win.play(Write(txt, rate_func=linear, run_time=1.0), run_time=1.0)   #先把字写好
        win.play(
            Unwrite(txt,                            #参数 “vmobject”
                    rate_func=linear,               #参数 “rate_func”：匀速手擦
                    reverse=False,                  #参数 “reverse”：非默认，从头擦起
                    run_time=1.4,                   #参数 “run_time”
                    lag_ratio=0.2),                 #参数 “lag_ratio”
            run_time=1.4,
        )
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：先 `Write(txt, rate_func=linear, run_time=1.0)` 写出 "Goodbye Manim"，再 `Unwrite(txt, rate_func=linear, reverse=False, run_time=1.4, lag_ratio=0.2)` 手擦回去；`reverse=False` 是非默认方向——从**第一个**子对象擦起（默认 `True` 从最后一个擦起）。RTM 自有版播完**不**自动移出场景（`remover` 恒 `False`，只把进度置 0），所以字擦完仍留在画面上。

<video src="assets/RTM output/02-反向擦除-unwrite.mp4" controls width="560"></video>

> 提醒：`Unwrite` 的倒转是类内手工 `rate_func(1-alpha)` 算的。`reverse_rate_function` 虽不是 `Unwrite` 自己的形参，但继承链会读到它：默认 `False` 就是从完整擦到消失，传 `True` 会再倒一次（见参数表）。`run_time` 在 RTM 自有版**默认写死 `1.0`**、不按长度自动取；`lag_ratio` 不传仍自动。
>
> 本页 demo 的 `Uncreate` / `Unwrite` / `Create` / `Write` 是从 `real_time_manim` **顶层**导入的；**RTM 自有版须 `from real_time_manim.vulkan_bind import`**，两版有几处默认值相反。样例显式给了 `run_time=1.4, lag_ratio=0.2` 且 `reverse=False`，画面方向一致。

### `Add` 

```python
Add(*mobjects, run_time=0.0, **kwargs)
```

继承 `Add(Animation)`。它是把一个或多个 mobject **瞬间放进场景**的动画版本，等价于 `Scene.add`，但因为是动画，所以能被 `Succession`/`AnimationGroup` 组合、能排时间轴。多个 mobject 会被合成一个 `Group`；默认 `run_time=0.0` 即"插入即完成"，给 `run_time>0` 就变成"放进去之后停留这么久"。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `*mobjects` | `Mobject` | —（必填） | 一个或多个；多于 1 个时内部包成 `Group` |
| `run_time` | `float` | `0.0` | 加入后的停留时长（插入本身是瞬时的）。**能填** `0` 或任意正数 |
| `introducer` | `bool` | `False` | RTM 自有 `Add` **未固定**该形参（走 `Animation` 默认 `False`、显式传 `True` 生效）
| 其余 | — | — | `Animation` 通用参数 |

> **返回**：`Add` 实例。

#### 样例：Succession 排时间轴，瞬间加入 vs 停留半秒

黄框里三个点分两批进场景：绿点 `run_time=0.0` 瞬间加入，隔 0.4 秒红蓝两点包成 `Group` 一起加入并停留半秒——全部排在一条 `Succession` 时间轴上。

```python
from real_time_manim import Scene, Text, Rectangle, Circle, BLUE, GREEN, RED, YELLOW, \
    GREY_B, UP, DOWN, LEFT, RIGHT, Create, FadeIn, Write
from real_time_manim.vulkan_bind import MLWindow, Wait, Succession, Add

class AddDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("02-Add", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        l5 = Text("Add(*mobjects, run_time=0.0 instant / 0.5 hold) in Succession",
                  font_size=30, color=GREY_B).next_to(title, DOWN, buff=0.4)   #签名标签
        rect = (Rectangle(width=3.4, height=1.4, color=YELLOW)
                .next_to(l5, DOWN, buff=0.6))   #装点的黄框
        dot_a = Circle(radius=0.16, color=GREEN).move_to(rect.get_left() + RIGHT * 0.7)   #第一个被加入的点
        dot_b = Circle(radius=0.16, color=RED).move_to(rect.get_center() + RIGHT * 0.7)   #第二个被加入的点
        dot_c = Circle(radius=0.16, color=BLUE).move_to(rect.get_right() + LEFT * 0.7)   #与 “dot_b” 同组加入
        win.play(FadeIn(l5, shift=DOWN), run_time=0.4)   #标签从下方淡入
        win.play(Create(rect, run_time=0.8), run_time=0.8)   #画出黄框
        win.play(
            Succession(
                Add(dot_a, run_time=0.0),           #参数 “run_time=0.0”：瞬间加入
                Wait(0.4),                          #间隔 0.4s
                Add(dot_b, dot_c, run_time=0.5),    #多于 1 个包成 Group，run_time=0.5 停留半秒
            ),
        )
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：画好黄框后，一条 `Succession` 排三步——`Add(dot_a, run_time=0.0)` 让绿点瞬间进场景（插入即完成），`Wait(0.4)` 隔 0.4 秒，`Add(dot_b, dot_c, run_time=0.5)` 把红蓝两点包成 `Group` 一起加入、加入后停留半秒。三色点各自到自己的槽位才出现，正好对照 `run_time=0`（瞬间）与 `run_time>0`（加入后停留）两种用法。

<video src="assets/RTM output/02-反向擦除-add.mp4" controls width="560"></video>

> 提醒：两个及以上 mobject 会被 `Add` 包成 `Group`，当作一个动画播（样例里 `dot_b`、`dot_c` 就是）。
>
> 本页 demo 沿用从 `real_time_manim.vulkan_bind` 导入 `Add` / `Succession` 的写法。原先"manim `Succession` 装 RTM `Wait` 报 `TypeError`、manim `Add` 不登记进场景"的互操作问题**已修复**（`window/patches.py`：`prepare_animation` 在 composition/scene 模块重绑定 + `_RtmAnimationAdapter` 语义桥接 + manim `Add` 识别，测试 `tests/test_gap_interop.py`），现从 `manim` 导入两者同样可用。`win.play(Add(x))` 直接播等价于 `self.add(x)`，但能吃 `run_time`。
