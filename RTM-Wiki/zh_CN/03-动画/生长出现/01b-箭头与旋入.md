# 生长出现：GrowArrow / SpinInFromNothing

Grow 家族的两个特化成员：`GrowArrow` 让箭头从起点长向箭尖，`SpinInFromNothing` 让对象边旋转边长大。

## 参数

### `GrowArrow`

```python
GrowArrow(arrow, point_color=None, **kwargs)
```

箭头**从起点长向箭尖**（起点 `scale(0)` 并 `move_to(arrow.get_start)`，由渲染端的 `_grow_scale` / `_grow_point` 通道完成，因此箭头尖端始终朝向目标方向生长），是画箭头/向量的标准出场方式。继承 `GrowArrow(Animation)`。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `arrow` | `Arrow` | —（必填） | 出场的箭头对象 |
| `point_color` | `ParsableManimColor \| None` | `None` | 起始颜色；`None` 沿用对象自身颜色。**能填**任意颜色 |
| `**kwargs` | `Any` | — | `Animation` 通用参数（`run_time=1.0`、`rate_func`…）。非 `Transform` 子类，`path_arc`/`path_func` 传了被吞、无效 |

> **返回**：`GrowArrow` 实例。

### `SpinInFromNothing`

```python
SpinInFromNothing(mobject, angle=PI / 2, point_color=None, **kwargs)
```

从中心**边旋转边长大**（RTM 实现是给渲染端写 `_grow_rot = angle * alpha`，不走路径函数），`angle` 是长大过程中额外转过的总角度（`2*PI` = 转一整圈）。继承 `SpinInFromNothing(GrowFromCenter) ← GrowArrow(Animation)`（RTM 自有链）。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `Mobject` | —（必填） | 出场对象 |
| `angle` | `float` | `PI / 2` | 长大过程中额外转过的总角度。**能填**任意弧度（`2*PI` 转一整圈、`PI/2` 只转 90°） |
| `point_color` | `ParsableManimColor \| None` | `None` | 起始颜色，`None` 沿用对象自身颜色 |
| `**kwargs` | `Any` | — | `Animation` 通用参数。RTM 自有版**根本没有 `path_func` 形参**（旋转由 `_grow_rot` 通道实现，不是路径插值），传 `path_func=` 只会被 `**kwargs` 吞掉、不起作用 |

> **返回**：`SpinInFromNothing` 实例。

#### 样例：箭头从起点长出 / 两种角度的旋入

`GrowArrow`（`point_color=RED`，箭头从起点长向箭尖）与 `SpinInFromNothing`（`angle=2*PI` 多转一整圈 + `point_color=BLUE`，对照默认 `angle=PI/2` 的小转）。

```python
import os
from real_time_manim import (
    BLUE,
    GOLD,
    GREY_B,
    PURPLE,
    RED,
    YELLOW,
    DOWN,
    LEFT,
    ORIGIN,
    RIGHT,
    UP,
    PI,
    Arrow,
    Circle,
    Scene,
    Star,
    Text,
    VGroup,
)
from real_time_manim.vulkan_bind import (
    MLWindow,
    FadeIn,
    FadeOut,
    GrowArrow,
    SpinInFromNothing,
    Wait,
    Write,
)
from real_time_manim.record import fast_record_scene  # noqa: F401

class Page_01b_箭头与旋入(Scene):
    def construct(self):
        win = MLWindow(1280, 720, hidden=True)   # 参数 w=1280 / h=720 / hidden=True
        win.scene = self

        title = Text("生长出现：GrowArrow / SpinInFromNothing", font_size=42, color=YELLOW).to_edge(UP)
        win.play(Write(title, run_time=0.8), run_time=0.8)

        # —— 一、GrowArrow：箭头从起点长向箭尖 ——
        l1 = Text("GrowArrow(arrow, point_color=RED, run_time=1.7)",
                  font_size=32, color=GREY_B).next_to(title, DOWN, buff=0.5)
        arr = Arrow(ORIGIN + LEFT * 3.2 + DOWN * 1.0, ORIGIN + RIGHT * 1.2 + DOWN * 1.0,
                    buff=0, color=GOLD, stroke_width=6).next_to(l1, DOWN, buff=0.9).shift(LEFT * 1.0)
        win.play(FadeIn(l1, shift=DOWN), run_time=0.4)
        win.play(
            GrowArrow(arr,                          # 参数 arrow
                      point_color=RED,              # 参数 point_color=RED（起点偏红，长出恢复金色）
                      run_time=1.7),                # 参数 **kwargs(run_time)
            run_time=1.7,
        )
        win.play(FadeOut(VGroup(l1, arr)), run_time=0.5)

        # —— 二、SpinInFromNothing：边旋转边长大（angle 非默认：多转一整圈）——
        l2 = Text("SpinInFromNothing(mobject, angle=2*PI, point_color=BLUE)",
                  font_size=32, color=GREY_B).next_to(title, DOWN, buff=0.5)
        star = Star(n=5, outer_radius=1.0, color=PURPLE).next_to(l2, DOWN, buff=0.8).shift(LEFT * 2.2)
        win.play(FadeIn(l2, shift=DOWN), run_time=0.4)
        win.play(
            SpinInFromNothing(                      # 参数 mobject
                star,
                angle=2 * PI,                       # 参数 angle=2*PI（长大时多转一整圈）
                point_color=BLUE,                   # 参数 point_color=BLUE
                run_time=1.9),                      # 参数 **kwargs(run_time)
            run_time=1.9,
        )
        # 对照：angle 取默认值 PI/2 的小转
        l3 = Text("SpinInFromNothing(mobject, angle=PI/2)   # 默认角度对照",
                  font_size=32, color=GREY_B).next_to(l2, DOWN, buff=1.9).shift(RIGHT * 2.4)
        ci = Circle(radius=0.6, color=GREY_B).next_to(l3, DOWN, buff=0.6)
        win.play(FadeIn(VGroup(l3, ci), shift=DOWN), run_time=0.4)
        win.play(
            SpinInFromNothing(                      # 参数 mobject
                ci,
                angle=PI / 2,                       # 参数 angle=PI/2（= 默认值，仅转 90°）
                run_time=1.5),                      # 参数 **kwargs(run_time)
            run_time=1.5,
        )

        win.play(Wait(0.5))
        win.play(FadeOut(VGroup(title, star, l3, ci)), run_time=0.6)
        win.close()


if __name__ == "__main__":
    here = os.path.dirname(os.path.abspath(__file__))
    fast_record_scene(
        Page_01b_箭头与旋入,
        out_path=os.path.join(os.path.dirname(here), "RTM output", "01b-箭头与旋入.mp4"),
        fps=60, hidden=True, overwrite=True, cleanup=True, verbose=True)
```

这段代码在做什么：三段依次演示——① `GrowArrow(arr, point_color=RED, run_time=1.7)` 让金色箭头从左端起点长向右端箭尖，起点带一点红色；② `SpinInFromNothing(star, angle=2*PI, point_color=BLUE, run_time=1.9)` 让紫星边转一整圈边长大、起点偏蓝；③ 对照组 `SpinInFromNothing(ci, angle=PI/2, run_time=1.5)` 用默认角度只转 90°，两者的旋转圈数差异一眼可见。

<video src="assets/RTM output/01b-箭头与旋入.mp4" controls width="560"></video>

> 提醒：`angle` 只影响"长大时转多少"，不影响最终姿态（终态都是对象本身的角度）；想要自定义**出场路径**（沿曲线飞入等），RTM 自有 `SpinInFromNothing` / `GrowArrow` **没有 `path_func`**（非 `Transform` 子类，传了被吞）——请改用 `Transform(path_func=...)` 或 `MoveAlongPath`。

无法演示：`point_color=None` 无独立画面（默认 = 沿用对象自身颜色）；`path_func` 自定义路径 —— RTM 自有 `SpinInFromNothing` **无该形参**（旋转由 `_grow_rot` 实现，非路径插值），传了无效；CE 版才用 `spiral_path(angle)` 占用 `path_func`。样例 docstring 里的旧说法沿用 CE 口径，以本页参数表为准。
