# 动画的生命周期与公共构造参数

每个动画类（`Create`/`FadeIn`/…）都继承 `Animation` 的四阶段生命周期，也共用一套公共构造参数；RTM 的 `win.play(...)` 接受这些关键字参数。搞懂这两样，很多"为什么"就有答案了。

## 参数

### `Animation`（动画基类：生命周期 + 公共构造参数）

```python
Animation(mobject, lag_ratio=0.0, run_time=1.0, rate_func=smooth,
          reverse_rate_function=False, name=None, remover=False,
          suspend_mobject_updating=True, introducer=False, use_override=True)
```

每个动画对象在一次 `win.play(...)` 中都会经历四个阶段，**你不需要重写它们**，但理解它们能解释很多"为什么"：

| 阶段 | 时机 | 作用 |
| --- | --- | --- |
| `begin()` | 播放前的一次性初始化 | 保存 `starting_mobject = mobject.copy()`、构建 target，必要时挂起 updater（`suspend_mobject_updating=True` 时） |
| `interpolate(alpha)` | 每帧调用一次，`alpha` 0 → 1 | 真正的插值；`rate_func` 与 `lag_ratio` 都在这一步生效（`get_sub_alpha()` 算出每个子对象自己的进度） |
| `finish()` | 播放结束时 | 强制 `interpolate(1)` 并恢复 updater |
| `_setup_scene()` / `clean_up_from_scene(scene)` | 开始前 / 结束后 | 开始前把 **introducer** 的 mobject 加进场景；结束后把 **remover** 的 mobject 从场景移除 |

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `Mobject \| None` | `None` | 被动画的对象；**能填**任意 `Mobject`。`None` 时用空 `Mobject`（`Wait`/`Add` 之外一般都要传） |
| `run_time` | `float` | `1.0` | 动画总时长（秒）。**能填**任意正数。**RTM 自有类构造期不校验**（直接存值，传负数/0 都不报错）；**ManimCE 版**构造期即抛 `ValueError("The run_time of Animation cannot be negative...")`（`0` 不报错）。RTM 侧的兜底在 `win.play`：对**整条 play 的总 `run_time <= 0`** 抛 `ValueError`（`window/play.py:_validate_play_run_time`，对齐 CE 的 `Scene.validate_run_time`），不足一帧的正值会抬到一帧并告警 |
| `lag_ratio` | `float` | `0.0` | 子对象错峰比例：第 `i` 个子对象的进度 = `rate_func` 作用于 `alpha*full_length - i*lag_ratio`，其中 `full_length = (n-1)*lag_ratio + 1`；不改变总时长，只把总时长在 `n` 个子对象间重新分配 |
| `rate_func` | `Callable` | `smooth` | 速率函数，决定"进度 ↔ 时间"的映射。**能填** `linear`、`smooth`、`there_and_back`、`rush_into`、`rush_from`、`double_smooth`、`exponential_decay`…（见 [速率函数](../../08-工具/02-速率函数.md)） |
| `reverse_rate_function` | `bool` | `False` | `True` 反转速率函数（"倒放"手感）。**不建议**当 `remover`/`introducer` 用：它不改这两个标志 |
| `name` | `str \| None` | `None` | 渲染日志里显示的名字，默认 `<类名>(<Mobject名>)`。**不建议改**：只影响日志，画面无变化 |
| `remover` | `bool` | `False` | `True` 播完把 mobject 从场景移除 |
| `introducer` | `bool` | `False` | `True` 播放前把 mobject 加入场景 |
| `suspend_mobject_updating` | `bool` | `True` | 动画期间挂起 mobject 自身的 updater（避免 updater 覆盖插值）。**不建议改**：mobject 没有 updater 时两种取值画面完全相同 |
| `use_override` | `bool` | `True` | 若该 mobject 类型用 `override_animation` 重写了此动画类，是否使用重写版本。重写机制已接线（`Animation.__new__` 查重写注册表，`animation_override_for` 支持跨命名空间同名回退，`False` 保留原动画类）。**不建议改**：日常用不到 |

> **返回**：`Animation` 实例，直接交给 `win.play(...)` 播放。

### `Animation.set_default`

```python
@classmethod
def set_default(cls, **kwargs) -> None:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `**kwargs` | `Any` | — | 要批量覆盖的默认值（如 `run_time=2, rate_func=linear`）；**能填**上表任意构造参数。全局生效、**不建议**在库代码里改；传空参 `set_default()` 恢复原始默认值 |

> **返回**：无（原地修改该动画类的构造默认值）。

### `set_rate_func`（链式方法）

```python
def set_rate_func(self, func: Callable[[float], float]) -> "Animation":
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `func` | `Callable[[float], float]` | — | 新的速率函数（如 `linear`）。返回 `self`，可继续链式调用 |

> **返回**：`self`（原地改 `rate_func` 后返回自身）。`set_run_time` / `get_run_time` / `get_rate_func` / `set_name` / `is_introducer` / `is_remover` / `copy` 等链式方法 RTM 自有 `Animation` 均已实现（测试 `tests/test_gap_wait_timeline.py`）。

#### 样例：Animation 公共构造参数逐个演示

把构造参数逐个显式传一遍：`run_time` / `lag_ratio` / `rate_func` / `reverse_rate_function` / `introducer` / `remover`，外加 `set_default` 批量默认值与 `set_rate_func` 链式方法。

```python
import os
from real_time_manim import (
    BLUE,
    DOWN,
    GREEN,
    GREY_B,
    LEFT,
    ORANGE,
    RIGHT,
    UP,
    YELLOW,
    PI,
    Circle,
    Scene,
    Square,
    Text,
    Triangle,
    VGroup,
    linear,
)
from real_time_manim.vulkan_bind import (
    MLWindow,
    Create,
    FadeIn,
    FadeOut,
    Rotate,
    Wait,
    Write,
)
from real_time_manim.record import fast_record_scene  # noqa: F401

class Page_01_生命周期与公共参数(Scene):
    def construct(self):
        win = MLWindow(1280, 720, hidden=True)   # 参数 w / h / hidden
        win.scene = self                          # 参数 win.scene

        title = Text("01-动画的生命周期与公共构造参数", font_size=42, color=YELLOW).to_edge(UP)
        win.play(Write(title), run_time=0.8)

        # —— 签名上屏：所有动画共享的构造参数 ——
        s1 = Text("Animation(mobject, lag_ratio=0.0, run_time=1.0, rate_func=smooth,", font_size=28, color=GREY_B)
        s2 = Text("           reverse_rate_function=False, name=None, remover=False,", font_size=28, color=GREY_B)
        s3 = Text("           introducer=False, use_override=True)", font_size=28, color=GREY_B)
        sig = VGroup(s1, s2, s3).arrange(DOWN, buff=0.06).to_edge(UP).shift(DOWN * 1.0)
        win.play(FadeIn(sig, shift=DOWN), run_time=0.5)

        # —— 步骤 1：run_time + rate_func ——
        l1 = Text("Create(sq, run_time=1.4, rate_func=linear)", font_size=30, color=GREY_B)
        l1.next_to(sig, DOWN, buff=0.35)
        sq = Square(side_length=1.2, color=BLUE).set_fill(BLUE, 0.5).shift(LEFT * 3.4 + DOWN * 2.4)
        ci = Circle(radius=0.62, color=GREEN).set_fill(GREEN, 0.5).shift(DOWN * 2.4)
        tri = Triangle(color=ORANGE).scale(0.75).set_fill(ORANGE, 0.5).shift(RIGHT * 3.4 + DOWN * 2.4)
        win.play(FadeIn(l1, shift=DOWN), run_time=0.4)
        win.play(Create(sq, run_time=1.4, rate_func=linear))    # 参数 run_time / rate_func

        # —— 步骤 2：lag_ratio：Write 按字形错峰 ——
        win.play(FadeOut(l1), run_time=0.3)
        l2 = Text("Write(txt, lag_ratio=0.5, run_time=1.6)", font_size=30, color=GREY_B)
        l2.next_to(sig, DOWN, buff=0.35)
        txt = Text("lag_ratio", font_size=40, color=YELLOW).shift(DOWN * 2.4)
        win.play(FadeIn(l2, shift=DOWN), run_time=0.4)
        win.play(Write(txt, lag_ratio=0.5, run_time=1.6))       # 参数 lag_ratio（字形逐个写）
        win.play(FadeOut(VGroup(l2, txt)), run_time=0.3)

        # —— 步骤 3：introducer / remover：生命周期的进出场景两个钩子 ——
        l3 = Text("FadeIn(sq2, introducer=True) / FadeOut(sq2, remover=True)",
                  font_size=30, color=GREY_B).next_to(sig, DOWN, buff=0.35)
        sq2 = Square(side_length=1.2, color=YELLOW).set_fill(YELLOW, 0.5).shift(DOWN * 2.4)
        win.play(FadeIn(l3, shift=DOWN), run_time=0.4)
        win.play(FadeIn(sq2, introducer=True, shift=UP, run_time=0.9))   # 参数 introducer
        win.play(Wait(0.3))
        win.play(FadeOut(sq2, remover=True, run_time=0.9))               # 参数 remover

        # —— 步骤 4：reverse_rate_function：倒放 ——
        win.play(FadeOut(l3), run_time=0.3)
        l4 = Text("Rotate(tri, PI/2, reverse_rate_function=True)", font_size=30, color=GREY_B)
        l4.next_to(sig, DOWN, buff=0.35)
        win.play(FadeIn(l4, shift=DOWN), run_time=0.4)
        win.play(Rotate(tri, PI / 2, reverse_rate_function=True,
                        run_time=1.2, rate_func=linear))        # 参数 reverse_rate_function（从 PI/2 倒回 0）
        win.play(FadeOut(l4), run_time=0.3)

        # —— 步骤 5：set_default 批量默认值 + set_rate_func 链式方法 ——
        l5 = Text("Rotate.set_default(run_time=1.2, rate_func=linear)", font_size=30, color=GREY_B)
        l6 = Text("  ->  win.play(Rotate(ci, PI/2))   # 1.2s 线性由默认值提供", font_size=28, color=GREY_B)
        l7 = Text("rot.set_rate_func(linear)  # RTM 动画实现的链式方法", font_size=28, color=GREY_B)
        sig5 = VGroup(l5, l6, l7).arrange(DOWN, buff=0.06).next_to(sig, DOWN, buff=0.35)
        win.play(FadeIn(sig5, shift=DOWN), run_time=0.4)
        Rotate.set_default(run_time=1.2, rate_func=linear)      # Animation.set_default(**kwargs)
        win.play(Rotate(ci, PI / 2))                            # 参数 run_time=1.2 / rate_func=linear（来自默认值）
        Rotate.set_default()                                    # 传空参恢复默认
        rot = Rotate(ci, -PI / 2, run_time=0.8)
        rot.set_rate_func(linear)                               # 方法 set_rate_func
        win.play(rot)

        win.play(FadeOut(VGroup(title, sig, sq, ci, tri, sig5)), run_time=0.6)
        win.close()


if __name__ == "__main__":
    here = os.path.dirname(os.path.abspath(__file__))
    fast_record_scene(Page_01_生命周期与公共参数,
                      out_path=os.path.join(os.path.dirname(here), "RTM output", "01-生命周期与公共参数.mp4"),
                      fps=60, hidden=True, overwrite=True, cleanup=True, verbose=True)
```

这段代码在做什么：开场写下标题和整行 `Animation(...)` 签名，然后分五步演示——

- ① `Create(sq, run_time=1.4, rate_func=linear)` 非默认时长+匀速；
- ② `Write(txt, lag_ratio=0.5, run_time=1.6)` 按字形错峰、一个字一个字写出来；
- ③ `FadeIn(sq2, introducer=True)` / `FadeOut(sq2, remover=True)` 走一遍进出场景的两个钩子；
- ④ `Rotate(tri, PI/2, reverse_rate_function=True)` 从终点倒着转回来；
- ⑤ `Rotate.set_default(run_time=1.2, rate_func=linear)` 让后面的 `Rotate(ci, PI/2)` 不传参也按 1.2 秒线性执行；收尾再 `set_default()` 恢复默认，并用 `set_rate_func(linear)` 手动改速率函数对照一次。

> 提醒：
>
> - `FadeOut` 内部固定 `remover=True`（传不传都一样）。
> - `FadeIn` 的 `introducer` 在 RTM **未固定**：默认 `False`，显式传 `introducer=True` 也接受。要演示"任意动画的 introducer/remover"，传给 `Create` / 自定义动画更稳。
> - `set_default` 是类级全局开关，用完记得恢复。

无法演示：

- `name` —— 只影响 repr/渲染日志，画面无变化；
- `suspend_mobject_updating` —— 无视频：mobject 没有 updater 时传 True/False 画面完全一致；
- `use_override` —— 重写机制已接线（`override_animation` 注册表 + `animation_override_for` 跨命名空间同名回退，`use_override=False` 保原类），仍不演示：需要自定义 Mobject 子类，画面无可视参数差异；
- `set_run_time` / `set_name` / `get_run_time` / `get_rate_func` / `is_introducer` / `is_remover` / `copy` —— 已实现（测试 `tests/test_gap_wait_timeline.py`），仍不演示：纯属性存取，画面无差异。
