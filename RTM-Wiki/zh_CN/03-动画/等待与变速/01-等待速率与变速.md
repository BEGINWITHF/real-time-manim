# 等待、速率与变速：Wait / ChangeSpeed / Animation

"等待与变速"收录的类：`Wait` 纯等待、`ChangeSpeed` 给任意动画按时间百分比配速度倍率、`Animation` 基类直接实例化当占位——三者均实测可渲（`Wait` 走 RTM 自有实现，`ChangeSpeed` 由 `window/patches.py` 的 `_sm.prepare_animation = _patched_prepare_animation` + `_RtmAnimationAdapter` 桥接（不在 `compat.py`），`Animation` 为 manim 基类经时间轴渲染）；另附 8 种 `rate_func` 的同场对比。

## 参数

### `Wait`

```python
Wait(run_time=1, stop_condition=None, frozen_frame=None, rate_func=linear, **kwargs)
```

继承 `Wait(Animation)`。"什么都不做"的动画：纯等待 `run_time` 秒。`stop_condition` 是每帧求值的无参函数，返回真值即提前结束；`frozen_frame` 控制是否渲染成静帧（`None` 由场景自动判断，`False` 则仍然跑 updater）。要**放进 `Succession`/`AnimationGroup` 时间轴**时才需要显式构造 `Wait`。相关 API：`Scene.wait(duration=1.0, stop_condition=None, frozen_frame=None)`、`Scene.pause(duration)`、`Scene.wait_until(stop_condition, max_time=60)`。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `run_time` | `float` | `1` | 等待秒数 |
| `stop_condition` | `Callable[[], bool] \| None` | `None` | 每帧求值的结束条件，为真即提前结束；**与 `frozen_frame=True` 同时给会抛 `ValueError`**（manim 同款报错）。RTM 自有 `Wait` 同样支持，见[播放与等待（场景篇）](../../01-场景与相机/场景/03-播放与等待.md) |
| `frozen_frame` | `bool \| None` | `None` | 是否静帧；`None` 自动判断（场景没有任何 updater 时冻结，否则步进）；`True` 期间 updaters 一律不驱动、画面定格 |
| `rate_func` | `Callable` | `linear` | 等待期间的进度函数（一般不用改——等待期间没有可插值的画面内容） |
| `**kwargs` | `Any` | — | `Animation` 通用参数 |

> **返回**：`Animation`（交给 `play` 播放，或放进 `Succession`/`AnimationGroup` 时间轴）。

#### 样例：run_time 纯等待 1 秒

蓝方块配 `Wait(run_time=1.0)` 纯停 1 秒，前后用 `FadeIn`/`FadeOut` 进出场景。

```python
from real_time_manim import Scene, Text, VGroup, Square, BLUE, GREY_B, YELLOW, UP, DOWN, \
    FadeIn, FadeOut, Write
from real_time_manim.vulkan_bind import MLWindow, Wait

class WaitDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("01-Wait", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        lab = Text("win.play(Wait(1.0))   # run_time=1.0s",
                   font_size=30, color=GREY_B).next_to(title, DOWN, buff=0.4)   #签名标签
        sq = Square(side_length=1.1, color=BLUE).set_fill(BLUE, 0.5).next_to(lab, DOWN, buff=0.6)   #等待期间的蓝方块
        txt = Text("waiting...", font_size=30, color=GREY_B).next_to(sq, DOWN, buff=0.4)   #等待提示文字
        win.play(FadeIn(lab, shift=DOWN), FadeIn(sq), FadeIn(txt), run_time=0.4)   #标签与方块淡入
        win.play(Wait(1.0))   #参数 “run_time”：什么都不做地等 1 秒
        win.play(FadeOut(VGroup(lab, sq, txt)), run_time=0.4)   #整组淡出收场
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：标签淡入后 `win.play(Wait(1.0))` 停 1 秒——`run_time` 就是停的秒数，画面定住什么都不发生；然后整组淡出收场。等待前后各留 0.6 秒让结果停稳。

### `ChangeSpeed`

```python
ChangeSpeed(anim, speedinfo, rate_func=None, affects_speed_updaters=True, **kwargs)
```

继承 `ChangeSpeed(Animation)`，来源 `animation/speedmodifier.py`；RTM 侧由 **`window/patches.py`** 接线（`_sm.prepare_animation = _patched_prepare_animation` + `_RtmAnimationAdapter` 把 RTM 自有子动画桥接进 manim 的 `ChangeSpeed`——**不在 `compat.py`**）。**给另一个动画加变速**：以 `run_time` 的百分比为节点指定不同速度倍率（`1` = 正常、`0.1` = 慢动作、`0` = 停住），节点之间平滑过渡。内部重写子动画的 `rate_func` 并按新时间轴重算总时长。一次只能有一个 `affects_speed_updaters=True` 的 `ChangeSpeed` 在播，否则 `AssertionError`。静态方法 `ChangeSpeed.add_updater(mobject, update_function, index=None, call_updater=False)`：用它加的 updater 才会响应变速（函数签名带 `dt` 时会把变速后的 `dt` 喂进去）。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `anim` | `Animation \| _AnimationBuilder` | — | 被变速的动画（`AnimationGroup` 会被逐个子动画处理后原样重建） |
| `speedinfo` | `dict[float, float]` | — | `{时间百分比: 速度倍率}`。**能填** 如 `{0.3:1, 0.6:0.1, 1:1}`；缺 `0` 自动补 `1`，缺 `1` 自动补最后一个倍率 |
| `rate_func` | `Callable \| None` | `None` | 覆盖被包装动画的速率函数（`None` 用它自己的） |
| `affects_speed_updaters` | `bool` | `True` | 是否同时让 `ChangeSpeed.add_updater` 添加的 updater 跟着变速 |
| `**kwargs` | `Any` | — | `Animation` 通用参数（`run_time` 由内部按新时间轴计算） |

> **返回**：`Animation`（交给 `play` 播放）。

#### 样例：speedinfo 按百分比配速，对撞双点

两个对撞的点各跑 1 秒平移（`AnimationGroup` 同时起跑），外面套 `ChangeSpeed` 按进度百分比配速：前 30% 常速、中段 0.25 倍慢放、末段 2 倍快进。

```python
from real_time_manim import Scene, Text, VGroup, Dot, Line, BLUE, RED, YELLOW, GREY_B, \
    UP, DOWN, LEFT, RIGHT, AnimationGroup, ChangeSpeed, FadeIn, Write
from real_time_manim.vulkan_bind import MLWindow, Wait

class ChangeSpeedDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("01-ChangeSpeed", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        lab3 = Text("ChangeSpeed(AnimationGroup(a.shift, b.shift),",
                    font_size=30, color=GREY_B)
        lab4 = Text("  speedinfo={0.3:1, 0.5:0.25, 1:2}, rate_func=linear)",
                    font_size=30, color=GREY_B)
        lab = VGroup(lab3, lab4).arrange(DOWN, buff=0.06).next_to(title, DOWN, buff=0.4)   #两行签名标签
        a = Dot(radius=0.14, color=RED).move_to(LEFT * 3.2 + DOWN * 1.2)
        b = Dot(radius=0.14, color=BLUE).move_to(RIGHT * 3.2 + DOWN * 1.2)
        trk = Line(LEFT * 3.2 + DOWN * 1.2, RIGHT * 3.2 + DOWN * 1.2, stroke_width=2, color=GREY_B)
        trk.set_stroke(opacity=0.4)
        win.play(FadeIn(lab, shift=DOWN), FadeIn(VGroup(a, b, trk)), run_time=0.4)   #标签与对撞双点淡入
        win.play(ChangeSpeed(
            AnimationGroup(a.animate(run_time=1).shift(RIGHT * 6.4),
                           b.animate(run_time=1).shift(LEFT * 6.4)),
            speedinfo={0.3: 1, 0.5: 0.25, 1: 2},   #参数 “speedinfo”：前 30% 常速、中段 0.25 倍、末段 2 倍
            rate_func=linear,                      #参数 “rate_func”
            affects_speed_updaters=True))          #参数 “affects_speed_updaters”
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：红蓝两点对撞平移，`speedinfo={0.3: 1, 0.5: 0.25, 1: 2}` 按进度百分比配速——前 30% 常速、30%~50% 降到 0.25 倍慢放（肉眼可见停顿）、50% 之后 2 倍快进冲到终点；`rate_func=linear` 让段内速度恒定不加缓动。

#### 样例：add_updater 挂的 updater 跟着变速

黄点的位移不是用动画播的，而是 `ChangeSpeed.add_updater` 挂的 updater 按 `dt` 累积；套进 `ChangeSpeed(Wait(1.6), ...)` 后**连 updater 都跟着变速**——中段 0.15 倍慢放时黄点几乎停住。

```python
from real_time_manim import Scene, Text, VGroup, Dot, Line, YELLOW, GREY_B, UP, DOWN, \
    LEFT, RIGHT, ChangeSpeed, FadeIn, Write
from real_time_manim.vulkan_bind import MLWindow, Wait

class ChangeSpeedUpdaterDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("01-ChangeSpeed-updater", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        lab5 = Text("ChangeSpeed.add_updater(m, fn)  +  ChangeSpeed(",
                    font_size=30, color=GREY_B)
        lab6 = Text("    Wait(1.6), speedinfo={0.3:1, 0.55:0.15, 1:1})",
                    font_size=30, color=GREY_B)
        lab = VGroup(lab5, lab6).arrange(DOWN, buff=0.06).next_to(title, DOWN, buff=0.4)   #两行签名标签
        m = Dot(radius=0.14, color=YELLOW).move_to(LEFT * 3.2 + DOWN * 1.2)
        trk = Line(LEFT * 3.2 + DOWN * 1.2, RIGHT * 3.2 + DOWN * 1.2, stroke_width=2, color=GREY_B)
        trk.set_stroke(opacity=0.4)
        win.play(FadeIn(lab, shift=DOWN), FadeIn(VGroup(m, trk)), run_time=0.4)   #标签与轨道淡入
        ChangeSpeed.add_updater(m, lambda mob, dt: mob.shift(RIGHT * 3.4 * dt))   #参数 “ChangeSpeed.add_updater”：挂变速 updater
        win.play(ChangeSpeed(Wait(1.6), speedinfo={0.3: 1, 0.55: 0.15, 1: 1},   #参数 “speedinfo”：中段 0.15 倍慢放
                             affects_speed_updaters=True))
        m.clear_updaters()   #解除 updater
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：黄点由 `ChangeSpeed.add_updater(m, lambda mob, dt: mob.shift(RIGHT * 3.4 * dt))` 挂的 updater 按 `dt` 累积位移；外面套 `ChangeSpeed(Wait(1.6), speedinfo={0.3: 1, 0.55: 0.15, 1: 1})`——前 30% 常速滑行、中段 0.15 倍几乎停住、末段恢复常速走完。播完 `clear_updaters` 解除。

<video src="assets/RTM output/01-等待速率与变速-changespeed_updater.mp4" controls width="560"></video>

> 提醒：`ChangeSpeed.speedinfo` 的键是**进度百分比**（0~1），不是秒数；`affects_speed_updaters=True` 同时只允许一个在播（多个叠加会 `AssertionError`）；要让自己的 updater 响应变速，必须用 `ChangeSpeed.add_updater` 挂，普通 `add_updater` 的 `dt` 不受变速影响。

### `Animation`（基类直接使用）

```python
Animation(mobject, lag_ratio=0.0, run_time=1.0, rate_func=smooth, reverse_rate_function=False,
          name=None, remover=False, suspend_mobject_updating=True, introducer=False, use_override=True)
```

所有动画的基类，来源 `animation/animation.py`。直接实例化时，它就是"**什么都不改地占用 `run_time` 秒**"（每帧把 mobject 插值回自身），常用于 `Succession`/`LaggedStartMap` 中占位；也是自定义动画的起点：继承它并重写 `interpolate_mobject()` 即可写自己的动画。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `Mobject` | — | 被作用的对象 |
| `lag_ratio` | `float` | `0.0` | 与其他动画组合时的错峰比例 |
| `run_time` | `float` | `1.0` | 时长（秒） |
| `rate_func` | `Callable` | `smooth` | 进度函数 |
| `reverse_rate_function` | `bool` | `False` | 是否反转进度函数 |
| `name` | `str \| None` | `None` | 动画名 |
| `remover` | `bool` | `False` | 播完是否从场景移除 |
| `suspend_mobject_updating` | `bool` | `True` | 播放期间是否挂起 mobject 自带 updater |
| `introducer` | `bool` | `False` | 播放前是否加入场景 |
| `use_override` | `bool` | `True` | 是否使用 `override_animation` 重写 |

> **返回**：`Animation`。裸 `Animation` 不改变画面，`name` / `lag_ratio` / `suspend_mobject_updating` / `introducer` / `use_override` / `reverse_rate_function` 没有可视效果（见"无法演示"）。

#### 样例：基类占位 1.2 秒

裸 `Animation` 什么都不改地占用 1.2 秒——绿方块纹丝不动，这正是它在时间轴里当占位的用法。

```python
from real_time_manim import Scene, Text, Square, GREEN, YELLOW, GREY_B, UP, DOWN, \
    Animation, FadeIn, Write
from real_time_manim.vulkan_bind import MLWindow, Wait

class AnimationDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("01-Animation", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        lab = Text("Animation(sq, run_time=1.2, rate_func=linear)  # placeholder",
                   font_size=30, color=GREY_B).next_to(title, DOWN, buff=0.4)   #签名标签
        sq = Square(side_length=1.3, color=GREEN).set_fill(GREEN, 0.5).next_to(lab, DOWN, buff=0.6)   #占位不动的绿方块
        win.play(FadeIn(lab, shift=DOWN), FadeIn(sq), run_time=0.4)   #标签与方块淡入
        win.play(Animation(sq, run_time=1.2, rate_func=linear))   #参数 “mobject” / “run_time” / “rate_func”：占 1.2 秒
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：`Animation(sq, run_time=1.2, rate_func=linear)` 每帧把绿方块插值回自身——画面上什么都不发生，时间轴实打实地走掉 1.2 秒。

## 速率函数速览

`rate_func` 是所有动画的公共参数（写法与默认值见[公共参数](../通用/01-生命周期与公共参数.md)）。同一条平移动画配 8 种最常用的速率函数同场对比：4 种平滑/冲激族先跑，同一批点复位后再跑 4 种往返/超调族。

#### 样例：同一条平移动画 × 8 种速率函数

四个彩点跑同一条 `dot.animate(run_time=1.8, rate_func=F).shift(RIGHT*6.4)`，只换 `rate_func`：第一批 `linear` / `smooth` / `rush_into` / `rush_from`，复位后第二批 `there_and_back` / `exponential_decay` / `squish(.35,.65)` / `wiggle`。

```python
from real_time_manim import Scene, Text, VGroup, Dot, Line, BLUE, GREEN, GREY_B, ORANGE, \
    RED, YELLOW, UP, DOWN, LEFT, RIGHT, FadeIn, FadeOut, Write
from real_time_manim import exponential_decay, linear, rush_from, \
    rush_into, smooth, squish_rate_func, there_and_back, wiggle
from real_time_manim.vulkan_bind import MLWindow, Wait

class RateFuncDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("01-rate_func", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        cols = [RED, BLUE, GREEN, ORANGE]
        names1 = ["linear", "smooth", "rush_into", "rush_from"]
        funcs1 = [linear, smooth, rush_into, rush_from]
        lab1 = Text("dot.animate(run_time=1.8, rate_func=F).shift(RIGHT*6.4)",
                    font_size=30, color=GREY_B).next_to(title, DOWN, buff=0.4)   #签名标签
        win.play(FadeIn(lab1, shift=DOWN), run_time=0.4)   #标签从下方淡入
        tracks = VGroup()
        labels1 = VGroup()
        dots1 = []
        for i, nm in enumerate(names1):
            y = 0.55 - i * 1.15
            labels1.add(Text(nm, font_size=26, color=cols[i]).move_to(LEFT * 5.6 + UP * y))
            trk = Line(LEFT * 3.2 + UP * y, RIGHT * 3.2 + UP * y, stroke_width=2, color=GREY_B)
            trk.set_stroke(opacity=0.4)
            tracks.add(trk)
            dots1.append(Dot(radius=0.12, color=cols[i]).move_to(trk.get_start()))
        win.play(FadeIn(labels1), FadeIn(tracks), FadeIn(VGroup(*dots1)), run_time=0.4)   #四条轨道就位
        win.play(*[d.animate(run_time=1.8, rate_func=f).shift(RIGHT * 6.4)
                   for d, f in zip(dots1, funcs1)])   #参数 “rate_func” ×4：同跑拉开差距
        win.play(Wait(0.4))   #停留看结果
        win.play(FadeOut(lab1), FadeOut(labels1), run_time=0.3)   #换标签
        for d in dots1:   #无动画地摆回起点：直接改属性
            d.move_to(LEFT * 3.2 + UP * d.get_center()[1])
        names2 = ["there_and_back", "exponential_decay", "squish(.35,.65)", "wiggle"]
        funcs2 = [there_and_back, exponential_decay, squish_rate_func(linear, 0.35, 0.65), wiggle]
        labels2 = VGroup()
        for i, nm in enumerate(names2):
            labels2.add(Text(nm, font_size=26, color=cols[i]).move_to(LEFT * 5.6 + UP * (0.55 - i * 1.15)))
        lab2 = Text("reset: 4 more rate_funcs (round-trip / overshoot)",
                    font_size=30, color=GREY_B).next_to(title, DOWN, buff=0.4)   #第二批签名标签
        win.play(FadeIn(lab2, shift=DOWN), FadeIn(labels2), run_time=0.3)   #第二批标签淡入
        win.play(*[d.animate(run_time=1.8, rate_func=f).shift(RIGHT * 6.4)
                   for d, f in zip(dots1, funcs2)])   #参数 “rate_func” ×4：往返/衰减/挤压/摆动
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：四条轨道上四个彩点跑**同一条**平移动画、只换 `rate_func` 同时起跑，位置立刻拉开：`linear` 匀速在中、`smooth` 两头慢、`rush_into` 慢进快出、`rush_from` 快进慢出。然后同一批点无动画摆回起点，再换第二批跑：`there_and_back` 回到起点、`exponential_decay` 一步冲到底、`squish_rate_func(linear, .35, .65)` 中段快两头慢、`wiggle` 来回摆出超调。

<video src="assets/RTM output/01-等待速率与变速-ratefunc.mp4" controls width="560"></video>

> 提醒：`squish_rate_func(linear, 0.35, 0.65)` 是"调用返回函数"的写法——先调用拿到包装后的函数再传入；`rate_func` 是给**有位移的动画**用的，`Wait` 上用它没有可见效果。
