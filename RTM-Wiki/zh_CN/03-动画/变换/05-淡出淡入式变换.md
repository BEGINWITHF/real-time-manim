# 淡出—淡入式变换

源淡出、目标淡入的「换东西」式变换，适合形状差异大、用 `Transform` 会糊成一团的场合；外加把**两个动画本身**互相插值的 `TransformAnimations`。

## 参数

### FadeTransform

```python
FadeTransform(mobject, target_mobject, stretch=True, dim_to_match=1, **kwargs)
```

**源淡出的同时目标淡入**，并且目标会被拉伸/缩放到源的尺寸再复原；播完后源恢复原状并被移除，目标加入场景。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `Mobject` | —（必填） | 源（播完恢复原状并从场景移除） |
| `target_mobject` | `Mobject` | —（必填） | 目标（播完加入场景） |
| `stretch` | `bool` | `True` | 是否把目标拉伸到与源同尺寸 |
| `dim_to_match` | `int` | `1` | `stretch=False` 时用：`0/1/2` 分别按 x/y/z 方向匹配长度 |
| `**kwargs` | … | — | `Transform`/`Animation` 通用参数 |

> **返回**：`FadeTransform` 实例（继承 `FadeTransform(Transform)`）。

### FadeTransformPieces

```python
FadeTransformPieces(mobject, target_mobject, stretch=True, dim_to_match=1, **kwargs)
```

与 `FadeTransform` 相同，但**按子对象逐个配对淡入淡出**（两边子对象一一对应变换）而不是整体替换，用于「整体结构不变、只是每块换掉」的情况；构造时先 `align_submobjects` 对齐两边个数。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `Mobject` | —（必填） | 源（播完恢复原状并从场景移除） |
| `target_mobject` | `Mobject` | —（必填） | 目标（播完加入场景） |
| `stretch` | `bool` | `True` | 是否把目标拉伸到与源同尺寸 |
| `dim_to_match` | `int` | `1` | `stretch=False` 时用：`0/1/2` 分别按 x/y/z 方向匹配长度 |
| `**kwargs` | … | — | `Transform`/`Animation` 通用参数 |

> **返回**：`FadeTransformPieces` 实例。**2026-10-16 起构造器 `run_time=` 已支持**（`AnimationGroup` 新增 `run_time=` / `group=` 形参），`run_time` / `rate_func` 放在**构造器**或 **play 级别**传皆可；本页样例沿用 play 级别写法（成片即此版本），代码内注释保留了这段沿革。

### TransformAnimations

```python
TransformAnimations(start_anim, end_anim, rate_func=squish_rate_func(smooth), **kwargs)
```

把**两个动画本身**互相插值（同时跑 `start_anim` 与 `end_anim`，并把两者 mobject 的点集互相变换）；源码标注 `TODO, this may be deprecated`，需要「动画之间过渡」时通常改用 `AnimationGroup` + `lag_ratio` 或 `Succession`。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `start_anim` | `Animation` | —（必填） | 起始动画 |
| `end_anim` | `Animation` | —（必填） | 结束动画 |
| `rate_func` | `Callable` | `squish_rate_func(smooth)` | 把进度挤在中段的进度曲线 |
| `run_time` | `float` | `max(start.run_time, end.run_time)` | 不传时取两个动画时长的较大值 |
| `**kwargs` | … | — | `Transform`/`Animation` 通用参数 |

> **返回**：`TransformAnimations` 实例（继承 `TransformAnimations(Transform)`）。

## 样例

#### 样例：FadeTransform / FadeTransformPieces / TransformAnimations

本页专属样例（`assets/RTM code/05-淡出淡入式变换.py`）：`FadeTransform` 两种组合（`stretch=True` 默认；`stretch=False + dim_to_match=0` 只按 x 方向匹配长度）、`FadeTransformPieces` 子对象逐件配对（样例把 `run_time` / `rate_func` 放在 play 级别传——2026-10-16 之后构造器 `run_time=` 也已支持，两种写法等价）、`TransformAnimations` 用 `MCreate` / `MFadeOut` 两个原生子动画互插（`rate_func=squish_rate_func(smooth)`、`run_time=1.5`）。

```python
import os

from real_time_manim import (
    BLUE,
    GREEN,
    GREY_B,
    ORANGE,
    RED,
    YELLOW,
    DOWN,
    LEFT,
    RIGHT,
    UP,
    Circle,
    Rectangle,
    Scene,
    Square,
    Text,
    Triangle,
    VGroup,
    smooth,
    squish_rate_func,
)
from real_time_manim.vulkan_bind import (
    MLWindow,
    Create,
    FadeIn,
    FadeOut,
    FadeTransform,
    FadeTransformPieces,
    Wait,
    Write,
)
# TransformAnimations 是 ManimCE 原生动画（RTM 未重写，随 RTM 一起导出）；
# 且需要原生子动画（要 set_run_time / starting_mobject），故子动画也用原生版别名导入
from real_time_manim import Create as MCreate, FadeOut as MFadeOut, TransformAnimations
from real_time_manim.record import fast_record_scene  # noqa: F401


class Page_05_淡出淡入式变换(Scene):
    def construct(self):
        win = MLWindow(1280, 720, hidden=True)   # 参数 w / h / hidden
        win.scene = self                          # 参数 win.scene

        title = Text("淡出—淡入式变换", font_size=44, color=ORANGE).to_edge(UP)
        win.play(Write(title), run_time=0.8)

        # —— ① FadeTransform：源淡出、目标淡入（并拉伸到源尺寸）——
        lab1 = VGroup(
            Text("FadeTransform(rect, circ, stretch=True,", font_size=30, color=GREY_B),
            Text("              dim_to_match=1, run_time=1.2)", font_size=30, color=GREY_B),
        ).arrange(DOWN, buff=0.12).next_to(title, DOWN, buff=0.35)
        rect = Rectangle(width=4.0, height=1.0, color=BLUE).set_fill(BLUE, 0.5).move_to(LEFT * 2.4 + DOWN * 1.4)
        circ = Circle(radius=1.1, color=GREEN).set_fill(GREEN, 0.5).move_to(RIGHT * 3.0 + DOWN * 1.4)
        self.add(rect)                             # 源对象先放进场景
        win.play(FadeIn(lab1, shift=DOWN), run_time=0.4)
        win.play(
            FadeTransform(rect, circ, stretch=True, dim_to_match=1,   # 参数 stretch / dim_to_match ✓
                          run_time=1.2),                               # 参数 run_time ✓
            run_time=1.2,
        )
        win.play(FadeOut(VGroup(lab1, circ)), run_time=0.5)

        # —— ② FadeTransform：stretch=False 时 dim_to_match 才生效（0 = 按 x 方向匹配）——
        lab2 = VGroup(
            Text("FadeTransform(rect2, tri, stretch=False,", font_size=30, color=GREY_B),
            Text("              dim_to_match=0, run_time=1.2)", font_size=30, color=GREY_B),
        ).arrange(DOWN, buff=0.12).next_to(title, DOWN, buff=0.35)
        rect2 = Rectangle(width=4.5, height=0.8, color=RED).set_fill(RED, 0.5).move_to(LEFT * 2.4 + DOWN * 1.4)
        tri = Triangle(color=YELLOW).scale(1.1).set_fill(YELLOW, 0.5).move_to(RIGHT * 3.0 + DOWN * 1.4)
        self.add(rect2)
        win.play(FadeIn(lab2, shift=DOWN), run_time=0.4)
        win.play(
            FadeTransform(rect2, tri, stretch=False, dim_to_match=0,  # 参数 stretch=False / dim_to_match=0 ✓
                          run_time=1.2),
            run_time=1.2,
        )
        win.play(FadeOut(VGroup(lab2, tri)), run_time=0.5)

        # —— ③ FadeTransformPieces：按子对象逐个配对淡入淡出 ——
        lab3 = VGroup(
            Text("FadeTransformPieces(grp, grp2,", font_size=30, color=GREY_B),
            Text("  stretch=True, dim_to_match=1)", font_size=30, color=GREY_B),
        ).arrange(DOWN, buff=0.12).next_to(title, DOWN, buff=0.35)
        grp = VGroup(Square(side_length=1.0, color=BLUE),
                     Circle(radius=0.5, color=GREEN).shift(RIGHT * 1.6)).move_to(LEFT * 2.6 + DOWN * 1.4)
        grp2 = VGroup(Circle(radius=0.5, color=RED),
                      Triangle(color=YELLOW).scale(0.55).shift(RIGHT * 1.6)).move_to(RIGHT * 3.0 + DOWN * 1.4)
        self.add(grp)
        win.play(FadeIn(lab3, shift=DOWN), run_time=0.4)
        # 注：样例沿用旧写法——RTM 的 FadeTransformPieces 是 AnimationGroup，
        #     run_time / rate_func 放在 play 级别传（2026-10-16 起构造器也收 run_time，两种皆可）。
        win.play(FadeTransformPieces(grp, grp2, stretch=True, dim_to_match=1),   # 参数 stretch / dim_to_match ✓
                 run_time=1.5,                                                    # 参数 run_time ✓（play 级别）
                 rate_func=smooth)                                               # 参数 rate_func ✓
        win.play(FadeOut(VGroup(lab3, grp2)), run_time=0.5)

        # —— ④ TransformAnimations：两个动画本身互相插值 ——
        lab4 = VGroup(
            Text("TransformAnimations(MCreate(sq),", font_size=30, color=GREY_B),
            Text("  MFadeOut(sq), run_time=1.5,", font_size=30, color=GREY_B),
            Text("  rate_func=squish_rate_func(smooth))", font_size=30, color=GREY_B),
        ).arrange(DOWN, buff=0.12).next_to(title, DOWN, buff=0.3)
        sq = Square(side_length=1.8, color=GREEN).set_fill(GREEN, 0.5).move_to(LEFT * 2.8 + DOWN * 1.4)
        win.play(FadeIn(lab4, shift=DOWN), run_time=0.4)
        win.play(Create(sq), run_time=0.6)
        win.play(                                   # 两个动画本身互相插值
            TransformAnimations(MCreate(sq), MFadeOut(sq),          # 参数 start_anim / end_anim ✓
                                rate_func=squish_rate_func(smooth), # 参数 rate_func ✓（非默认）
                                run_time=1.5),                      # 参数 run_time ✓（非默认）
            run_time=1.5,
        )

        win.play(Wait(0.4))
        win.play(FadeOut(VGroup(title, lab4)), run_time=0.6)
        win.close()                                 # 参数 win.close()
```

这段代码在做什么：四段演示。① 蓝色矩形交叉淡变成绿色圆——源淡出、目标淡入同时进行，目标先被拉伸到源的尺寸再复原（`stretch=True`）；② 换成 `stretch=False + dim_to_match=0`，目标三角形只按 x 方向匹配长度，保留自己的高矮比例；③ `FadeTransformPieces` 把「方块+圆」逐件换成「圆+三角」——每个子对象各自配对淡入淡出，而不是整组替换（`run_time`/`rate_func` 放在 `play` 级别传，见样例注释）；④ `TransformAnimations` 把 `Create` 和 `FadeOut` 两个动画本身互相插值：方块一边被画出来一边淡掉，进度被 `squish_rate_func` 挤在中段。

> 提醒：`FadeTransform` / `FadeTransformPieces` 从 `real_time_manim.vulkan_bind` 导入（RTM 自带实现，实测交叉淡变正常）；`TransformAnimations` 是 ManimCE 原生动画（RTM 未重写，随 `real_time_manim` 一起导出），且它的子动画要用原生版（需要 `set_run_time` / `starting_mobject`），所以样例里别名导入了 `MCreate` / `MFadeOut`。
