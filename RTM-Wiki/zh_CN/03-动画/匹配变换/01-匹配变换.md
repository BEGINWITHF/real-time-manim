# 匹配变换：TransformMatchingShapes / Tex

这个变换家族把源与目标都拆成「零件」，再按键配对：每个零件先算一个**键（key）**，键相同的零件互相 `Transform`，键不同的零件淡出/淡入（或按参数强行变换）。

公式推导、字母重排这类「只让变化的项动」的场面，就是它的主场。

## 参数

### `TransformMatchingShapes` 

```python
TransformMatchingShapes(mobject, target_mobject, transform_mismatches=False,
                        fade_transform_mismatches=False, key_map=None, **kwargs)
```

按**形状**匹配。先取两边所有带点的子对象，归一化（移到原点、高度设为 1、坐标保留 3 位小数）后做哈希：哈希相同就算「同一形状」，互相变换；不匹配的源零件淡出、目标零件淡入。

典型用途是 `Text("the morse code")` → `Text("here come dots")` 这种字母重排。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `Mobject` | — | 源（播完会被移除，由 `target_mobject` 接管） |
| `target_mobject` | `Mobject` | — | 目标（播完加入场景） |
| `transform_mismatches` | `bool` | `False` | `True`：不匹配的零件也用 `Transform` 强行变形 |
| `fade_transform_mismatches` | `bool` | `False` | `True`：不匹配的零件用 `FadeTransformPieces` 过渡 |
| `key_map` | `dict \| None` | `None` | 手工指定「虽然键不同但应当配对」：`{源键: 目标键}` |
| `**kwargs` | … | — | 透传给内部每个子变换（常用 `path_arc=PI/2`），以及 `Animation` 通用参数 |

> **返回**：`TransformMatchingShapes` 实例。

#### 样例：默认同形匹配（path_arc 弧线）

`the morse code` 重排成 `here come dots`。默认参数下，同形字母沿弧线互换，异形零件淡出、新字母淡入。

```python
from real_time_manim import GREY_B, YELLOW, DOWN, UP, PI, Scene, Text, VGroup, FadeIn, Write
from real_time_manim.vulkan_bind import MLWindow, TransformMatchingShapes, Wait

class ShapesDefaultDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("01-ShapesDefault", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        l1 = Text("TransformMatchingShapes(src, tar, transform_mismatches=False,",
                  font_size=28, color=GREY_B)
        l2 = Text("    fade_transform_mismatches=False, key_map=None, path_arc=PI/2)",
                  font_size=28, color=GREY_B)
        lab1 = VGroup(l1, l2).arrange(DOWN, buff=0.06).next_to(title, DOWN, buff=0.4)   #两行签名标签
        src = Text("the morse code", font_size=44).next_to(lab1, DOWN, buff=0.8)   #源：待重排的句子
        tar = Text("here come dots", font_size=44).move_to(src)   #目标：重排后的句子
        win.play(FadeIn(lab1, shift=DOWN), run_time=0.4)   #标签从下方淡入
        self.add(src)   #源对象先加进场景（播完会被移除，目标接管）
        win.play(
            TransformMatchingShapes(                #参数 “mobject”（源，播完移除）
                src,
                tar,                                #参数 “target_mobject”（播完接管场景）
                transform_mismatches=False,         #参数 “transform_mismatches”：False，异形走淡出淡入
                fade_transform_mismatches=False,    #参数 “fade_transform_mismatches”：False
                key_map=None,                       #参数 “key_map”：None，不手工配对
                path_arc=PI / 2,                    #参数 “path_arc”（**kwargs）：同形零件走弧线
            ),
            run_time=2.6,
        )
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：源句 `src` 先 `self.add` 进场景。`TransformMatchingShapes` 把两边每个字母归一化，再按形状哈希配对：`h`/`e`/`o`… 这些同形字母沿 `path_arc=PI/2` 的弧线走到新单词里的位置，对不上的字母原地淡出、目标字母淡入。播完源句被移除，`tar` 接管场景。

#### 样例：transform_mismatches=True 强行变形

同一句话再跑一遍，唯一的区别是 `transform_mismatches=True`：对不上的零件不再淡出淡入，而是被强行 `Transform` 变形过去。

```python
from real_time_manim import GREY_B, YELLOW, DOWN, UP, PI, Scene, Text, VGroup, FadeIn, Write

        win.play(Write(title), run_time=0.5)   #写出标题

        l3 = Text("TransformMatchingShapes(src, tar, transform_mismatches=True, ...)",
                  font_size=28, color=GREY_B).next_to(title, DOWN, buff=0.4)   #签名标签
        src2 = Text("the morse code", font_size=44).next_to(l3, DOWN, buff=0.8)   #源：待重排的句子
        tar2 = Text("here come dots", font_size=44).move_to(src2)   #目标：重排后的句子
        win.play(FadeIn(l3, shift=DOWN), run_time=0.4)   #标签从下方淡入
```

#### 样例：key_map 手工键配对

`cat` → `hat`：`key_map` 手工把不同形状的源 `"c"` 配给目标 `"h"`，只有首字母互换变形。

```python
from real_time_manim import GREY_B, YELLOW, DOWN, LEFT, UP, PI, Scene, Text, VGroup, FadeIn, Write
from real_time_manim.vulkan_bind import MLWindow, TransformMatchingShapes, Wait

class ShapesKeyMapDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("01-ShapesKeyMap", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        l4 = Text("key_map = {shape_key('c'): shape_key('h')}  # 手工键配对",
                  font_size=28, color=GREY_B).next_to(title, DOWN, buff=0.4)   #签名标签
        l5 = Text("TransformMatchingShapes(cat, hat, key_map=key_map, ...)",
                  font_size=28, color=GREY_B).next_to(l4, DOWN, buff=0.06)   #第二行签名标签
        lab2 = VGroup(l4, l5)
        src3 = Text("cat", font_size=52, color=GREY_B).next_to(lab2, DOWN, buff=0.8).shift(LEFT * 2.0)   #源单词 cat
        tar3 = Text("hat", font_size=52, color=GREY_B).move_to(src3)   #目标单词 hat（只换首字母）
        win.play(FadeIn(lab2, shift=DOWN), run_time=0.4)   #标签从下方淡入
        self.add(src3)   #源对象先加进场景（播完会被移除，目标接管）
        key_map = {
            TransformMatchingShapes.get_mobject_key(src3[0]):   #源字母 “c” 的形状键
            TransformMatchingShapes.get_mobject_key(tar3[0]),   #目标字母 “h” 的形状键
        }
        win.play(
            TransformMatchingShapes(                #参数 “mobject”（源，播完移除）
                src3,
                tar3,                               #参数 “target_mobject”（播完接管场景）
                transform_mismatches=False,         #参数 “transform_mismatches”：False
                fade_transform_mismatches=False,    #参数 “fade_transform_mismatches”：False
                key_map=key_map,                    #参数 “key_map”（“c” → “h” 强制配对）
                path_arc=PI / 2,                    #参数 “path_arc”（**kwargs）：同形零件走弧线
            ),
            run_time=2.4,
        )
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：`get_mobject_key(src3[0])` / `get_mobject_key(tar3[0])` 现场算出源首字母 `c` 与目标首字母 `h` 的形状键（形状不同，哈希自然不同）。两个键塞进 `key_map` 后，这对字母被强制配对：只有首字母互换变形，`a`/`t` 原地不动。

### `TransformMatchingTex` 

```python
TransformMatchingTex(mobject, target_mobject, transform_mismatches=False,
                     fade_transform_mismatches=False, key_map=None, **kwargs)
```

按 **LaTeX 片段的 `tex_string`** 匹配：只要两边某个子部分的 TeX 源串相同，就互相变换——这是「公式推导时只让变化的项动、其余项原地不动」的利器。对 `Group`/`VGroup`，它会递归下钻到真正带 `tex_string` 的部件。（MathTex 样例已在 RTM 实测：MathTex 走 Typst 转换通道，公式逐字渲染正常）

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `Mobject` | — | 源 |
| `target_mobject` | `Mobject` | — | 目标 |
| `transform_mismatches` | `bool` | `False` | 不匹配零件是否强行 `Transform` |
| `fade_transform_mismatches` | `bool` | `False` | 不匹配零件是否用 `FadeTransformPieces` |
| `key_map` | `dict \| None` | `None` | 手工键配对 `{源键: 目标键}` |
| `**kwargs` | … | — | 内部子变换参数与 `Animation` 通用参数 |

> **返回**：`TransformMatchingTex` 实例。

#### 样例：fade_transform_mismatches 与默认对照

MathTex 按 `tex_string` 匹配，同一公式跑两遍：`x²+y²=z²` → `x²=z²−y²`，先开 `fade_transform_mismatches=True`，再换回默认行为做对照。

```python
from real_time_manim import GREY_B, YELLOW, DOWN, UP, MathTex, Scene, Text, VGroup, \
    FadeIn, FadeOut, Write
from real_time_manim.vulkan_bind import MLWindow, TransformMatchingTex, Wait

class MatchingTexDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("01-MatchingTex", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        l6 = Text("TransformMatchingTex(eq1, eq2, transform_mismatches=False,",
                  font_size=28, color=GREY_B)
        l7 = Text("    fade_transform_mismatches=True, key_map=None)",
                  font_size=28, color=GREY_B)
        lab3 = VGroup(l6, l7).arrange(DOWN, buff=0.06).next_to(title, DOWN, buff=0.4)   #两行签名标签
        eq1 = MathTex("{{x}}^2", "+", "{{y}}^2", "=", "{{z}}^2").next_to(lab3, DOWN, buff=0.8)   #源公式 x²+y²=z²
        eq2 = MathTex("{{x}}^2", "=", "{{z}}^2", "-", "{{y}}^2").move_to(eq1)   #目标公式 x²=z²−y²
        win.play(FadeIn(lab3, shift=DOWN), run_time=0.4)   #标签从下方淡入
        self.add(eq1)   #源公式先加进场景（播完会被移除，目标接管）
        win.play(
            TransformMatchingTex(                  #参数 “mobject”（源，播完移除）
                eq1,
                eq2,                                #参数 “target_mobject”（播完接管场景）
                transform_mismatches=False,         #参数 “transform_mismatches”：False
                fade_transform_mismatches=True,     #参数 “fade_transform_mismatches”：True，异形用 FadeTransformPieces
                key_map=None,                       #参数 “key_map”：None，不手工配对
            ),
            run_time=2.4,
        )
        # 同一变换的默认行为对照：异形零件直接淡出/淡入
        eq3 = MathTex("{{x}}^2", "+", "{{y}}^2", "=", "{{z}}^2").move_to(eq1)   #对照：源公式换回
        eq4 = MathTex("{{x}}^2", "=", "{{z}}^2", "-", "{{y}}^2").move_to(eq1)   #对照：同一目标公式
        l8 = Text("(default) transform_mismatches=False, fade_transform_mismatches=False",
                  font_size=28, color=GREY_B).next_to(title, DOWN, buff=0.4)   #对照标签
        win.play(FadeOut(VGroup(lab3, eq2)), FadeIn(l8, shift=DOWN), run_time=0.5)   #换标签，结果让位
        self.add(eq3)   #对照的源公式加进场景
        win.play(
            TransformMatchingTex(                  #参数 “mobject”（源，播完移除）
                eq3,
                eq4,                                #参数 “target_mobject”（播完接管场景）
                transform_mismatches=False,         #参数 “transform_mismatches”：False
                fade_transform_mismatches=False,    #参数 “fade_transform_mismatches”：False，异形直接淡出淡入
                key_map=None,                       #参数 “key_map”：None，不手工配对
            ),
            run_time=2.4,
        )
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：`x²+y²=z²` 变形为 `x²=z²−y²`。`x²`/`=`/`z²` 的 TeX 源串两边相同，原地不动；只有 `+`/`y²` 与 `−`/`y²` 在动。

第一遍开 `fade_transform_mismatches=True`，异形零件用 `FadeTransformPieces` 过渡；换标签后第二遍走默认行为，异形直接淡出、新件淡入。两条并排看，就能看出参数差别。

<video src="assets/RTM output/01-匹配变换-tex.mp4" controls width="560"></video>

> 提醒：
>
> - `TransformMatchingShapes` / `TransformMatchingTex` 从 `real_time_manim.vulkan_bind` 导入（RTM 自带实现，见开头修复记录）。
> - `key_map` 里的键要用 `类.get_mobject_key(零件)` 现场算，例如 `TransformMatchingShapes.get_mobject_key(src3[0])`；记得源键配目标键，方向别写反。
> - 源对象记得先 `self.add` 进场景：播完源会被移除，目标接管。

### `TransformMatchingAbstractBase`（抽象基类）

```python
TransformMatchingAbstractBase(mobject, target_mobject, transform_mismatches=False,
                              fade_transform_mismatches=False, key_map=None, **kwargs)
```

上面两个类的**抽象基类**，规定了两个静态钩子：`get_mobject_parts`（拆零件）和 `get_mobject_key`（算键）。直接实例化它，会在调用钩子时 `raise NotImplementedError`；只有自定义「按文本内容/按自定义属性匹配」时才需要继承它。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `Mobject` | — | 源 |
| `target_mobject` | `Mobject` | — | 目标 |
| `transform_mismatches` | `bool` | `False` | 不匹配零件是否强行 `Transform` |
| `fade_transform_mismatches` | `bool` | `False` | 不匹配零件是否用 `FadeTransformPieces` |
| `key_map` | `dict \| None` | `None` | 手工键配对 `{源键: 目标键}` |
| `**kwargs` | … | — | 内部子变换参数与 `Animation` 通用参数 |

> **返回**：基类实例（**不可直接播放**）。
>
> **不匹配零件的处理规则**（三个类共用）：
>
> - `transform_mismatches=True` → 用 `Transform`；
> - `fade_transform_mismatches=True` → 用 `FadeTransformPieces`；
> - 两者都 `False`（默认）→ 源零件朝目标方向 `FadeOut`、目标零件朝源方向 `FadeIn`。
>
> 自定义匹配时继承它并实现两个钩子（手册示例 `MatchByColor` 用 `submobjects` + `str(get_color())` 作键）。

### `TransformMatchingStrings`（手册提到的「按字符串匹配」）

按字符串内容匹配的能力，已由 `TransformMatchingTex`（按 `tex_string`）覆盖。实测直接导入会报错：

```text
ImportError: cannot import name 'TransformMatchingStrings' from 'manim'
(C:\...\Lib\site-packages\manim\__init__.py). Did you mean: 'TransformMatchingShapes'?
```

无法演示：`TransformMatchingAbstractBase` 是抽象基类（`get_mobject_key` 直接 `raise NotImplementedError`），不可直接播放；自定义匹配（如按颜色）需要继承它并实现两个钩子。`TransformMatchingStrings` 则不存在于当前两引擎（见上文小节与错误原文）。
