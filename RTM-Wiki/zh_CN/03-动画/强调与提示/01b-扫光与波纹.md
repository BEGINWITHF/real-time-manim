# 扫光与波纹（ShowPassingFlash、ApplyWave）

让一束光沿笔画扫过、让波纹横穿对象的三个"流光/扰动"动画。

## 参数

### `ShowPassingFlash` 

```python
ShowPassingFlash(mobject, time_width=0.1, run_time=1.0, remover=True, **kwargs)
```

每一帧只显示一小段"滑动的光束"沿笔画扫过（而不是逐渐画满），播完后对象按 `remover` 处理，适合给边框/曲线做"能量流过"的效果。**继承** `ShowPassingFlash(Animation)`。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `VMobject` | —（必填） | 被扫过的矢量对象 |
| `time_width` | `float` | `0.1` | 光束长度占整条笔画的比例（`1` = 一整条，`2` = 两倍长） |
| `run_time` | `float` | `1.0` | 时长 |
| `remover` | `bool` | `True` | 播完是否把对象移出场景。2026-10-16 起**可显式传 `False`**（此前恒 `True`）：`False` 时对象留在场景并恢复全笔画 |
| `**kwargs` | … | — | `Animation` 通用参数（`rate_func`、`lag_ratio`…） |

> **返回**：`ShowPassingFlash` 实例。

一行上手：

```python
win.play(ShowPassingFlash(RegularPolygon(5, color=DARK_GRAY).scale(2), time_width=0.5))
```

### `ShowPassingFlashWithThinningStrokeWidth` 

```python
ShowPassingFlashWithThinningStrokeWidth(vmobject, n_segments=10, time_width=0.1, remover=True, **kwargs)
```

把 `n_segments` 个线宽递减、光束宽度递减的 `ShowPassingFlash` 叠加播放，形成"彗尾逐渐变细"的扫光效果（该类**无 docstring**，依据源码整理）。**继承** `ShowPassingFlashWithThinningStrokeWidth(AnimationGroup)`。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `vmobject` | `VMobject` | —（必填） | 被扫过的矢量对象 |
| `n_segments` | `int` | `10` | 分段数 |
| `time_width` | `float` | `0.1` | 起始光束宽度 |
| `remover` | `bool` | `True` | 播完是否移除 |
| `**kwargs` | … | — | 透传给每段 `ShowPassingFlash`（其中的 `time_width` 会被先弹出） |

> **返回**：`ShowPassingFlashWithThinningStrokeWidth` 实例。

一行上手：

```python
win.play(ShowPassingFlashWithThinningStrokeWidth(Circle(stroke_width=8), run_time=2))
```

### `ApplyWave` 

```python
ApplyWave(mobject, direction=UP, amplitude=0.2, wave_func=smooth, time_width=1,
          ripples=1, run_time=2, **kwargs)
```

让一道**波纹横穿对象**，使点集按方向周期性偏移后再复原（形状最终完全恢复）；`ripples` 控制波峰数量，`time_width` 控制波相对对象宽度的长度。**继承** `ApplyWave(Animation)`。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `Mobject` | —（必填） | 被扰动的对象 |
| `direction` | `Vector3DLike` | `UP` | 波推动点的方向（会归一化） |
| `amplitude` | `float` | `0.2` | 最大偏移量 |
| `wave_func` | `RateFunction` | `smooth` | 单个波峰的形状函数 |
| `time_width` | `float` | `1` | 波长相对对象宽度的比例 |
| `ripples` | `int` | `1` | 波纹个数 |
| `run_time` | `float` | `2` | 时长 |
| `**kwargs` | … | — | `Animation` 通用参数。RTM 自有 `ApplyWave` **没有 `apply_function_kwargs`**（它不是 `Homotopy` 子类，这个 kwarg 传进去会被 `**kwargs` 吞掉、不起作用） |

> **返回**：`ApplyWave` 实例。

一行上手：

```python
win.play(ApplyWave(Tex("WaveWaveWave").scale(2), ripples=3, amplitude=0.3))
```

#### 样例：ShowPassingFlash / 彗尾扫光 / ApplyWave 逐项演示

本页成片按 ShowPassingFlash → ShowPassingFlashWithThinningStrokeWidth → ApplyWave 的顺序各演示一段，参数逐条标在画面里。

```python
from real_time_manim import (
    BLUE,
    DARK_GRAY,
    GREEN,
    GREY_B,
    YELLOW,
    DOWN,
    LEFT,
    RIGHT,
    UP,
    Circle,
    RegularPolygon,
    Scene,
    ShowPassingFlashWithThinningStrokeWidth,
    Text,
    VGroup,
    smooth,
)
from real_time_manim.vulkan_bind import (
    MLWindow,
    ApplyWave,
    FadeIn,
    FadeOut,
    ShowPassingFlash,
    Wait,
    Write,
)
from real_time_manim.record import fast_record_scene  # noqa: F401  文件末尾 __main__ 使用


class Page_01b_扫光与波纹(Scene):
    def construct(self):
        win = MLWindow(1280, 720, hidden=True)   # 参数 w=1280 / h=720 / hidden=True
        win.scene = self                          # 参数 win.scene

        title = Text("ShowPassingFlash / ApplyWave",
                     font_size=36, color=GREEN).to_edge(UP)   #标题只用 ASCII：两引擎字体回退才稳
        win.play(Write(title), run_time=0.8)

        # —— 步骤 1：ShowPassingFlash(mobject, time_width, **kwargs) ——
        sig1 = Text("ShowPassingFlash(poly, time_width=0.5, run_time=1.6)",
                    font_size=30, color=GREY_B).next_to(title, DOWN, buff=0.4)
        poly = RegularPolygon(5, color=DARK_GRAY).scale(1.6).next_to(sig1, DOWN, buff=0.7)
        win.play(FadeIn(sig1, shift=DOWN), run_time=0.45)
        win.play(
            ShowPassingFlash(
                poly,                                    # 参数 mobject ✓
                time_width=0.5,                          # 参数 time_width=0.5 ✓（默认 0.1：光束占整条 50%）
                run_time=1.6,                            # 参数 **kwargs(run_time) ✓
            ),
            run_time=1.6,
        )
        # RTM 版 remover 默认 True，播完把 mobject 移出场景，因此不再对五边形 FadeOut
        #（2026-10-16 起 remover 可显式传 False，让对象留在场景）。
        win.play(FadeOut(sig1), run_time=0.45)

        # —— 步骤 2：ShowPassingFlashWithThinningStrokeWidth(
        #                vmobject, n_segments, time_width, remover, **kwargs) ——
        s2a = Text("ShowPassingFlashWithThinningStrokeWidth(", font_size=28, color=GREY_B)
        s2b = Text("    ring, n_segments=12, time_width=0.15,", font_size=28, color=GREY_B)
        s2c = Text("    remover=True, run_time=1.8)", font_size=28, color=GREY_B)
        sig2 = VGroup(s2a, s2b, s2c).arrange(DOWN, buff=0.08).next_to(title, DOWN, buff=0.4)
        ring = Circle(radius=1.2, stroke_width=10, color=BLUE).next_to(sig2, DOWN, buff=0.6)
        win.play(FadeIn(sig2, shift=DOWN), run_time=0.45)
        win.play(
            ShowPassingFlashWithThinningStrokeWidth(
                ring,                                    # 参数 vmobject ✓
                n_segments=12,                           # 参数 n_segments=12 ✓（默认 10）
                time_width=0.15,                         # 参数 time_width=0.15 ✓（默认 0.1）
                remover=True,                            # 参数 remover=True ✓（默认值，显式传）
                run_time=1.8,                            # 参数 **kwargs(run_time) ✓
            ),
            run_time=1.8,
        )
        win.play(FadeOut(sig2), FadeOut(ring), run_time=0.45)

        # —— 步骤 3：ApplyWave(mobject, direction, amplitude, wave_func,
        #                      time_width, ripples, run_time) ——
        s3a = Text("ApplyWave(txt, direction=UP, amplitude=0.35,", font_size=30, color=GREY_B)
        s3b = Text("           wave_func=smooth, time_width=1,", font_size=30, color=GREY_B)
        s3c = Text("           ripples=3, run_time=2)", font_size=30, color=GREY_B)
        sig3 = VGroup(s3a, s3b, s3c).arrange(DOWN, buff=0.08).next_to(title, DOWN, buff=0.4)
        wtxt = Text("WaveWaveWave", font_size=46, color=YELLOW).next_to(sig3, DOWN, buff=0.9)
        win.play(FadeIn(sig3, shift=DOWN), run_time=0.45)
        win.play(
            ApplyWave(
                wtxt,                                    # 参数 mobject ✓
                direction=UP,                            # 参数 direction=UP ✓（显式：波推动方向）
                amplitude=0.35,                          # 参数 amplitude=0.35 ✓（默认 0.2）
                wave_func=smooth,                        # 参数 wave_func=smooth ✓（单个波峰形状）
                time_width=1,                            # 参数 time_width=1 ✓（波长占比）
                ripples=3,                               # 参数 ripples=3 ✓（默认 1）
                run_time=2,                              # 参数 run_time=2 ✓
            ),
        )
        win.play(FadeOut(sig3), FadeOut(wtxt), run_time=0.5)
        win.play(Wait(0.3))

        win.play(FadeOut(title), run_time=0.5)
        win.close()
```

这段代码在做什么：先写标题，然后三段演示。

- 第一段：一个深灰五边形，`ShowPassingFlash` 让一束占整条笔画 50% 的光沿边扫一圈（1.6 秒）。
- 第二段：一个蓝色圆环，`ShowPassingFlashWithThinningStrokeWidth` 用 12 段线宽递减的扫光叠加出"彗尾变细"的效果。
- 第三段：黄色文字 "WaveWaveWave"，`ApplyWave` 让 3 个波峰从下往上横穿它，播完形状完全复原。

每段播完清场，最后关窗口。

> 提醒：
>
> - `ShowPassingFlash` 的 `remover` 默认 `True`（保持向后兼容）：播完对象**被移出场景**（样例用默认值，因此不再对五边形 `FadeOut`）；显式 `remover=False` 时对象留在场景，且恢复全笔画（`_restore_full_stroke`）。
> - `ApplyWave` 的 `time_width`/`ripples` 都是相对对象**宽度**的；同样参数用在更宽的对象上，波形会更平缓。
