# 圈注与聚焦（Circumscribe、FocusOn、Wiggle）

给对象画一圈临时边框、把光斑收缩聚焦、以及把对象"抖一下"的三个提示动画。

## 参数

### `Circumscribe` 

```python
Circumscribe(mobject, shape=Rectangle, fade_in=False, fade_out=False, time_width=0.3,
             buff=SMALL_BUFF, color=PURE_YELLOW, run_time=1, stroke_width=DEFAULT_STROKE_WIDTH, **kwargs)
```

在对象周围**画一圈临时边框再擦掉**；**注意 `shape` 传的是类，而不是实例**。

`shape` 的校验两版不同：

- **CE 版**只认 `Rectangle` / `Circle`，其他类抛 `ValueError("shape should be either Rectangle or Circle.")`。
- **RTM 自有版不报错**：`shape is Rectangle` 走 `SurroundingRectangle`，**其余一律按 `Circle` 处理**（传 `Dot` 之类也静默画圆）。

**继承** `Circumscribe(Succession)` ← `AnimationGroup` ← `Animation`（RTM 自有链与 CE 同构）。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `Mobject` | —（必填） | 被圈起来的对象 |
| `shape` | `type[Rectangle] \| type[Circle]` | `Rectangle` | 边框形状**类**（`Rectangle` 或 `Circle`） |
| `fade_in` | `bool` | `False` | 边框渐显（并反转绘制方向） |
| `fade_out` | `bool` | `False` | 边框渐隐 |
| `time_width` | `float` | `0.3`（哨兵默认） | 已接入（2026-10-16，测试 `tests/test_gap_indication_fade.py`）：**显式传**（含显式 `0.3`）时非 fade 分支改用 `ShowPassingFlash` 光束语义（每帧只点亮宽 `time_width` 的一小段）；**不传时保持旧的 `Create` 渐进绘制**（既有渲染逐帧不变，默认值以哨兵对象标识、`signature` 仍打印 `0.3`）；`fade_in`/`fade_out=True` 分支**忽略**该参数（本页两条样例走的正是 fade 分支） |
| `buff` | `float` | `SMALL_BUFF` | 边框与对象的间距 |
| `color` | `ParsableManimColor` | `PURE_YELLOW` | 边框颜色。RTM 自有版默认值写的是 `None`、内部兜底成 manim 的 **`YELLOW`**（偏奶油）
| `run_time` | `float` | `1` | 整体时长（fade 模式下自动平分两段） |
| `stroke_width` | `float` | `DEFAULT_STROKE_WIDTH (=4)` | 边框线宽 |
| `**kwargs` | … | — | 转发给内部 `Succession` 及其子动画 |

> **返回**：`Circumscribe` 实例。

一行上手：

```python
lbl = Tex("Circumscribe").scale(2)
win.play(Circumscribe(lbl, Circle, fade_out=True))
```

### `FocusOn` 

```python
FocusOn(focus_point, opacity=0.2, color=GREY, run_time=2, **kwargs)
```

一个**大光斑收缩到目标点**并留下小亮点的"聚焦"效果（内部先建一个半径=画面半径的大 `Dot`，再变换成贴在目标上的小圆点），播完自动移除（`remover=True`）。**继承** `FocusOn(Transform)`。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `focus_point` | `Point3DLike \| Mobject` | —（必填） | 聚焦点；给 mobject 时取中心 |
| `opacity` | `float` | `0.2` | 聚焦后光斑的不透明度 |
| `color` | `ParsableManimColor` | `GREY` | 光斑颜色 |
| `run_time` | `float` | `2` | 时长 |
| `**kwargs` | … | — | `Transform`/`Animation` 通用参数 |

> **返回**：`FocusOn` 实例。

一行上手：

```python
win.play(FocusOn(Dot(color=PURE_YELLOW).shift(DOWN)))
```

### `Wiggle` 

```python
Wiggle(mobject, scale_value=1.1, rotation_angle=0.01 * TAU, n_wiggles=6,
       scale_about_point=None, rotate_about_point=None, run_time=2, **kwargs)
```

对象在原地**小幅缩放 + 左右摆动 `n_wiggles` 次**后复原（用 `wiggle` 速率函数），像被"抖了一下"；与 `ApplyWave` 的区别是 `Wiggle` 整体摆动、`ApplyWave` 波在内部传播。**继承** `Wiggle(Animation)`。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `Mobject` | —（必填） | 被摇动的对象 |
| `scale_value` | `float` | `1.1` | 临时放大幅度 |
| `rotation_angle` | `float` | `0.01*TAU (=3.6°)` | 单次摆动角度 |
| `n_wiggles` | `int` | `6` | 摆动次数 |
| `scale_about_point` | `Point3DLike \| None` | `None` | 缩放中心，`None` 用对象中心 |
| `rotate_about_point` | `Point3DLike \| None` | `None` | 旋转中心，`None` 用对象中心 |
| `run_time` | `float` | `2` | 时长 |
| `**kwargs` | … | — | `Animation` 通用参数 |

> **返回**：`Wiggle` 实例。

一行上手：

```python
win.play(Wiggle(Tex("Wiggle").scale(3)))
```

#### 样例：Circumscribe 两种边框 / FocusOn / Wiggle 逐项演示

本页成片按 Circumscribe(矩形) → Circumscribe(圆形) → FocusOn → Wiggle 的顺序各演示一段，参数逐条标在画面里。

```python
from real_time_manim import (
    GREEN,
    GREY_B,
    PURE_YELLOW,
    PURPLE,
    SMALL_BUFF,
    TEAL,
    TAU,
    DOWN,
    UP,
    Circle,
    Dot,
    FocusOn,
    Rectangle,
    Scene,
    Text,
    VGroup,
    Wiggle,
)
from real_time_manim.vulkan_bind import (
    MLWindow,
    Circumscribe,
    FadeIn,
    FadeOut,
    Wait,
    Write,
)
from real_time_manim.record import fast_record_scene  # noqa: F401  文件末尾 __main__ 使用


class Page_02_圈注与聚焦(Scene):
    def construct(self):
        win = MLWindow(1280, 720, hidden=True)   # 参数 w=1280 / h=720 / hidden=True
        win.scene = self                          # 参数 win.scene

        title = Text("Circumscribe / FocusOn / Wiggle",
                     font_size=36, color=GREEN).to_edge(UP)   #标题只用 ASCII：两引擎字体回退才稳
        win.play(Write(title), run_time=0.8)

        lbl = Text("Circumscribe", font_size=46, color=GREEN).shift(DOWN * 1.6)

        # —— 步骤 1：Circumscribe(shape=Rectangle, fade_out=True) ——
        s1a = Text("Circumscribe(lbl, shape=Rectangle, fade_in=False,", font_size=28, color=GREY_B)
        s1b = Text("    fade_out=True, time_width=0.3, buff=SMALL_BUFF,", font_size=28, color=GREY_B)
        s1c = Text("    color=PURE_YELLOW, run_time=1.6, stroke_width=6)", font_size=28, color=GREY_B)
        sig1 = VGroup(s1a, s1b, s1c).arrange(DOWN, buff=0.08).next_to(title, DOWN, buff=0.35)
        win.play(FadeIn(sig1, shift=DOWN), run_time=0.45)
        cs1 = Circumscribe(
            lbl,                                     # 参数 mobject ✓
            shape=Rectangle,                         # 参数 shape=Rectangle（类，不是实例）✓
            fade_in=False,                           # 参数 fade_in=False ✓
            fade_out=True,                           # 参数 fade_out=True ✓（默认 False：边框渐隐）
            time_width=0.3,                          # 参数 time_width=0.3（本例 fade_out=True：fade 分支忽略该参数）
            buff=SMALL_BUFF,                         # 参数 buff=SMALL_BUFF ✓
            color=PURE_YELLOW,                       # 参数 color=PURE_YELLOW ✓
            run_time=1.6,                            # 参数 run_time=1.6 ✓（fade 模式自动平分两段）
            stroke_width=6,                          # 参数 stroke_width=6 ✓（默认 4）
        )
        # 手动把标签 lbl 放进场景（Circumscribe 的 .mobject 是 None、不携带文本）；
        # 边框 _frame 自 2026-10-16 起也会被 play 层"组子动画呈现"自动带进场景，
        # 这里的 self.add 变成幂等兜底，播完 clean_up_from_scene 仍会移除 _frame。
        self.add(lbl, cs1._frame)
        win.play(cs1)
        win.play(FadeOut(sig1), run_time=0.4)

        # —— 步骤 2：Circumscribe(shape=Circle, fade_in=True) ——
        s2a = Text("Circumscribe(lbl, shape=Circle, fade_in=True,", font_size=30, color=GREY_B)
        s2b = Text("    buff=0.18, color=TEAL, stroke_width=6, run_time=1.6)", font_size=30, color=GREY_B)
        sig2 = VGroup(s2a, s2b).arrange(DOWN, buff=0.08).next_to(title, DOWN, buff=0.35)
        win.play(FadeIn(sig2, shift=DOWN), run_time=0.4)
        cs2 = Circumscribe(
            lbl,                                     # 参数 mobject ✓
            shape=Circle,                            # 参数 shape=Circle ✓（默认 Rectangle）
            fade_in=True,                            # 参数 fade_in=True ✓（默认 False：边框渐显）
            buff=0.18,                               # 参数 buff=0.18 ✓（默认 SMALL_BUFF）
            color=TEAL,                              # 参数 color=TEAL ✓（默认 PURE_YELLOW）
            stroke_width=6,                          # 参数 stroke_width=6 ✓
            run_time=1.6,                            # 参数 run_time=1.6 ✓
        )
        self.add(cs2._frame)
        win.play(cs2)
        win.play(FadeOut(sig2), FadeOut(lbl), run_time=0.4)

        # —— 步骤 3：FocusOn(focus_point, opacity, color, run_time) ——
        s3a = Text("FocusOn(dot, opacity=0.4,", font_size=32, color=GREY_B)
        s3b = Text("         color=PURPLE, run_time=1.4)", font_size=32, color=GREY_B)
        sig3 = VGroup(s3a, s3b).arrange(DOWN, buff=0.08).next_to(title, DOWN, buff=0.35)
        dot = Dot(radius=0.1, color=PURPLE).next_to(sig3, DOWN, buff=1.2)
        win.play(FadeIn(sig3, shift=DOWN), run_time=0.4)
        self.add(dot)
        win.play(
            FocusOn(
                dot,                                   # 参数 focus_point（传 mobject → 取中心）✓
                opacity=0.4,                           # 参数 opacity=0.4 ✓（默认 0.2）
                color=PURPLE,                          # 参数 color=PURPLE ✓（默认 GREY）
                run_time=1.4,                          # 参数 run_time=1.4 ✓（默认 2）
            ),
        )
        win.play(FadeOut(sig3), FadeOut(dot), run_time=0.4)

        # —— 步骤 4：Wiggle(mobject, scale_value, rotation_angle, n_wiggles,
        #                   scale_about_point, rotate_about_point, run_time) ——
        s4a = Text("Wiggle(wig, scale_value=1.35, rotation_angle=0.03*TAU,", font_size=28, color=GREY_B)
        s4b = Text("        n_wiggles=4, scale_about_point=None,", font_size=28, color=GREY_B)
        s4c = Text("        rotate_about_point=None, run_time=1.6)", font_size=28, color=GREY_B)
        sig4 = VGroup(s4a, s4b, s4c).arrange(DOWN, buff=0.08).next_to(title, DOWN, buff=0.35)
        wig = Text("Wiggle", font_size=52, color=GREEN).next_to(sig4, DOWN, buff=0.9)
        win.play(FadeIn(sig4, shift=DOWN), run_time=0.4)
        self.add(wig)
        win.play(
            Wiggle(
                wig,                                   # 参数 mobject ✓
                scale_value=1.35,                      # 参数 scale_value=1.35 ✓（默认 1.1）
                rotation_angle=0.03 * TAU,             # 参数 rotation_angle=0.03*TAU ✓（默认 0.01*TAU）
                n_wiggles=4,                           # 参数 n_wiggles=4 ✓（默认 6）
                scale_about_point=None,                # 参数 scale_about_point=None ✓（用对象中心）
                rotate_about_point=None,               # 参数 rotate_about_point=None ✓（用对象中心）
                run_time=1.6,                          # 参数 run_time=1.6 ✓（默认 2）
            ),
        )
        win.play(FadeOut(sig4), FadeOut(wig), run_time=0.45)
        win.play(Wait(0.3))

        win.play(FadeOut(title), run_time=0.5)
        win.close()
```

这段代码在做什么：先写标题，放一个绿色 "Circumscribe" 文字，然后四段演示。

- 第一段：黄色矩形边框画出来再渐隐（`fade_out=True`），圈住文字。
- 第二段：青色圆形边框渐显再擦掉（`fade_in=True` + `shape=Circle`）。
- 第三段：紫色大光斑收缩到小圆点上（`FocusOn`，`opacity=0.4`）。
- 第四段：文字 "Wiggle" 整体放大 1.35 倍、摆 4 次后复原。

`self.add(lbl, cs1._frame)` 负责把**标签**送进场景（`Circumscribe` 的 `.mobject` 是 `None`、不携带文本），内部边框则由 play 层自动呈现（代码注释里标了原因）。

> 提醒：
>
> - `shape` 传的是**类**（`Rectangle` / `Circle`）而不是实例；传**其他类**时，**CE 版抛 `ValueError`**，**RTM 自有版不报错**（非 `Rectangle` 一律按 `Circle` 画圆，见参数表）。
> - `Circumscribe` 的 `.mobject` 是 `None`、**不会携带被圈的文本**，所以样例手动 `self.add(lbl, ...)` 把标签放进场景；内部边框 `_frame` 自 2026-10-16 的"组子动画呈现"（`_ensure_animated_present` 会走一层 `animations` 的 mobject）起也会被自动带进场景，`self.add(cs1._frame)` 因此成了**幂等兜底**——加不加都看得见，播完 `clean_up_from_scene` 会把 `_frame` 清掉。
> - `FocusOn` 播完自己会移除（`remover=True`），不用再 `FadeOut`。
