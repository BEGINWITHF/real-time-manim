# 强调与闪烁（Indicate、Flash、Blink）

把观众视线临时拉到某个对象上的三个动画：放大染色强调（`Indicate`）、放射闪光（`Flash`）、明暗闪烁（`Blink`）。

## 参数

### `Indicate` 

```python
Indicate(mobject, scale_factor=1.2, color=PURE_YELLOW, rate_func=there_and_back, **kwargs)
```

临时把对象**放大并染成高亮色再回到原样**（`rate_func=there_and_back` 保证"去一趟再回来"），是最常用的"重点提示"动画。**继承** `Indicate(Animation)`。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `Mobject` | —（必填） | 被强调的对象 |
| `scale_factor` | `float` | `1.2` | 强调时的放大倍数 |
| `color` | `ParsableManimColor` | `PURE_YELLOW` | 强调时的颜色（播完恢复原色）。RTM 自有版默认值是 manim 的 **`YELLOW`**（`#F7D96F`，偏奶油），纯黄）——两版默认颜色不同，显式传值即一致 |
| `rate_func` | `RateFunction` | `there_and_back` | 去—回的进度曲线 |
| `run_time` | `float` | `1.0`（固定） | 构造器里 `kwargs.pop('run_time')` **直接丢弃**：`Indicate(sq, run_time=3)` 无效、恒 `1.0`；要改时长只能**在 play 级**传（`win.play(Indicate(...), run_time=1.4)` 会 setattr 覆盖） |
| `**kwargs` | … | — | `Animation` 通用参数（`reverse_rate_function`、`name`…）。RTM 自有 `Indicate` **不是 `Transform` 子类**，`path_arc` 之类传了无效（被 `**kwargs` 吞掉） |

> **返回**：`Indicate` 实例。

一行上手：

```python
win.play(Indicate(Tex("Indicate").scale(3)))
```

### `Flash`

```python
Flash(point, line_length=0.2, num_lines=12, flash_radius=0.1, line_stroke_width=3,
      color=PURE_YELLOW, time_width=1, run_time=1.0, **kwargs)
```

从某点向四周**放射出一圈闪光短线**（每条线是一次 `ShowPassingFlash`，由 `AnimationGroup` 组合）；`point` 可以是坐标点，也可以是 mobject（自动取中心）。**继承** `Flash(AnimationGroup)`。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `point` | `Point3DLike \| Mobject` | —（必填） | 闪光中心 |
| `line_length` | `float` | `0.2` | 每条线长度 |
| `num_lines` | `int` | `12` | 线条数量 |
| `flash_radius` | `float` | `0.1` | 线条起点距中心的距离 |
| `line_stroke_width` | `int` | `3` | 线宽 |
| `color` | `ParsableManimColor` | `PURE_YELLOW` | 线条颜色 |
| `time_width` | `float` | `1` | 传给 `ShowPassingFlash` 的光束宽度 |
| `run_time` | `float` | `1.0` | 时长 |
| `**kwargs` | … | — | 存为 `animation_config`，透传给每条线的 `ShowPassingFlash`（如 `rate_func=rush_from`） |

> **返回**：`Flash` 实例。

一行上手：

```python
win.play(Flash(Dot(color=PURE_YELLOW).shift(DOWN), num_lines=30, color=RED))
```

### `Blink`

```python
Blink(mobject, time_on=0.5, time_off=0.5, blinks=1, hide_at_end=False, **kwargs)
```

让对象**闪烁**：按 `blinks` 次数反复"显示 `time_on` 秒 / 隐藏 `time_off` 秒"，常与 `TypeWithCursor` 组合做光标闪烁（见 [01b-带光标打字](../文字与数字/01b-带光标打字.md)）。**继承** `Blink(Succession)` ← `AnimationGroup` ← `Animation`。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `Mobject` | —（必填） | 被闪烁的对象 |
| `time_on` | `float` | `0.5` | 每次可见时长 |
| `time_off` | `float` | `0.5` | 每次隐藏时长 |
| `blinks` | `int` | `1` | 闪烁次数 |
| `hide_at_end` | `bool` | `False` | `True` 则结束时保持隐藏 |
| `run_time` | `float` | 由 `time_on`/`time_off`/`blinks` 算出 | `kwargs.pop('run_time')` **直接丢弃**：实际时长恒为 `blinks × (time_on + time_off)`（`hide_at_end=False` 再补一次 `time_on`），构造器里传 `run_time=` 无效 |
| `**kwargs` | … | — | 转发给内部 `Succession`（`run_time` 除外，见上一行） |

> **返回**：`Blink` 实例。

一行上手：

```python
win.play(Blink(Text("Blinking").scale(1.5), blinks=3))
```

#### 样例：Indicate / Flash / Blink 逐项演示

本页成片按 Indicate → Flash → Blink 的顺序各演示一段，参数逐条标在画面里。

```python
from real_time_manim import (
    BLUE,
    DARK_GRAY,
    GREEN,
    GREY_B,
    RED,
    DOWN,
    UP,
    Dot,
    Flash,
    Scene,
    Square,
    Text,
    VGroup,
    rush_from,
    there_and_back,
)
from real_time_manim.vulkan_bind import (
    MLWindow,
    Blink,
    FadeIn,
    FadeOut,
    Indicate,
    Write,
)
from real_time_manim.record import fast_record_scene  # noqa: F401  文件末尾 __main__ 使用


class Page_01_强调与闪烁(Scene):
    def construct(self):
        win = MLWindow(1280, 720, hidden=True)   # 参数 w=1280 / h=720 / hidden=True
        win.scene = self                          # 参数 win.scene

        title = Text("Indicate / Flash / Blink",
                     font_size=38, color=GREEN).to_edge(UP)   #标题只用 ASCII：两引擎字体回退才稳
        win.play(Write(title), run_time=0.8)

        # —— 步骤 1：Indicate(mobject, scale_factor, color, rate_func, **kwargs) ——
        s1a = Text("Indicate(sq, scale_factor=1.6,", font_size=32, color=GREY_B)
        s1b = Text("          color=RED, rate_func=there_and_back)", font_size=32, color=GREY_B)
        sig1 = VGroup(s1a, s1b).arrange(DOWN, buff=0.08).next_to(title, DOWN, buff=0.4)
        sq = Square(side_length=1.6, color=BLUE).set_fill(BLUE, 0.5).next_to(sig1, DOWN, buff=0.7)
        win.play(FadeIn(sig1, shift=DOWN), run_time=0.45)
        win.play(
            Indicate(
                sq,                                      # 参数 mobject ✓
                scale_factor=1.6,                        # 参数 scale_factor=1.6 ✓（默认 1.2）
                color=RED,                               # 参数 color=RED ✓（默认 PURE_YELLOW）
                rate_func=there_and_back,                # 参数 rate_func ✓（显式：去一趟再回来）
            ),
            run_time=1.4,                                # 参数 **kwargs(run_time)：play 级覆盖 ✓
        )
        win.play(FadeOut(sig1), FadeOut(sq), run_time=0.45)

        # —— 步骤 2：Flash(point, line_length, num_lines, flash_radius,
        #                   line_stroke_width, color, time_width, run_time, **kwargs) ——
        s2a = Text("Flash(dot, line_length=0.3, num_lines=30,", font_size=30, color=GREY_B)
        s2b = Text("        flash_radius=0.18, line_stroke_width=5,", font_size=30, color=GREY_B)
        s2c = Text("        color=RED, time_width=1.5, rate_func=rush_from)", font_size=30, color=GREY_B)
        sig2 = VGroup(s2a, s2b, s2c).arrange(DOWN, buff=0.08).next_to(title, DOWN, buff=0.4)
        dot = Dot(radius=0.12, color=DARK_GRAY).next_to(sig2, DOWN, buff=1.0)
        win.play(FadeIn(sig2, shift=DOWN), run_time=0.45)
        win.play(
            Flash(
                dot,                                     # 参数 point（传 mobject → 取中心）✓
                line_length=0.3,                         # 参数 line_length=0.3 ✓（默认 0.2）
                num_lines=30,                            # 参数 num_lines=30 ✓（默认 12）
                flash_radius=0.18,                       # 参数 flash_radius=0.18 ✓（默认 0.1）
                line_stroke_width=5,                     # 参数 line_stroke_width=5 ✓（默认 3）
                color=RED,                               # 参数 color=RED ✓（默认 PURE_YELLOW）
                time_width=1.5,                          # 参数 time_width=1.5 ✓（默认 1）
                run_time=1.2,                            # 参数 run_time=1.2 ✓（默认 1.0）
                rate_func=rush_from,                     # 参数 **kwargs → 透传给每条线的 ShowPassingFlash ✓
            ),
            run_time=1.2,
        )
        win.play(FadeOut(sig2), FadeOut(dot), run_time=0.45)

        # —— 步骤 3：Blink(mobject, time_on, time_off, blinks, hide_at_end, **kwargs) ——
        s3a = Text("Blink(txt, time_on=0.35, time_off=0.25,", font_size=32, color=GREY_B)
        s3b = Text("        blinks=3, hide_at_end=True)", font_size=32, color=GREY_B)
        sig3 = VGroup(s3a, s3b).arrange(DOWN, buff=0.08).next_to(title, DOWN, buff=0.4)
        txt = Text("Blinking", font_size=48, color=GREEN).next_to(sig3, DOWN, buff=0.9)
        win.play(FadeIn(sig3, shift=DOWN), run_time=0.45)
        self.add(txt)                                  #Blink 不负责引入对象：先放进场景才闪得起来
        win.play(
            Blink(
                txt,                                     # 参数 mobject ✓
                time_on=0.35,                            # 参数 time_on=0.35 ✓（默认 0.5）
                time_off=0.25,                           # 参数 time_off=0.25 ✓（默认 0.5）
                blinks=3,                                # 参数 blinks=3 ✓（默认 1）
                hide_at_end=True,                        # 参数 hide_at_end=True ✓（默认 False：结束时保持隐藏）
            ),
        )
        win.play(FadeOut(sig3), run_time=0.45)

        win.play(FadeOut(title), run_time=0.5)
        win.close()
```

这段代码在做什么：开一个 RTM 窗口把场景绑上去，先写出标题，然后分三段演示。

- 第一段：淡入参数说明和一个蓝色方块，`Indicate` 把方块放大 1.6 倍、染成红色再回到原样。
- 第二段：一个深灰小圆点，`Flash` 从它中心放射 30 条短线（`rate_func=rush_from` 让光线冲出去）。
- 第三段：绿色文字 "Blinking" 先 `self.add` 进场景，再按 `time_on=0.35` / `time_off=0.25` 闪 3 次，`hide_at_end=True` 闪完保持隐藏。

每段播完都把说明和对象淡出，最后收标题、关窗口。

> 提醒：
>
> - `Blink` **不负责把对象引入场景**——忘了先 `self.add(txt)`，就会全程黑屏、什么也闪不出来（样例里就是靠这行救回来的）。
> - `Indicate` 的 `rate_func` 记得留 `there_and_back` 这类**往返**曲线："回来"这半程是它负责的；换成单向曲线，对象就停在放大染色的状态。
> - `Flash` 的 `**kwargs` 是透传给每条线的 `ShowPassingFlash` 的；想改光线的节奏，就把 `rate_func` 写进 `Flash(...)` 里。
> - `Blink` 默认 `hide_at_end=False`，闪完对象还在；想"闪完就消失"传 `True`。
