# 变换路径与序列工具：paths、simple_functions、iterables

三个小工具模块：变换轨迹、数学小函数与序列处理；除标注外都可 `from manim import ...`。RTM 直接复用 manim 实现——`Transform` 的 `path_func` 钩子与 numpy 序列运算逐位一致。本页两条样例分别演示 `path_along_arc` 的三种轨迹和 `adjacent_pairs` 闭合连边 + 三个数学小函数取值，均已在 RTM 实测出片。

## `path_along_arc` —— 沿圆弧变换（`utils/paths.py`）

```python
path_along_arc(arc_angle: float, axis: Vector3DLike = OUT) -> PathFuncType
```

用于 `Transform(m1, m2, path_func=...)`：让每个点沿圆弧转 `arc_angle` 弧度到达终点（绕 `axis`）。`arc_angle=TAU/2` 是绕半圈，`-TAU/2` 反向；`|arc_angle| < 0.01` 时自动退化成直线路径。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `arc_angle` | `float` | 必填 | 每个点绕过的角度（弧度，可为负） |
| `axis` | `Vector3DLike` | `OUT` | 旋转轴 |

> **返回**：`PathFuncType`，签名 `(start_points, end_points, alpha) -> points`，直接传给 `Transform(..., path_func=...)`。

#### 样例：同一条弦的三条变换轨迹

三条泳道的起点、终点完全相同（同一条弦），同时出发：上道 `path_along_arc(-TAU / 2)` 弧线鼓到弦的上方、中道默认直线、下道 `path_along_arc(TAU / 2)` 弧线鼓到下方——半圈的圆弧恰好是以弦为直径的半圆。

```python
from real_time_manim import Scene, Text, VGroup, Dot, Line, Circle, BLUE, GREEN, \
    RED, YELLOW, GREY_B, UP, DOWN, TAU, path_along_arc, Transform, \
    FadeIn, Write, Create
from real_time_manim.vulkan_bind import MLWindow, Wait

class PathArcDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("04b-path_along_arc", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        xs0, xs1 = -1.8, 1.8   #三条泳道共用的起点与终点横坐标（弦长相同）
        lanes = [
            (1.1, GREEN, "path_along_arc(-TAU/2)", -TAU / 2),   #上：反向绕半圈（弧线鼓到上方）
            (-0.2, BLUE, "straight (default)", None),   #中：默认直线路径
            (-1.4, RED, "path_along_arc(TAU/2)", TAU / 2),   #下：正向绕半圈（弧线鼓到下方）
        ]
        movers = []
        for y, c, nm, arc in lanes:
            track = Line([xs0, y, 0], [xs1, y, 0], color=GREY_B, stroke_width=2)
            track.set_stroke(opacity=0.3)   #弦（参考直线，半透明）
            lab = Text(nm, font_size=16, color=c).next_to(track, UP, buff=0.15)   #泳道名在轨道上方
            s0 = Circle(radius=0.12, color=GREY_B, stroke_width=2).move_to([xs0, y, 0])   #起点环
            s1 = Circle(radius=0.12, color=GREY_B, stroke_width=2).move_to([xs1, y, 0])   #终点环
            dot = Dot([xs0, y, 0], radius=0.14, color=c)   #出发的点
            target = Dot([xs1, y, 0], radius=0.14, color=c)   #终点处的目标点
            win.play(FadeIn(VGroup(track, lab, s0, s1)), run_time=0.4)   #泳道先就位
            movers.append((dot, target, arc))
        win.play(FadeIn(VGroup(*[m for m, _, _ in movers])), run_time=0.3)   #三个点就位
        win.play(*[Transform(m, t, path_func=path_along_arc(a) if a else None,
                             run_time=1.6)
                   for m, t, a in movers])   #同一条弦 × 三种 path_func 同时出发
        note = Text("Transform(..., path_func=path_along_arc(arc))",
                    font_size=18, color=YELLOW).to_edge(DOWN)   #底部说明
        win.play(FadeIn(note), run_time=0.35)   #说明淡入
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：三条泳道的灰色半透明弦是"直线距离"参考，三个彩色的点同时做同样终点的 `Transform`——只有 `path_func` 不同。绿点和红点分别向弦的两侧鼓出半圆（`±TAU/2` 正好各是直径等于弦的半圆），蓝点按默认直线走。中途抽任何一帧，都能看到三个点在完全不同的轨迹上。

<video src="assets/RTM output/04b-路径与序列工具-paths.mp4" controls width="560"></video>

> 提醒：`path_along_arc` 的弧是**绕起点—终点中点转出来的圆弧**，`±π` 时就是以弦为直径的半圆，弧的"鼓起高度"等于弦长的一半——弦拉太长弧就飞出画面，取景时要留够空间；小角度（`< 0.01`）它会自动退化成直线，不会因数值问题抖动。

## 其余路径函数（`utils/paths.py`）

| 函数签名 | 作用 |
| --- | --- |
| `straight_path() -> PathFuncType` | 直线路径（`Transform` 的默认行为） |
| `clockwise_path() -> PathFuncType` | 顺时针绕半圆（= `path_along_arc(-π)`） |
| `counterclockwise_path() -> PathFuncType` | 逆时针绕半圆（= `path_along_arc(π)`） |
| `path_along_circles(arc_angle, circles_centers, axis=OUT)` | 每个点绕**各自的圆心**转（不在顶层导出，需 `real_time_manim.manim.utils.paths.path_along_circles`） |
| `spiral_path(angle, axis=OUT)` | 边转边向终点收拢的螺旋路径（不在顶层导出，需 `real_time_manim.manim.utils.paths.spiral_path`） |
| `STRAIGHT_PATH_THRESHOLD = 0.01` | 角度小于此值时自动退化成直线（不在顶层导出） |

## `iterables` —— 序列小工具

> 标 ⚙ 的需要 `from real_time_manim.manim.utils.iterables import ...`（深层路径，RTM 的别名会解析到自带的同一份模块），其余可 `from real_time_manim import ...`。

| 签名 | 频率 | 作用 |
| --- | --- | --- |
| `listify(obj) -> list` | 🟡 | 智能转列表：字符串变 `[str]`，可迭代对象变 `list(...)`，其他变 `[obj]` |
| `tuplify(obj) -> tuple` | ⚪ | 同上，转元组 |
| `adjacent_pairs(objects)` | 🟡 | 环形取相邻对：`[1,2,3,4] → (1,2),(2,3),(3,4),(4,1)`（画多边形边时常用） |
| `adjacent_n_tuples(objects, n)` | ⚪ | 环形取长度为 n 的元组（`adjacent_pairs` 的推广） |
| `remove_nones(sequence) -> list` | 🟡 | 过滤掉所有"假值"元素（`None`、`""`、`0`、`False`…） |
| `list_update(l1, l2) -> list` | 🟡 | 去重合并且**保持 l2 顺序不变** |
| `list_difference_update(l1, l2) -> list` | 🟡 | l1 中不在 l2 里的元素 |
| `concatenate_lists(*list_of_lists) -> list` | 🟡 | 拉平多个列表成一个 |
| `remove_list_redundancies(lst) -> list` | 🟡 | 去重且保留**最后一次出现**（按末次出现位置排序），替代 `list(set(...))` |
| `make_even(i1, i2) -> tuple[list, list]` | ⚪ | 把较短的那个用**复制前面元素**补齐到等长 |
| `make_even_by_cycling(i1, i2) -> tuple[list, list]` | ⚪ | 同上，但用**循环**补齐 |
| `all_elements_are_instances(iterable, Class) -> bool` | ⚪ | 判断是否全部为某类型 |
| `stretch_array_to_length(nparray, length)` | ⚪ | 按索引重采样把数组拉长到指定长度 |
| ⚙ `batch_by_property(items, property_func)` | ⚪ | 按属性值把序列切成连续同质批次 |
| ⚙ `resize_array(nparray, length)` | ⚪ | 循环填充/截断到指定长度 |
| ⚙ `resize_preserving_order(nparray, length)` | ⚪ | 复制元素方式改长度（保序） |
| ⚙ `resize_with_interpolation(nparray, length)` | ⚪ | 线性插值方式改长度 |
| ⚙ `uniq_chain(*args)` | ⚪ | 生成器：按给定顺序产出所有去重元素 |
| ⚙ `hash_obj(obj) -> int` | ⚪ | 给可变容器（dict/set/list）算哈希 |

#### 样例：`adjacent_pairs` 闭合连边与三个数学小函数

左边四个点用 `adjacent_pairs` 逐条画边——注意第四条边自动从末点**回到首点**，闭合成四边形；右边三行分别是 `choose(5, 2)`、`clip(3.7, 0, 1)`、`sigmoid(0)` 的实际取值，底部一行是 `remove_list_redundancies` 的去重结果。

```python
from real_time_manim import Scene, Text, VGroup, Dot, Line, BLUE, GREEN, RED, \
    YELLOW, GREY_B, TEAL, WHITE, UP, DOWN, LEFT, adjacent_pairs, choose, \
    clip, sigmoid, FadeIn, Write, Create
from real_time_manim.vulkan_bind import MLWindow, Wait

class SequenceDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("04b-iterables_functions", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        pts = [(-3.2, -0.9, 0), (-1.5, -2.0, 0),   #左边四个点（不规则四边形）
               (-0.9, 0.5, 0), (-2.9, 1.4, 0)]
        head = Text("adjacent_pairs: 4 pts -> 4 edges", font_size=15, color=GREY_B)
        head.move_to([-2.1, 2.1, 0])   #左图标题
        dots = VGroup(*[Dot(p, radius=0.09, color=RED) for p in pts])   #四个顶点
        win.play(FadeIn(head), FadeIn(dots), run_time=0.5)   #标题与顶点先就位
        edges = [Line(a, b, color=BLUE, stroke_width=4)   #相邻对：(1,2)(2,3)(3,4)(4,1)
                 for a, b in adjacent_pairs(pts)]   #最后自动补上 (4,1)，闭合成四边形
        for e in edges:
            win.play(Create(e), run_time=0.35)   #四条边逐条画出（第四条回到起点）

        vals = VGroup(
            Text("choose(5, 2) = %d" % choose(5, 2), font_size=18, color=WHITE),
            Text("clip(3.7, 0, 1) = %.1f" % clip(3.7, 0, 1), font_size=18, color=GREEN),
            Text("sigmoid(0) = %.3f" % sigmoid(0), font_size=18, color=TEAL),
        ).arrange(DOWN, buff=0.28, aligned_edge=LEFT)   #右侧三行取值
        vals.move_to([1.9, 0.3, 0])
        win.play(FadeIn(vals), run_time=0.6)   #三行数值淡入
        note = Text("remove_list_redundancies: [1,2,1,3,2] -> [1,3,2]",
                    font_size=17, color=YELLOW).to_edge(DOWN)   #去重且保留最后一次出现
        win.play(FadeIn(note), run_time=0.35)   #底部说明淡入
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：四个红点按顺序喂给 `adjacent_pairs`，出来的是 `(1,2)(2,3)(3,4)(4,1)` 四对——四条蓝边逐条画出，最后一条自然地把图形**封口**，这就是"环形相邻对"的用处（画任意多边形边框一行搞定）。右侧三行是三个数学小函数的现场取值：组合数 `C(5,2)=10`、截断 `clip(3.7,0,1)=1.0`、`sigmoid(0)=0.500`；底部一行说明去重函数是"保留最后一次出现"——`2` 的最后一次在末尾，所以它排到了 `3` 后面。

<video src="assets/RTM output/04b-路径与序列工具-iterables.mp4" controls width="560"></video>

> 提醒：`adjacent_pairs` 返回的是 **zip 迭代器**不是列表（想多次遍历或取长度要先 `list(...)`）；`remove_list_redundancies` 保留的是**最后一次**出现的位置，`[1,2,1,3,2]` 的结果是 `[1,3,2]` 而不是 `[1,2,3]`——要保留首次出现顺序得自己用 `dict.fromkeys`。

## `simple_functions` —— 数学小工具（`utils/simple_functions.py`）

| 签名 | 频率 | 作用 |
| --- | --- | --- |
| `sigmoid(x) -> float` | 🟡 | 逻辑函数 `1/(1+e^-x)`；`ArrowVectorField` 默认 `length_func` 就用它做饱和压缩；样例 2 右侧已出镜 `sigmoid(0) = 0.500` |
| `clip(a, min_a, max_a)` | 🟡 | 把 `a` 截断到 `[min_a, max_a]`，支持任何可比较对象；样例 2 出镜 `clip(3.7, 0, 1) = 1.0` |
| `choose(n, k) -> int` | ⚪ | 组合数 C(n,k)（带 `lru_cache`）；样例 2 出镜 `choose(5, 2) = 10` |
| `binary_search(function, target, lower_bound, upper_bound, tolerance=1e-4) -> float \| None` | ⚪ | 数值二分：在区间内找使 `function(x) == target` 的 x，找不到返回 `None` |

无法演示：`listify` / `tuplify` / `adjacent_n_tuples` / `remove_nones` / `list_update` / `list_difference_update` / `concatenate_lists` / `make_even` / `resize_*` / `batch_by_property` / `uniq_chain` / `hash_obj` / `binary_search` / `straight_path` / `clockwise_path` / `counterclockwise_path` / `path_along_circles` / `spiral_path` —— 前三类是"输入输出都是 list/tuple/数值"的纯数据函数，画面里只能以文本形式复述结果（样例 2 已给出同族代表）；`clockwise_path` / `counterclockwise_path` 与样例 1 的 `path_along_arc(±π)` 逐位相同，`straight_path` 就是样例 1 中道的默认行为。
