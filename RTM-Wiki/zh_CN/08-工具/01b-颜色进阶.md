# 颜色（二）：插值与模块级工具

接着[颜色](01-颜色.md)往下：`ManimColor` 的两色插值、逐通道方法速查，以及插值 / 平均 / 随机取色和一批颜色与浮点互转函数，全部可 `from manim import ...`。本页两条样例均已在 RTM 实测出片（随机取色样例用固定种子，保证两引擎取到同一批颜色）。

## 参数

### `ManimColor.interpolate`

```python
ManimColor.interpolate(other: Self, alpha: float) -> Self
```

在 RGBA 空间做线性插值，`alpha=0` 是自身、`alpha=1` 是 `other`；渐变、按数值上色、动画配色过渡都靠它。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `other` | `ManimColor` | 必填 | 目标色，能填任意可解析颜色 |
| `alpha` | `float` | 必填 | 插值位置 0~1；0 = 自身，1 = 目标色，中间线性过渡 |

> **返回**：新的 `ManimColor`（原色不改）。

#### 样例：`RED → BLUE` 九档插值带

`alpha` 从 0 到 1 均分 9 档逐块点亮，正中那块改用模块级的 `interpolate_color(...)` 写法——颜色与 `interpolate` 逐位相同。

```python
from real_time_manim import Scene, Square, Text, VGroup, ManimColor, interpolate_color, \
    RED, BLUE, YELLOW, WHITE, GREY_B, UP, DOWN, RIGHT, FadeIn, Write
from real_time_manim.vulkan_bind import MLWindow, Wait

class ColorInterpolateDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("01b-interpolate", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        cols = [RED.interpolate(BLUE, i / 8) for i in range(9)]   #alpha 从 0 到 1 均分 9 档
        sq = VGroup(*[Square(side_length=0.85, stroke_width=1).set_fill(c, 1) for c in cols])   #9 个色块
        sq.arrange(RIGHT, buff=0.12).move_to(UP * 0.55)   #从左到右排成一条插值带
        sq[4].set_fill(interpolate_color(RED, BLUE, 0.5), 1)   #正中那块改用函数式写法，颜色与 interpolate 逐位相同
        lab = Text("RED.interpolate(BLUE, i / 8)", font_size=18, color=GREY_B)
        lab.next_to(sq, UP, buff=0.3)   #插值带上方标注调用写法
        l0 = Text("alpha=0  RED", font_size=16, color=GREY_B).next_to(sq[0], DOWN, buff=0.22)   #左端 = 自身
        l1 = Text("alpha=1  BLUE", font_size=16, color=GREY_B).next_to(sq[-1], DOWN, buff=0.22)   #右端 = 目标色
        lm = Text("interpolate_color(RED, BLUE, 0.5)", font_size=16, color=WHITE)
        lm.next_to(sq[4], DOWN, buff=0.55)   #正中那块 = 函数式写法的同一个结果
        self.add(lab, l0, l1, lm)   #先把标签放进场景（色块稍后逐块淡入）
        for m in sq:   #按 alpha 从小到大逐块淡入，肉眼看到颜色一路渐变
            win.play(FadeIn(m), run_time=0.12)
        win.play(FadeIn(lab), FadeIn(l0), FadeIn(l1), FadeIn(lm), run_time=0.5)   #三处标签淡入
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：九个色块按 `alpha = 0, 1/8, …, 1` 逐块从红亮到蓝，中间那块特意改写成 `interpolate_color(RED, BLUE, 0.5)`——画面上看不出任何色差，证明两种写法是同一个结果。左端标 `alpha=0`（原色）、右端标 `alpha=1`（目标色），插值就是这么一档一档走过去的。

<video src="assets/RTM output/01b-颜色进阶-interpolate.mp4" controls width="560"></video>

> 提醒：`interpolate` 插的是 **RGBA** 空间——两边透明度不同时，中间档的 alpha 也会跟着线性变化，想只改颜色不改透明度请配合 `opacity(...)` 使用。

### `ManimColor` 其余常用方法速查

支持 `+ - * / // % **`、`~color`、`int()`、`color[i]`、`==` 这些运算与下标比较；带"并入样例"标记的在下方两条样例里出过片。

| 签名 | 频率 | 作用 |
| --- | --- | --- |
| `to_rgb() -> FloatRGB` | 🟡 | 3 个 0~1 浮点 |
| `to_int_rgb() -> IntRGB` | ⚪ | 3 个 0~255 整数 |
| `to_rgba() -> FloatRGBA` | 🟡 | 4 个 0~1 浮点（含 alpha） |
| `to_int_rgba() -> IntRGBA` | ⚪ | 4 个 0~255 整数 |
| `to_rgba_with_alpha(alpha) -> FloatRGBA` | ⚪ | 换一个 alpha 后的 RGBA 数组 |
| `to_int_rgba_with_alpha(alpha) -> IntRGBA` | ⚪ | 同上，整数形式 |
| `to_integer() -> int` | ⚪ | `0xRRGGBB` 整数（丢 alpha） |
| `to_hsv() -> FloatHSV` | 🟡 | `[h, s, v]`，各 0~1 |
| `to_hsl() -> FloatHSL` | ⚪ | `[h, l, s]`，各 0~1 |
| `invert(with_alpha=False) -> Self` | 🟡 | 逐通道线性取反（返回新对象）—— **样例 2 已演示** |
| `opacity(opacity) -> Self` | 🟡 | 只换 alpha、保留颜色 —— **样例 2 已演示** |
| `contrasting(threshold=0.5, light=None, dark=None) -> Self` | 🟡 | 按亮度返回更易读的一色（默认白/黑），做深底白字、浅底黑字 —— **样例 2 已演示** |
| `into(class_type) -> Self` | ⚪ | 换成别的颜色空间类（如 `HSV`），内部值不变 |
| `gradient(colors, length)` | ⚪ | **会抛 `NotImplementedError`**，请改用模块级 `color_gradient` |
| `ManimColorDType` | ⚪ | 内部浮点 dtype，只在做 numpy 底层处理时用 |

### `interpolate_color` / `average_color` / `random_color` / `random_bright_color`

```python
interpolate_color(color1: ManimColorT, color2: ManimColorT, alpha: float) -> ManimColorT
average_color(*colors: ParsableManimColor) -> ManimColor
random_color() -> ManimColor
random_bright_color() -> ManimColor
```

几个取色函数各管一摊：

- `interpolate_color(c1, c2, alpha)` 是 `c1.interpolate(c2, alpha)` 的函数式写法，方便塞进 `lambda`；
- `average_color(*colors)` 逐通道取平均得到中间色（**忽略 alpha**，结果不透明度 1.0）；
- `random_color()` 从整套 Manim 调色板随机取一色；
- `random_bright_color()` 是随机色与 `WHITE` 各半混合（**开销较大**，别在循环里大量调用）。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `color1` / `color2` | `ManimColor` | 必填 | 插值两端，能填任意可解析颜色 |
| `alpha` | `float` | 必填 | `0` = color1，`1` = color2 |
| `*colors` | `ParsableManimColor` | 必填 | 参与平均的颜色（≥1 个） |

> **返回**：`ManimColor`。

#### 样例：取色函数与三个实例方法同场

三行各演示一组：

- 第一行是三个取色函数（平均色 / 随机色 / 亮随机色，随机部分先 `random.seed(7)` 固定）；
- 第二行是 `invert()` / `opacity(0.35)`；
- 第三行是 `contrasting()` 在深浅两种底板上自动挑出的字色。

```python
import random

from real_time_manim import Scene, Square, Rectangle, Text, VGroup, ManimColor, \
    average_color, random_color, random_bright_color, RED, BLUE, YELLOW, \
    WHITE, GREY_B, UP, DOWN, LEFT, RIGHT, FadeIn, Write
from real_time_manim.vulkan_bind import MLWindow, Wait

class ColorHelpersDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("01b-ColorHelpers", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        random.seed(7)   #固定随机种子，保证每次运行（含两引擎）取到同一批随机色
        # —— 第一行：三个取色函数 ——
        gen = [average_color(RED, BLUE), random_color(), random_bright_color()]   #平均色 / 随机色 / 亮随机色
        glab = ["average_color(RED, BLUE)", "random_color()", "random_bright_color()"]
        gsw = VGroup(*[Square(side_length=1.3, stroke_width=2).set_fill(c, 1) for c in gen])
        gsw.arrange(RIGHT, buff=1.2).move_to(UP * 1.7)   #横排三块，中间留出标签宽度
        gt = VGroup(*[Text(s, font_size=15, color=GREY_B).next_to(m, DOWN, buff=0.18)
                      for s, m in zip(glab, gsw)])   #函数名在色块下方
        gh = VGroup(*[Text(c.to_hex(), font_size=15, color=WHITE).next_to(m, UP, buff=0.18)
                      for c, m in zip(gen, gsw)])   #十六进制结果在色块上方
        # —— 第二行：三个实例方法 ——
        src = ManimColor("RED")
        meth = [src, src.invert(), src.opacity(0.35)]   #原色 / 逐通道取反 / 只换 alpha
        mlab = ["'RED'", "invert()", "opacity(0.35)"]
        msw = VGroup(*[Square(side_length=1.3, stroke_width=2).set_fill(c, 1) for c in meth])
        msw.arrange(RIGHT, buff=1.2).move_to(DOWN * 0.35)   #横排三块
        mt = VGroup(*[Text(s, font_size=15, color=GREY_B).next_to(m, DOWN, buff=0.18)
                      for s, m in zip(mlab, msw)])   #方法名在色块下方
        # —— 第三行：contrasting 自动挑可读的字色 ——
        dark = Rectangle(width=3.6, height=1.0, stroke_width=2).set_fill("#333333", 1)
        dark.set_stroke(GREY_B, 1).move_to(LEFT * 2.1 + DOWN * 2.5)   #深色底板
        dtx = Text("dark bg -> white text", font_size=20,
                   color=ManimColor("#333333").contrasting()).move_to(dark)   #深底上挑出白字
        lite = Rectangle(width=3.6, height=1.0, stroke_width=2).set_fill("#DDDDDD", 1)
        lite.set_stroke(GREY_B, 1).move_to(RIGHT * 2.1 + DOWN * 2.5)   #浅色底板
        ltx = Text("light bg -> black text", font_size=20,
                   color=ManimColor("#DDDDDD").contrasting()).move_to(lite)   #浅底上挑出黑字
        self.add(gt, gh, mt)   #标签先进场
        win.play(FadeIn(gsw), FadeIn(gt), FadeIn(gh), run_time=0.6)   #第一行色块与标签
        win.play(FadeIn(msw), FadeIn(mt), run_time=0.6)   #第二行色块与标签
        win.play(FadeIn(VGroup(dark, dtx, lite, ltx)), run_time=0.6)   #第三行对照底板
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：三行各演示一组。

- 第一行三个色块分别是"红蓝平均"（正中那块粉紫）、`random_color()` 抽到的原色、`random_bright_color()` 把它和白色各半混出来的浅色，色块上方标着各自的 `to_hex()`。
- 第二行从红原色出发：`invert()` 变成补色青蓝，`opacity(0.35)` 变成半透明（黑底上看是暗红）。
- 第三行两块底板分别深、浅，`contrasting()` 给它们挑出白色和黑色的字——这就是"深底白字、浅底黑字"的一行解法。

> 提醒：
>
> - `random_color()` / `random_bright_color()` 走 Python 全局随机状态，**每次跑颜色都不一样**——样例开头 `random.seed(7)` 就是为了让两引擎、每次渲染取到同一批色；写进正式项目时记得自己控制种子。
> - `random_bright_color()` 官方标了"开销较大"，别放进大循环。

### 颜色模块其余工具

| 函数签名 | 作用 |
| --- | --- |
| `color_to_rgb(color) -> FloatRGB` | 任意可解析颜色 → 3 个 0~1 浮点 |
| `color_to_rgba(color, alpha=1.0) -> FloatRGBA` | → 4 个 0~1 浮点 |
| `color_to_int_rgb(color) -> IntRGB` | → 3 个 0~255 整数 |
| `color_to_int_rgba(color, alpha=1.0) -> IntRGBA` | → 4 个 0~255 整数 |
| `rgb_to_color(rgb) -> ManimColor` | 3 元数组 → 颜色 |
| `rgba_to_color(rgba) -> ManimColor` | 4 元数组 → 颜色 |
| `rgb_to_hex(rgb) -> str` | 3 元数组 → `"#RRGGBB"` |
| `hex_to_rgb(hex_code) -> FloatRGB` | `"#RRGGBB"` → 3 元浮点 |
| `invert_color(color) -> ManimColor` | `color.invert()` 的函数式写法 |
| `get_shaded_rgb(rgb, point, unit_normal_vect, light_source) -> FloatRGB` | 按表面朝向与光源位置加明暗，自定义三维着色时用 |
| `HSV` | `HSV([h, s, v], alpha=1.0)`，属性 `hue/saturation/value`（别名 `h/s/v`）可读写；`RGBA` 是 `ManimColor` 的别名 |
| `RandomColorGenerator(seed=None, sample_colors=None)` + `.next() -> ManimColor` | 可设种子的颜色生成器，`sample_colors` 可限定候选调色板 |

无法演示：`to_rgb` / `to_int_rgb` / `to_rgba` / `to_int_rgba` / `to_rgba_with_alpha` / `to_integer` / `to_hsv` / `to_hsl` / `into` —— 都是取值 / 换表示的数值转换，返回的是一串数字，不产生画面。

`ManimColor.gradient` —— 必抛 `NotImplementedError`，只能改用 `color_gradient`。

`color_to_*` / `rgb_to_*` / `hex_to_rgb` / `invert_color` / `get_shaded_rgb` / `HSV` / `RGBA` / `RandomColorGenerator` —— 与样例里已演示的对应方法逐位同效（`RandomColorGenerator(seed=...)` 就是可控版 `random_color()`），单独出片没有新信息。
