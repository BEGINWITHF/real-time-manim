# 向量与几何工具（一）：space_ops

`utils/space_ops.py` 提供向量旋转、夹角、归一化、质心、复数互换等几何工具，全部可 `from manim import ...`；RTM 直接复用 manim 实现，numpy 计算逐位一致。本页三条样例分别演示绕轴旋转向量、夹角与质心、鞋带面积与正多边形顶点，均已在 RTM 实测出片；其余函数收在页面后半的速查表里。

## 命名陷阱（先看这个）

源码里**没有**下列常见于其他 Manim 分支/教程的名字，别直接调用：

| 教程里可能出现 | 本版本（0.21.0）的正确写法 |
| --- | --- |
| `rotation_between_vectors(v1, v2)` | `rotation_matrix(angle_between_vectors(v1, v2), np.cross(v1, v2))` 自行组合 |
| `angle_between(v1, v2)` | **`angle_between_vectors(v1, v2)`** |
| `get_unit_vector(v)` | `normalize(v)`（`space_ops.normalize`）；`Line.get_unit_vector()` 是二维 `Line` 的方法 |
| `complex_to_vec3(z)` | **`complex_to_R3(z)`** |

## `rotate_vector` —— 绕轴旋转向量

```python
rotate_vector(vector: Vector3DLike, angle: float, axis: Vector3DLike = OUT) -> Vector3D
```

把向量绕 `axis` 转 `angle` 弧度，返回新向量（不改原向量），是"按角度算新位置"最常用的工具，例如 `rotate_vector(RIGHT, TAU/8)`。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `vector` | `Vector3DLike` | 必填 | 要旋转的向量（2 维会自动补 z=0；>3 维抛 `ValueError`） |
| `angle` | `float` | 必填 | 旋转角（弧度，逆时针为正） |
| `axis` | `Vector3DLike` | `OUT` | 旋转轴 |

> **返回**：`Vector3D`（`np.ndarray`）。

#### 样例：同一向量转 45° 与 90°

以 `RIGHT` 为基准画灰色箭头，`rotate_vector(RIGHT, PI / 4)` 转出黄色 45° 箭头、`rotate_vector(RIGHT, PI / 2)` 转出绿色 90° 箭头（恰好落在 `UP` 上），两条角弧标出转过的角度。

```python
from real_time_manim import Scene, Text, Vector, Arc, Dot, GREY_B, YELLOW, GREEN, \
    WHITE, UP, DOWN, RIGHT, ORIGIN, PI, rotate_vector, FadeIn, Write, Create
from real_time_manim.vulkan_bind import MLWindow, Wait

class RotateDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("04-rotate_vector", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        o = Dot(ORIGIN, radius=0.06, color=WHITE)   #坐标原点
        v0 = Vector(2.4 * RIGHT, color=GREY_B)   #基准向量：RIGHT 本身
        l0 = Text("RIGHT", font_size=18, color=GREY_B).next_to(v0.get_end(), DOWN, buff=0.2)
        win.play(FadeIn(o), Create(v0), FadeIn(l0), run_time=0.7)   #先把基准箭头画出来

        v45 = Vector(2.4 * rotate_vector(RIGHT, PI / 4), color=YELLOW)   #绕默认轴 OUT 逆时针转 45°
        a45 = Arc(radius=1.2, start_angle=0, angle=PI / 4, arc_center=ORIGIN,
                  color=YELLOW, stroke_width=5)   #0 → 45° 的角弧
        l45 = Text("rotate(PI/4)", font_size=17, color=YELLOW).move_to([1.3, 1.9, 0])   #45° 标签（放在角弧外侧）
        win.play(Create(a45), Create(v45), FadeIn(l45), run_time=0.7)   #转 45° 的结果

        v90 = Vector(2.4 * rotate_vector(RIGHT, PI / 2), color=GREEN)   #转 90°：RIGHT 恰好转成 UP
        a90 = Arc(radius=1.7, start_angle=0, angle=PI / 2, arc_center=ORIGIN,
                  color=GREEN, stroke_width=4)   #0 → 90° 的角弧（更大的一圈）
        l90 = Text("rotate(PI/2)", font_size=17, color=GREEN).move_to([2.1, 0.8, 0])   #90° 标签
        win.play(Create(a90), Create(v90), FadeIn(l90), run_time=0.7)   #转 90° 的结果
        note = Text("rotate_vector(v, angle, axis=OUT) returns a new vector",
                    font_size=18, color=YELLOW).to_edge(DOWN)   #底部说明：不改原向量
        win.play(FadeIn(note), run_time=0.35)   #说明淡入
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：灰色 `RIGHT` 箭头是没转的样子，黄色是转 45° 的结果、绿色是转 90° 的结果（`RIGHT` 转 90° 正好变成 `UP`，箭头直直向上）。两条角弧半径不同、互不遮挡，直观看出 `angle` 是绕屏幕法线 `OUT` 轴的逆时针角；原向量 `RIGHT` 转完后原封不动——函数返回的是**新**向量。

<video src="assets/RTM output/04-向量与几何工具-rotate.mp4" controls width="560"></video>

> 提醒：`angle` 是**弧度**不是角度（`45°` 要写 `PI / 4` 或 `45 * DEGREES`）；想要"绕任意轴"就传第三个参数 `axis`，三维里最常用 `X_AXIS` / `Y_AXIS`；要矩阵形式用 `rotation_matrix(angle, axis)`。

## 夹角、极角与中心：`angle_between_vectors` / `angle_of_vector` / `center_of_mass` / `midpoint`

| 函数签名 | 作用 |
| --- | --- |
| `angle_between_vectors(v1: np.ndarray, v2: np.ndarray) -> float` | 两向量夹角，**恒落在 `[0, π]`**（`arctan2` 半角公式，数值稳定） |
| `angle_of_vector(vector) -> float` | 向量投影到 xy 平面后的极角（`atan2`，`(-π, π]`）；也接受 `(2, n)` 点集，返回逐点角度数组 |
| `center_of_mass(points: PointNDLike_Array) -> PointND` | 点集的算术平均（等权质心） |
| `midpoint(point1, point2)` | 两点中点（`center_of_mass([p1, p2])` 的语法糖） |

#### 样例：两向量夹角与不规则四边形的质心

右边画红、蓝两支向量，用 `angle_between_vectors` 量出夹角并用角弧标出（数值直接显示在弧旁）；左下按顺序连四个点成不规则四边形，`center_of_mass` 落出金色质心点，底边 `midpoint` 落出绿色中点。

```python
import numpy as np
from real_time_manim import Scene, Text, VGroup, Dot, Vector, Arc, Polygon, RED, \
    BLUE, YELLOW, GREEN, GREY_B, GOLD, UP, DOWN, RIGHT, ORIGIN, \
    angle_between_vectors, angle_of_vector, center_of_mass, midpoint, \
    FadeIn, Write, Create
from real_time_manim.vulkan_bind import MLWindow, Wait

class AngleCentroidDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("04-angle_centroid", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        a = Vector([2.6, 0.9, 0], color=RED)   #向量 1
        b = Vector([1.1, 2.4, 0], color=BLUE)   #向量 2
        la = Text("v1", font_size=18, color=RED).next_to(a.get_end(), RIGHT, buff=0.15)
        lb = Text("v2", font_size=18, color=BLUE).next_to(b.get_end(), UP, buff=0.15)
        ang = angle_between_vectors(a.get_end(), b.get_end())   #两向量夹角，恒在 [0, PI]
        aa, ab = angle_of_vector(a.get_end()), angle_of_vector(b.get_end())   #各自的极角，用来摆角弧
        arc = Arc(radius=1.15, start_angle=aa, angle=ab - aa, arc_center=ORIGIN,
                  color=YELLOW, stroke_width=6)   #两箭头之间的角弧
        lt = Text("%.3f rad" % ang, font_size=17, color=YELLOW).move_to([1.05, 0.45, 0])   #夹角数值
        win.play(Create(a), FadeIn(la), run_time=0.5)   #先画 v1
        win.play(Create(b), FadeIn(lb), run_time=0.5)   #再画 v2
        win.play(Create(arc), FadeIn(lt), run_time=0.5)   #量出夹角

        pts = [np.array([-3.1, -1.0, 0]), np.array([-1.2, -2.0, 0]),   #左下四个点（不规则四边形）
               np.array([-0.7, 0.5, 0]), np.array([-2.9, 1.3, 0])]
        quad = Polygon(*pts, color=GREY_B, stroke_width=3)   #按顺序连线成四边形
        pdots = VGroup(*[Dot(p, radius=0.09, color=RED) for p in pts])   #四个顶点
        com = center_of_mass(pts)   #质心 = 各点算术平均
        star = Dot(com, radius=0.12, color=GOLD)   #质心点
        lc = Text("center_of_mass", font_size=16, color=GOLD).next_to(star, DOWN, buff=0.18)
        mid = midpoint(pts[0], pts[1])   #底边中点
        mdot = Dot(mid, radius=0.09, color=GREEN)
        lm = Text("midpoint", font_size=15, color=GREEN).next_to(mdot, DOWN, buff=0.15)
        win.play(Create(quad), FadeIn(pdots), run_time=0.7)   #不规则四边形
        win.play(FadeIn(star), FadeIn(lc), run_time=0.4)   #质心落点
        win.play(FadeIn(mdot), FadeIn(lm), run_time=0.4)   #中点落点
        note = Text("angle_between_vectors -> [0, PI]", font_size=18, color=YELLOW).to_edge(DOWN)
        win.play(FadeIn(note), run_time=0.35)   #底部说明淡入
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：右侧两支向量画好后，`angle_between_vectors` 给出弧度值（画面里显示 `0.643 rad`），角弧的起止角则用 `angle_of_vector` 量两支向量各自的极角来摆——夹角大不了 `[0, π]`，谁先谁后都一样。左下四个红点连成不规则四边形，金色的 `center_of_mass` 落在"重心"位置（四点算术平均），绿色的 `midpoint` 恰好在底边正中——质心对不规则形状同样成立。

<video src="assets/RTM output/04-向量与几何工具-angle_centroid.mp4" controls width="560"></video>

> 提醒：这几个函数吃的都是 **numpy 数组**——给 `Vector` 这类 mobject 要先 `.get_end()` 取出坐标；`angle_of_vector` 只看 xy 平面（z 分量被忽略），三维夹角一律用 `angle_between_vectors`。

## 多边形：`regular_vertices` / `shoelace` / `shoelace_direction`

| 函数签名 | 作用 |
| --- | --- |
| `regular_vertices(n: int, *, radius: float = 1, start_angle: float \| None = None) -> tuple` | 半径 `radius` 的圆上生成 `n` 个均匀顶点，返回 `(顶点数组, 起始角)`；`start_angle=None` 时偶数 `n` 从 0 起、奇数 `n` 从 90° 起 |
| `shoelace(x_y) -> float` | 鞋带公式求**有向**面积；必须喂 `np.array`，且实现是 `np.trapezoid(y, x)`——**不自动补首尾闭合边**，闭合多边形要自己把首点再接一遍 |
| `shoelace_direction(x_y) -> str` | 顶点走向是 `"CW"` 还是 `"CCW"`（按上游约定：面积为正标 `"CW"`） |

#### 样例：正五边形与顺时针正方形的面积

左边用 `regular_vertices(5, radius=1.4, start_angle=PI / 2)` 取正五边形顶点并连线，手动闭合后用 `shoelace` 求出有向面积（显示 `-4.660`）、`shoelace_direction` 给出 `CCW`；右边一个按"左下 → 左上 → 右上 → 右下"顺时针顺序排列的正方形，同法得到 `4.0` 与 `CW`——顶点顺序一换，面积符号跟着翻转。

```python
import numpy as np
from real_time_manim import Scene, Text, VGroup, Dot, Polygon, PURPLE, GREEN, \
    TEAL, YELLOW, GREY_B, GOLD, UP, DOWN, PI, regular_vertices, shoelace, \
    shoelace_direction, FadeIn, Write, Create
from real_time_manim.vulkan_bind import MLWindow, Wait

class PolygonDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("04-shoelace_regular_vertices", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        verts, sa = regular_vertices(5, radius=1.4, start_angle=PI / 2)   #半径 1.4 的正五边形顶点 + 起始角
        poly = Polygon(*verts, color=PURPLE, fill_opacity=0.3, stroke_width=5).shift([-2.3, -0.4, 0])   #左半：正五边形
        vdots = VGroup(*[Dot(v + np.array([-2.3, -0.4, 0]), radius=0.08, color=GOLD)
                         for v in verts])   #五个顶点打点
        lv = Text("regular_vertices(n=5, radius=1.4)", font_size=15, color=GREY_B)
        lv.move_to([-2.3, 2.4, 0])   #左图标题
        area = shoelace(np.array(list(verts) + [verts[0]]))   #鞋带公式：有向面积（喂 np.array，手动补回首点闭合）
        dire = shoelace_direction(np.array(verts))   #顶点走向：“CW” 或 “CCW”
        la = Text("shoelace = %.3f" % area, font_size=16, color=PURPLE).move_to([-2.3, -2.75, 0])   #面积数值
        ld = Text("shoelace_direction = " + dire, font_size=16, color=YELLOW).move_to([-2.3, -3.2, 0])   #走向
        win.play(FadeIn(lv), Create(poly), FadeIn(vdots), run_time=0.9)   #正五边形整体亮相
        win.play(FadeIn(la), FadeIn(ld), run_time=0.5)   #面积与走向两行

        sq = [np.array([1.0, -1.0, 0]), np.array([1.0, 1.0, 0]),   #右半：顺时针顺序的正方形
              np.array([3.0, 1.0, 0]), np.array([3.0, -1.0, 0])]   #（左下 → 左上 → 右上 → 右下）
        sqp = Polygon(*sq, color=TEAL, fill_opacity=0.3, stroke_width=5)
        sqdots = VGroup(*[Dot(p, radius=0.08, color=GREEN) for p in sq])
        ls = Text("clockwise order (4 pts)", font_size=15, color=GREY_B).move_to([2.0, 2.4, 0])   #右图标题
        sarea = shoelace(np.array(sq + [sq[0]]))   #顺时针顺序 + 闭合首点 → 有向面积为正
        sdir = shoelace_direction(np.array(sq))
        lsa = Text("shoelace = %.1f" % sarea, font_size=16, color=TEAL).move_to([2.0, -1.6, 0])
        lsd = Text("shoelace_direction = " + sdir, font_size=16, color=YELLOW).move_to([2.0, -2.05, 0])
        win.play(Create(sqp), FadeIn(sqdots), FadeIn(ls), run_time=0.7)   #顺时针正方形
        win.play(FadeIn(lsa), FadeIn(lsd), run_time=0.5)   #它的面积与走向
        note = Text("shoelace(np.array) + close the loop", font_size=18, color=YELLOW).to_edge(DOWN)   #底部说明：要闭合、要 np.array
        win.play(FadeIn(note), run_time=0.35)   #底部说明：要闭合、要 np.array
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：左边 `regular_vertices` 直接吐出正五边形的五个顶点，连线成形后把首点再接一遍、`shoelace` 才能算出完整面积（`-4.660`，正好是 `½·n·r²·sin(2π/n)` 的负值）；右边正方形故意按顺时针顺序给顶点，面积变成正的 `4.0`、`shoelace_direction` 也标成 `CW`。两个例子放一起就是结论：面积的**绝对值**是多边形大小，**符号**由顶点绕向决定。

<video src="assets/RTM output/04-向量与几何工具-polygon.mp4" controls width="560"></video>

> 提醒：两个坑都在样例里踩过了——`shoelace` 直接吃 Python `list` 会抛 `TypeError`（必须 `np.array`），而且它**不自动闭合**（首点要手动补到末尾，否则少算最后一条边的贡献）；`shoelace_direction` 只看符号，喂不喂闭合点都一样。

## 其余 space_ops 函数速查

含旋转矩阵、Z 轴对齐、复数互换与低频工具（参数与默认值已并入签名与说明）：

| 函数签名 | 作用 |
| --- | --- |
| `rotation_matrix(angle: float, axis: Vector3DLike, homogeneous: bool = False) -> np.ndarray` | 绕任意轴旋转的 3×3 矩阵（内部 scipy `Rotation.from_rotvec`）；`homogeneous=True` 返回 4×4 齐次形式，`axis` 会先归一化 |
| `z_to_vector(vector: np.ndarray) -> np.ndarray` | 返回 SO(3) 矩阵 `M` 使 `M @ [0,0,1] = normalize(vector)`；把"默认朝 Z"的面片/圆/圆锥转到任意朝向，`Cube.generate_points` 内部靠它摆 6 个面 |
| `normalize(vect, fall_back: np.ndarray \| None = None) -> np.ndarray` | 归一化为单位向量；零向量时返回 `fall_back`（缺省全 0 向量） |
| `compass_directions(n: int = 4, start_vect: np.ndarray = RIGHT) -> np.ndarray` | 把 `start_vect` 每隔 `TAU/n` 旋转一次，得到 `n` 个均匀方向（默认 4 个即上右下左） |
| `complex_to_R3(complex_num: complex) -> np.ndarray` | 复数 → 三维点：`complex_to_R3(1+1j)` → `[1, 1, 0]` |
| `R3_to_complex(point: Sequence[float]) -> np.ndarray` | 三维点 → 复数（只取前两个分量） |
| `complex_func_to_R3_func(complex_func) -> Callable` | 把复变函数包成可直接喂给 `ParametricFunction`/`Surface` 的三维函数（画 `e^z`、`z²` 很方便） |
| `norm_squared(v) -> float` | 向量模长平方（不取根号） |
| `cross(v1, v2) -> Vector3D` | 三维叉积（`np.cross` 的手写版） |
| `rotation_about_z(angle) -> np.ndarray` | 绕 Z 轴旋转的 3×3 矩阵 |
| `rotation_matrix_transpose(angle, axis) -> np.ndarray` | 旋转矩阵的转置（即逆旋转） |
| `rotation_matrix_from_quaternion(quat) -> np.ndarray` | 四元数 → 旋转矩阵 |
| `rotation_matrix_transpose_from_quaternion(quat) -> list[np.ndarray]` | 四元数 → 转置旋转矩阵 |
| `normalize_along_axis(array, axis) -> np.ndarray` | 沿指定轴对数组做归一化（原地） |
| `quaternion_mult(*quats)` | 四元数 Hamilton 乘积；空参数返回单位四元数 `[1,0,0,0]` |
| `quaternion_from_angle_axis(angle, axis, axis_normalized=False)` | 角度+轴 → 四元数 |
| `angle_axis_from_quaternion(quaternion)` | 四元数 → `(angle, axis)` |
| `quaternion_conjugate(quaternion)` | 四元数共轭（虚部取反） |
| `get_unit_normal(v1, v2, tol=1e-6) -> Vector3D` | 两向量所在平面的单位法向量；退化时返回 `DOWN` |
| `line_intersection(line1, line2) -> np.ndarray` | 两条 **xy 平面内**直线的交点（各由两点定义）；平行或有 z 分量会抛错 |
| `find_intersection(p0s, v0s, p1s, v1s, threshold=1e-5) -> list[Point3D]` | 两条空间直线（或射线）的最近点；支持批量传数组 |
| `perpendicular_bisector(line, norm_vector=OUT) -> Sequence[np.ndarray]` | 两点连线的垂直平分线的两个端点（可指定垂面法向） |
| `cartesian_to_spherical(vec) -> np.ndarray` | `[x,y,z]` → `[r, theta, phi]`（`theta` 方位角、`phi` 极角） |
| `spherical_to_cartesian(spherical) -> np.ndarray` | `[r, theta, phi]` → `[x,y,z]` |
| `get_winding_number(points) -> float` | 多边形绕原点的缠绕数（1 = 包含原点） |
| `cross2d(a, b)` | 二维叉积/行列式，支持批量 `(n,2)` 数组 |
| `thick_diagonal(dim, thickness=2) -> MatrixMN` | 生成带状（对角线附近为 1）的 0/1 矩阵 |
| `earclip_triangulation(verts, ring_ends) -> list` | 带洞多边形的耳切三角化索引（内部算法，填充/三角网格用） |
