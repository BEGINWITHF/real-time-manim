# 速率函数 rate functions

速率函数把动画进度 `t ∈ [0, 1]` 映射成实际进度 `f(t)`，通过 `play(..., rate_func=...)` 传入——同一段位移换一条曲线，观感完全不同。

常用函数已导出到顶层（`rate_func=smooth`），标准缓动 `ease_*` **未导出**，必须写 `rate_func=rate_functions.ease_out_bounce`。`smoothstep` / `smootherstep` 等近亲与 `ease_*` 走通用回退，RTM 逐点求值渲染（`use_vectorized=False` 下标量实现同样安全）。

三条样例分别画"四条常用曲线"、"四条带花样的曲线"和"同一条位移 × 四种速率"，均已在 RTM 实测出片。

> **2026-10-17 更新（计数口径统一）**：manim 0.21 `manim.utils.rate_functions` 模块**本模块定义 50 个名字** = **47 个 rate function**（`__all__` 显式列 17 个 + `ease_*` 全家族 30 个按模块属性取）+ 2 个装饰器（`unit_interval` / `zero`）+ 1 个 `Protocol`（`RateFunction`）——与本页四节 12 + 5 + 30 + 3 = 50 逐项对齐。`real_time_manim` 顶层直接导出其中 **17 个**（12 常用 + 5 特殊/工厂），`ease_*` 30 个与装饰器/`Protocol` 不在顶层，须写 `rate_functions.` 前缀。

## `rate_func`（`play` 的动画参数）

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `rate_func` | `Callable[[float], float]` | `smooth` | 能填：顶层导出的常用函数（`linear`、`smooth`、`rush_into`…）、工厂产物（`squish_rate_func(smooth, 0.2, 0.8)`）、`rate_functions.ease_*` 标准缓动；输入 `t ∈ [0, 1]`，输出实际进度（**可越出 0~1**，位移类没问题、`set_opacity` 类别用越界函数） |

#### 样例：同一条位移 × 四种速率

四条泳道画完全相同的位移轨道，每条轨道左侧的小方盒里画出该泳道的速率曲线缩略图，四个同色的点同时起跑——只有 `rate_func` 不同，位置立刻分开；`there_and_back` 的点最后还会跑回起点。

```python
from real_time_manim import Scene, Text, VGroup, Line, Dot, Arrow, Rectangle, \
    FunctionGraph, BLUE, GREEN, RED, YELLOW, GREY_B, UP, DOWN, LEFT, \
    FadeIn, Write, Create
from real_time_manim import linear, rush_into, smooth, \
    there_and_back
from real_time_manim.vulkan_bind import MLWindow, Wait

class RateMotionDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("02-rate_func on a shift", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        names = ["linear", "smooth", "rush_into", "there_and_back"]   #四条泳道各配一种速率
        funcs = [linear, smooth, rush_into, there_and_back]
        cols = [GREY_B, BLUE, GREEN, RED]
        xs0, xs1 = -2.4, 6.0   #位移轨道的起点与终点（四条完全相同）
        mx0, mx1 = -5.0, -3.0   #左侧小曲线盒的横向范围
        lanes, dots = [], []
        for i, (nm, f, c) in enumerate(zip(names, funcs, cols)):
            y = 1.9 - i * 1.2   #四条泳道的纵坐标
            box = Rectangle(width=mx1 - mx0, height=1.0, stroke_width=1)
            box.set_stroke(GREY_B, 1, opacity=0.5).set_fill(opacity=0)   #空心小方框当绘图区
            box.move_to([(mx0 + mx1) / 2, y, 0])
            lab = Text(nm, font_size=15, color=c).next_to(box, LEFT, buff=0.25)   #泳道名放在曲线盒左边

            def g(u, f=f):   #把本泳道的速率函数画进小盒（横 0→1、纵 0→1）
                t = (u - mx0) / (mx1 - mx0)
                v = f(t)
                v = 0.0 if v < 0.0 else (1.0 if v > 1.0 else v)   #越界压到盒边
                return y + (v - 0.5) * 0.8   #f=0 → 盒底、f=1 → 盒顶

            curve = FunctionGraph(g, x_range=[mx0, mx1, (mx1 - mx0) / 40],
                                  color=c, stroke_width=3)   #该泳道的速率曲线缩略图
            trk = Line([xs0, y, 0], [xs1, y, 0], color=GREY_B, stroke_width=2)
            trk.set_stroke(opacity=0.4)   #位移轨道（半透明灰线）
            dot = Dot([xs0, y, 0], radius=0.13, color=c)   #起跑的点，颜色与曲线同色
            lanes += [box, lab, curve, trk]
            dots.append((dot, y, f))
        note = Text("same shift, only rate_func differs", font_size=19, color=YELLOW).to_edge(DOWN)   #底部说明
        win.play(FadeIn(VGroup(*lanes)), FadeIn(note), run_time=0.5)   #四条泳道与说明就位
        self.add(*[d for d, _, _ in dots])   #把四个点加进场景（起点都在轨道左端）
        win.play(*[d.animate(run_time=1.6, rate_func=f).move_to([xs1, y, 0])
                   for d, y, f in dots])   #参数 “rate_func”：同一条位移 × 四种速率同时起跑
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：四条泳道的轨道、起点、时长完全一样，唯一的变量是传给 `animate` 的 `rate_func`：

- `linear` 匀速走满；
- `smooth` 两端慢中间快；
- `rush_into` 起手极慢，最后猛冲；
- `there_and_back` 走到终点又折返回到起点。

左侧小盒里同色的曲线就是各自的 `f(t)` 形态，点的实时位置和曲线高度逐帧对得上。

> 提醒：
>
> - `rate_func` 吃的是**进度→进度**的函数，不是 easing 的时间戳。
> - `there_and_back` / `wiggle` 类函数动画结束时输出会归零，位移动画表现为"回到原点"；拿它驱动 `set_fill(opacity=...)` 这类要求严格 0~1 的属性就会出幺蛾子。

## 常用速率函数（顶层可直接用）（12 个）

| 函数 | RTM | 频率 | 曲线形态 |
| --- | --- | --- | --- |
| `linear` | — | 🔴 | 恒等直线 `y = t`，完全匀速 |
| `smooth` | — | 🔴 | S 形 sigmoid（`inflection=10`），两端平滑起步收尾 —— **Manim 多数动画的默认值** |
| `smoothstep` | — | 🟡 | `3t²−2t³`，端点一阶导为 0，最经典的 SmoothStep |
| `smootherstep` | — | 🟡 | `6t⁵−15t⁴+10t³`，端点一、二阶导均为 0，比 smoothstep 更柔 |
| `smoothererstep` | — | ⚪ | 三阶平滑版（到三阶导都为 0），最"绵软"的 S 形 |
| `there_and_back` | — | 🔴 | 去了又回：0→1→0，中点最快，适合"弹一下再复位" |
| `there_and_back_with_pause` | — | 🟡 | 同上但在终点停留 `pause_ratio=1/3` 的时间再回来 |
| `exponential_decay` | — | 🔴 | `1−e^(−t/0.1)`：瞬间冲到接近终点，之后长尾无限逼近，适合"飞入后停住" |
| `rush_into` | — | 🟡 | 起手极慢、后段猛冲到位（末尾急停）的加速曲线 |
| `rush_from` | — | 🟡 | 起手即猛冲、后段缓缓落位的减速曲线 |
| `slow_into` | — | ⚪ | 四分之一圆弧 `sqrt(1−(1−t)²)`：满速起步、渐减到 0（无缓入段） |
| `double_smooth` | — | ⚪ | 前后各半段各来一次 `smooth`，中点附近有短暂"停顿感" |

#### 样例：四条常用速率函数的曲线

在“横轴进度 t、纵轴实际进度 f(t)”的坐标系里，把 `linear`、`smooth`、`rush_into`、`rush_from` 四条曲线逐条画出，右侧配同色图例——`f(t)` 在对角线上方就是超前、下方就是落后。

```python
from real_time_manim import Scene, Text, VGroup, Arrow, FunctionGraph, BLUE, \
    GREEN, RED, YELLOW, GREY_B, UP, DOWN, LEFT, FadeIn, Write, Create
from real_time_manim import linear, rush_from, rush_into, smooth
from real_time_manim.vulkan_bind import MLWindow, Wait

class RateCurveCommonDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("02-common rate_funcs", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        x0, x1, y0, y1 = -6.0, 2.6, -2.4, 1.8   #绘图区：横 t 从左到右、纵 f(t) 从下到上
        lo, hi = -0.05, 1.05   #纵轴显示范围（上下各留 5% 余量）

        def plot(f, color):   #把速率函数画成曲线：屏幕横坐标反算回 t，再把 f(t) 映射进绘图区
            def g(u):
                t = (u - x0) / (x1 - x0)   #屏幕 x → 进度 t
                y = f(t)   #速率函数给出的实际进度
                if y < lo:
                    y = lo   #越界就压到边界（样例 2 的 wiggle 会冲出 0~1）
                elif y > hi:
                    y = hi
                return y0 + (y - lo) / (hi - lo) * (y1 - y0)   #映射成场景 y 坐标
            return FunctionGraph(g, x_range=[x0, x1, (x1 - x0) / 96], color=color, stroke_width=5)

        xax = Arrow([x0 - 0.3, y0, 0], [x1 + 0.4, y0, 0], color=GREY_B, stroke_width=4, buff=0)   #横轴：进度 t
        yax = Arrow([x0, y0 - 0.3, 0], [x0, y1 + 0.35, 0], color=GREY_B, stroke_width=4, buff=0)   #纵轴：实际进度 f(t)
        lt = Text("t", font_size=22, color=GREY_B).next_to(xax, DOWN, buff=0.12)   #横轴名
        lf = Text("f(t)", font_size=22, color=GREY_B).next_to(yax, UP, buff=0.12)   #纵轴名
        l0 = Text("0", font_size=18, color=GREY_B).next_to([x0, y0, 0], DOWN, buff=0.15)   #原点刻度
        l1t = Text("1", font_size=18, color=GREY_B).next_to([x1, y0, 0], DOWN, buff=0.15)   #t=1 刻度
        l1f = Text("1", font_size=18, color=GREY_B).next_to([x0, y1, 0], LEFT, buff=0.15)   #f(t)=1 刻度
        win.play(FadeIn(VGroup(xax, yax, lt, lf, l0, l1t, l1f)), run_time=0.4)   #坐标轴先就位

        names = ["linear", "smooth", "rush_into", "rush_from"]   #四条常用速率函数
        funcs = [linear, smooth, rush_into, rush_from]
        cols = [GREY_B, BLUE, GREEN, RED]
        for i, (nm, f, c) in enumerate(zip(names, funcs, cols)):
            g = plot(f, c)   #第 i 条曲线
            lab = Text(nm, font_size=17, color=c).move_to([3.2, 1.2 - i * 0.8, 0])   #右侧同色图例
            win.play(Create(g), run_time=0.6)   #逐条把曲线画出来
            win.play(FadeIn(lab), run_time=0.2)   #补上它的名字
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：先搭好“横 t 纵 f(t)”的坐标系，然后逐条画出四条常用速率函数：

- 灰色 `linear` 就是对角线（完全匀速）；
- 蓝色 `smooth` 是两端平缓中间陡的 S 形；
- 绿色 `rush_into` 全程在对角线下方（起手慢、后段追上来）；
- 红色 `rush_from` 反之（起手快、后段拖尾）。

四条曲线共用一个 `plot` 包装：屏幕横坐标反算回 `t`，`f(t)` 再线性映射进绘图区。

> 提醒：
>
> - `linear` / `smooth` 等 12 个常用函数是 `manim` 顶层直接导出的，`from manim import linear` 或 `from manim.utils.rate_functions import linear` 都行。
> - `smoothstep` 系列里没有单独列出的走通用回退，逐点求值（`use_vectorized=False`），曲线形态一致，但不走向量化快路径。

## 特殊用途与工厂函数（5 个）

| 函数 | RTM | 频率 | 曲线形态与用法 |
| --- | --- | --- | --- |
| `running_start(t, pull_factor=-0.5)` | — | 🟡 | 起手先向**反方向**回拉一小段再冲向终点，弹性"预备动作"感 |
| `wiggle(t, wiggles=2)` | — | 🟡 | `there_and_back × sin(wiggles·π·t)`，在 0↔1 之间来回抖动 `wiggles` 次 |
| `lingering` | — | ⚪ | 在 `[0, 0.8]` 线性完成、末段 20% 保持不动（收尾滞留） |
| `not_quite_there(func=smooth, proportion=0.7)` | — | 🟡 | **工厂**：只走到 `func` 结果的 `proportion` 倍，永远"差一点" |
| `squish_rate_func(func, a=0.4, b=0.6)` | — | 🔴 | **工厂**：把 `func` 压缩到时间区间 `[a, b]` 内完成，之前保持 0、之后保持 1 |

#### 样例：工厂 / 往返 / 标准缓动的曲线

同一坐标系里画四种"带花样"的速率函数：

- `squish_rate_func(smooth, 0.2, 0.8)` 把 S 曲线压进 0.2~0.8；
- `wiggle(t, 3)` 来回抖三次；
- `lingering` 末段滞留；
- `rate_functions.ease_out_bounce` 皮球落地弹跳。

这一组会冲出 0~1，纵轴范围放宽到 −1.1~1.4。

```python
from real_time_manim import Scene, Text, VGroup, Arrow, FunctionGraph, RED, \
    YELLOW, TEAL, PURPLE, GREY_B, UP, DOWN, LEFT, FadeIn, Write, Create
from real_time_manim import rate_functions
from real_time_manim import lingering, smooth, squish_rate_func, \
    wiggle
from real_time_manim.vulkan_bind import MLWindow, Wait

class RateCurveFactoryDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("02-squish / wiggle / ease", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        x0, x1, y0, y1 = -6.0, 2.6, -2.4, 1.8   #绘图区
        lo, hi = -1.1, 1.4   #这一组会冲出 0~1（wiggle 来回摆、ease 有回拉），范围放宽

        def ypos(v):   #把一个 f 值换算成场景 y 坐标（刻度标签用）
            return y0 + (v - lo) / (hi - lo) * (y1 - y0)

        def plot(f, color):   #同样把速率函数画成曲线
            def g(u):
                t = (u - x0) / (x1 - x0)   #屏幕 x → 进度 t
                y = f(t)   #速率函数给出的实际进度
                if y < lo:
                    y = lo   #压到显示边界
                elif y > hi:
                    y = hi
                return ypos(y)
            return FunctionGraph(g, x_range=[x0, x1, (x1 - x0) / 96], color=color, stroke_width=5)

        xax = Arrow([x0 - 0.3, y0, 0], [x1 + 0.4, y0, 0], color=GREY_B, stroke_width=4, buff=0)   #横轴：进度 t
        yax = Arrow([x0, y0 - 0.3, 0], [x0, y1 + 0.35, 0], color=GREY_B, stroke_width=4, buff=0)   #纵轴：实际进度 f(t)
        lt = Text("t", font_size=22, color=GREY_B).next_to(xax, DOWN, buff=0.12)   #横轴名
        lf = Text("f(t)", font_size=22, color=GREY_B).next_to(yax, UP, buff=0.12)   #纵轴名
        ticks = VGroup(*[Text(v, font_size=17, color=GREY_B).next_to([x0, ypos(float(v)), 0], LEFT, buff=0.15)
                         for v in ("1", "0", "-1")])   #纵轴三个刻度：上 1、中 0、下 -1
        l1t = Text("1", font_size=18, color=GREY_B).next_to([x1, y0, 0], DOWN, buff=0.15)   #t=1 刻度
        win.play(FadeIn(VGroup(xax, yax, lt, lf, ticks, l1t)), run_time=0.4)   #坐标轴先就位

        names = ["squish(smooth, .2, .8)", "wiggle(t, 3)", "lingering", "ease_out_bounce"]   #四种“带花样”的速率函数
        funcs = [squish_rate_func(smooth, 0.2, 0.8), lambda t: wiggle(t, 3),
                 lingering, rate_functions.ease_out_bounce]
        cols = [PURPLE, RED, YELLOW, TEAL]
        for i, (nm, f, c) in enumerate(zip(names, funcs, cols)):
            g = plot(f, c)   #第 i 条曲线
            lab = Text(nm, font_size=16, color=c).move_to([3.4, 1.2 - i * 0.8, 0])   #右侧同色图例
            win.play(Create(g), run_time=0.6)   #逐条把曲线画出来
            win.play(FadeIn(lab), run_time=0.2)   #补上它的名字
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：四条曲线各是一种"花样"。

- 紫色是工厂 `squish_rate_func(smooth, 0.2, 0.8)` 的产物——原本铺满全程的 S 曲线被压进 0.2~0.8 这一段（两端水平）；
- 红色 `wiggle(t, 3)` 在 0 和 1 之间来回荡三次；
- 黄色 `lingering` 走完 80% 后末段纹丝不动；
- 青色 `ease_out_bounce` 是标准缓动里的落地弹跳，先冲过 1 再弹回。

四条一起说明：速率函数不仅可以是预定义名字，还能用工厂现场加工，甚至越出 0~1。

## 标准缓动 `rate_functions.ease_*`（30 个，来自 easings.net）

> 10 个族 × 3 种（`_in` 缓入 / `_out` 缓出 / `_in_out` 两头缓），**都必须写 `rate_functions.` 前缀**；样例 2 已出镜 `ease_out_bounce`（落地弹跳），同族其余成员画法完全相同。

| 族 | 缓入 `ease_in_*` | 缓出 `ease_out_*` | 缓入缓出 `ease_in_out_*` | 族特征 |
| --- | --- | --- | --- | --- |
| `_sine` | 起手很慢的正弦加速 | 收尾很慢的正弦减速 | 两头慢中间快 | 最柔和，无过冲 |
| `_quad` | 二次方加速起步 | 二次方减速到位 | 二次方两头慢 | 基础加速度感 |
| `_cubic` | 三次方起步（前段几乎不动） | 三次方收尾 | 三次方两头慢 | 幂次越高，中段越猛 |
| `_quart` | 四次方起步 | 四次方收尾 | 四次方两头慢 | 同上，更极端 |
| `_quint` | 五次方起步 | 五次方收尾 | 五次方两头慢 | 10 个族里最"呆滞起步"的多项式 |
| `_expo` | 指数级：前 90% 时间几乎不动 | 指数级：瞬间到位再微调 | 两头几乎静止 | 反差最强 |
| `_circ` | 圆弧形缓入 | 圆弧形缓出 | 圆弧两头慢 | 边界处有明显直角感 |
| `_back` | 先回退、冲过头、再回来 | 冲过目标再回弹一次 | 两头各回退一次 | **有回拉/过冲** |
| `_elastic` | 弹簧拉伸式起点震荡（可为负值） | 弹簧回弹式震荡收尾 | 两头震荡 | 震荡最明显，可超出 [0,1] |
| `_bounce` | 反向弹跳（像倒放落地弹起） | 皮球落地多次弹跳收尾 | 两头弹跳 | 阶梯状弹跳 |

> 注：`_back`、`_elastic`、`_bounce` 的中间值会越出 `[0, 1]`，用于位移动画没问题，但别用它驱动 `set_opacity` 之类要求严格 0~1 的属性。

## 装饰器与协议（少用，3 个）

> 这 3 个名字**不在** `manim` 顶层导出，必须写 `rate_functions.` 前缀；RTM 均未内置（走通用回退）。

| 名称 | 类型 | 作用 |
| --- | --- | --- |
| `unit_interval(func)` | 装饰器 | 保证 `t<0` 返回 0、`t>1` 返回 1，区间内才调用原函数。所有"正常进度"型速率函数都套了它 |
| `zero(func)` | 装饰器 | 保证 `t` 超出 `[0,1]` 一律返回 0。`there_and_back`、`wiggle` 用它实现"动画结束后归零" |
| `RateFunction` | Protocol 类 | 类型标注用：`def __call__(self, t: float, *args, **kwargs) -> float` |

无法演示：`unit_interval` / `zero` / `RateFunction` —— 装饰器包在别的函数外面、Protocol 只做类型标注，单独出片与原函数逐帧相同（样例 1 的曲线已是套上 `unit_interval` 后的最终形态）。

`smoothstep` / `smootherstep` / `smoothererstep` / `double_smooth` / `slow_into` / `exponential_decay` / `there_and_back_with_pause` 等 S 形变体与 `ease_*` 其余 29 个 —— 画法与样例 1/2 完全相同（套同一个 `plot`），形态差异收在上方参数表里。

`running_start` / `not_quite_there` 等未单列的走通用回退，形态见参数表。
