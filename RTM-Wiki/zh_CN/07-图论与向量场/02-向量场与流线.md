# 向量场：ArrowVectorField 与 VectorField

三者都继承 `VectorField`：给一个 `func(point) -> vector`，它负责配色、生成可视元素、推动 mobject 沿场运动。模块常量 `DEFAULT_SCALAR_FIELD_COLORS = [BLUE_E, GREEN, YELLOW, RED]` 是默认"按模长渐变"配色（不在顶层导出，需 `from manim.mobject.vector_field import ...`）。RTM 没有专门实现向量场，走通用矢量回退出图——实测箭头网格、RK4 单步、持续 updater 流动、子 mobject 群体漂移全部正常（见下方各样例）。

## ArrowVectorField —— 用箭头网格表示向量场

### class ArrowVectorField（RTM 通用矢量回退渲染）

```python
ArrowVectorField(func: Callable[[np.ndarray], np.ndarray], color: ParsableManimColor | None = None, color_scheme: Callable[[np.ndarray], float] | None = None, min_color_scheme_value: float = 0, max_color_scheme_value: float = 2, colors: Sequence[ParsableManimColor] = DEFAULT_SCALAR_FIELD_COLORS, x_range: Sequence[float] = None, y_range: Sequence[float] = None, z_range: Sequence[float] = None, three_dimensions: bool = False, length_func: Callable[[float], float] = lambda norm: 0.45 * sigmoid(norm), opacity: float = 1.0, vector_config: dict | None = None, **kwargs)
```

在规则网格上采样 `func`，画一整片 `Vector` 箭头；默认**箭头颜色随模长在 `colors` 渐变**（`color` 给了值则整体单色），长度用 `length_func` 压缩防止过长。**返回** `ArrowVectorField`（是 `VGroup`，可直接 `self.add`）。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `func` | `Callable[[ndarray], ndarray]` | 必填 | 位置 → 向量的场函数 |
| `color` | `ParsableManimColor \| None` | `None` | 给了就整体单色，关掉按位置配色 |
| `color_scheme` | `Callable[[ndarray], float] \| None` | `None` | 向量 → 标量的映射；默认取 `np.linalg.norm`（模长） |
| `min_color_scheme_value` / `max_color_scheme_value` | `float` | `0` / `2` | 标量映射到渐变首/末色的区间 |
| `colors` | `Sequence[ParsableManimColor]` | `[BLUE_E, GREEN, YELLOW, RED]` | 渐变色列表 |
| `x_range` / `y_range` / `z_range` | `Sequence[float] \| None` | `None` | `[min, max, step]`；缺省自动取画幅范围，step 缺省 0.5 |
| `three_dimensions` | `bool` | `False` | 三维采样；给了 `z_range` 会自动变 `True` |
| `length_func` | `Callable[[float], float]` | `0.45 * sigmoid(norm)` | 实际模长 → 显示长度（默认饱和式压短） |
| `opacity` | `float` | `1.0` | 箭头不透明度 |
| `vector_config` | `dict \| None` | `None` | 传给 `Vector` 构造（`stroke_width`、`tip_shape`…） |
| `**kwargs` | - | - | 透传给 `VectorField` |

其他公开方法 ⚪：`get_vector(point)` —— 依据场函数与配色生成单根箭头（一般自动调用）。

#### 样例：ArrowVectorField 构造参数

同一张场渲两遍：第一段用默认配色与默认长度函数（蓝→绿→黄→红随模长渐变），第二段 `color=RED` 整体单色、`length_func=lambda x: x/3` 线性定长、`vector_config={"stroke_width": 2}` 换细箭杆。

```python
import numpy as np
from real_time_manim import Scene, Text, \
    RED, YELLOW, GREY_B, UP, DOWN, RIGHT, \
    Write, FadeIn
from real_time_manim.vulkan_bind import MLWindow, Wait

class ArrowVectorFieldDemo(Scene):
    TUNED = False   #False 用默认配色与长度函数；True 换单色 + 线性长度

    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("02-ArrowVectorField", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题
        lab = Text(
            "color=RED, length_func=lambda x: x/3, vector_config={stroke_width:2}"
            if self.TUNED else "default: color=norm gradient, length_func=0.45*sigmoid",
            font_size=24, color=GREY_B,
        ).next_to(title, DOWN, buff=0.3)   #显示当前构造参数
        win.play(FadeIn(lab, shift=DOWN), run_time=0.3)   #标签从下方淡入
        func = lambda pos: np.sin(pos[1] / 2) * RIGHT + np.cos(pos[0] / 2) * UP   #场函数：位置 -> 向量
        if self.TUNED:
            vf = ArrowVectorField(
                func,                                   #参数 “func”
                x_range=[-4, 4, 1], y_range=[-2.5, 2.5, 1],   #采样网格
                color=RED,                              #参数 “color”：整体单色
                length_func=lambda x: x / 3,            #参数 “length_func”：线性定长
                vector_config={"stroke_width": 2},      #参数 “vector_config”
            )
        else:
            vf = ArrowVectorField(
                func,                                   #参数 “func”
                x_range=[-4, 4, 1], y_range=[-2.5, 2.5, 1],   #采样网格
            )
        win.play(FadeIn(vf), run_time=0.8)   #整片箭头淡入
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：用 `sin/cos` 造一个位置→向量的场函数，在 `x∈[-4,4]`、`y∈[-2.5,2.5]` 的网格上每 1 格采样一根箭头。第一段是构造函数的默认行为——箭头按模长在蓝绿黄红渐变、长度被 sigmoid 压短；第二段把三个参数一次换掉：整片染红、长度改线性 `x/3`（模长大的箭头明显更长）、箭杆细到 2 号。

<video src="assets/RTM output/02-向量场与流线-field.mp4" controls width="560"></video>

> 提醒：`color` 与 `colors`/`color_scheme` 是互斥关系——`color` 一给就整片同色，想恢复按位置渐变就把 `color` 留 `None`。另外 `length_func` 收到的是**归一化后的模长**，返回值直接当箭头长度用，给常数函数就能画出等长箭头。

## VectorField —— 向量场基类（不画东西，只给运动规则）

### class VectorField（RTM 通用矢量回退渲染）

```python
VectorField(func: Callable[[Point3D], Vector3D], color: ParsableManimColor | None = None, color_scheme: Callable[[Vector3D], float] | None = None, min_color_scheme_value: float = 0, max_color_scheme_value: float = 2, colors: Sequence[ParsableManimColor] = DEFAULT_SCALAR_FIELD_COLORS, **kwargs)
```

`ArrowVectorField` 与 `StreamLines` 的公共基类，本身不产生任何可见元素，提供"让 mobject 沿场运动"的一整套方法与按位置配色机制；参数同上表（无网格相关参数）。

### 公开方法

| 签名 | 频率 | 作用 |
| --- | --- | --- |
| `nudge(mob, dt=1, substeps=1, pointwise=False) -> VectorField` | 🔴 | 用 RK4 把 `mob` 沿场推一步；`dt` 越大走得越远，`substeps` 越大越精确；`pointwise=True` 逐点推动（会形变） |
| `get_nudge_updater(speed=1, pointwise=False) -> Callable` | 🔴 | 返回 updater，交给 `mob.add_updater(...)` 让 mobject 持续沿场流动 |
| `nudge_submobjects(dt=1, substeps=1, pointwise=False) -> VectorField` | 🟡 | 对自己的所有子 mobject 各推一步 |
| `start_submobject_movement(speed=1, pointwise=False) -> VectorField` | 🟡 | 挂 updater 让所有子 mobject 持续流动；重复调用会替换旧 updater |
| `stop_submobject_movement() -> VectorField` | 🟡 | 停掉上一条 updater |
| `shift_func(func, shift_vector) -> Callable` | 🟡 | 静态工具：返回 `lambda p: func(p - shift_vector)`，平移场函数定义域 |
| `scale_func(func, scalar) -> Callable` | 🟡 | 静态工具：返回 `lambda p: func(p * scalar)`，缩放场函数定义域 |
| `fit_to_coordinate_system(coordinate_system) -> None` | ⚪ | 把场的锚点换算到给定坐标系（**只能调一次**，会原地变换） |
| `get_colored_background_image(sampling_rate=5) -> Image` | ⚪ | 生成按位置配色的位图（`StreamLines` 内部用它上色）；单色场会报错 |
| `get_vectorized_rgba_gradient_function(start, end, colors) -> Callable` | ⚪ | "标量数组 → RGBA 数组"的向量化渐变函数（OpenGL 渲染器用） |

### nudge / get_nudge_updater —— 单步推动与持续流动

`vf.nudge(dot, dt=1, substeps=20)` 用 RK4 把红点沿场推一大步（**直接落位**，不产生动画，配合前后的 `Line` 标注就能看清位移）；`dot.add_updater(vf.get_nudge_updater(speed=1))` 换成持续 updater，红点就沿着场线一直流。

#### 样例：nudge 单步与持续 updater

半透明场当背景，红点先被 RK4 单步推到新位置（橙线标出这一步的位移），再挂 `get_nudge_updater` 沿场流动 2 秒，最后 `clear_updaters` 停住。

```python
import numpy as np
from real_time_manim import Scene, Text, VGroup, Dot, Line, ArrowVectorField, \
    RED, ORANGE, YELLOW, GREY_B, UP, DOWN, RIGHT, \
    Write, FadeIn, Create
from real_time_manim.vulkan_bind import MLWindow, Wait

class NudgeDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("02-VectorField-nudge", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题
        lab = VGroup(
            Text("vf.nudge(dot, dt=1, substeps=20)   # one RK4 step",
                 font_size=26, color=GREY_B),
            Text("dot.add_updater(vf.get_nudge_updater(speed=1))",
                 font_size=26, color=GREY_B),
        ).arrange(DOWN, buff=0.06).next_to(title, DOWN, buff=0.3)   #两行签名标签
        win.play(FadeIn(lab, shift=DOWN), run_time=0.3)   #标签从下方淡入
        func = lambda pos: np.sin(pos[1] / 2) * RIGHT + np.cos(pos[0] / 2) * UP   #场函数
        vf = ArrowVectorField(func, x_range=[-4, 4, 1], y_range=[-2.5, 2.5, 1],
                              opacity=0.4)   #半透明的场当背景
        dot = Dot(radius=0.12, color=RED).move_to([-3.5, -1.4, 0])   #出发点
        win.play(FadeIn(vf), FadeIn(dot), run_time=0.5)   #场与红点淡入
        start = dot.get_center().copy()   #记住起点
        vf.nudge(dot, dt=1, substeps=20)   #参数 “dt” / “substeps”：RK4 推一大步（直接落位）
        step = Line(start, dot.get_center(), stroke_width=4, color=ORANGE)   #画出这一步的位移
        win.play(Create(step), run_time=0.4)   #橙色线段标出单步位移
        win.play(Wait(0.3))   #进行 0.3s 的等待
        dot.add_updater(vf.get_nudge_updater(speed=1))   #参数 “speed”：换成持续沿场流动
        win.play(Wait(2.0))   #红点沿场线流动 2 秒
        dot.clear_updaters()   #解除 updater，点停住
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：`opacity=0.4` 的箭头网格当底图，左下角放一个红点。`vf.nudge(dot, dt=1, substeps=20)` 是**一次性的**：点直接跳到新位置，所以手动从起点画一条橙色线段把这步位移标出来；随后 `add_updater(vf.get_nudge_updater(speed=1))` 换成持续模式，红点在 2 秒里顺着场线蜿蜒流动，`clear_updaters()` 一调就定住。

<video src="assets/RTM output/02-向量场与流线-nudge.mp4" controls width="560"></video>

> 提醒：`nudge` 本身**不产生动画**（点是瞬移的），想让人看见过程就得自己补 `Line` 标注或改用 updater；`substeps=1` 时 RK4 退化成单次采样，`dt` 开大容易冲过头，动画里常用 `dt=1, substeps=20` 这种"大步快推"。持续 updater 挂上后**画面停多久它就走多久**，务必记得 `clear_updaters()`。

### start_submobject_movement / stop_submobject_movement —— 群体流动

对 `ArrowVectorField`（`StreamLines` 同理）整体调 `start_submobject_movement(speed=1.5)`，它的每一根箭头都会各自沿场漂移；`stop_submobject_movement()` 停在当前位置。

#### 样例：子 mobject 群体流动

稀疏一点的绿色箭头网格，挂上 `start_submobject_movement(speed=1.5)` 后所有箭头一起沿场漂移 2 秒，再 `stop_submobject_movement()` 停住。

```python
import numpy as np
from real_time_manim import Scene, Text, ArrowVectorField, \
    GREEN, YELLOW, GREY_B, UP, DOWN, RIGHT, \
    Write, FadeIn
from real_time_manim.vulkan_bind import MLWindow, Wait

class SubmobjectMoveDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("02-VectorField-submobjects", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题
        lab = Text("vf.start_submobject_movement(speed=1.5) ... stop_...()",
                   font_size=26, color=GREY_B).next_to(title, DOWN, buff=0.3)   #签名标签
        win.play(FadeIn(lab, shift=DOWN), run_time=0.3)   #标签从下方淡入
        func = lambda pos: np.sin(pos[1] / 2) * RIGHT + np.cos(pos[0] / 2) * UP   #场函数
        vf = ArrowVectorField(func, x_range=[-4, 4, 1.5], y_range=[-2.25, 2.25, 1.5],
                              color=GREEN)   #稀疏一点的绿色箭头网格
        win.play(FadeIn(vf), run_time=0.5)   #整片箭头淡入
        vf.start_submobject_movement(speed=1.5)   #参数 “speed”：所有箭头一起沿场漂移
        win.play(Wait(2.0))   #漂移 2 秒
        vf.stop_submobject_movement()   #停在当前位置
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：把网格步长放大到 1.5、整片染绿，得到一个稀疏的箭头阵；`start_submobject_movement(speed=1.5)` 给**每根箭头**挂上沿场流动的 updater，2 秒里整片箭头像被风吹着一样同步漂移，`stop_submobject_movement()` 一调全体定格。

<video src="assets/RTM output/02-向量场与流线-submobject.mp4" controls width="560"></video>

> 提醒：这个方法动的是场对象自己的子 mobject（每根 `Vector`），**不是**让任意 mobject 跟着走——要推动别的东西用 `nudge`/`get_nudge_updater`。重复调用会替换旧 updater，停用只能靠 `stop_submobject_movement()`，`clear_updaters()` 对它无效。
