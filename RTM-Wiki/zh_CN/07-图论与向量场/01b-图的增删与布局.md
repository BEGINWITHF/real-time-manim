# 图的增删与布局变换

`GenericGraph` 提供索引访问与一组支持 `.animate` 的增删/布局方法，全部可配合 `win.play(g.animate.xxx(...))` 做平滑动画。RTM 没有专门实现图渲染，走通用矢量回退出图——实测索引取点取边、增点增边、删点删边、连续改布局全部正常（见下方各样例）。

## g[k] —— 索引取顶点/边

### GenericGraph.__getitem__（RTM 通用矢量回退渲染）

```python
GenericGraph.__getitem__(k: Hashable | tuple[Hashable, Hashable]) -> Mobject
```

`g[顶点名]` 取顶点 mobject，`g[(u, v)]` 取边 mobject，这是最常用的访问方式（配合 `.animate` 做单点/单边动画）；找不到时抛 `ValueError`。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `k` | `Hashable` | 顶点名，取到顶点 mobject |
| `k` | `tuple[Hashable, Hashable]` | `(u, v)` 边元组，取到边 mobject |

#### 样例：getitem 取点取边

四个顶点围成一圈，先 `g[2].animate.shift(...)` 挪动 2 号顶点（相连的边自动跟随），再 `g[(1, 2)].animate.set_stroke(...)` 把 (1,2) 这条边加粗变橙。

```python
from real_time_manim import Scene, Graph, Text, \
    BLACK, YELLOW, GREY_B, ORANGE, UP, DOWN, LEFT, \
    Write, FadeIn, Create
from real_time_manim.vulkan_bind import MLWindow, Wait

class GetItemDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("01b-Graph-getitem", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题
        lab = Text("g[2].animate.shift(...)   g[(1,2)].animate.set_stroke(...)",
                   font_size=26, color=GREY_B).next_to(title, DOWN, buff=0.3)   #签名标签
        win.play(FadeIn(lab, shift=DOWN), run_time=0.3)   #标签从下方淡入
        g = Graph(
            [1, 2, 3, 4], [(1, 2), (2, 3), (3, 4), (4, 1)],   #四个顶点围成一圈
            layout="circular", layout_scale=2.2,             #环形布局
            labels=True, label_fill_color=BLACK,             #顶点数字标签
        )
        win.play(Create(g), run_time=0.8)   #逐笔画出整张图
        win.play(g[2].animate.shift(UP + LEFT), run_time=0.8)   #参数 “k”：挪 2 号顶点，相连的边自动跟随
        win.play(g[(1, 2)].animate.set_stroke(ORANGE, width=8), run_time=0.5)   #参数 “k”：把 (1,2) 这条边加粗变色
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：先逐笔画出四顶点环形图，然后把 2 号顶点往左上挪一格——挂了 updater 的四条边会自动跟着端点走。

接着把 `(1, 2)` 这条边单独加粗到 8 号并染成橙色，演示边也能被精确索引并单独动画。

<video src="assets/RTM output/01b-图的增删与布局-getitem.mp4" controls width="560"></video>

> 提醒：索引取到的是**同一个 mobject 本体**（不是副本），对它做的任何 `.animate` 都直接作用在图上；想改完恢复就自己再 `set_stroke` 回去。

## add_vertices / add_edges —— 增加顶点与边

### GenericGraph.add_vertices / add_edges

```python
GenericGraph.add_vertices(*vertices: Hashable, positions: dict | None = None, labels: bool | dict = False, label_fill_color: str = BLACK, vertex_type: type[Mobject] = Dot, vertex_config: dict | None = None, vertex_mobjects: dict | None = None)
GenericGraph.add_edges(*edges: tuple[Hashable, Hashable], edge_type: type[Mobject] = Line, edge_config: dict | None = None, **kwargs)
```

`g.animate.add_vertices(...)` 会平滑地"长出"新顶点（`positions=None` 时放图中心，**实际几乎总要给 `positions`**）；`add_edges` 里出现的新顶点会被自动创建。二者**返回**新增顶点与边组成的 `Group`。

### 增删参数

| 方法 | 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| add_vertices | *vertices | `Hashable` | 必填 | 新顶点名 |
| add_vertices | positions | `dict \| None` | `None` | `{顶点: [x,y,z]}`；缺省放图中心 |
| add_vertices | labels | `bool \| dict` | `False` | 同构造参数 |
| add_vertices | label_fill_color | `str` | `BLACK` | 标签色 |
| add_vertices | vertex_type | `type[Mobject]` | `Dot` | 顶点类 |
| add_vertices | vertex_config | `dict \| None` | `None` | 顶点参数（会与图的默认参数合并） |
| add_vertices | vertex_mobjects | `dict \| None` | `None` | 直接指定顶点 mobject |
| add_edges | *edges | `tuple` | 必填 | 边 `(u, v)` |
| add_edges | edge_type | `type[Mobject]` | `Line` | 边的类 |
| add_edges | edge_config | `dict \| None` | `None` | 公共边参数，或 `{(u,v): 参数dict}` |
| add_edges | **kwargs | - | - | 转发给 `add_vertices`（`positions`、`labels`、`vertex_config`…） |

#### 样例：add 增点增边

三顶点两边的环形图先长出一条连着新顶点 4 的边，再加一个孤点 5，最后把 4、5 两点连起来。

```python
from real_time_manim import Scene, Graph, Text, \
    BLACK, YELLOW, GREY_B, UP, DOWN, LEFT, \
    Write, FadeIn, Create
from real_time_manim.vulkan_bind import MLWindow, Wait

class GraphAddDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        self.play = win.play   #保险接线：增删/改布局由 win.play 直接播，不回调 self.play（move_camera 等场景方法才真会调）
        title = Text("01b-Graph-add", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题
        lab = Text("g.animate.add_edges((1,4), positions=..., labels=True)",
                   font_size=26, color=GREY_B).next_to(title, DOWN, buff=0.3)   #签名标签
        win.play(FadeIn(lab, shift=DOWN), run_time=0.3)   #标签从下方淡入
        g = Graph(
            [1, 2, 3], [(1, 2), (2, 3)],   #先画三个顶点两条边
            layout="circular", layout_scale=2.0,   #环形布局
            labels=True, label_fill_color=BLACK,   #顶点数字标签
        )
        win.play(Create(g), run_time=0.6)   #逐笔画出初始图
        win.play(g.animate.add_edges((1, 4), positions={4: [3.2, 1.2, 0]},   #参数 “*edges” / “positions”
                                     labels=True), run_time=0.8)   #新边连带新顶点 4 一起长出来
        win.play(g.animate.add_vertices(5, positions={5: [3.2, -1.4, 0]},   #参数 “*vertices”
                                         labels=True), run_time=0.6)   #只加一个孤点 5
        win.play(g.animate.add_edges((4, 5)), run_time=0.5)   #再把 4、5 两个新顶点连起来
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：

- `add_edges((1, 4), positions=..., labels=True)` 里出现了图中没有的顶点 4，上游会按 `positions` 自动创建它，边和点一起平滑长出。
- `add_vertices(5, ...)` 只补一个带标签的孤点。
- 最后 `add_edges((4, 5))` 把两个新点连上（不给 `positions` 时新点会放在图中心，这里两点已存在所以直接连线）。

<video src="assets/RTM output/01b-图的增删与布局-add.mp4" controls width="560"></video>

> 提醒：
>
> - `add_edges` 的 `**kwargs` 全部转发给 `add_vertices`——所以 `positions`、`labels`、`label_fill_color` 写在 `add_edges(...)` 里一样有效。
> - **2026-10-17 实测**：图的动态方法（add/remove/change_layout）在 `.animate` 下走 `override_animate` 返回 `AnimationGroup`/`Uncreate`/`_MethodAnimation`，由 `win.play` 直接播，**不**调用 `self.play`——样例首行的 `self.play = win.play` 属保险接线（真正必须接的是 `move_camera` 这类场景方法）。

## remove_vertices / remove_edges —— 删除顶点与边

### GenericGraph.remove_vertices / remove_edges

```python
GenericGraph.remove_vertices(*vertices: Hashable)
GenericGraph.remove_edges(*edges: tuple[Hashable, Hashable])
```

删除顶点会连带删除所有与之相连的边；删除边则保留顶点。`g.animate.remove_vertices(...)` / `g.animate.remove_edges(...)` 生成 `Uncreate` 动画，**返回**被移除 mobject 组成的 `Group`。

| 方法 | 参数 | 类型 | 说明 |
| --- | --- | --- | --- |
| remove_vertices | *vertices | `Hashable` | 要删的顶点；关联边一并删除 |
| remove_edges | *edges | `tuple[Hashable, Hashable]` | 要删的边；两端顶点保留 |

#### 样例：remove 删边删点

四点成圈外加一条弦 `(1, 3)`：先 `remove_edges((1, 3))` 只删弦（弦整条淡出），再 `remove_vertices(4)` 删掉 4 号点（连带它的两条边一起消失）。

```python
from real_time_manim import Scene, Graph, Text, \
    BLACK, YELLOW, GREY_B, UP, DOWN, LEFT, \
    Write, FadeIn, Create
from real_time_manim.vulkan_bind import MLWindow, Wait

class GraphRemoveDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        self.play = win.play   #保险接线：增删/改布局由 win.play 直接播，不回调 self.play（move_camera 等场景方法才真会调）
        title = Text("01b-Graph-remove", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题
        lab = Text("g.animate.remove_edges((1,3))  then  g.animate.remove_vertices(4)",
                   font_size=24, color=GREY_B).next_to(title, DOWN, buff=0.3)   #签名标签
        win.play(FadeIn(lab, shift=DOWN), run_time=0.3)   #标签从下方淡入
        g = Graph(
            [1, 2, 3, 4], [(1, 2), (2, 3), (3, 4), (4, 1), (1, 3)],   #四点成圈外加一条弦
            layout="circular", layout_scale=2.2,   #环形布局
            labels=True, label_fill_color=BLACK,   #顶点数字标签
        )
        win.play(Create(g), run_time=0.8)   #逐笔画出整张图
        win.play(g.animate.remove_edges((1, 3)), run_time=0.5)   #参数 “*edges”：只删边，顶点保留
        win.play(g.animate.remove_vertices(4), run_time=0.5)   #参数 “*vertices”：删顶点，连带它的边一起删
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：五条边的图先删掉横穿的弦 `(1, 3)`，四个顶点一个不少；再删顶点 4，与它相连的 `(3, 4)`、`(4, 1)` 两条边跟着一起淡出——演示"删点级联删边、删边不动点"的差别。

<video src="assets/RTM output/01b-图的增删与布局-remove.mp4" controls width="560"></video>

> 提醒：删除后**布局不会自动重排**——剩下的顶点就停在原位，想重新摆开要再调 `change_layout`。

## change_layout —— 重新布局

### GenericGraph.change_layout

```python
GenericGraph.change_layout(layout: LayoutName | dict[Hashable, Point3DLike] | LayoutFunction = "spring", layout_scale: float | tuple[float, float, float] = 2, layout_config: dict[str, Any] | None = None, partitions: list[list[Hashable]] | None = None, root_vertex: Hashable | None = None) -> Graph
```

按新布局把所有顶点 `move_to` 到新位置，最常配合 `.animate` 做"布局变换"转场；**返回** `self`（可链式）。

### 参数

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| layout | 同构造 | `"spring"` | 新布局 |
| layout_scale | `float \| tuple` | `2` | 新缩放 |
| layout_config | `dict \| None` | `None` | 布局算法参数 |
| partitions | `list[list] \| None` | `None` | 会并入 `layout_config["partitions"]` |
| root_vertex | `Hashable \| None` | `None` | 会并入 `layout_config["root_vertex"]` |

#### 样例：change_layout 连续变换布局

五点环形图连续做两次布局变换：`"spring"` 力导向散开（种子 7 写死），再换成手写坐标字典 `{1: [-3.2, 0, 0], ...}` 排成一条水平线。

```python
from real_time_manim import Scene, Graph, Text, VGroup, \
    BLACK, YELLOW, GREY_B, UP, DOWN, LEFT, \
    Write, FadeIn, Create
from real_time_manim.vulkan_bind import MLWindow, Wait

class GraphChangeLayoutDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        self.play = win.play   #保险接线：增删/改布局由 win.play 直接播，不回调 self.play（move_camera 等场景方法才真会调）
        title = Text("01b-Graph-change_layout", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题
        lab = VGroup(
            Text('g.animate.change_layout("spring", layout_config={"seed":7})',
                 font_size=26, color=GREY_B),
            Text("g.animate.change_layout({1:[-3.2,0,0], ...})  # manual",
                 font_size=26, color=GREY_B),
        ).arrange(DOWN, buff=0.06).next_to(title, DOWN, buff=0.3)   #两行签名标签
        win.play(FadeIn(lab, shift=DOWN), run_time=0.3)   #标签从下方淡入
        g = Graph(
            [1, 2, 3, 4, 5], [(1, 2), (2, 3), (3, 4), (4, 5), (5, 1)],   #五点成圈
            layout="circular", layout_scale=2.2,   #初始环形布局
            labels=True, label_fill_color=BLACK,   #顶点数字标签
        )
        win.play(Create(g), run_time=0.6)   #逐笔画出整张图
        win.play(g.animate.change_layout("spring", layout_config={"seed": 7}),   #参数 “layout”
                 run_time=1.0)   #所有顶点平移到新布局，边跟着走
        win.play(g.animate.change_layout(
            {1: [-3.2, 0, 0], 2: [-1.6, 0, 0], 3: [0, 0, 0],   #手写坐标字典也是合法布局
             4: [1.6, 0, 0], 5: [3.2, 0, 0]}), run_time=1.0)   #这次把五个顶点排成一条水平线
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：五点环形图先 morph 到带种子的 spring 力导向布局——顶点边平移到新位置，边的 updater 保证线段始终连着端点。

再 morph 到手写坐标字典，五个点被拉成一条水平直线，演示 `layout` 既认算法名也认现成坐标。

<video src="assets/RTM output/01b-图的增删与布局-change_layout.mp4" controls width="560"></video>

> 提醒：
>
> - `change_layout` 接受的 `layout`/`layout_config` 与构造时完全同一套规则——`"spring"`/`"random"` 要写死 `seed`，`"circular"` 这类确定性布局传 `seed` 会 `TypeError`；手写坐标字典的键必须**覆盖图中全部顶点**。
> - 两引擎坐标要逐帧对上，随机布局的 seed 一个都不能省。

## 其他图论细节

| 项 | 说明 |
| --- | --- |
| `Graph.update_edges(graph)` | updater 本体：把每条边端点重设为两端顶点当前位置，由 `add_updater` 自动挂上，**不要手动调** |
| `Graph.vertices` / `.edges` / `._layout` | 公开属性：顶点 dict、边 dict `{(u,v): mobject}`、当前布局坐标 |
| 顶点位置的手动修改 | `g[v].move_to(...)` 直接挪即可，边会跟着动；但 `_layout` 不会同步（`change_layout` 才整体重算） |
| `LayoutFunction`（Protocol） | 自定义布局函数需是纯函数 `(graph, scale=2, **kwargs) -> dict[node, np.ndarray(3)]`，不许修改传入的图 |
| 图动态方法与 RTM | `add_vertices`/`remove_vertices`/`change_layout` 的 `.animate` 版由 `_AnimationBuilder` 构建动画、`win.play` 直接播，实测**不**回调 `self.play`；样例首行的 `self.play = win.play` 属保险接线（`move_camera` 等场景方法才真正需要，见 add/remove 样例首行） |
