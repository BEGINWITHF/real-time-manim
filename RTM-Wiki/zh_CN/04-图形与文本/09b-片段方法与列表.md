# MathTex 片段方法与列表、标题

承接 [LaTeX 公式](09-LaTeX公式.md)：公式片段的上色/取件/透明度方法，以及 LaTeX 项目符号列表与页眉标题。每个方法各一条样例，样例里把该方法**全部可填参数**各改一次。

> **片段怎么拆分**：`{{ }}` 标记只对**同一个字符串参数内部**生效，`MathTex("{{x}}^2+{{y}}^2={{z}}^2")` 实际只拆成 `x` 与 `^2+{{y}}^2={{z}}^2` 两片（实测两引擎一致）。想按片段上色/取件，就把每片写成**独立参数**：`MathTex("{{x}}^2", "+", "{{y}}^2", "=", "{{z}}^2")`。下面所有样例都用后一种写法。

## 参数

### `MathTex.set_color_by_tex`

```python
def set_color_by_tex(self, tex: str, color: ParsableManimColor, **kwargs) -> Self:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `tex` | `str` | 必填 | 片段文本（要**完全等于**该片段的 `tex_string`，如 `"x"`）；样例依次染 `x`/`y`/`z` |
| `color` | `ManimColor` | 必填 | 目标颜色；同一个片段在不同公式里可以染不同色（样例最后一段 `x→ORANGE`、`z→PURPLE` 链式两次） |

#### 样例：依次给 x / y / z 上色 + 链式两次

```python
import os
import subprocess
import sys
from real_time_manim import (
    Scene, MathTex, BulletedList, Title, Text, Rectangle, VGroup,
    BLUE, GREEN, RED, ORANGE, YELLOW, PURPLE, TEAL, GOLD, GREY_B, WHITE,
    UP, DOWN, LEFT, RIGHT, ORIGIN,
    Create, FadeIn, FadeOut, Write, MED_LARGE_BUFF,
)
from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim.record import fast_record_scene

class ColorByTexDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("09b-set_color_by_tex", font_size=30, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        # —— 同一个公式，三段各染一次（每次只给一个 “tex / color” 组合）——
        pairs = [("x", RED), ("y", GREEN), ("z", BLUE)]   #参数 “tex / color”
        for i, (tex, col) in enumerate(pairs):
            eq = MathTex("{{x}}^2", "+", "{{y}}^2", "=", "{{z}}^2", font_size=52)
            eq.set_color_by_tex(tex, col)   #参数 “tex=片段文本 / color=目标颜色”
            eq.move_to([-4.2 + i * 4.2, 0.9, 0])
            cap = Text('set_color_by_tex("%s")' % tex, font_size=18, color=GREY_B).next_to(eq, DOWN, buff=0.4)
            win.play(Write(eq), FadeIn(cap), run_time=0.6)   #依次染红 x、绿 y、蓝 z

        # —— 一个片段在不同公式里可以染不同颜色 ——
        eq2 = MathTex("{{x}}^2", "+", "{{y}}^2", "=", "{{z}}^2", font_size=52)
        eq2.set_color_by_tex("x", ORANGE)   #同一个 “x”，这次染橙色
        eq2.set_color_by_tex("z", PURPLE)   #再来一次，染紫色
        eq2.move_to([-1.6, -1.7, 0])
        cap2 = Text('x->ORANGE  z->PURPLE', font_size=18, color=GREY_B).next_to(eq2, DOWN, buff=0.35)
        win.play(Write(eq2), FadeIn(cap2), run_time=0.6)   #链式调用两次
        win.play(Wait(0.5))   #停留看结果
        win.close()   #关闭 RTM 窗口


# ===== 样例 2：set_color_by_tex_to_color_map —— 一次染多片 =================
```

这段代码在做什么：同一套公式画三遍，每遍只染一个片段（红 `x`、绿 `y`、蓝 `z`），字幕标着这次用的是哪个 `tex`。最后一条公式在**同一个对象**上连着调用两次 `set_color_by_tex`，`x` 变橙、`z` 变紫，`y` 保持白色——说明它是就地改色、可以链式调用。

<video src="assets/RTM output/09b-片段方法与列表-colorbytex.mp4" controls width="560"></video>

> 提醒：`tex` 必须与片段的 `tex_string` **完全相等**（不认子串、不认空格差异）；染色只改颜色不改几何，所以不会影响 `get_part_by_tex` 的查找。

### `MathTex.set_color_by_tex_to_color_map`

```python
def set_color_by_tex_to_color_map(self, texs_to_color_map: dict[str, ParsableManimColor], **kwargs) -> Self:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `texs_to_color_map` | `dict[str, color]` | 必填 | 片段→颜色的字典，一次染多片；等价于连续多次 `set_color_by_tex`。也可以写成构造参数 `MathTex(..., tex_to_color_map={...})`（样例两种都演示） |

### `MathTex.get_part_by_tex`

```python
def get_part_by_tex(self, tex: str, **kwargs) -> Mobject:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `tex` | `str` | 必填 | 片段文本；**匹配不到返回 `None`**（不是报错——紧接着用 `part.width` 才会 `AttributeError`，实测两引擎一致） |

返回匹配片段的子对象。

### `MathTex.set_opacity_by_tex`

```python
def set_opacity_by_tex(self, tex: str, opacity: float = 0.5, remaining_opacity: float | None = None, **kwargs) -> Self:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `tex` | `str` | 必填 | 要调透明度的片段 |
| `opacity` | `float` | `0.5` | 该片段的不透明度；样例先用默认 0.5，再显式给 `1.0` |
| `remaining_opacity` | `float \| None` | `None` | 其余片段的不透明度；不填就"只改这一片"，填了就"高亮主角、压暗其他"（样例 `0.25` / `0.3`） |

```python
# ===== 样例 6：BulletedList —— 项目符号列表 ================================
```

这段代码在做什么：把公式的 `submobjects` 逐个遍历，读出每个 `MathTexPart` 的 `tex_string` 并排成标签列表打在下方——屏幕上能看到 `0: x`、`1: ^2`、`2: +`… 这样的对照，这就是上面几个方法用来匹配片段的那份文本。

<video src="assets/RTM output/09b-片段方法与列表-parts.mp4" controls width="560"></video>

> 提醒：`submobjects` 的**顺序就是 LaTeX 的书写顺序**（含 `^2`、`+` 这类非字母片段），做下标式查找时要按这个顺序数。

### `BulletedList`

```python
def __init__(self, *items: str, buff: float = MED_LARGE_BUFF, dot_scale_factor: float = 2, tex_environment: str | None = None, **kwargs) -> None:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `*items` | `str...` | 必填 | 每个条目一个字符串；样例三/三条 |
| `buff` | `float` | `MED_LARGE_BUFF`（0.5） | 条目间距；样例用 `0.3 ×` 收紧对比 |
| `dot_scale_factor` | `float` | `2` | 项目符号点号的缩放；样例放大到 4 |
| `tex_environment` | `str \| None` | `None` | **不建议改**：外层 LaTeX 环境，通常交给默认即可（改它等于换整个列表的排版环境） |
| `fade_all_but(index_or_string, opacity=0.5)` | 方法 | — | 只支持**下标**：传字符串会抛 `Exception: Could not locate part by provided tex string '…'`（`BulletedList` 条目的 `tex_string` 带结尾的 `\\` 换行，纯文本或 `\item x` 都匹配不上；**两引擎一致**）。样例只用下标 |

#### 样例：默认间距 / 收紧+放大点号 / `fade_all_but` 换主角

```python
import os
import subprocess
import sys
from real_time_manim import (
    Scene, MathTex, BulletedList, Title, Text, Rectangle, VGroup,
    BLUE, GREEN, RED, ORANGE, YELLOW, PURPLE, TEAL, GOLD, GREY_B, WHITE,
    UP, DOWN, LEFT, RIGHT, ORIGIN,
    Create, FadeIn, FadeOut, Write, MED_LARGE_BUFF,
)
from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim.record import fast_record_scene

class BulletedListDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("09b-BulletedList", font_size=30, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        # —— buff 用默认值，dot_scale_factor 用默认 2 ——
        bl = BulletedList("first item", "second item", "third item",
                          font_size=40)   #参数 “*items”
        bl.move_to([-3.2, 0.9, 0])
        win.play(Write(bl), run_time=0.7)   #默认间距与点号大小

        # —— buff 收紧 + dot_scale_factor 放大 ——
        bl2 = BulletedList("tight", "spacing", "list", font_size=40,
                           buff=MED_LARGE_BUFF * 0.3,   #参数 “buff”：条目间距
                           dot_scale_factor=4)   #参数 “dot_scale_factor”：点号放大
        bl2.move_to([2.6, 0.9, 0])
        cap2 = Text("buff=0.3x  dot_scale_factor=4", font_size=18, color=GREY_B).next_to(bl2, DOWN, buff=0.4)
        win.play(Write(bl2), FadeIn(cap2), run_time=0.7)

        # —— fade_all_but：按“下标”压暗除某条以外的所有条目 ——
        bl3 = BulletedList("alpha", "beta", "gamma", font_size=40).move_to([-1.6, -1.6, 0])
        win.play(Write(bl3), run_time=0.6)
        bl3.fade_all_but(1, opacity=0.25)   #参数 “index_or_string=1”：只有第 1 条保持原样
        win.play(FadeIn(Text("fade_all_but(1, opacity=0.25)",
                             font_size=18, color=GREY_B).next_to(bl3, DOWN, buff=0.3)),
                 run_time=0.4)
        bl3.fade_all_but(2, opacity=0.25)   #参数换成 2：改成压暗第 0、1 条
        win.play(FadeIn(Text("fade_all_but(2, opacity=0.25)",
                             font_size=18, color=GREY_B).next_to(bl3, DOWN, buff=0.05)),
                 run_time=0.4)
        win.play(Wait(0.5))   #停留看结果
        win.close()   #关闭 RTM 窗口


# ===== 样例 7：Title —— 页眉标题与下划线 ===================================
```

这段代码在做什么：

- 左边是默认参数的列表。
- 右边把 `buff` 收到 0.3 倍、`dot_scale_factor` 放大到 4，条目更紧、点号更大。
- 下面那条演示 `fade_all_but` 的两个下标——先 `1`（只有 `beta` 亮），再 `2`（`alpha`、`beta` 都压暗、只剩 `gamma`）。

> 提醒：`fade_all_but` 只会把**被压暗的**条目改成给定 `opacity`，之前压暗过、这次不在"其余"里的条目**不会自动恢复**（样例第二次调用后 `beta` 仍是暗的）；想逐个恢复就自己按条目 `set_opacity`。

### `Title`

```python
def __init__(self, *text_parts: str, include_underline: bool = True, match_underline_width_to_text: bool = False, underline_buff: float = MED_SMALL_BUFF, **kwargs) -> None:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `*text_parts` | `str...` | 必填 | 标题文本；可以拆成多片（便于分别上色），样例给了单片的四种写法 |
| `include_underline` | `bool` | `True` | 是否画下划线；`False` 就完全没有那条线 |
| `match_underline_width_to_text` | `bool` | `False` | 下划线宽度：`False` 铺满屏幕宽，`True` 只跟文字等宽 |
| `underline_buff` | `float` | `MED_SMALL_BUFF`（0.25） | 下划线与文字的间距；样例给 `0.55` 明显拉开 |

#### 样例：四种组合（默认 / 等宽带 / 无下划线 / 大间距）

```python
import os
import subprocess
import sys
from real_time_manim import (
    Scene, MathTex, BulletedList, Title, Text, Rectangle, VGroup,
    BLUE, GREEN, RED, ORANGE, YELLOW, PURPLE, TEAL, GOLD, GREY_B, WHITE,
    UP, DOWN, LEFT, RIGHT, ORIGIN,
    Create, FadeIn, FadeOut, Write, MED_LARGE_BUFF,
)
from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim.record import fast_record_scene

class TitleDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口

        # —— 默认：自带一条与屏幕等宽的下划线 ——
        t1 = Title("Chapter 1")   #参数 “*text_parts”
        win.play(Write(t1), run_time=0.6)   #默认下划线铺满屏幕宽
        win.play(FadeOut(t1), run_time=0.3)

        # —— match_underline_width_to_text：下划线只跟文字一样宽 ——
        t2 = Title("Chapter 2", match_underline_width_to_text=True)   #参数 “match_underline_width_to_text=True”
        win.play(Write(t2), run_time=0.6)
        win.play(FadeOut(t2), run_time=0.3)

        # —— include_underline=False：完全不要下划线 ——
        t3 = Title("Chapter 3", include_underline=False)   #参数 “include_underline=False”
        win.play(Write(t3), run_time=0.6)
        win.play(FadeOut(t3), run_time=0.3)

        # —— underline_buff：下划线与文字的间距 ——
        t4 = Title("Chapter 4", match_underline_width_to_text=True,
                   underline_buff=0.55)   #参数 “underline_buff=0.55”（默认 MED_SMALL_BUFF）
        win.play(Write(t4), run_time=0.8)   #下划线明显离文字更远
        win.play(Wait(0.5))   #停留看结果
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：四个标题依次出现又淡出。

- 第一个什么都不传，下划线铺满屏幕宽。
- 第二个 `match_underline_width_to_text=True`，下划线只跟文字等宽。
- 第三个 `include_underline=False`，没有下划线。
- 第四个把 `underline_buff` 拉到 0.55，下划线明显与文字拉开距离。
