# 线与箭头（一）：线段、虚线与箭头

"线"与"箭头"是两类基础构件：`Line` 家族（直线、带弧度的线、虚线、切线、直角拐号）和 `Arrow` 家族（单头/双头箭头、向量）。这些类都定义在 `mobject/geometry/line.py`，都能设填充描边样式（见 [VMobject 样式](07-VMobject样式.md)），箭头还能换尖端外形（见[箭头尖端](02b-箭头尖端.md)）。

渲染通道上：

- `Line` / `DashedLine` / `Arrow` 为原生通道（核心类已实渲染验证，2026-10-11）；
- `TangentLine`（`line.py:413`，`Line` 子类）走原生 `_send_line`（`paint.py:996`）；
- `Vector` / `DoubleArrow`（`line.py:714/819`，`Arrow` 子类）走原生 `_send_arrow`（`paint.py:967`，`DoubleArrow` 另有专项 `tests/test_double_arrow.py`）；
- 只有 `Elbow`（`line.py:465`，`VMobject` 直系）落通用回退。

四类均已随两条样例实测出片。

## 参数

### Line、DashedLine、TangentLine（随 `02-线与箭头-lines.mp4`）、Elbow（随 `02-线与箭头-lines.mp4`，通用回退）

```python
def __init__(self, start: Point3DLike | Mobject = [-1, 0, 0],
             end: Point3DLike | Mobject = [1, 0, 0], buff: float = 0,
             path_arc: float = 0, **kwargs: Any) -> None:  # Line

def __init__(self, *args: Any, dash_length: float = 0.05,
             dashed_ratio: float = 0.5, **kwargs: Any) -> None:  # DashedLine

def __init__(self, vmob: VMobject, alpha: float, length: float = 1,
             d_alpha: float = 1e-06, **kwargs: Any) -> None:  # TangentLine

def __init__(self, width: float = 0.2, angle: float = 0,
             **kwargs: Any) -> None:  # Elbow
```

线段与虚线（`DashedLine` 的位置参数与 `Line` 相同）：

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `start` / `end` | `Point3DLike \| Mobject` | `[-1,0,0]` / `[1,0,0]` | 起点/终点；**能填**坐标，也能填 `Mobject`（线自动贴到对象上） |
| `buff` | `float` | `0` | 两端缩进量 |
| `path_arc` | `float` | `0` | 把线段弯成圆弧的角度（弧度）；`0` 是直线，正负控制弯向 |
| `dash_length` | `float` | `0.05` | （`DashedLine`）每小段实线长度 |
| `dashed_ratio` | `float` | `0.5` | （`DashedLine`）一个"实段+空段"周期里**实段占的比例**：`0.5` 实空等长，越接近 1 越连续 |

> **Line / DashedLine 返回**：线对象（`Line` 继承 `VMobject`）。`DashedLine` 0.21 起只有上面两个虚线形参——没有 `num_dashes=`（别照抄旧资料，会一路被 `**kwargs` 吞掉或报错）。

切线与直角：

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `vmob` | `VMobject` | 必填 | （`TangentLine`）被求切线的曲线（任意 `VMobject` 都行） |
| `alpha` | `float` | 必填 | （`TangentLine`）曲线上的位置比例，`0` 起点、`1` 终点，中点取 `0.5` |
| `length` | `float` | `1` | （`TangentLine`）切线段总长 |
| `d_alpha` | `float` | `1e-06` | （`TangentLine`）数值求导步长；**不建议改** |
| `width` | `float` | `0.2` | （`Elbow`）两小段的长度 |
| `angle` | `float` | `0` | （`Elbow`）整体旋转（弧度）；`PI/2` 转 90° 换朝向 |

> **TangentLine / Elbow 返回**：直线段对象。

#### 样例：直的、弯的、虚的、切线与直角

左列自上而下四条线：默认直线、同端点但 `path_arc=0.6` 弯出来的弧线、`dash_length=0.15` 的青色虚线；右上一段圆弧并在其中点挂一条红色切线，右下两个 `Elbow` 分别以 `angle=0` 和 `angle=PI/2` 画出。

```python
from real_time_manim import Scene, Line, DashedLine, TangentLine, Elbow, Arc, Text, \
    BLUE, YELLOW, ORANGE, TEAL, GREEN, RED, GREY_B, UP, DOWN, PI, \
    Create, FadeIn, Write
from real_time_manim.vulkan_bind import MLWindow, Wait

class LinesDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("02-Line / DashedLine / TangentLine / Elbow", font_size=28, color=YELLOW)
        title.to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        # —— Line：起点终点 + path_arc 把“直线”掰弯 ——
        ln = Line([-5.6, 2.2, 0], [0.4, 2.2, 0], stroke_width=6, color=YELLOW)   #默认 path_arc=0：直的
        c1 = Text("Line(start, end)", font_size=22, color=GREY_B).next_to(ln, DOWN, buff=0.15)
        win.play(Create(ln), FadeIn(c1), run_time=0.6)   #画出直线 + 字幕

        ln2 = Line([-5.6, 0.9, 0], [0.4, 0.9, 0], path_arc=0.6, stroke_width=6, color=ORANGE)   #同两端点，path_arc≠0 弯成弧
        c2 = Text("Line(path_arc=0.6)", font_size=22, color=GREY_B).next_to(ln2, DOWN, buff=0.15)
        win.play(Create(ln2), FadeIn(c2), run_time=0.6)   #画出弧线 + 字幕

        # —— DashedLine：dash_length / dashed_ratio ——
        dl = DashedLine([-5.6, -0.7, 0], [0.4, -0.7, 0], dash_length=0.15,
                       dashed_ratio=0.55, color=TEAL, stroke_width=5)   #实段 0.15、实占 0.55
        c3 = Text("DashedLine(dash_length=0.15)", font_size=22, color=GREY_B).next_to(dl, DOWN, buff=0.15)
        win.play(Create(dl), FadeIn(c3), run_time=0.6)   #画出虚线 + 字幕

        # —— TangentLine：曲线在 alpha 处的切线 ——
        arc = Arc(radius=1.0, start_angle=-PI / 3, angle=2 * PI / 3, color=BLUE, stroke_width=6)
        arc.shift([4.6, 1.9, 0])   #右上角放一段圆弧
        tl = TangentLine(arc, 0.5, length=2.4, color=RED, stroke_width=6)   #弧中点（alpha=0.5）处的切线
        c4 = Text("TangentLine(arc, 0.5)", font_size=22, color=GREY_B).move_to([4.6, 0.3, 0])   #切线下方
        win.play(Create(arc), run_time=0.5)   #先画弧
        win.play(Create(tl), FadeIn(c4), run_time=0.6)   #再画切线 + 字幕

        # —— Elbow：直角拐角（angle 转方向）——
        e1 = Elbow(width=0.5, angle=0, color=GREEN, stroke_width=6).shift([3.8, -1.9, 0])   #原始朝向
        e2 = Elbow(width=0.5, angle=PI / 2, color=GREEN, stroke_width=6).shift([5.4, -1.9, 0])   #转 90°
        c5 = Text("Elbow(angle=0 / PI/2)", font_size=22, color=GREY_B).move_to([4.6, -2.9, 0])
        win.play(FadeIn(e1), FadeIn(e2), run_time=0.5)   #两个拐角一起出现
        win.play(FadeIn(c5), run_time=0.3)   #字幕淡入
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：画面分三块。

- 左列三条线共享同一对端点：第一条默认参数（直的黄色线），第二条只加 `path_arc=0.6` 就弯成橙色弧线，第三条 `DashedLine` 用 `dash_length=0.15` 拉出青色虚线。
- 右上先画蓝色圆弧，再在弧的中点（`alpha=0.5`）生成一条 2.4 长的红色切线。
- 右下两个直角拐号一个原朝向、一个转了 90°，直观对比 `angle` 的作用。

<video src="assets/RTM output/02-线与箭头-lines.mp4" controls width="560"></video>

> 提醒：
>
> - `start`/`end` 传 `Mobject` 时线会贴到对象上（做"连接线"很常用）。
> - `path_arc` 的弯向由符号决定，正负各弯一边。
> - `TangentLine` 的 `alpha` 是**曲线参数比例**不是横坐标——曲线绕远时"中点"未必是几何中点。
> - `Elbow` 默认只有 0.2 长，是个小小的拐角记号，不是坐标轴。

### Arrow、Vector（随 `02-线与箭头-arrows.mp4`）、DoubleArrow（随 `02-线与箭头-arrows.mp4`，专项 `tests/test_double_arrow.py`）

```python
def __init__(self, *args: Any, stroke_width: float = 6, buff: float = 0.25,
             max_tip_length_to_length_ratio: float = 0.25,
             max_stroke_width_to_length_ratio: float = 5,
             **kwargs: Any) -> None:  # Arrow

def __init__(self, direction: array-like = RIGHT, buff: float = 0,
             **kwargs: Any) -> None:  # Vector

def __init__(self, *args: Any, **kwargs: Any) -> None:  # DoubleArrow
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `*args` | — | `[-1,0,0]`、`[1,0,0]` | （`Arrow` / `DoubleArrow`）前两个位置参数是 `start`、`end`，即 `Arrow(LEFT*2, RIGHT*2)`；也能传 `Mobject` |
| `stroke_width` | `float` | `6` | 线宽（含箭杆） |
| `buff` | `float` | `0.25` | 两端缩进——注意 `Arrow` 默认 **0.25**（`Line` 是 0），让尖端完整停在端点内 |
| `max_tip_length_to_length_ratio` | `float` | `0.25` | 尖端长/箭长上限；箭越短尖头越自动变小，**不建议手调** |
| `max_stroke_width_to_length_ratio` | `float` | `5` | 线宽/箭长上限，短箭不会变成"胖疙瘩"；**不建议手调** |
| `direction` | `array-like` | `RIGHT` | （`Vector`）从原点指向的方向/终点坐标 |
| `buff` | `float` | `0` | （`Vector`）起点缩进，默认贴着原点出发 |

> **返回**：带箭头尖端的线。常用方法：`Arrow.scale(factor, scale_tips=True)`（缩放时是否同步缩放尖端）、`Arrow.get_normal_vector()`；`Vector.coordinate_label(integer_labels=True, n_dim=2, color=None)` 返回端点坐标的标注（`Matrix`）。`DoubleArrow` 参数与 `Arrow` 完全一致，只是两端都有尖端。

#### 样例：常规箭头、短粗箭头、双头与向量坐标标注

四组箭头：

- 常规长度的蓝色 `Arrow`；
- 又短又粗的红色箭头——`max_*_ratio` 自动把尖端压小、线宽截顶，依然头身协调；
- 紫色 `DoubleArrow` 展示尺寸标注线；
- 下面两个 `Vector`，右边那个用 `coordinate_label()` 在端点旁标出 `(2, 1)`。

```python
from real_time_manim import Scene, Arrow, Vector, DoubleArrow, Text, \
    BLUE, RED, GREEN, TEAL, PURPLE, YELLOW, WHITE, GREY_B, UP, DOWN, UR, \
    Create, FadeIn, Write
from real_time_manim.vulkan_bind import MLWindow, Wait

class ArrowsDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("02-Arrow / Vector / DoubleArrow", font_size=30, color=YELLOW)
        title.to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        # —— Arrow：比例自动控制，短线不会头重脚轻 ——
        a1 = Arrow([-5.6, 2.0, 0], [0.6, 2.0, 0], color=BLUE, buff=0)   #常规长度
        c1 = Text("Arrow(start, end, buff=0)", font_size=22, color=GREY_B).next_to(a1, DOWN, buff=0.15)
        win.play(Create(a1), FadeIn(c1), run_time=0.7)   #画出常规箭头 + 字幕

        a2 = Arrow([-5.6, 0.6, 0], [-2.4, 0.6, 0], color=RED, buff=0, stroke_width=14)   #又短又粗：尖端自动限比例
        c2 = Text("short arrow + stroke_width=14", font_size=22, color=GREY_B).next_to(a2, DOWN, buff=0.15)
        win.play(Create(a2), FadeIn(c2), run_time=0.7)   #画出短粗箭头 + 字幕

        # —— DoubleArrow：两端都有尖端 ——
        da = DoubleArrow([3.4, 2.0, 0], [6.6, 2.0, 0], color=PURPLE, buff=0)   #双头（尺寸标注线，右移给坐标标注让位）
        c3 = Text("DoubleArrow", font_size=22, color=GREY_B).next_to(da, DOWN, buff=0.15)
        win.play(Create(da), FadeIn(c3), run_time=0.7)   #画出双头箭头 + 字幕

        # —— Vector：原点出发 + coordinate_label 标坐标 ——
        v = Vector([2.4, 1.4, 0], color=GREEN).shift([-4.8, -1.7, 0])   #方向向量（从“原点”指向 direction）
        c4 = Text("Vector([2.4, 1.4])", font_size=22, color=GREY_B).move_to([-4.4, -3.0, 0])
        win.play(Create(v), FadeIn(c4), run_time=0.7)   #画出向量 + 字幕

        v2 = Vector([2, 1, 0], color=TEAL)   #放原点：coordinate_label 按端点世界坐标取整
        lab = v2.coordinate_label(color=WHITE).next_to(v2.get_end(), UR, buff=0.2)   #端点旁标 (2, 1)
        c5 = Text("coordinate_label()", font_size=22, color=GREY_B).move_to([1.4, -0.9, 0])
        win.play(Create(v2), run_time=0.5)   #画出向量
        win.play(FadeIn(lab), FadeIn(c5), run_time=0.5)   #坐标标注 + 字幕
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：四组箭头依次出现。

- 第一行蓝色常规箭头（`buff=0` 让尖端贴齐端点）。
- 第二行红色箭头只有 3.2 长却给到 `stroke_width=14`——`max_*_ratio` 自动把尖头缩小、线宽截顶，画出来依然协调。
- 右上紫色 `DoubleArrow` 两端尖头，是标注"两点间距"的标准画法。
- 下方两个 `Vector`，第二个在箭头尖旁用 `coordinate_label()` 摆了一个 `(2, 1)` 坐标标注。

<video src="assets/RTM output/02-线与箭头-arrows.mp4" controls width="560"></video>

> 提醒：
>
> - `Arrow` 的 `buff` 默认 **0.25**（`Line` 是 0），想要箭尖精确顶到端点就显式写 `buff=0`。
> - 两个 `max_*_ratio` 是"防呆"参数——短线粗箭之所以不畸形全靠它们，**不建议**改小。
> - `Vector` 出生在原点、`buff=0`，平移请用 `.shift(...)`；`coordinate_label()` 返回的是普通 `Matrix`，位置要自己 `.next_to(...)` 摆（样例即此写法）。
> - **坑**：`coordinate_label()` 标的是**端点当前的世界坐标**并按 `integer_labels=True` 取整——样例特意把向量放原点，端点正好 `(2,1)`；若先 `.shift(...)` 再标注，标出来的是平移后的坐标（实测本页曾 `shift([2.8,-2.6])` 后标成 `(5, -2)`）。
