# 线与箭头（二）：尖端基类与七种箭头形状

承接[线与箭头（一）](02-线与箭头.md)：`TipableVMobject` 是所有"能装箭头尖端"对象的基类（`Line`/`Arrow`/`Arc`/`Circle` 都继承它）。本页先讲它的三个构造参数与 `add_tip` / `get_tip` 两个方法，再给出七种可换的尖端外形（`mobject/geometry/tips.py`）。

尖端属自定义曲线，走通用 bezier 回退渲染——尖端基类与七种箭头外形已实渲染验证（2026-10-11），本页两条样例已实测出片。

## 参数

### TipableVMobject：tip_length / add_tip / get_tip

```python
def __init__(self, tip_length: float = 0.35,
             normal_vector: Vector3DLike = [0, 0, 1],
             tip_style: dict | None = None, **kwargs: Any) -> None:  # TipableVMobject

def add_tip(self, tip: ArrowTip | None = None,
            tip_shape: type[ArrowTip] | None = None,
            tip_length: float | None = None,
            tip_width: float | None = None,
            at_start: bool = False) -> Self:  # TipableVMobject.add_tip

def get_tip(self) -> VMobject:  # TipableVMobject.get_tip
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `tip_length` | `float` | `0.35` | 尖端长度（构造期给定，`add_tip(tip_length=)` 可覆盖） |
| `normal_vector` | `array-like` | `OUT`（`[0,0,1]`） | 尖端所在平面的法向量；**不建议改** |
| `tip_style` | `dict \| None` | `None` | 尖端样式覆盖字典，一般留 `None` |
| `tip` | `ArrowTip \| None` | `None` | （`add_tip`）直接塞一个**造好的尖端实例**——与 `tip_shape` 二选一 |
| `tip_shape` | `type[ArrowTip] \| None` | `None` | （`add_tip`）传**类本身**（不加括号），如 `ArrowSquareTip` |
| `tip_length` | `float \| None` | `None` | （`add_tip`）覆盖构造期的尖端长度 |
| `tip_width` | `float \| None` | `None` | （`add_tip`）覆盖尖端宽度 |
| `at_start` | `bool` | `False` | `True` = 尖端装到**起点**那头（默认装末端） |

> **返回**：`add_tip(...)` 返回对象自身（可链式、可配合 `.animate`）；`get_tip()` 返回尖端对象——注意**没有参数**（不是 `get_tip(0)`），双尖端时取回末端那个；要一次拿全部用 `get_tips()`（返回顺序 = 装入顺序）。`TipableVMobject` 通常不直接实例化，而是拿 `Line`/`Arc` 等现成对象调它的方法。

#### 样例：给线和弧装尖端、取尖端、换装法

五行演示：

- 第一条是**默认无尖**的光杆线；
- 第二条构造期就给 `tip_length=0.6`，`add_tip()` 装尖后用 `get_tip()` 取回尖端并染黄（证明取到）；
- 第三条 `at_start=True` 尖头装左端；
- 第四条 `tip=` 直接塞现成的方头实例；
- 右侧一段弧，弧尾也装上了尖。

```python
from real_time_manim import Scene, Line, Arc, Text, \
    BLUE, RED, GREEN, TEAL, YELLOW, GREY_B, UP, DOWN, PI, \
    ArrowSquareTip, Create, FadeIn, Write
from real_time_manim.vulkan_bind import MLWindow, Wait

class TipsBaseDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("02b-add_tip / get_tip / tip_length", font_size=30, color=YELLOW)
        title.to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        # —— 线默认没有尖端，add_tip() 现场装 ——
        ln1 = Line([-5.5, 2.0, 0], [0.5, 2.0, 0], color=BLUE, stroke_width=7)   #Line 默认无尖端
        c1 = Text("Line (no tip yet)", font_size=22, color=GREY_B).next_to(ln1, DOWN, buff=0.15)
        win.play(Create(ln1), FadeIn(c1), run_time=0.6)   #画出光杆线 + 字幕

        # —— tip_length 构造期给定；get_tip() 取回尖端对象 ——
        ln2 = Line([-5.5, 0.75, 0], [0.5, 0.75, 0], color=RED, stroke_width=7, tip_length=0.6)   #构造期给 tip_length
        c2 = Text("tip_length=0.6 + add_tip() + get_tip()", font_size=20, color=GREY_B)
        c2.next_to(ln2, DOWN, buff=0.15)   #字幕在下方
        win.play(Create(ln2), run_time=0.5)   #先画光杆
        win.play(ln2.animate.add_tip(), run_time=0.5)   #按 tip_length=0.6 装上尖端
        tip = ln2.get_tip()   #取回刚装上的尖端对象（get_tip 无参数）
        win.play(tip.animate.set_color(YELLOW), FadeIn(c2), run_time=0.4)   #把尖端染黄，证明取到了

        # —— at_start：尖端装在起点那头 ——
        ln3 = Line([-5.5, -0.5, 0], [0.5, -0.5, 0], color=GREEN, stroke_width=7)   #起点在左
        c3 = Text("add_tip(at_start=True)", font_size=22, color=GREY_B).next_to(ln3, DOWN, buff=0.15)
        win.play(Create(ln3), run_time=0.4)   #先画光杆
        win.play(ln3.animate.add_tip(at_start=True), FadeIn(c3), run_time=0.5)   #尖头装到左端

        # —— tip=：直接塞一个造好的尖端实例 ——
        ln4 = Line([-5.5, -1.75, 0], [0.5, -1.75, 0], color=TEAL, stroke_width=7)   #准备装方头
        c4 = Text("add_tip(tip=ArrowSquareTip(...))", font_size=18, color=GREY_B)
        c4.next_to(ln4, DOWN, buff=0.15)   #字幕在下方
        win.play(Create(ln4), run_time=0.4)   #先画光杆
        win.play(ln4.animate.add_tip(tip=ArrowSquareTip(length=0.42)), FadeIn(c4), run_time=0.5)   #装现成的方头实例

        # —— 任意弧也能加尖（弧尾出箭头）——
        arc = Arc(radius=1.1, start_angle=-PI / 4, angle=PI / 2, color=YELLOW, stroke_width=7)
        arc.shift([4.6, 1.0, 0])   #右上一段弧
        c5 = Text("arc.add_tip(tip_length=0.3)", font_size=22, color=GREY_B).move_to([4.6, -0.6, 0])
        win.play(Create(arc), run_time=0.5)   #先画弧
        win.play(arc.animate.add_tip(tip_length=0.3), FadeIn(c5), run_time=0.5)   #弧尾装尖 + 字幕
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：前四条线走完 `add_tip` 的四种玩法。

- 裸线无尖。
- 构造期定长 `0.6` 装尖（`get_tip()` 取出染黄，肉眼可见"取到了"）。
- `at_start=True` 反向装尖。
- `tip=ArrowSquareTip(...)` 装现成实例。

右侧演示"尖端不止属于线"：一段 `Arc` 在弧尾装出带尖的弧，字幕标出 `tip_length=0.3`。

<video src="assets/RTM output/02b-箭头尖端-tips_base.mp4" controls width="560"></video>

> 提醒：
>
> - `get_tip()` **无参数**（老资料若有 `get_tip(0)` 写法是错的），需要全部尖端用 `get_tips()`。
> - `tip=` 传**实例**、`tip_shape=` 传**类**——写 `tip_shape=ArrowSquareTip` 不加括号，写 `tip=ArrowSquareTip(length=0.42)` 才加。
> - 构造期 `tip_length` 与 `add_tip(tip_length=)` 同时出现时以后者为准。
> - `Line` 默认光杆无尖，`Arrow` 才是出厂带尖的——别在 `Line` 上等尖端自己出现。

### 尖端外形七类：tip_shape 可选值

```python
StealthTip(fill_opacity=1, stroke_width=3, length=0.175, start_angle=PI, **kwargs)
ArrowTriangleTip(fill_opacity=0, stroke_width=3, length=0.35, width=0.35, start_angle=PI, **kwargs)
ArrowTriangleFilledTip(fill_opacity=1, stroke_width=0, **kwargs)
ArrowCircleTip(fill_opacity=0, stroke_width=3, length=0.35, start_angle=PI, **kwargs)
ArrowCircleFilledTip(fill_opacity=1, stroke_width=0, **kwargs)
ArrowSquareTip(fill_opacity=0, stroke_width=3, length=0.35, start_angle=PI, **kwargs)
ArrowSquareFilledTip(fill_opacity=1, stroke_width=0, **kwargs)
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `fill_opacity` | `float` | 空心版 `0` / 实心版 `1` | 是否填充；注意 `StealthTip` 默认**就是实心**（`1`） |
| `stroke_width` | `float` | 空心版 `3` / 实心版 `0` | 描边宽度，与填充互补 |
| `length` | `float` | `0.35`（`StealthTip` 为 `0.175`） | 尖端长度；实心版经 `**kwargs` 透传（实测 `ArrowTriangleFilledTip(length=0.5)` 生效） |
| `width` | `float` | `0.35` | 尖端宽度；只有 `ArrowTriangleTip` 显式列出，其余形状是"长宽相等"或由 `**kwargs` 进 |
| `start_angle` | `float` | `PI` | 尖端朝向（弧度）；**不建议改** |

> **返回**：尖端类本身（`ArrowTip` 子类，`ArrowTip` 继承 `VMobject`）。七类两两成对——空心版 `fill_opacity=0 + stroke_width=3`，实心版 `fill_opacity=1 + stroke_width=0`；唯一例外 `StealthTip` 无配对空心版，出厂实心且更短小。

#### 样例：七种尖端逐行对比

七支同参数的蓝色箭头（`buff=0`、`stroke_width=6`），每支只换 `tip_shape=`，右侧竖排类名。注意 `tip_shape` 传的是**类**（不加括号）；`StealthTip` 实心短尖，`Arrow*Tip` 三组各自空心/实心成对。

```python
from real_time_manim import Scene, Arrow, Text, \
    StealthTip, ArrowTriangleTip, ArrowTriangleFilledTip, \
    ArrowCircleTip, ArrowCircleFilledTip, ArrowSquareTip, ArrowSquareFilledTip, \
    YELLOW, GREY_B, UP, RIGHT, Create, FadeIn, Write
from real_time_manim.vulkan_bind import MLWindow, Wait

class TipShapesDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("02b-7 tip shapes (tip_shape=...)", font_size=30, color=YELLOW)
        title.to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        names = ["StealthTip", "ArrowTriangleTip", "ArrowTriangleFilledTip",
                 "ArrowCircleTip", "ArrowCircleFilledTip",
                 "ArrowSquareTip", "ArrowSquareFilledTip"]   #七种尖端类名
        shapes = [StealthTip, ArrowTriangleTip, ArrowTriangleFilledTip,
                  ArrowCircleTip, ArrowCircleFilledTip,
                  ArrowSquareTip, ArrowSquareFilledTip]   #七种类本身（传类不传实例）
        ys = [2.6, 1.7, 0.8, -0.1, -1.0, -1.9, -2.8]   #七行的纵坐标
        for name, shape, y in zip(names, shapes, ys):   #逐行画：箭头 + 右侧类名
            a = Arrow([-5.2, y, 0], [2.2, y, 0], buff=0, stroke_width=6,
                      tip_shape=shape)   #tip_shape 传“类”，不加括号
            lab = Text(name, font_size=22, color=GREY_B).next_to(a, RIGHT, buff=0.3)
            win.play(Create(a), FadeIn(lab), run_time=0.45)   #画箭头 + 类名字幕
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：用 `zip` 把类名、类、纵坐标三张表对齐，循环画七行——每行一支同参数蓝箭头，唯一变量是 `tip_shape=`，右侧贴出类名。一眼可比：`StealthTip` 实心且尖最短；三角/圆/方三组各自空心（细描边）在上、实心（填满）在下。

<video src="assets/RTM output/02b-箭头尖端-tip_shapes.mp4" controls width="560"></video>

> 提醒：`tip_shape=` 收的是**类不是实例**——写成 `tip_shape=ArrowSquareTip()`（加了括号）应改用 `tip=ArrowSquareTip(...)`。想让 `Arrow` 默认尖端换成某形状，直接 `Arrow(..., tip_shape=...)` 即可（本样例正是此写法）；批量换风格时把 `tip_shape` 存进变量传递最省事。
