# 表格方法

[表格](14-表格.md) 的四个实例方法：给单元格加高亮块、取出单元格、取"已高亮好"的背景块、以及表格自己的编排出场动画。每个方法各一条样例。

> **位置 `pos` 是 `(行, 列)`，1 起算**：`(1, 1)` 是左上角单元格——和 Python 下标不同（下标从 0 开始），四个方法统一用这套坐标。

## 参数

### `Table.add_highlighted_cell` 

```python
def add_highlighted_cell(self, pos: Sequence[int] = (1, 1), color: ParsableManimColor = YELLOW, **kwargs) -> Self:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `pos` | `Sequence[int]` | `(1, 1)` | 单元格位置 `(行, 列)`，1 起算；样例 `(1, 2)` 与 `(2, 1)` 各加一个 |
| `color` | `ManimColor` | `YELLOW` | 高亮块颜色；样例 `YELLOW` / `BLUE` |
| `**kwargs` | `Any` | — | 继续传给背景块（`BackgroundRectangle`）；样例 `fill_opacity=0.4` |

就地给表格加一块**背景高亮**并返回表格自身（可链式），高亮块随后跟着表格一起变换。

#### 样例：两个单元格、两种颜色、加 `fill_opacity`

```python
import os
import subprocess
import sys
from real_time_manim import (
    Scene, Table, Text, Rectangle, VGroup,
    BLUE, GREEN, RED, ORANGE, YELLOW, PURPLE, TEAL, GREY_B, WHITE,
    UP, DOWN, LEFT, RIGHT,
    Create, FadeIn, FadeOut, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim.record import fast_record_scene

class HighlightDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("14b-add_highlighted_cell", font_size=30, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.4)   #写出标题

        t = Table([["a", "b"], ["c", "d"]], include_outer_lines=True,
                  element_to_mobject=Text, element_to_mobject_config={"font_size": 34})
        t.scale(0.9).move_to([0, 0.6, 0])
        win.play(Write(t), FadeIn(cap("Table([[a,b],[c,d]])", t)), run_time=0.7)

        # —— pos 用 (行, 列) 定位（1 起算），color 是高亮块颜色 ——
        t.add_highlighted_cell((1, 2), color=YELLOW)   #参数 “pos / color”
        win.play(Write(t), run_time=0.5)
        c1 = Text("add_highlighted_cell((1, 2), YELLOW)",
                  font_size=18, color=GREY_B).move_to([0, -1.5, 0])
        win.play(FadeIn(c1), run_time=0.4)

        # —— **kwargs 继续传给背景块（如 fill_opacity）——
        t.add_highlighted_cell((2, 1), color=BLUE, fill_opacity=0.4)   #参数 “**kwargs”
        win.play(Write(t), run_time=0.5)
        newc = Text("add_highlighted_cell((2, 1), BLUE, fill_opacity=0.4)",
                    font_size=18, color=GREY_B).move_to([0, -2.1, 0])
        win.play(FadeIn(newc), run_time=0.4)
        win.play(Wait(0.4))   #停留看结果
        win.close()   #关闭 RTM 窗口


# ===== 样例 2：get_cell / get_highlighted_cell —— 取出单元格 ===============
```

这段代码在做什么：先摆一张 2×2 表，然后 `add_highlighted_cell((1, 2), color=YELLOW)` 高亮右上格。接着 `add_highlighted_cell((2, 1), color=BLUE, fill_opacity=0.4)` 高亮左下格并让它半透明——`**kwargs` 直接落到背景块上。

<video src="assets/RTM output/14b-表格方法-highlight.mp4" controls width="560"></video>

> 提醒：高亮块是**表格的子对象**，所以之后对表格做 `scale`/`shift`/`set_row_colors`，高亮块会跟着走；重复对同一格调用会叠出新的背景块（不会替换旧的）。

### `Table.get_cell` 

```python
def get_cell(self, pos: Sequence[int] = (1, 1), **kwargs) -> Polygon:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `pos` | `Sequence[int]` | `(1, 1)` | 单元格位置 `(行, 列)`，1 起算；样例 `(1, 2)` |
| `**kwargs` | `Any` | — | 传给返回的 `Polygon`（如 `color=`、`fill_opacity=`） |

返回该单元格的**多边形**（`Polygon`），可以单独上色、做动画——适合"只高亮这一格的边框/填充"。

#### 样例：取出单元格并单独上色

```python
import os
import subprocess
import sys
from real_time_manim import (
    Scene, Table, Text, Rectangle, VGroup,
    BLUE, GREEN, RED, ORANGE, YELLOW, PURPLE, TEAL, GREY_B, WHITE,
    UP, DOWN, LEFT, RIGHT,
    Create, FadeIn, FadeOut, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim.record import fast_record_scene

class GetCellDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("14b-get_cell / get_highlighted_cell", font_size=30, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.4)   #写出标题

        t = Table([["1", "2"], ["3", "4"]], include_outer_lines=True,
                  element_to_mobject=Text, element_to_mobject_config={"font_size": 34})
        t.scale(0.9).move_to([0, 0.6, 0])
        win.play(Write(t), FadeIn(cap("Table([[1,2],[3,4]])", t)), run_time=0.7)

        # —— get_cell：拿到单元格多边形，可以单独改样式 ——
        cell = t.get_cell((1, 2))   #参数 “pos”
        win.play(cell.animate.set_fill(RED, 0.45), run_time=0.6)
        c1 = Text("get_cell((1, 2)) -> Polygon",
                  font_size=18, color=GREY_B).move_to([0, -1.5, 0])
        win.play(FadeIn(c1), run_time=0.4)

        # —— get_highlighted_cell：直接拿到“已高亮好”的背景块 ——
        hl = t.get_highlighted_cell((2, 2), color=TEAL)   #参数 “pos / color”
        win.play(FadeIn(hl), run_time=0.5)
        newc = Text("get_highlighted_cell((2, 2), TEAL)",
                    font_size=18, color=GREY_B).move_to([0, -2.1, 0])
        win.play(FadeIn(newc), run_time=0.4)
        win.play(Wait(0.4))   #停留看结果
        win.close()   #关闭 RTM 窗口


# ===== 样例 3：create —— 表格的编排出场动画 ================================
```

这段代码在做什么：建一张 2×2 表，`cell = t.get_cell((1, 2))` 取出右上格的多边形，`cell.animate.set_fill(RED, 0.45)` 只给这一格刷红底。接着 `get_highlighted_cell((2, 2), TEAL)` 直接拿到右下格的背景块并淡入。

<video src="assets/RTM output/14b-表格方法-getcell.mp4" controls width="560"></video>

> 提醒：`get_cell` 返回的是**格子多边形**（描边可见），和 `get_highlighted_cell` 的**背景矩形**不是一回事；想要"有底色的格子"用后者更省事（自带 `BackgroundRectangle` 的 `buff`/`fill_opacity` 处理）。

### `Table.get_highlighted_cell` 

```python
def get_highlighted_cell(self, pos: Sequence[int] = (1, 1), color: ParsableManimColor = YELLOW, **kwargs) -> BackgroundRectangle:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `pos` | `Sequence[int]` | `(1, 1)` | 单元格位置 `(行, 列)`，1 起算；样例 `(2, 2)` |
| `color` | `ManimColor` | `YELLOW` | 背景块颜色；样例 `TEAL` |
| `**kwargs` | `Any` | — | 传给 `BackgroundRectangle`（如 `fill_opacity=`、`buff=`） |

返回**背景矩形**对象（不自带"加入表格"，要自己 `FadeIn`/`add`），适合先拿到再决定什么时候显示。

这段代码在做什么：与上一条同一个场景的后半段——`hl = t.get_highlighted_cell((2, 2), color=TEAL)` 拿到右下格的背景块，再 `win.play(FadeIn(hl))` 让它出现。因为返回的是普通 mobject，也可以先 `hl.set_opacity(0)`，之后再动画。

> 提醒：它返回的对象**没有**自动加进表格——想让高亮跟着表格变换，就 `t.add(hl)`；只是临时显示则直接 `FadeIn` 即可。

### `Table.create` 

```python
def create(self, lag_ratio: float = 1, line_animation: Callable[[VMobject | VGroup], Animation] = Create, label_animation: Callable[[VMobject | VGroup], Animation] = Write, element_animation: Callable[[VMobject | VGroup], Animation] = Create, entry_animation: Callable[[VMobject | VGroup], Animation] = FadeIn, **kwargs) -> AnimationGroup:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `lag_ratio` | `float` | `1` | 各组（线 / 标签 / 单元格）之间的错峰比例；样例 `0.15` 让它们几乎同时出现 |
| `line_animation` | `类` | `Create` | 网格线的出场动画；样例换成 `Write` |
| `label_animation` | `类` | `Write` | 行列标签的出场动画 |
| `element_animation` | `类` | `Create` | 单元格内容的出场动画 |
| `entry_animation` | `类` | `FadeIn` | 整格条目的动画 |
| `**kwargs` | `Any` | — | 传给内部 `AnimationGroup`（如 `run_time=`） |

返回一个 **`AnimationGroup`**，直接交给 `win.play(...)` 播放——比 `Create(table)` 更有"先出线、再写字"的层次感。

#### 样例：默认 `create()` 与 `create(lag_ratio=0.15, line_animation=Write)`

```python
import os
import subprocess
import sys
from real_time_manim import (
    Scene, Table, Text, Rectangle, VGroup,
    BLUE, GREEN, RED, ORANGE, YELLOW, PURPLE, TEAL, GREY_B, WHITE,
    UP, DOWN, LEFT, RIGHT,
    Create, FadeIn, FadeOut, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim.record import fast_record_scene

class CreateDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("14b-Table.create", font_size=30, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.4)   #写出标题

        # —— 默认 create()：线 Create、标签 Write、元素 Create、条目 FadeIn ——
        t1 = Table([["a", "b"], ["c", "d"]], include_outer_lines=True,
                   element_to_mobject=Text, element_to_mobject_config={"font_size": 32})
        t1.scale(0.8).move_to([0, 0.8, 0])
        win.play(t1.create(), FadeIn(cap("create()（默认动画）", t1)), run_time=1.2)

        # —— lag_ratio / line_animation / label_animation 可替换 ——
        t2 = Table([["1", "2"], ["3", "4"]], include_outer_lines=True,
                   element_to_mobject=Text, element_to_mobject_config={"font_size": 32})
        t2.scale(0.8).move_to([0, -1.8, 0])
        win.play(FadeOut(t1),
                 t2.create(lag_ratio=0.15, line_animation=Write),   #参数 “lag_ratio / line_animation”
                 FadeIn(cap("create(lag_ratio=0.15, line_animation=Write)", t2)), run_time=1.2)
        win.play(Wait(0.5))   #停留看结果
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：第一张表直接 `win.play(t1.create())`，看默认的"线 → 标签 → 单元格"顺序。第二张表换成 `t2.create(lag_ratio=0.15, line_animation=Write)`——`lag_ratio` 调小后各组几乎同时开始，线改成 `Write` 的书写感，两者对比很明显。

<video src="assets/RTM output/14b-表格方法-create.mp4" controls width="560"></video>

> 提醒：`create()` 返回的是**动画组**，不是表格本身——表格对象仍然要先建好（`win.play` 之前不要把表格 `add` 进场景，否则会出现两遍）。
