# 角度与标注框（二）：带标签的标注

带标签的线/多边形定义在 `mobject/geometry/labeled.py`，都基于 `Label`（"文本 + 背景框 + 外框"的三层组合）。每个类各一条样例，样例里把该类**全部可填参数**各改一次。

> **配置 dictionary 只在标签是字符串时生效**：`label_config` / `box_config` / `frame_config` 只在 `label` 为 `str` 时被使用（字符串会用 `MathTex` 渲染）；直接传现成的 `Text`/`MathTex` 对象时这三个字典会被忽略，样式以对象自身为准（样例第一条就演示了这一点）。

## 参数

### `Label`

```python
def __init__(self, label: str | ManimTextLabel, label_config: dict | None = None, box_config: dict | None = None, frame_config: dict | None = None, **kwargs) -> None:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `label` | `str \| MathTex \| Text \| Typst` | 必填 | 标签内容；**字符串**会用 `MathTex` 渲染（此时下面三个字典才生效），也可以直接传现成对象 |
| `label_config` | `dict \| None` | `None` | 传给标签的配置（仅字符串生效；默认 `color=WHITE`、`font_size=48`），如 `{"color": RED, "font_size": 72}` |
| `box_config` | `dict \| None` | `None` | 传给背景框的配置，如 `{"color": TEAL, "fill_opacity": 0.8}` |
| `frame_config` | `dict \| None` | `None` | 传给外框的配置，如 `{"color": ORANGE, "stroke_width": 6}` |

返回 `VGroup`（外框 + 背景框 + 文本三层），可以整体 `.scale()`、`.move_to()`。

#### 样例：默认 / 三个字典各改一次 / 传现成对象

```python
import os
import subprocess
import sys
from real_time_manim import (
    Scene, Label, LabeledLine, LabeledArrow, LabeledPolygram,
    Line, Arrow, Polygon, Triangle, Square, Text,
    BLUE, GREEN, RED, ORANGE, YELLOW, PURPLE, TEAL, GOLD, GREY_B, WHITE,
    UP, DOWN, LEFT, RIGHT, ORIGIN,
    Create, FadeIn, FadeOut, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim.record import fast_record_scene

class LabelDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("04b-Label", font_size=30, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        # —— 默认：白字 + 默认背景框 ——
        l1 = Label("x")   #参数 “label”：字符串用 MathTex 渲染
        l1.move_to([-4.2, 1.2, 0])
        cap1 = Text('Label("x")', font_size=18, color=GREY_B).next_to(l1, DOWN, buff=0.3)
        win.play(FadeIn(l1), FadeIn(cap1), run_time=0.5)

        # —— label_config：只对字符串标签生效（颜色 / 字号）——
        l2 = Label("y", label_config={"color": RED, "font_size": 72})   #参数 “label_config”
        l2.move_to([-0.6, 1.2, 0])
        cap2 = Text('label_config={"color": RED, "font_size": 72}', font_size=18, color=GREY_B).next_to(l2, DOWN, buff=0.3)
        win.play(FadeIn(l2), FadeIn(cap2), run_time=0.5)

        # —— box_config：背景框的颜色与不透明度 ——
        l3 = Label("z", box_config={"color": TEAL, "fill_opacity": 0.8})   #参数 “box_config”
        l3.move_to([3.0, 1.2, 0])
        cap3 = Text('box_config={"color": TEAL, "fill_opacity": 0.8}', font_size=18, color=GREY_B).next_to(l3, DOWN, buff=0.3)
        win.play(FadeIn(l3), FadeIn(cap3), run_time=0.5)

        # —— frame_config：外框的颜色与线宽 ——
        l4 = Label("w", frame_config={"color": ORANGE, "stroke_width": 6})   #参数 “frame_config”
        l4.move_to([-4.2, -1.0, 0])
        cap4 = Text('frame_config={"color": ORANGE, "stroke_width": 6}', font_size=18, color=GREY_B).next_to(l4, DOWN, buff=0.3)
        win.play(FadeIn(l4), FadeIn(cap4), run_time=0.5)

        # —— label 不是字符串时不读 *_config：直接拿现成 mobject 当标签 ——
        l5 = Label(Text("hi", color=YELLOW, font_size=40),
                   label_config={"color": RED})   #参数 “label” 给 Mobject：config 被忽略
        l5.move_to([-0.6, -1.0, 0])
        cap5 = Text("Label(Text(...))  config 被忽略", font_size=18, color=GREY_B).next_to(l5, DOWN, buff=0.3)
        win.play(FadeIn(l5), FadeIn(cap5), run_time=0.5)
        win.play(Wait(0.4))   #停留看结果
        win.close()   #关闭 RTM 窗口


# ===== 样例 2：LabeledLine —— 线上带标签 ===================================
```

这段代码在做什么：第一块是默认样式。接着三块分别只改一个字典，每块下面标着这次改的是哪个参数：

- `label_config`（红字、72 号）；
- `box_config`（青色半透明底）；
- `frame_config`（橙色粗外框）。

最后一块把 `Text` 直接当标签传进去，同时照样给 `label_config={"color": RED}`，但屏幕上的字仍是 `Text` 自己的黄色小字——说明字典只对字符串标签生效。

> 提醒：想给现成 `Text`/`MathTex` 改样式，就在那个对象上设置（`Text("hi", color=YELLOW)`），别指望 `label_config`。

### `LabeledLine`

```python
def __init__(self, label: str | ManimTextLabel, label_position: float = 0.5, label_config: dict | None = None, box_config: dict | None = None, frame_config: dict | None = None, *args, **kwargs) -> None:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `label` | `str \| MathTex \| Text \| Typst` | 必填 | 线上的标签（字符串用 `MathTex` 渲染） |
| `label_position` | `float` | `0.5` | 标签在线上的位置比例（0 起点 ~ 1 终点）；样例 0.2 / 0.5 / 0.8 依次对比 |
| `label_config` | `dict \| None` | `None` | 标签配置（仅对字符串标签生效） |
| `box_config` | `dict \| None` | `None` | 背景框配置 |
| `frame_config` | `dict \| None` | `None` | 边框配置 |
| `*args` / `**kwargs` | — | — | **`start`/`end` 必须写成关键字**（`LabeledLine("3cm", start=..., end=...)`）：签名前 5 个位置参数先被 `label` / `label_position` / `label_config` / `box_config` / `frame_config` 吃掉，按位置传第 2~6 个参数会全部错位（撞 manim 上游 bug，98-功能清单 §5.2 已注明） |

#### 样例：三个 `label_position` + 三件套配置 + 现成对象标签

```python
import os
import subprocess
import sys
from real_time_manim import (
    Scene, Label, LabeledLine, LabeledArrow, LabeledPolygram,
    Line, Arrow, Polygon, Triangle, Square, Text,
    BLUE, GREEN, RED, ORANGE, YELLOW, PURPLE, TEAL, GOLD, GREY_B, WHITE,
    UP, DOWN, LEFT, RIGHT, ORIGIN,
    Create, FadeIn, FadeOut, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim.record import fast_record_scene

class LabeledLineDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("04b-LabeledLine", font_size=30, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        # —— label_position：标签在线上的位置比例（0 起点 ~ 1 终点）——
        for i, pos in enumerate([0.2, 0.5, 0.8]):   #参数 “label_position”
            ln = LabeledLine("3cm", start=[-4.4, 1.5 - i * 1.5, 0], end=[-0.4, 1.5 - i * 1.5, 0],
                             label_position=pos)   #参数 “start / end 必须用关键字”
            cap = Text("label_position=%.1f" % pos, font_size=18, color=GREY_B).next_to(ln, RIGHT, buff=0.4)
            win.play(Create(ln), FadeIn(cap), run_time=0.5)   #标签沿线滑动

        # —— label_config / box_config / frame_config 三件套 ——
        ln2 = LabeledLine("L", start=[1.6, 0.4, 0], end=[5.4, 0.4, 0],
                          label_config={"color": RED, "font_size": 64},
                          box_config={"color": TEAL, "fill_opacity": 0.8},
                          frame_config={"color": ORANGE, "stroke_width": 5})
        cap2 = Text("label/box/frame_config", font_size=18, color=GREY_B).next_to(ln2, DOWN, buff=0.4)
        win.play(Create(ln2), FadeIn(cap2), run_time=0.6)

        # —— 同一根线也能给现成 mobject 当标签 ——
        ln3 = LabeledLine(Text("Tetra", color=YELLOW, font_size=32),
                          start=[1.6, -1.4, 0], end=[5.4, -1.4, 0], label_position=0.35)
        cap3 = Text("label=Text(...)  label_position=0.35", font_size=18, color=GREY_B).next_to(ln3, DOWN, buff=0.4)
        win.play(Create(ln3), FadeIn(cap3), run_time=0.6)
        win.play(Wait(0.4))   #停留看结果
        win.close()   #关闭 RTM 窗口


# ===== 样例 3：LabeledArrow —— 箭头版 ======================================
```

这段代码在做什么：画面分左右两块。

- 左边三根同样的线，`label_position` 依次给 0.2 / 0.5 / 0.8，标签沿着线从左往右滑动。
- 右边上面那根把 `label_config` / `box_config` / `frame_config` 一起给了（红字、青色底、橙色框）。
- 下面那根把 `Text` 当标签传进去并把 `label_position` 设成 0.35。

<video src="assets/RTM output/04b-带标签标注-labeledline.mp4" controls width="560"></video>

> 提醒：`label_position=0` / `1` 时标签正好压在端点上（画线时要给端点留白）；`start`/`end` 之外的颜色、线宽等参数继续用关键字传给底层 `Line`。

### `LabeledArrow`

```python
def __init__(self, *args, **kwargs) -> None:   # 转发给 LabeledLine / Arrow，签名同 LabeledLine
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `label` / `label_position` / `label_config` / `box_config` / `frame_config` | — | 同 `LabeledLine` | 与 `LabeledLine` 完全同一套参数 |
| `start` / `end` | `array-like` | 必填 | 同样**必须用关键字** |
| `**kwargs` | — | — | 其余参数继续传给 `Arrow`（样例给了 `color=GOLD`） |

```python
# ===== 样例 4：LabeledPolygram —— 多边形内部自动找位置 =====================
```

这段代码在做什么：上面两根金色箭头只差 `label_position`（0.2 / 0.6）；下面那根把三件套配置全给上——红字、紫色底、黄色外框——证明它和 `LabeledLine` 是同一套配置接口，只是形状换成箭头。

<video src="assets/RTM output/04b-带标签标注-labeledarrow.mp4" controls width="560"></video>

> 提醒：箭头头部的宽度会占用线的长度，所以同样 `label_position` 下标签看起来比线段版更靠前一点；要精确控制就把 `label_position` 当"比例"理解，别当百分比刻度。

### `LabeledPolygram`

```python
def __init__(self, *vertex_groups: Point3DLike_Array, label: str | ManimTextLabel, precision: float = 0.01, label_config: dict | None = None, box_config: dict | None = None, frame_config: dict | None = None, **kwargs) -> None:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `*vertex_groups` | `array-like...` | 必填 | **每个顶点组必须是一整圈顶点**：`LabeledPolygram([v1, v2, v3], label=...)`。把三个点当成三个位置参数传（`LabeledPolygram(v1, v2, v3, ...)`）会抛 `IndexError: too many indices for array: array is 1-dimensional, but 2 were indexed`（实测两引擎一致）；开口环会自动闭合 |
| `label` | `str \| Mobject` | 必填 | 放在多边形"最内点"（pole of inaccessibility）处的标签 |
| `precision` | `float` | `0.01` | PolyLabel 算法精度，**要与图形尺度匹配**：图形跨几个单位时默认值够用，图形跨上万单位就要放大到 1~10（样例用 0.5 对比） |
| `label_config` | `dict \| None` | `None` | 标签配置 |
| `box_config` | `dict \| None` | `None` | 背景框配置 |
| `frame_config` | `dict \| None` | `None` | 边框配置 |

它只放**一个**标签：多个顶点组一起传时，PolyLabel 在所有环里找面积最大的那块放标签，不是每个环一个。

#### 样例：单环 / `precision` / 双环 / 三件套

```python
import os
import subprocess
import sys
from real_time_manim import (
    Scene, Label, LabeledLine, LabeledArrow, LabeledPolygram,
    Line, Arrow, Polygon, Triangle, Square, Text,
    BLUE, GREEN, RED, ORANGE, YELLOW, PURPLE, TEAL, GOLD, GREY_B, WHITE,
    UP, DOWN, LEFT, RIGHT, ORIGIN,
    Create, FadeIn, FadeOut, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim.record import fast_record_scene

class LabeledPolygramDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("04b-LabeledPolygram", font_size=30, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        # —— 一个顶点组（一组闭合环）：标签自动落在多边形内部最“宽敞”的位置 ——
        ring = [[-5.4, -0.4, 0], [-3.4, -0.4, 0], [-4.4, 1.6, 0]]   #参数 “*vertex_groups”：每组是一圈顶点
        tri = LabeledPolygram(ring, label="A", color=TEAL)   #参数 “label”
        win.play(Create(tri), FadeIn(Text("one ring, label=\"A\"", font_size=18, color=GREY_B).next_to(tri, DOWN, buff=0.35)),
                 run_time=0.6)

        # —— precision：PolyLabel 算法的搜索精度，要与图形尺度匹配 ——
        square = [[-1.8, -0.6, 0], [1.4, -0.6, 0], [1.4, 1.6, 0], [-1.8, 1.6, 0]]
        big = LabeledPolygram(square, label="B", precision=0.5, color=GREEN)   #参数 “precision=0.5”
        win.play(Create(big), FadeIn(Text("precision=0.5", font_size=18, color=GREY_B).next_to(big, DOWN, buff=0.35)),
                 run_time=0.6)

        # —— 多个顶点组：每个环各自闭合，标签落在最大的那块里 ——
        two = LabeledPolygram([[3.2, 0.2, 0], [5.6, 0.2, 0], [4.4, 1.8, 0]],   #第一圈：大三角
                              [[6.0, 0.2, 0], [6.8, 0.2, 0], [6.4, 0.8, 0]],   #第二圈：小三角
                              label="2x", color=ORANGE)   #参数 “*vertex_groups”：两组环
        win.play(Create(two), FadeIn(Text("two rings, label=\"2x\"", font_size=18, color=GREY_B).next_to(two, DOWN, buff=0.35)),
                 run_time=0.6)

        # —— 标签配置三件套：label_config / box_config / frame_config ——
        poly = LabeledPolygram([[-5.4, -2.6, 0], [-3.4, -2.6, 0], [-4.4, -1.0, 0]],
                               label="C",
                               label_config={"color": RED, "font_size": 60},
                               box_config={"color": TEAL, "fill_opacity": 0.8},
                               frame_config={"color": ORANGE, "stroke_width": 5})
        win.play(Create(poly), FadeIn(Text("label/box/frame_config", font_size=18, color=GREY_B).next_to(poly, DOWN, buff=0.35)),
                 run_time=0.6)
        win.play(Wait(0.5))   #停留看结果
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：四块对比。

- 左边一个三角形只给一圈顶点（标签自动落在内部最宽敞处）。
- 中上那个正方形把 `precision` 放到 0.5。
- 右上把**两整圈**顶点一起传（大三角 + 小三角），标签落在大的那块里。
- 左下第四个三角形把三件套配置全给上——红字、青色底、橙色外框。

<video src="assets/RTM output/04b-带标签标注-labeledpoly.mp4" controls width="560"></video>

> 提醒：顶点组要按"一圈"给，跨环的坐标别混在同一个列表里；`precision` 给得比图形尺度还大时搜索会变粗、标签位置可能偏，按提示"精度对应尺度"取最稳。
