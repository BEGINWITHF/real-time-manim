# 多边形与星形（一）：Polygram 家族

本节类定义在 `mobject/geometry/polygram.py`，都继承 `Polygram` → `VMobject`：手画多边形、规则多边形、星形与万能圆角方法。`Polygram` / `Polygon` / `Triangle` 走原生通道；`Star(Polygon)`（`polygram.py:465`）同样是多边形，走**原生** `_send_polygon`（`paint.py:1036`），专项断言见 `tests/test_polygram_groups.py:195`（"一个 `Star` 就是一组 10 个顶点"），不再是"通用 bezier 回退"；`RegularPolygram` / `RegularPolygon` / `round_corners` 随本页样例出图。本页两条样例（`polygons` / `stars_round`）已于 2026-10-17 出图并（`frames>4.0` 均为 0）。

## 参数

### Polygram、Polygon、RegularPolygon（随本页样例）、Triangle

```python
def __init__(self, *vertex_groups: ArrayLike, color: ManimColor = BLUE,
             **kwargs: Any) -> None:  # Polygram

def __init__(self, *vertices: ArrayLike, **kwargs: Any) -> None:  # Polygon

def __init__(self, n: int = 6, **kwargs: Any) -> None:  # RegularPolygon

def __init__(self, **kwargs: Any) -> None:  # Triangle
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `*vertex_groups` | `array-like...` | 必填 | （`Polygram`）**每个位置参数 = 一组顶点**，每组本身是点列表：写 `Polygram([p1, p2, p3, p4])`；若把单点当参数直传（`Polygram(p1, p2, ...)`）会 `IndexError`（实测） |
| `color` | `ManimColor` | `BLUE` | 颜色（默认蓝，样例都显式换了色） |
| `*vertices` | `array-like...` | 必填 | （`Polygon`）各顶点坐标，按顺序连线后**自动闭合**；`[x, y]` 省略 z 自动补 0 |
| `n` | `int` | `6` | （`RegularPolygon`）边数；**能填** ≥3 的整数 |
| `radius` | `float` | `1` | （继承）外接圆半径，`RegularPolygon`/`Triangle` 通用 |
| `start_angle` | `float \| None` | `None` | （继承）起始角，`None` 按形状自动取 |

> **返回**：闭合多边形对象。常用方法：`get_vertices()` 返回全部顶点数组（样例 2 用它摆顶点圆点）；`round_corners(...)` 见第二小节。`Triangle` ≡ `RegularPolygon(n=3)` 的特化，只是省了写 `n`。

#### 样例：乱序蝴蝶结、不规则四边形、等边三角与 n 边数

上排三形：`Polygram` 四顶点故意按"左上→右下→右上→左下"穿插，连线**自交**成蝴蝶结（顺序决定形状）；`Polygon` 四顶点常规顺序得填充四边形；`Triangle()` 等边三角。下排 `RegularPolygon` 只改 `n`，画出 n=4 / 6 / 8 三件套。

```python
from real_time_manim import Scene, Polygram, Polygon, RegularPolygon, Triangle, Text, \
    TEAL, GREEN, PURPLE, ORANGE, BLUE, YELLOW, GREY_B, UP, DOWN, \
    Create, FadeIn, Write
from real_time_manim.vulkan_bind import MLWindow, Wait

class PolygonsDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("03-Polygram / Polygon / RegularPolygon / Triangle", font_size=26, color=YELLOW)
        title.to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        # —— Polygram：一组顶点=一个位置参数，顺序乱穿可自交 ——
        pb = Polygram([[-5.6, 2.0, 0], [-2.6, 0.8, 0], [-3.6, 2.0, 0], [-4.6, 0.8, 0]],
                      color=TEAL, stroke_width=5)   #顶点按“左上→右下→右上→左下”穿插
        cap1 = Text("Polygram (crossed order)", font_size=20, color=GREY_B).move_to([-4.6, 0.4, 0])
        win.play(Create(pb), FadeIn(cap1), run_time=0.7)   #画出蝴蝶结形 + 字幕

        # —— Polygon：按顶点顺序连线闭合、可填充 ——
        pg = Polygon([-1.6, 2.0, 0], [1.6, 2.0, 0], [0.9, 0.7, 0], [-0.7, 0.7, 0],
                     color=GREEN, fill_opacity=0.55, stroke_width=5)   #四顶点不规则四边形
        cap2 = Text("Polygon(*vertices)", font_size=20, color=GREY_B).move_to([0, 0.4, 0])
        win.play(Create(pg), FadeIn(cap2), run_time=0.7)   #画出四边形 + 字幕

        # —— Triangle：等边三角形（n=3 特化）——
        tri = Triangle(radius=1.2, color=BLUE, fill_opacity=0.55).shift([4.6, 1.5, 0])   #等边三角
        cap3 = Text("Triangle()", font_size=20, color=GREY_B).move_to([4.6, 0.4, 0])
        win.play(Create(tri), FadeIn(cap3), run_time=0.6)   #画出三角形 + 字幕

        # —— RegularPolygon：n 边数一变形状即变 ——
        r4 = RegularPolygon(n=4, radius=1.1, color=PURPLE, fill_opacity=0.55).shift([-4.6, -1.5, 0])   #n=4
        r6 = RegularPolygon(n=6, radius=1.1, color=ORANGE, fill_opacity=0.55).shift([0, -1.5, 0])   #n=6
        r8 = RegularPolygon(n=8, radius=1.1, color=BLUE, fill_opacity=0.55).shift([4.6, -1.5, 0])   #n=8
        cap4 = Text("RegularPolygon(n=4 / 6 / 8)", font_size=22, color=GREY_B).move_to([0, -2.8, 0])
        win.play(Create(r4), run_time=0.45)   #画 n=4
        win.play(Create(r6), run_time=0.45)   #画 n=6
        win.play(Create(r8), FadeIn(cap4), run_time=0.45)   #画 n=8 + 字幕
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：左上是"同样的四个点、换个书写顺序就自交"的蝴蝶结 `Polygram`；中上绿色 `Polygon` 按顺序给四个点连线闭合再填充；右上 `Triangle()` 直接出等边三角。下排三个正多边形**只有 `n` 不同**（4 紫 / 6 橙 / 8 蓝），直观展示"边数一变形状即变"。

<video src="assets/RTM output/03-多边形与星形-polygons.mp4" controls width="560"></video>

> 提醒：`Polygram` 的顶点组**必须整组塞进一个位置参数**（列表套点列表），单点直传会 `IndexError`——`Polygon` 才是每个顶点一个位置参数的写法。顶点顺序决定连边方式，想要什么边就按什么顺序给点。`radius` 默认 1 很小，构图时记得按需放大。

### RegularPolygram（随本页样例）、Star（原生 `_send_polygon`）、Polygram.round_corners（随本页样例）

```python
def __init__(self, num_vertices: int, *, density: int = 2, radius: float = 1,
             start_angle: float | None = None, **kwargs: Any) -> None:  # RegularPolygram

def __init__(self, n: int = 5, *, outer_radius: float = 1,
             inner_radius: float | None = None, density: int = 2,
             start_angle: float = TAU / 4, **kwargs: Any) -> None:  # Star

def round_corners(self, radius: float = 0.5,
                  evenly_distribute_anchors: bool = False,
                  components_per_rounded_corner: int = 2) -> Self:  # Polygram.round_corners
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `num_vertices` / `n` | `int` | 必填 / `5` | 顶点（角）总数；**能填** ≥3 的整数 |
| `density` | `int` | `2` | 连线密度——每隔几个点连一条：`1` = 正多边形，`2` = 二角星/五角星线框；`Star` 仅在 `inner_radius=None` 时生效 |
| `radius` | `float` | `1` | （`RegularPolygram`）外接圆半径 |
| `outer_radius` | `float` | `1` | （`Star`）外顶点半径 |
| `inner_radius` | `float \| None` | `None` | （`Star`）内顶点半径；`None` 由 `density` 推算（想要标准比例就留 `None`） |
| `start_angle` | `float \| None` | `None` / `TAU/4` | 起始角/旋转；`Star` 默认 `TAU/4` 让一个角朝上 |
| `radius` | `float` | `0.5` | （`round_corners`）圆角半径，**能填** 0 ~ 最短边一半 |
| `evenly_distribute_anchors` | `bool` | `False` | 锚点均匀分布；**不建议改** |
| `components_per_rounded_corner` | `int` | `2` | 每个圆角的分段数；**不建议改** |

> **返回**：星形/圆角后的多边形对象（`round_corners` 返回**自身**，可链式——样例在构造链尾直接调用）。`RegularPolygram` 是 `RegularPolygon` 与 `Star` 的共同生成器；`get_vertices()` 同样适用于它们。

#### 样例：三种星、同形梯形的两种圆角、顶点圆点

上排三颗星：内半径手动指定的金色五角星、`RegularPolygram(density=2)` 的五角星**线框**（自带交叉线）、`inner_radius=None` 交给 `density=3` 推算的七角星。下排同一对梯形只换 `round_corners` 半径（0.15 vs 0.55），最右六边形用 `get_vertices()` 在每个顶点摆上黄点。

```python
from real_time_manim import Scene, Polygon, RegularPolygon, Star, RegularPolygram, \
    Dot, VGroup, Text, GOLD, TEAL, ORANGE, PURPLE, BLUE, YELLOW, GREY_B, \
    UP, DOWN, Create, FadeIn, Write
from real_time_manim.vulkan_bind import MLWindow, Wait

class StarsRoundDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("03-Star / RegularPolygram / round_corners / get_vertices",
                     font_size=24, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        # —— 第一排：三种星 ——
        s5 = Star(n=5, outer_radius=1.5, inner_radius=0.6, color=GOLD, fill_opacity=0.9)
        s5.shift([-4.7, 1.5, 0])   #内半径手动指定的五角星
        cap1 = Text("Star(inner_radius=0.6)", font_size=19, color=GREY_B).move_to([-4.7, 0.4, 0])
        win.play(Create(s5), FadeIn(cap1), run_time=0.6)   #画金五角星 + 字幕

        rp = RegularPolygram(5, density=2, radius=1.4, color=TEAL, stroke_width=5)
        rp.shift([-0.6, 1.5, 0])   #正五角星基类：隔 1 点连线（自带交叉线）
        cap2 = Text("RegularPolygram(density=2)", font_size=19, color=GREY_B).move_to([-0.6, 0.4, 0])
        win.play(Create(rp), FadeIn(cap2), run_time=0.6)   #画五角星线框 + 字幕

        s7 = Star(n=7, outer_radius=1.4, density=3, color=BLUE, fill_opacity=0.6)
        s7.shift([4.6, 1.5, 0])   #七角星：inner_radius 交给 density 推算
        cap3 = Text("Star(n=7, density=3)", font_size=19, color=GREY_B).move_to([4.6, 0.4, 0])
        win.play(Create(s7), FadeIn(cap3), run_time=0.6)   #画七角星 + 字幕

        # —— 第二排：同形梯形，只差圆角半径 ——
        t1 = Polygon([-5.9, -0.7, 0], [-3.3, -0.7, 0], [-3.7, -2.5, 0], [-5.5, -2.5, 0],
                     color=ORANGE, fill_opacity=0.55).round_corners(0.15)   #轻微圆角
        cap4 = Text("round_corners(0.15)", font_size=19, color=GREY_B).move_to([-4.6, -2.85, 0])
        win.play(Create(t1), FadeIn(cap4), run_time=0.6)   #画小圆角梯形 + 字幕

        t2 = Polygon([-2.7, -0.7, 0], [-0.1, -0.7, 0], [-0.5, -2.5, 0], [-2.3, -2.5, 0],
                     color=PURPLE, fill_opacity=0.55).round_corners(0.55)   #大圆角
        cap5 = Text("round_corners(0.55)", font_size=19, color=GREY_B).move_to([-1.4, -2.85, 0])
        win.play(Create(t2), FadeIn(cap5), run_time=0.6)   #画大圆角梯形 + 字幕

        # —— get_vertices()：把每个顶点标出来 ——
        hexa = RegularPolygon(n=6, radius=1.1, color=BLUE, fill_opacity=0.3).shift([4.6, -1.6, 0])   #六边形坯子
        dots = VGroup(*[Dot(p, radius=0.07, color=YELLOW) for p in hexa.get_vertices()])   #顶点处摆黄点
        cap6 = Text("get_vertices() -> dots", font_size=19, color=GREY_B).move_to([4.6, -2.85, 0])
        win.play(Create(hexa), run_time=0.5)   #先画六边形
        win.play(FadeIn(dots), FadeIn(cap6), run_time=0.5)   #顶点黄点 + 字幕
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：上排三颗星各示范一种定尺寸的方式——金星手动给 `inner_radius=0.6`（尖更锐）、青色 `RegularPolygram(5, density=2)` 展示生成器本体（五条边互相穿过的线框）、蓝星七角且内半径留给 `density=3` 推算。下排两个**形状相同**的梯形只差 `round_corners` 半径，0.15 仅微圆、0.55 圆得明显；最右的六边形先画坯子，再把 `get_vertices()` 返回的六个顶点各摆一颗黄点，验证"顶点数=6"。

<video src="assets/RTM output/03-多边形与星形-stars_round.mp4" controls width="560"></video>

> 提醒：`density=1` 时 `RegularPolygram` 就退化成正多边形（与 `RegularPolygon` 同形）。`Star` 的 `density` 只在 `inner_radius=None` 时起作用——两者同给以 `inner_radius` 为准。`round_corners` 是**链式方法**（返回自身），半径超过最短边一半会把边整个吃掉、形状变形，样例梯形高 1.8 给 0.55 已是接近上限的示范。`RegularPolygram`/`Star` 用 `Create` 画时按顶点顺序走笔，交叉星会看到"穿线"过程，属正常现象。
