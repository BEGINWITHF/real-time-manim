# 角度与标注框（一）：角度与高亮框

`Angle`/`RightAngle` 在 `line.py`，标注框类在 `shape_matchers.py`。每条样例都把该函数的**全部可填参数**各改一次，串在同一条视频里对比。

## 参数

### `Angle`

```python
def __init__(self, line1: Line, line2: Line, radius: float | None = None, quadrant: AngleQuadrant = (1, 1), other_angle: bool = False, dot: bool = False, dot_radius: float | None = None, dot_distance: float = 0.55, dot_color: ParsableManimColor = WHITE, elbow: bool = False, **kwargs) -> None:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `line1` | `Line` | 必填 | 第一条边。**能填**任何 `Line`/`Arrow`（样例里两条边从同一点出发） |
| `line2` | `Line` | 必填 | 第二条边。同一个对象只能标一次角，要标两次就给两份拷贝 |
| `radius` | `float \| None` | `None` | 标记弧半径。**能填**任意正数；不填按两条边自动推算（样例 0.45～1.5 三种都出现过） |
| `quadrant` | `tuple[int, int]` | `(1, 1)` | 选四个象限之一：`(1,1)` / `(-1,1)` / `(1,-1)` / `(-1,-1)`；样例把四个都画了一遍 |
| `other_angle` | `bool` | `False` | 画另一侧（优角）。样例给出 `True` 的红色大弧 |
| `dot` | `bool` | `False` | 弧内加一个圆点（示意"角度大小"） |
| `dot_radius` | `float \| None` | `None` | 圆点半径，不填按弧半径的 1/10 |
| `dot_distance` | `float` | `0.55` | 圆点相对位置：0 在顶点、1 在弧上 |
| `dot_color` | `ManimColor` | `WHITE` | 圆点颜色（样例黄点） |
| `elbow` | `bool` | `False` | 用直角折角代替弧（这样画直角最省事） |
| `get_value(degrees=False)` | 方法 | — | **别用**：ManimCE 0.21 上游 bug，`Angle` 里没有 `angle_value` 属性，两引擎同崩。要读角度就用两条边的 `get_angle()` 之差（样例最后一段就是这么算的） |

#### 样例：半径 / 四个象限 / 优角 / 圆点 / 直角折角

一行四个 `quadrant`，下面依次是 `other_angle=True`、`dot` 系列、`elbow=True`，每格都带参数字幕。

```python
import os
import subprocess
import sys
from real_time_manim import (
    Scene, Line, Arrow, Dot, Square, Circle, Triangle, Text, VGroup,
    Angle, RightAngle, SurroundingRectangle, BackgroundRectangle, Cross, Underline,
    BLUE, GREEN, RED, ORANGE, YELLOW, PURPLE, TEAL, GOLD, GREY_B, WHITE,
    UP, DOWN, LEFT, RIGHT, ORIGIN, PI,
    Create, FadeIn, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim.record import fast_record_scene

class AngleDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("04-Angle", font_size=30, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        # —— 四个 quadrant：同一个角，标记弧画到不同象限 ——
        quads = [(1, 1), (-1, 1), (1, -1), (-1, -1)]   #参数 “quadrant”
        for i, q in enumerate(quads):
            l1 = Line(ORIGIN, RIGHT * 1.6)   #参数 “line1”
            l2 = Line(ORIGIN, UP * 1.6)   #参数 “line2”
            ang = Angle(l1, l2, radius=0.45, quadrant=q, color=ORANGE)   #参数 “radius / quadrant”
            grp = VGroup(l1, l2, ang).move_to([-4.3 + i * 2.6, 1.5, 0])
            cap = Text("quadrant=%s" % (q,), font_size=18, color=GREY_B).next_to(grp, DOWN, buff=0.25)
            win.play(Create(grp), FadeIn(cap), run_time=0.5)   #逐个画角 + 象限字幕

        # —— other_angle（优角）+ dot 系列：弧内加圆点并改半径/位置/颜色 ——
        l1 = Line(ORIGIN, RIGHT * 1.6)
        l2 = Line(ORIGIN, UP * 1.6)
        big = Angle(l1, l2, radius=1.5, other_angle=True, color=RED)   #参数 “other_angle=True”
        grp = VGroup(l1, l2, big).move_to([-1.4, -1.6, 0])
        cap = Text("other_angle=True", font_size=18, color=GREY_B).next_to(grp, DOWN, buff=0.25)
        win.play(Create(grp), FadeIn(cap), run_time=0.5)   #优角 + 字幕

        l1b = Line(ORIGIN, RIGHT * 1.6)   #第二条边的另一份拷贝（一个对象只能标一次角）
        l2b = Line(ORIGIN, UP * 1.6)
        marked = Angle(l1b, l2b, radius=1.0, dot=True, dot_radius=0.12,
                       dot_distance=0.75, dot_color=YELLOW, color=TEAL)   #参数 “dot / dot_radius / dot_distance / dot_color”
        grp2 = VGroup(l1b, l2b, marked).move_to([1.6, -1.6, 0])
        cap2 = Text("dot=True dot_distance=0.75", font_size=18, color=GREY_B).next_to(grp2, DOWN, buff=0.25)
        win.play(Create(grp2), FadeIn(cap2), run_time=0.5)   #带圆点 + 字幕

        # —— elbow=True：用直角折角代替弧；get_value() 读出角度数值 ——
        l1c = Line(ORIGIN, RIGHT * 1.6)
        l2c = Line(ORIGIN, UP * 1.6)
        elbow = Angle(l1c, l2c, radius=0.6, elbow=True, color=PURPLE)   #参数 “elbow=True”
        grp3 = VGroup(l1c, l2c, elbow).move_to([4.4, -1.6, 0])
        # get_value() 在 ManimCE 0.21 上游是坏的（Angle 里没有 angle_value 属性，
        # 两引擎同崩），这里改用两条边各自的方向角之差读出同一个数值
        deg = (l2c.get_angle() - l1c.get_angle()) % (2 * PI)
        cap3 = Text("elbow=True (%.1f deg)" % (deg / PI * 180),
                    font_size=18, color=GREY_B).next_to(grp3, DOWN, buff=0.25)   #两方向角之差 = 90.0
        win.play(Create(grp3), FadeIn(cap3), run_time=0.6)   #折角 + 角度读数
        win.play(Wait(0.5))   #停留看结果
        win.close()   #关闭 RTM 窗口


# ===== 样例 2：Angle.from_three_points —— 三点定角 =========================
```

这段代码在做什么：第一行四组同样的两条边，只换 `quadrant`，四个象限的标记弧轮着出现，一眼看清这个参数是选"弧画在哪一侧"。换行后：

- `other_angle=True` 画出另一侧的红色优角；
- `dot=True`+`dot_radius`+`dot_distance`+`dot_color` 在弧内摆一个位置、大小、颜色都可调的圆点；
- 最后 `elbow=True` 把弧换成直角折角，并用两条边方向角之差读出 `90.0` 打在字幕上（`get_value()` 本身在上游坏了，见参数表）。

<video src="assets/RTM output/04-角度与标注框-angle.mp4" controls width="560"></video>

> 提醒：`radius` 不填时按两条边自动推算，边很短时标记弧会贴到顶点，想要固定大小就显式给；`quadrant` 与 `other_angle` 是两件事——前者选象限，后者选"补角那一边"，一起用能覆盖四个方向的全部画法。

### `Angle.from_three_points`

```python
@classmethod
def from_three_points(cls, A: Point3DLike, B: Point3DLike, C: Point3DLike, **kwargs) -> Angle:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `A` | `Point3DLike` | 必填 | 第一条边的端点（不是顶点） |
| `B` | `Point3DLike` | 必填 | **顶点**：角就标在 B 处，两条边是 B→A 与 B→C |
| `C` | `Point3DLike` | 必填 | 第二条边的端点 |
| `**kwargs` | — | — | 其余参数与 `Angle` 相同（样例给了 `radius=0.7, color=GOLD`） |

#### 样例：三个点标角

三个白点把 A/B/C 摆在屏幕上，角标在中间的 B 上——不需要先画 `Line`。

```python
import os
import subprocess
import sys
from real_time_manim import (
    Scene, Line, Arrow, Dot, Square, Circle, Triangle, Text, VGroup,
    Angle, RightAngle, SurroundingRectangle, BackgroundRectangle, Cross, Underline,
    BLUE, GREEN, RED, ORANGE, YELLOW, PURPLE, TEAL, GOLD, GREY_B, WHITE,
    UP, DOWN, LEFT, RIGHT, ORIGIN, PI,
    Create, FadeIn, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim.record import fast_record_scene

class AngleThreePointsDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("04-Angle.from_three_points", font_size=30, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        a = ORIGIN + LEFT * 2.2 + DOWN * 1.2   #参数 “A” 起点
        b = ORIGIN + LEFT * 0.2 + DOWN * 1.2   #参数 “B” 顶点
        c = ORIGIN + RIGHT * 0.6 + UP * 0.8   #参数 “C” 终点
        dots = VGroup(Dot(a, radius=0.07, color=WHITE), Dot(b, radius=0.07, color=WHITE),
                      Dot(c, radius=0.07, color=WHITE))   #三个顶点用小圆点标出
        ang = Angle.from_three_points(a, b, c, radius=0.7, color=GOLD)   #三点定角（B 是顶点）
        cap = Text("Angle.from_three_points(A, B, C)", font_size=20, color=GREY_B).to_edge(DOWN, buff=1.0)
        win.play(FadeIn(dots), run_time=0.4)   #先看点
        win.play(Create(ang), FadeIn(cap), run_time=0.7)   #再画角
        win.play(Wait(0.5))   #停留看结果
        win.close()   #关闭 RTM 窗口


# ===== 样例 3：RightAngle —— 直角标记的长度与颜色 ==========================
```

这段代码在做什么：`a`/`b`/`c` 是三个屏幕坐标，先 `FadeIn(dots)` 把三点画出来（可以核对位置），再 `Angle.from_three_points(a, b, c, radius=0.7, color=GOLD)`——注意**角标在中间那个点 B 上**，两边分别是 B→A 与 B→C。`**kwargs` 与 `Angle` 完全一致，所以半径、颜色、`dot` 这些都能继续用。

<video src="assets/RTM output/04-角度与标注框-angle3p.mp4" controls width="560"></video>

> 提醒：三个点的顺序是 A（边上的点）→ B（顶点）→ C（另一条边上的点），把顶点放中间；点顺序换了角就标到别的点上，画面会立刻看出来。

### `RightAngle`

```python
def __init__(self, line1: Line, line2: Line, length: float | None = None, **kwargs) -> None:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |

# ===== 样例 4：SurroundingRectangle —— 颜色 / 间距 / 圆角 ==================

这段代码在做什么：三个直角并排，`length` 从 0.25 到 0.6 到不传，小方角随参数变大、最后按两条边自动取一个尺寸；颜色分别红/绿/蓝，用来确认 `**kwargs` 也照常生效。它就是 `Angle(..., elbow=True)` 的简写，画直角比手调弧半径省事。

<video src="assets/RTM output/04-角度与标注框-rightangle.mp4" controls width="560"></video>

> 提醒：`length` 是方角两条小边的**边长**（不是半径），给大了会超出两条边本身的长度，看起来像把角"包"住；两条边特别短时建议显式给小一点的值。

### `SurroundingRectangle`

```python
def __init__(self, *mobjects: Mobject, color: ParsableManimColor = PURE_YELLOW, buff: float | tuple[float, float] = SMALL_BUFF, corner_radius: float = 0.0, **kwargs) -> None:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `*mobjects` | `Mobject...` | 必填 | 被框的对象，**能填**任意多个；多个对象取**整体包围盒**（样例给了一个和两个各一次） |
| `color` | `ManimColor` | `PURE_YELLOW` | 框颜色（样例红/青各一次） |
| `buff` | `float \| tuple[float, float]` | `SMALL_BUFF`（0.1） | 与对象的间距，也可以给 `(水平, 垂直)` 两元组 |
| `corner_radius` | `float` | `0.0` | 圆角半径，0 是尖角 |

#### 样例：单对象 / 大间距圆角 / 两个对象

从左到右：默认框、`buff=0.45`+圆角、以及"两个对象一起框"（整体包围盒）。

```python
import os
import subprocess
import sys
from real_time_manim import (
    Scene, Line, Arrow, Dot, Square, Circle, Triangle, Text, VGroup,
    Angle, RightAngle, SurroundingRectangle, BackgroundRectangle, Cross, Underline,
    BLUE, GREEN, RED, ORANGE, YELLOW, PURPLE, TEAL, GOLD, GREY_B, WHITE,
    UP, DOWN, LEFT, RIGHT, ORIGIN, PI,
    Create, FadeIn, Write,

from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim.record import fast_record_scene

class SurroundingDemo(Scene):

        ci = Circle(radius=0.7, color=GREEN, fill_opacity=0.5).move_to([0, 1.2, 0])

        dot = Dot(point=[4.6, 1.8, 0], radius=0.1, color=ORANGE)
        f3 = SurroundingRectangle(tri, dot, color=TEAL, buff=0.2)   #参数 “*mobjects” 给两个：整体包围盒
        cap3 = Text("SurroundingRectangle(tri, dot)", font_size=18, color=GREY_B).next_to(VGroup(tri, dot, f3), DOWN, buff=0.25)

# ===== 样例 5：BackgroundRectangle —— 垫底色 / 描边 / 不透明度 / 边距 =====
```

这段代码在做什么：三个框依次出现。

- 第一个什么都不传，得到默认亮黄、间距 0.1、尖角。
- 第二个把 `buff` 拉到 0.45、`corner_radius` 给 0.25 并换成红色，框明显离对象更远而且是圆角。
- 第三个一次传两个对象（三角形 + 一个圆点），框把两者一起包住——`*mobjects` 收几个就按几个的整体包围盒来。

<video src="assets/RTM output/04-角度与标注框-surrounding.mp4" controls width="560"></video>

> 提醒：`buff` 也可以写成 `(横, 纵)` 两元组单独调两个方向；框只画描边（无填充），所以叠在对象上不会挡住内容，真要挡就配 `z_index` 或改用 `BackgroundRectangle`。

### `BackgroundRectangle`

```python
def __init__(self, *mobjects: Mobject, color: ParsableManimColor | None = None, stroke_width: float = 0, stroke_opacity: float = 0, fill_opacity: float = 0.75, buff: float | tuple[float, float] = 0, **kwargs) -> None:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `*mobjects` | `Mobject...` | 必填 | 被垫底的对象，可给多个（按整体包围盒垫） |
| `color` | `ManimColor \| None` | `None`（按黑） | 底色；不填就是黑底，适合压在深色画面上提可读性 |
| `stroke_width` | `float` | `0` | 底色块的描边宽度，0 是无描边 |
| `stroke_opacity` | `float` | `0` | 描边不透明度 |
| `fill_opacity` | `float` | `0.75` | 填充不透明度，0.75 = 透出 25% 背景 |
| `buff` | `float \| tuple[float, float]` | `0` | 比对象大出来的边距 |

#### 样例：默认黑底 / 换色加描边 / 加大边距

三块底色：默认（黑 75%）、紫色带描边且半透明、青色加大 `buff` 比字大一圈。

```python
import os
import subprocess
import sys
from real_time_manim import (
    Scene, Line, Arrow, Dot, Square, Circle, Triangle, Text, VGroup,
    Angle, RightAngle, SurroundingRectangle, BackgroundRectangle, Cross, Underline,
    BLUE, GREEN, RED, ORANGE, YELLOW, PURPLE, TEAL, GOLD, GREY_B, WHITE,
    UP, DOWN, LEFT, RIGHT, ORIGIN, PI,
    Create, FadeIn, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim.record import fast_record_scene

class BackgroundDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("04-BackgroundRectangle", font_size=30, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        # —— 默认：黑底 75% 不透明，垫在白字下面 ——
        t1 = Text("readable", font_size=34, color=WHITE).move_to([-3.0, 1.2, 0])
        b1 = BackgroundRectangle(t1)   #参数默认值：color=None（按黑）、fill_opacity=0.75、buff=0
        win.play(FadeIn(b1), run_time=0.4)   #先垫底
        win.play(FadeIn(t1), run_time=0.4)   #再上字

        # —— 换底色 + 加描边 + 调不透明度 ——
        t2 = Text("tinted", font_size=34, color=WHITE).move_to([1.4, 1.2, 0])
        b2 = BackgroundRectangle(t2, color=PURPLE, stroke_width=4, stroke_opacity=1,
                                 fill_opacity=0.5)   #参数 “color / stroke_width / stroke_opacity / fill_opacity”
        win.play(FadeIn(b2), run_time=0.4)
        win.play(FadeIn(t2), run_time=0.4)

        # —— buff 放大：底色比字大一圈 ——
        t3 = Text("padded", font_size=34, color=WHITE).move_to([-1.0, -1.4, 0])
        b3 = BackgroundRectangle(t3, color=TEAL, fill_opacity=0.9, buff=0.35)   #参数 “buff=0.35”
        cap = Text("buff=0.35", font_size=18, color=GREY_B).next_to(VGroup(t3, b3), DOWN, buff=0.25)
        win.play(FadeIn(b3), FadeIn(cap), run_time=0.4)
        win.play(FadeIn(t3), run_time=0.4)   #垫底比字大一圈
        win.play(Wait(0.5))   #停留看结果
        win.close()   #关闭 RTM 窗口


# ===== 样例 6：Cross / Underline —— 否定的两种画法 =========================
```

这段代码在做什么：每段都是"先 `FadeIn` 底色块、再 `FadeIn` 文字"，顺序就是叠放顺序。

- 第一块什么都不传，是黑底 75% 不透明（在深色画面上不一定看得出，但换成浅色底或加描边后就很明显）。
- 第二块换紫色、加 4px 描边、填充降到 0.5。
- 第三块把 `buff` 放到 0.35，底色块比文字四周都大一圈。

> 提醒：底色是**独立 mobject**，要压住场景里已有的东西得让它排在后面（`add` 的顺序或 `z_index`）；默认 `color=None` 按黑处理，在纯黑背景上几乎看不见——这正是它在深色画面里"提可读性"的用法。

### `Cross` / `Underline`

```python
def __init__(self, mobject: Mobject | None = None, stroke_color: ParsableManimColor = RED, stroke_width: float = 6.0, scale_factor: float = 1.0, **kwargs) -> None:   # Cross
def __init__(self, mobject: Mobject, buff: float = SMALL_BUFF, **kwargs) -> None:                                                                                     # Underline
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `Cross.mobject` | `Mobject \| None` | `None` | 被叉的对象：叉的位置与大小都跟它走；不传就是一个默认大小的叉 |
| `Cross.stroke_color` | `ManimColor` | `RED` | 叉的颜色 |
| `Cross.stroke_width` | `float` | `6.0` | 线宽 |
| `Cross.scale_factor` | `float` | `1.0` | 相对被叉对象的缩放 |
| `Underline.mobject` | `Mobject` | 必填 | 被下划的对象：线长自动等于它的宽度 |
| `Underline.buff` | `float` | `SMALL_BUFF`（0.1） | 与对象的垂直间距 |

#### 样例：叉的颜色/线宽/缩放 + 下划线的两种间距

左边两个叉（默认 vs 黄粗放大 1.4 倍），右边两条下划线（贴着字 vs 离字远）。

```python
import os
import subprocess
import sys
from real_time_manim import (
    Scene, Line, Arrow, Dot, Square, Circle, Triangle, Text, VGroup,
    Angle, RightAngle, SurroundingRectangle, BackgroundRectangle, Cross, Underline,
    BLUE, GREEN, RED, ORANGE, YELLOW, PURPLE, TEAL, GOLD, GREY_B, WHITE,
    UP, DOWN, LEFT, RIGHT, ORIGIN, PI,
    Create, FadeIn, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim.record import fast_record_scene

class CrossUnderlineDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("04-Cross / Underline", font_size=30, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        # —— Cross：位置与大小由被叉对象决定 ——
        sq = Square(side_length=1.2, color=BLUE, fill_opacity=0.5).move_to([-3.4, 0.6, 0])
        x1 = Cross(sq)   #参数 “mobject=sq”：叉在方块上，大小跟着方块
        cap1 = Text("Cross(sq)", font_size=18, color=GREY_B).next_to(VGroup(sq, x1), DOWN, buff=0.25)
        win.play(Create(sq), run_time=0.4)
        win.play(Create(x1), FadeIn(cap1), run_time=0.5)

        # —— 换颜色 / 线宽 / 缩放 ——
        ci = Circle(radius=0.6, color=GREEN, fill_opacity=0.5).move_to([0, 0.6, 0])
        x2 = Cross(ci, stroke_color=YELLOW, stroke_width=14, scale_factor=1.4)   #参数 “stroke_color / stroke_width / scale_factor”
        cap2 = Text("stroke_width=14 scale_factor=1.4", font_size=18, color=GREY_B).next_to(VGroup(ci, x2), DOWN, buff=0.25)
        win.play(Create(ci), run_time=0.4)
        win.play(Create(x2), FadeIn(cap2), run_time=0.5)

        # —— Underline：只给线宽和 buff（长度跟着对象宽度）——
        t = Text("underlined", font_size=34, color=WHITE).move_to([3.4, 0.6, 0])
        u1 = Underline(t, buff=0.08, color=RED)   #参数 “buff=0.08”
        cap3 = Text("Underline(t, buff=0.08)", font_size=18, color=GREY_B).next_to(VGroup(t, u1), DOWN, buff=0.35)
        win.play(FadeIn(t), run_time=0.4)
        win.play(Create(u1), FadeIn(cap3), run_time=0.5)

        t2 = Text("loose", font_size=34, color=WHITE).move_to([3.4, -1.6, 0])
        u2 = Underline(t2, buff=0.5, color=ORANGE)   #参数 “buff=0.5”：离字更远
        cap4 = Text("buff=0.5", font_size=18, color=GREY_B).next_to(VGroup(t2, u2), DOWN, buff=0.35)
        win.play(FadeIn(t2), run_time=0.4)
        win.play(Create(u2), FadeIn(cap4), run_time=0.5)
        win.play(Wait(0.5))   #停留看结果
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：`Cross(sq)` 的叉自动铺满方块；第二个叉换成黄色、线宽 14、`scale_factor=1.4`，明显比圆更大更粗。`Underline` 只吃对象和 `buff`——线长永远等于对象宽度，`buff=0.08` 时贴着字，`buff=0.5` 时离得很远，两条并排一眼看清间距参数。

<video src="assets/RTM output/04-角度与标注框-cross.mp4" controls width="560"></video>

> 提醒：`Cross` 的 `scale_factor` 是相对**被叉对象**的尺寸，不是绝对长度；`Underline` 想改颜色/线宽直接走 `**kwargs`（`color=`、`stroke_width=`），长度不用管。
