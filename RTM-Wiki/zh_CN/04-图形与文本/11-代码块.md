# 代码块

`Code` 把一段源码渲染成**带语法高亮**的代码块（基于 Pygments，50 种配色），用于"在画面里展示代码"。两个函数各一条样例。

> **两种构造方式**：`code_string=` 直接给源码字符串（样例都用它），`code_file=` 给文件路径（读文件内容）；两者二选一。`language` 不给时会按文件扩展名推断，字符串构造时建议显式写。

## 参数

### `Code` 

```python
def __init__(self, code_file: StrPath | None = None, code_string: str | None = None, language: str | None = None, formatter_style: str | Style = "vim", tab_width: int = 4, add_line_numbers: bool = True, line_numbers_from: int = 1, background: Literal["rectangle", "window"] = "rectangle", background_config: dict | None = None, paragraph_config: dict | None = None) -> None:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `code_file` | `str \| Path \| None` | `None` | 读文件当源码；与 `code_string` 二选一 |
| `code_string` | `str \| None` | `None` | 直接给源码字符串（样例用它，`\n` 换行、`\t` 缩进） |
| `language` | `str \| None` | `None` | 语法高亮的语言名（`"python"`、`"javascript"`…）；不写则按文件扩展名推断 |
| `formatter_style` | `str \| Style` | `"vim"` | 配色方案；样例 `"vim"` / `"monokai"`，可选值见 `Code.get_styles_list()` |
| `tab_width` | `int` | `4` | 制表符宽度（一个 `\t` 占几个字符宽）；样例 `8` |
| `add_line_numbers` | `bool` | `True` | 是否显示行号 |
| `line_numbers_from` | `int` | `1` | 行号从几开始；样例从 `10` 开始 |
| `background` | `"rectangle" \| "window"` | `"rectangle"` | 背景样式：`rectangle` 纯色块、`window` 带窗口标题栏的样子 |
| `background_config` | `dict \| None` | `None` | 透传给背景矩形的样式（如 `{"stroke_color": TEAL, "fill_opacity": 0.3}`） |
| `paragraph_config` | `dict \| None` | `None` | 透传给内部 `Paragraph` 的配置（如字体） |

返回 `Code`（`VGroup`：背景 + 每行文本），可以整体 `scale`/`move_to`，也可以按行取子对象单独上色。

#### 样例：语言 / 行号 / 制表符 / 背景样式 / 配色 / 两个 config

```python
import os
import subprocess
import sys
from real_time_manim import (
    Scene, Code, Text, VGroup,
    BLUE, GREEN, RED, ORANGE, YELLOW, TEAL, GREY_B,
    UP, DOWN, LEFT, RIGHT,
    Create, FadeIn, FadeOut, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim.record import fast_record_scene

class CodeDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("11-Code", font_size=30, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.4)   #写出标题

        # —— code_string + language：默认 tab_width=4、带行号、rectangle 背景 ——
        c1 = Code(code_string="def f(x):\n    return x ** 2\n\nprint(f(3))",
                  language="python")   #参数 “code_string / language”
        c1.scale(0.75).move_to([0, 0.9, 0])
        win.play(Write(c1), FadeIn(cap('language="python"', c1)), run_time=0.8)

        # —— tab_width / add_line_numbers / line_numbers_from ——
        c2 = Code(code_string="a = 1\nif a:\n\tprint(a)",
                  language="python", tab_width=8,   #参数 “tab_width”
                  add_line_numbers=True, line_numbers_from=10)   #参数 “add_line_numbers / line_numbers_from”
        c2.scale(0.75).move_to([-3.6, -1.9, 0])
        win.play(Write(c2), FadeIn(cap("tab_width=8, 行号从 10", c2)), run_time=0.7)

        # —— background="window" + formatter_style：窗口式背景与配色 ——
        c3 = Code(code_string="x = [1, 2, 3]\nprint(sum(x))",
                  language="python", background="window",   #参数 “background”
                  formatter_style="monokai")   #参数 “formatter_style”
        c3.scale(0.75).move_to([3.4, -1.9, 0])
        win.play(Write(c3), FadeIn(cap('background="window", style="monokai"', c3)), run_time=0.7)

        # —— background_config / paragraph_config：透传样式 ——
        c4 = Code(code_string="s = 'hi'",
                  language="python",
                  background_config={"stroke_color": TEAL, "fill_opacity": 0.3},   #参数 “background_config”
                  paragraph_config={"font": "monospace"})   #参数 “paragraph_config”
        c4.scale(0.75).move_to([0, -3.2, 0])
        win.play(Write(c4), run_time=0.6)
        win.play(Wait(0.5))   #停留看结果
        win.close()   #关闭 RTM 窗口


# ===== 样例 2：Code.get_styles_list —— 可用的配色方案 ======================
```

这段代码在做什么：第一块是最普通的 `language="python"`（默认 4 宽制表符、有行号、rectangle 背景）；左下把 `tab_width` 调到 8、行号从 10 开始；右下的 `background="window"` 配 `formatter_style="monokai"`，明显能看出窗口式底和深色配色；最后一块把 `background_config`（青色描边、0.3 填充）和 `paragraph_config`（等宽字体）一起传进去。

> 提醒：`code_string` 里的缩进要么用空格、要么用 `\t`——混用会让 `tab_width` 看起来"没生效"；`background="window"` 会多出一层标题栏，占的高度比 `rectangle` 大，排版时先按大一点留位。

### `Code.get_styles_list` 

```python
def get_styles_list() -> list[str]:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| （无参数） | — | — | 返回全部可用配色名（当前 50 个，如 `vim`、`monokai`、`friendly`…） |

这是个 **classmethod**：直接 `Code.get_styles_list()` 调用，返回字符串列表，用来查 `formatter_style` 能填什么。

#### 样例：列出前 6 个 + 同一段代码换三种配色

```python
import os
import subprocess
import sys
from real_time_manim import (
    Scene, Code, Text, VGroup,
    BLUE, GREEN, RED, ORANGE, YELLOW, TEAL, GREY_B,
    UP, DOWN, LEFT, RIGHT,
    Create, FadeIn, FadeOut, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim.record import fast_record_scene

class StylesDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("11-Code.get_styles_list", font_size=30, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.4)   #写出标题

        styles = Code.get_styles_list()   #方法 “get_styles_list()”：返回全部可用配色名
        # —— 前六个名字逐个上屏（也说明数量远多于常用的那几个）——
        names = VGroup(*[Text(s, font_size=22, color=GREY_B) for s in styles[:6]])
        names.arrange(DOWN, buff=0.18).move_to([-4.2, 0.4, 0])
        cnt = Text("共 %d 种" % len(styles), font_size=24, color=TEAL).next_to(names, DOWN, buff=0.4)
        win.play(FadeIn(names), FadeIn(cnt), run_time=0.7)

        # —— 同一个代码块换三种 style，直观看出差别 ——
        for i, style in enumerate(("vim", "monokai", "friendly")):
            code = Code(code_string="def f(x):\n    return x ** 2",
                        language="python", formatter_style=style)   #参数 “formatter_style”
            code.scale(0.6).move_to([0.6 + (i % 2) * 3.2, 0.9 - i * 1.9, 0])
            win.play(Write(code), FadeIn(cap(style, code, buff=0.2, size=16)), run_time=0.6)
        win.play(Wait(0.5))   #停留看结果
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：左边把 `get_styles_list()` 的前 6 个名字排成一列，下面标出总数（当前 50 种）；右边用同一段 Python 代码分别以 `vim`、`monokai`、`friendly` 三种 `formatter_style` 渲染，一眼能看出配色差异。

<video src="assets/RTM output/11-代码块-styles.mp4" controls width="560"></video>

> 提醒：`get_styles_list()` 返回的名单随 Pygments 版本变化，写死某个名字前先跑一次这个方法确认存在；样例里只展示前 6 个，避免整屏塞满。
