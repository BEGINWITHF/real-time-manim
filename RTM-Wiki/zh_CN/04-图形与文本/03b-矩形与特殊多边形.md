# 多边形与星形（二）：矩形与特殊多边形

承接[多边形与星形（一）](03-多边形与星形.md)：矩形家族、圆角、挖孔与凸包。每条样例都把该函数的**全部可填参数**各改一次，串在同一条视频里对比。

## 参数

### `Rectangle`

```python
def __init__(self, color: ParsableManimColor = WHITE, height: float = 2.0, width: float = 4.0, grid_xstep: float | None = None, grid_ystep: float | None = None, mark_paths_closed: bool = True, close_new_points: bool = True, **kwargs) -> None:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `color` | `ManimColor` | `WHITE` | 颜色。**能填**任何颜色（`BLUE`、`"#33AADD"`、(r,g,b)）；样例第一个矩形就换了它 |
| `height` | `float` | `2.0` | 高。**能填**任意正数；样例第二个矩形 `height=1.6` |
| `width` | `float` | `4.0` | 宽。**能填**任意正数；样例第二个矩形 `width=2.4` |
| `grid_xstep` | `float \| None` | `None` | **不建议改**：填了会在矩形内部挂一组子对象网格线（`submobjects` 多出一层，之后 `set_color`/`MoveToTarget`/`Create` 的行为都跟纯矩形不同）。要"带格子的矩形"更可控的做法是 `VGroup(矩形, 手画的线)`；样例第三个矩形只为演示效果填了它 |
| `grid_ystep` | `float \| None` | `None` | **不建议改**：同上 |
| `mark_paths_closed` | `bool` | `True` | **不建议改**：路径闭合标记，改了会影响填充判定 |
| `close_new_points` | `bool` | `True` | **不建议改**：新点是否自动闭合 |

#### 样例：换颜色 / 换宽高 / 加内部网格

三个矩形并排：默认 4×2、显式 `width`/`height`、带 `grid_xstep`/`grid_ystep` 的内部网格。参数值都打在各自字幕上。

```python
import os
import subprocess
import sys
from real_time_manim import (
    Scene, Rectangle, Square, RoundedRectangle, Cutout, ConvexHull, Circle,
    Triangle, Dot, VGroup, Text,
    BLUE, GREEN, TEAL, PURPLE, ORANGE, YELLOW, GREY_B, WHITE,
    UP, DOWN, LEFT, RIGHT, ORIGIN,
    Create, FadeIn, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim.record import fast_record_scene

class RectangleDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("03b-Rectangle", font_size=28, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        # —— 默认 4x2 ——
        r1 = Rectangle(color=BLUE)   #color 参数：默认 WHITE
        r1.move_to([-4.4, 1.4, 0])   #默认 width=4.0 / height=2.0
        cap1 = Text("Rectangle()  4x2", font_size=19, color=GREY_B).move_to([-4.4, 0.1, 0])
        win.play(Create(r1), FadeIn(cap1), run_time=0.6)   #画出默认矩形 + 字幕

        # —— width / height 显式给 ——
        r2 = Rectangle(width=2.4, height=1.6, color=GREEN)   #参数 “width / height”
        r2.move_to([0, 1.4, 0])   #窄而矮
        cap2 = Text("width=2.4 height=1.6", font_size=19, color=GREY_B).move_to([0, 0.1, 0])
        win.play(Create(r2), FadeIn(cap2), run_time=0.6)   #画出自定义尺寸 + 字幕

        # —— grid_xstep / grid_ystep：矩形内部画网格 ——
        r3 = Rectangle(width=3.2, height=1.8, color=ORANGE,
                       grid_xstep=0.8, grid_ystep=0.6)   #参数 “grid_xstep / grid_ystep”
        r3.move_to([4.4, 1.4, 0])   #内部被切成小格
        cap3 = Text("grid_xstep=0.8 grid_ystep=0.6", font_size=19, color=GREY_B).move_to([4.4, 0.1, 0])
        win.play(Create(r3), FadeIn(cap3), run_time=0.6)   #画出带网格矩形 + 字幕
        win.play(Wait(0.4))   #停留看结果
        win.close()   #关闭 RTM 窗口


# ===== 样例 2：Square —— side_length 可读写 ================================
```

这段代码在做什么：三个矩形都用 `Create` 画出来，各自带一行说明参数取值的字幕。第一个只用 `color`（尺寸走默认 4×2）；第二个把 `width`/`height` 显式改成 2.4/1.6，一眼看出"宽高就是这两个数"；第三个同时给 `grid_xstep=0.8` 和 `grid_ystep=0.6`，矩形内部于是多出一层网格子对象（这也是表格里不建议改的原因）。`mark_paths_closed`/`close_new_points` 保持默认。

<video src="assets/RTM output/03b-矩形与特殊多边形-rectangle.mp4" controls width="560"></video>

> 提醒：`width`/`height` 只是构造期的尺寸，之后想改尺寸用 `scale()`/`stretch()`；只有 `grid_*step` 会在矩形内部挂子对象，`get_vertices()`、`Create`、`set_color` 都会连带作用到那些网格线上。

### `Square`

```python
def __init__(self, side_length: float = 2.0, **kwargs) -> None:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `side_length` | `float` | `2.0` | 边长。构造时能填任意正数；**它同时是可读写属性**——构造完再写 `sq.side_length = 2.6` 会当场把形状缩放到新边长（走 `scale()`，不需要重建对象）。样例两件事都演示了 |

#### 样例：构造传 `side_length` / 构造后改 `side_length`

一个默认 2.0、一个构造时给 1.2、第三个画出来后直接写 `side_length = 2.6`。

```python
import os
import subprocess
import sys
from real_time_manim import (
    Scene, Rectangle, Square, RoundedRectangle, Cutout, ConvexHull, Circle,
    Triangle, Dot, VGroup, Text,
    BLUE, GREEN, TEAL, PURPLE, ORANGE, YELLOW, GREY_B, WHITE,
    UP, DOWN, LEFT, RIGHT, ORIGIN,
    Create, FadeIn, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim.record import fast_record_scene

class SquareDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("03b-Square", font_size=28, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        sq1 = Square(color=BLUE, fill_opacity=0.5)   #默认 side_length=2.0
        sq1.move_to([-3.6, 0.4, 0])
        cap1 = Text("Square()  2.0", font_size=19, color=GREY_B).move_to([-3.6, -1.5, 0])
        win.play(Create(sq1), FadeIn(cap1), run_time=0.6)   #画出默认正方形 + 字幕

        sq2 = Square(side_length=1.2, color=TEAL, fill_opacity=0.5)   #参数 “side_length”
        sq2.move_to([0, 0.4, 0])
        cap2 = Text("side_length=1.2", font_size=19, color=GREY_B).move_to([0, -1.5, 0])

        sq3.move_to([4.0, 0.4, 0])

        win.play(Wait(0.5))   #赋值后停留，让变化可见
        win.close()   #关闭 RTM 窗口


# ===== 样例 3：RoundedRectangle —— 圆角半径（单个 / 四角不同）==============
```

这段代码在做什么：前两个正方形只差 `side_length`（默认 2.0 与 1.2），并排看得出来边长就是这一个数。第三个先按默认大小画出来，画完后写 `sq3.side_length = 2.6`——视频里它当场变大，因为 setter 内部就是按 `value / 当前边长` 做 `scale()`。所以"构造时给"和"之后改"两条路都能用同一条视频看清。

<video src="assets/RTM output/03b-矩形与特殊多边形-square.mp4" controls width="560"></video>

> 提醒：`side_length` 是读的**相邻两点实际距离**，3D 旋转后读出来仍是对的；写它等价于 `scale(新值 / 旧值)`，所以填充、描边宽度都会跟着等比变。

### `RoundedRectangle`

```python
def __init__(self, corner_radius: float | list[float] = 0.5, **kwargs) -> None:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `corner_radius` | `float \| list[float]` | `0.5` | 圆角半径。**能填**一个数（四角同半径）或长度 4 的列表（顺序 左上→右上→右下→左下，四角各不同）；样例两种都演示 |
| `width` / `height` | `float` | `4.0` / `2.0` | 继承 `Rectangle`，样例里显式给了 3.4×1.6 |

#### 样例：一个半径 / 四角不同半径

上面是 `corner_radius=0.5`（四角一样），下面是 `corner_radius=[0.05, 0.35, 0.65, 1.0]`（左上到左下依次变圆）。

```python

import subprocess
import sys
from real_time_manim import (

    Triangle, Dot, VGroup, Text,

# ===== 样例 4：Cutout —— 从主形状里挖孔 ====================================
```

这段代码在做什么：两个同样 3.4×1.6 的圆角矩形，唯一区别是 `corner_radius` 的写法——上面给一个 0.5，四角都是同半径的圆角；下面给四元列表，四个角从 0.05 到 1.0 越来越圆，一眼看出列表的顺序就是左上→右上→右下→左下。圆角是真弧（走 Bezier 镶嵌，不是切角）；`Rectangle(..., corner_radius=0.3)` 这种写法也会转成这个类。

<video src="assets/RTM output/03b-矩形与特殊多边形-rounded.mp4" controls width="560"></video>

> 提醒：半径大过半边宽/半边高时，相邻两角的弧会互相吃掉，形状退化成"胶囊"；想看清四角差异就把 `width`/`height` 放大再试。

### `Cutout`

```python
def __init__(self, main_shape: VMobject, *mobjects: VMobject, **kwargs) -> None:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `main_shape` | `VMobject` | 必填 | 主形状。**能填**任意 `VMobject`；样例给的是带填充的矩形 |
| `*mobjects` | `VMobject...` | 必填 | 要挖掉的形状，**能填**任意多个；样例挖了一个圆孔 + 一个三角孔 |

#### 样例：一个圆孔 + 一个三角孔

先画主矩形，再换成 `Cutout(main, Circle, Triangle)`——三个形状各自的颜色/描边都在（孔只给描边）。

```python
import os
import subprocess
import sys
from real_time_manim import (
    Scene, Rectangle, Square, RoundedRectangle, Cutout, ConvexHull, Circle,
    Triangle, Dot, VGroup, Text,
    BLUE, GREEN, TEAL, PURPLE, ORANGE, YELLOW, GREY_B, WHITE,
    UP, DOWN, LEFT, RIGHT, ORIGIN,
    Create, FadeIn, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim.record import fast_record_scene

class CutoutDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("03b-Cutout", font_size=28, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        main = Rectangle(width=5.0, height=2.6, color=TEAL,
                         fill_opacity=0.9).move_to([-2.4, -0.4, 0])   #主形状（带填充）

        cut = Cutout(main,
                     Circle(radius=0.55, color=WHITE).move_to([-4.0, -0.4, 0]),   #挖一个圆孔

        win.play(Create(cut), FadeIn(cap), run_time=0.8)   #换成带孔形状 + 字幕
        win.play(Wait(0.4))   #停留看结果
        win.close()   #关闭 RTM 窗口


# ===== 样例 5：ConvexHull —— 一族点的凸包 ==================================
```

这段代码在做什么：先把带填充的主矩形画出来，第二步 `Create(cut)` 换成 `Cutout(main, 圆, 三角)`——`main_shape` 是主形状，后面跟的每个形状都作为**反向子路径**并进同一次填充。视频里可以看到换过去之后矩形内部多了圆和三角两组描边；`*mobjects` 的个数不受限，样例给了两个。

<video src="assets/RTM output/03b-矩形与特殊多边形-cutout.mp4" controls width="560"></video>

> 提醒：孔的"镂空"只由填充规则决定，跟"形状放在哪"无关——孔的形状只给描边（`fill_opacity=0`）时，主形状的填充会盖过孔的内部，看上去只是"画了个圈"；想让孔真的透出背景，把孔的 `fill_opacity` 也打开，或整块改用 `Difference`（见[布尔运算](05-布尔运算.md)）。

### `ConvexHull`

```python
def __init__(self, *points: Point3DLike, tolerance: float = 1e-05, **kwargs) -> None:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `*points` | `array-like...` | 必填 | 输入点集。**能填**任意多个点（列表、数组、`Dot` 都能混着给）；点的顺序无所谓，内部点会被丢掉 |
| `tolerance` | `float` | `1e-05` | **不建议改**：共线判定的容差，调大可能把近乎共线的点判成同一条边 |

#### 样例：七个散点求凸包

先把七个点用黄点画出来，再叠上 `ConvexHull(*pts)` 得到的最小凸多边形（绿色半透明）。

```python
import os
import subprocess
import sys
from real_time_manim import (
    Scene, Rectangle, Square, RoundedRectangle, Cutout, ConvexHull, Circle,
    Triangle, Dot, VGroup, Text,
    BLUE, GREEN, TEAL, PURPLE, ORANGE, YELLOW, GREY_B, WHITE,
    UP, DOWN, LEFT, RIGHT, ORIGIN,
    Create, FadeIn, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim.record import fast_record_scene

class ConvexHullDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("03b-ConvexHull", font_size=28, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        pts = [[-4.6, -1.2, 0], [-3.2, 1.4, 0], [-1.6, 0.2, 0], [-2.2, -1.6, 0],
               [-0.6, 1.0, 0], [0.4, -0.8, 0], [-1.0, 1.8, 0]]   #不规则的七个点
        dots = VGroup(*[Dot(p, radius=0.07, color=YELLOW) for p in pts])   #先把点画出来
        hull = ConvexHull(*pts, color=GREEN, fill_opacity=0.4)   #参数 “*points / tolerance”
        cap = Text("ConvexHull(*points, tolerance=1e-05)", font_size=19, color=GREY_B).move_to([-2.2, -2.7, 0])
        win.play(FadeIn(dots), run_time=0.5)   #散点
        win.play(FadeIn(hull), FadeIn(cap), run_time=0.8)   #凸包 + 字幕
        win.play(Wait(0.4))   #停留看结果
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：`pts` 是七个不规则散点，先 `FadeIn(dots)` 把点画出来，再 `FadeIn(hull)` 叠上 `ConvexHull(*pts)`——绿色多边形正好包住所有点：外侧的五个点成了顶点，中间那两个被丢在内部。点集顺序无所谓，`tolerance` 保持默认。

<video src="assets/RTM output/03b-矩形与特殊多边形-convexhull.mp4" controls width="560"></video>

> 提醒：至少给 3 个点，更少会退化成线段/点；`tolerance` 是共线容差，除非点数极多且手工验算过，不然不要动。
