# 基本形状（一）：圆弧、圆与点

几何最基础的一批形状：弧家族（`Arc` / `ArcBetweenPoints` / `TangentialArc`）、两点间的曲线箭头，以及圆与实心点。本节类全部定义在 `mobject/geometry/arc.py`，都继承 `Arc → TipableVMobject → VMobject`——因此都能加箭头尖端（见[箭头尖端](02b-箭头尖端.md)）、都能设填充描边样式（见[VMobject 样式](07-VMobject样式.md)）。本页三条样例均已在 RTM 实测出片。

## 参数

### Arc、ArcBetweenPoints（随 `01-基本形状-arc.mp4`）、TangentialArc（随 `01-基本形状-arc.mp4`）

```python
def __init__(self, radius: float | None = 1.0, start_angle: float = 0,
             angle: float = TAU / 4, num_components: int = 9,
             arc_center: Point3DLike = ORIGIN, **kwargs: Any) -> None:  # Arc

def __init__(self, start: Point3DLike, end: Point3DLike,
             angle: float = TAU / 4, radius: float | None = None,
             **kwargs: Any) -> None:  # ArcBetweenPoints

def __init__(self, line1: Line, line2: Line, radius: float,
             corner: Any = (1, 1), **kwargs: Any) -> None:  # TangentialArc
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `radius` | `float \| None` | `1.0`（`Arc`） | 圆弧半径，任意正数；`ArcBetweenPoints` 里默认 `None`（由 `angle` 推算） |
| `start_angle` | `float` | `0` | （`Arc`）起始角（弧度）：0 是正右方，逆时针为正 |
| `angle` | `float` | `TAU/4`（90°） | 张角（弧度）：负值顺时针；`ArcBetweenPoints`/`TangentialArc` 用它控制弯曲方向与大小 |
| `num_components` | `int` | `9` | （`Arc`）弧的分段数，越大越平滑；**不建议改**，默认已够用 |
| `arc_center` | `Point3DLike` | `ORIGIN` | （`Arc`）圆心坐标 |
| `start` / `end` | `Point3DLike` | 必填 | （`ArcBetweenPoints`）弧的两个端点坐标 |
| `line1` / `line2` | `Line` | 必填 | （`TangentialArc`）参与相交的两条**线对象**（内部求交点定弧心），不是方向向量 |
| `radius` | `float` | 必填 | （`TangentialArc`）拐角圆弧半径，**没有默认值，必须写** |
| `corner` | `tuple[int,int]` | `(1, 1)` | （`TangentialArc`）`(±1, ±1)` 四选一，挑交点四个象限里的拐角 |

> **返回**：弧对象（`Arc` 子类）。常用只读方法：`get_start()` / `get_end()` / `get_center()`（`Arc`）、`get_arc_angle()`（实际张角）。

#### 样例：弧家族三连

同一个视频里连画三个弧类：`Arc` 用 `arc_center` 直接定圆心、扫出上半圆并点出圆心位置；`ArcBetweenPoints` 用一对正/负 `angle` 展示"向哪边弯"；`TangentialArc` 先画两条相交虚线，再在交点处生成拐角圆弧。

```python
from real_time_manim import Scene, Arc, ArcBetweenPoints, TangentialArc, DashedLine, \
    Dot, Text, BLUE, GREEN, ORANGE, TEAL, YELLOW, GREY_B, UP, DOWN, PI, \
    Create, FadeIn, Write
from real_time_manim.vulkan_bind import MLWindow, Wait

class ArcDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("01-Arc family", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        # —— Arc：radius / start_angle / angle / arc_center ——
        arc = Arc(radius=1.2, start_angle=0, angle=PI, color=BLUE, stroke_width=8,
                  arc_center=[-4.6, -1.0, 0])   #半径 1.2、从正右方逆时针扫过 180° 的上半圆
        cdot = Dot([-4.6, -1.0, 0], radius=0.06, color=YELLOW)   #圆心点 = arc_center
        l1 = Text("Arc(angle=PI)", font_size=24, color=GREY_B)   #弧的标签
        l1.next_to(arc, DOWN, buff=0.3)   #放在弧的正下方
        win.play(Create(arc), FadeIn(cdot), run_time=0.8)   #画弧并点出圆心
        win.play(FadeIn(l1), run_time=0.3)   #标签淡入

        # —— ArcBetweenPoints：angle 控制弯曲方向与大小 ——
        ab1 = ArcBetweenPoints([-1.7, -0.3, 0], [1.7, -0.3, 0], angle=PI / 2,
                               color=GREEN, stroke_width=8)   #正角（逆时针）：向下兜成弧谷
        ab2 = ArcBetweenPoints([-1.7, -2.1, 0], [1.7, -2.1, 0], angle=-PI / 2,
                               color=ORANGE, stroke_width=8)   #负角（顺时针）：向上拱成弧背
        lu = Text("angle=+PI/2", font_size=24, color=GREY_B).next_to(ab1, UP, buff=0.15)
        ld = Text("angle=-PI/2", font_size=24, color=GREY_B).next_to(ab2, DOWN, buff=0.15)
        win.play(Create(ab1), FadeIn(lu), run_time=0.7)   #正角弧 + 上方标签
        win.play(Create(ab2), FadeIn(ld), run_time=0.7)   #负角弧 + 下方标签

        # —— TangentialArc：两条相交直线的拐角圆弧（corner 选象限）——
        ln1 = DashedLine([3.1, -1.0, 0], [6.1, -1.0, 0], color=GREY_B)   #参与相交的水平线
        ln2 = DashedLine([4.6, -2.7, 0], [4.6, 0.7, 0], color=GREY_B)   #参与相交的竖直线
        ta = TangentialArc(ln1, ln2, radius=0.9, corner=(1, 1), color=TEAL)   #交点处的拐角弧
        lt = Text("TangentialArc(corner=(1,1))", font_size=22, color=GREY_B)
        lt.next_to(ln1, DOWN, buff=0.25)   #放在水平虚线下方，避免与辅助线重叠
        win.play(Create(ln1), Create(ln2), run_time=0.6)   #先画两条辅助线
        win.play(Create(ta), FadeIn(lt), run_time=0.7)   #再画拐角弧 + 标签
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：先在画面里连画三种弧。左边 `Arc` 直接给圆心 `arc_center=[-4.6, -1.0, 0]`、半径 1.2、张角 `PI`，画出一个上半圆并在圆心点一个黄点；中间一对 `ArcBetweenPoints` 端点相同、`angle` 一正一负——正角从起点逆时针走弧（两端高中低的"弧谷"），负角顺时针走弧（中间高两端低的"弧背"）；右边先画两条相交的灰色虚线，再用 `TangentialArc` 在交点处生成半径 0.9 的拐角圆弧。

<video src="assets/RTM output/01-基本形状-arc.mp4" controls width="560"></video>

> 提醒：`TangentialArc` 收的是两条 **`Line` 对象**（内部求交点定弧心），别传方向向量；它的 `radius` 没有默认值，忘了写直接 `TypeError`。`Arc` 想换个位置画，用 `arc_center=` 比画完再 `shift` 更直观。`ArcBetweenPoints` 的弯曲方向口诀：两端点同高、从左往右看，正 `angle` 逆时针走弧得到"下弧谷"，负 `angle` 顺时针走弧得到"上拱背"。

### CurvedArrow（随 `01-基本形状-curved.mp4`）、CurvedDoubleArrow（随 `01-基本形状-curved.mp4`）

```python
def __init__(self, start_point: Point3DLike, end_point: Point3DLike,
             **kwargs: Any) -> None:  # CurvedArrow / CurvedDoubleArrow
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `start_point` / `end_point` | `Point3DLike` | 必填 | 曲线箭头的起点 / 终点 |
| `angle` | `float` | `TAU/4` | （继承 `ArcBetweenPoints`）弯曲角：正=逆时针拱，负=反向弯 |
| `radius` | `float \| None` | `None` | （继承）显式半径，`None` 由 `angle` 推算 |
| `**kwargs` | — | — | 其余透传给弧与尖端：`color`、`stroke_width` 等；尖端外形想换见[箭头尖端](02b-箭头尖端.md) |

> **返回**：带箭头尖端的弧对象。`CurvedDoubleArrow` 两端都有尖端，其余与 `CurvedArrow` 完全一致。

#### 样例：曲线箭头单头与双头

三条曲线箭头对比：默认弯向（正 `angle`，向上拱）、负 `angle` 反向弯（向下凸）、以及两端都带尖端的 `CurvedDoubleArrow`。

```python
from real_time_manim import Scene, CurvedArrow, CurvedDoubleArrow, Text, \
    BLUE, RED, GREEN, YELLOW, GREY_B, UP, TAU, Create, FadeIn, Write
from real_time_manim.vulkan_bind import MLWindow, Wait

class CurvedArrowDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("01-CurvedArrow / CurvedDoubleArrow", font_size=32, color=YELLOW)
        title.to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        ca1 = CurvedArrow([-3.2, 1.4, 0], [3.2, 1.4, 0], color=BLUE, stroke_width=6)   #默认 angle=TAU/4：向下兜成弧谷
        l1 = Text("CurvedArrow (default angle)", font_size=24, color=GREY_B)
        l1.next_to(ca1, UP, buff=0.1)   #标签放在箭头上方
        win.play(Create(ca1), FadeIn(l1), run_time=0.8)   #画出默认弯向的曲线箭头

        ca2 = CurvedArrow([-3.2, -0.4, 0], [3.2, -0.4, 0], angle=-TAU / 4,
                          color=GREEN, stroke_width=6)   #负角：弯向反过来（向上拱成弧背）
        l2 = Text("CurvedArrow(angle=-TAU/4)", font_size=24, color=GREY_B)
        l2.next_to(ca2, DOWN, buff=0.15)   #标签放在下方（弧线中间高、两端低）
        win.play(Create(ca2), FadeIn(l2), run_time=0.8)   #画出反向弯的曲线箭头

        cda = CurvedDoubleArrow([-3.2, -2.3, 0], [3.2, -2.3, 0], color=RED, stroke_width=6)   #两端都有尖端
        l3 = Text("CurvedDoubleArrow", font_size=24, color=GREY_B)
        l3.next_to(cda, UP, buff=0.2)   #标签放在弧谷里（凹面一侧，不出画）
        win.play(Create(cda), FadeIn(l3), run_time=0.8)   #画出双头曲线箭头
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：三条曲线箭头从上到下排开。第一条用默认参数（`angle=TAU/4`，逆时针走弧），在两端点之间向下兜成"弧谷"；第二条传 `angle=-TAU/4`，同样端点但弯向翻转、向上拱成"弧背"；第三条 `CurvedDoubleArrow` 形状与第一条相同但两端各多一个箭头尖端，表示"双向关系"，标签放在弧谷的凹面里。

<video src="assets/RTM output/01-基本形状-curved.mp4" controls width="560"></video>

> 提醒：直线箭头请用 `Arrow`（见[线与箭头](02-线与箭头.md)），`CurvedArrow` 是"带弯度"的版本，弯向只由 `angle` 的正负与大小决定。想让弯更明显就加大 `angle`（如 `PI`），或直接指定 `radius`。

### Circle、Dot

```python
def __init__(self, radius: float | None = None,
             color: ParsableManimColor = RED, **kwargs: Any) -> None:  # Circle

def __init__(self, point: Point3DLike = ORIGIN, radius: float = 0.08,
             stroke_width: float = 0, fill_opacity: float = 1.0,
             color: ParsableManimColor = WHITE, **kwargs: Any) -> None:  # Dot
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `radius` | `float \| None` | `None`（当 `1.0`） | （`Circle`）半径；任意正数 |
| `color` | `ManimColor` | `RED` | （`Circle`）描边颜色——注意默认是**红色**，且默认**无填充** |
| `point` | `Point3DLike` | `ORIGIN` | （`Dot`）圆点中心位置 |
| `radius` | `float` | `0.08` | （`Dot`）半径；做标注时常用 `0.12` ~ `0.2` |
| `stroke_width` | `float` | `0` | （`Dot`）描边宽度，默认无描边 |
| `fill_opacity` | `float` | `1.0` | （`Dot`）填充不透明度，`<1` 得到半透明点 |
| `color` | `ManimColor` | `WHITE` | （`Dot`）填充颜色 |

> **返回**：圆 / 圆点对象。`Circle` 常用方法：`surround(mobject)`（缩放到包住任意对象）、`point_at_angle(angle)`（取圆上一点）、`Circle.from_three_points(p1, p2, p3)`（过三点作圆）。

#### 样例：圆的包拢取点与默认红圈、三色圆点

左侧先让一个小圆 `animate.surround()` 套住方块，并在圆上 45° 处钉一个黄点；中间画一个不带任何参数的 `Circle()`，展示"默认半径 1、红色描边"；右侧三个 `Dot` 分别演示默认样式、放大改色、半透明。

```python
from real_time_manim import Scene, Circle, Dot, Square, Text, GREEN, BLUE, \
    YELLOW, ORANGE, TEAL, GREY_B, UP, DOWN, LEFT, RIGHT, DEGREES, \
    Create, FadeIn, Write
from real_time_manim.vulkan_bind import MLWindow, Wait

class CircleDotDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("01-Circle / Dot", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        # —— Circle.surround()：把圆缩放到包住任意对象 ——
        sq = Square(side_length=1.3, color=GREEN, fill_opacity=0.4).shift(LEFT * 4.2)   #被包住的方块
        cir = Circle(radius=0.55, color=BLUE, stroke_width=7).shift(LEFT * 4.2 + UP * 1.7)   #初始圆不套着方块
        l1 = Text("Circle.surround()", font_size=24, color=GREY_B)
        l1.next_to(sq, DOWN, buff=0.5)   #标签放在方块下方
        self.add(sq)   #方块先静态进场景
        win.play(FadeIn(cir), run_time=0.5)   #先看到“没套住”的小圆
        win.play(cir.animate.surround(sq), run_time=0.8)   #圆移动缩放，刚好包住方块（1.2 倍余量）
        win.play(FadeIn(l1), run_time=0.3)   #标签淡入
        pdot = Dot(cir.point_at_angle(45 * DEGREES), radius=0.07, color=YELLOW)   #在圆上 45° 处取一个点
        win.play(FadeIn(pdot), run_time=0.3)   #点出圆上的点

        # —— Circle 默认参数：radius=None 当 1，color=RED ——
        red_c = Circle().shift(RIGHT * 3.0)   #默认：半径 1、描边红色
        l2 = Text("Circle() default: r=1, RED", font_size=24, color=GREY_B)
        l2.next_to(red_c, DOWN, buff=0.35)   #标签放在红圈下方
        win.play(Create(red_c), FadeIn(l2), run_time=0.7)   #画出默认红圈

        # —— Dot：point / radius / color / fill_opacity ——
        d1 = Dot(point=[0.6, -2.5, 0])   #默认：半径 0.08、白色实心
        d2 = Dot(point=[2.2, -2.5, 0], radius=0.2, color=ORANGE)   #更大的橙色点
        d3 = Dot(point=[3.8, -2.5, 0], radius=0.12, color=TEAL, fill_opacity=0.5)   #半透明青点
        l3 = Text("Dot(radius=...)", font_size=24, color=GREY_B)
        l3.next_to(d2, DOWN, buff=0.4)   #标签放在中间那个点下方（避开红圈标签）
        win.play(FadeIn(d1), FadeIn(d2), FadeIn(d3), run_time=0.5)   #三个点一起淡入
        win.play(FadeIn(l3), run_time=0.3)   #标签淡入
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：左侧方块先进场，一个"没套住"的小圆从上方出现，随后 `surround()` 让圆平移缩放、刚好包住方块（默认留 1.2 倍余量），再用 `point_at_angle(45°)` 在圆周上点一个黄点；中间的 `Circle()` 什么参数都不传，展示"半径 1、红色描边、无填充"的默认长相；右侧三个圆点从左到右依次是默认白点、放大改橙色的点、半透明青点。

<video src="assets/RTM output/01-基本形状-circle_dot.mp4" controls width="560"></video>

> 提醒：`Circle` 默认**没有填充**（只有描边），想要实心圆得自己 `.set_fill(颜色, 不透明度)`；它的默认颜色是红色，别误当成"白色默认"。`Dot` 默认半径只有 0.08，在 1080p 画面里很小，做端点/节点标注时一般写 `radius=0.12` 起步。
