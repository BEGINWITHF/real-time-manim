# 基本形状（二）：标注点、扇环与自由曲线

承接[基本形状（一）](01-基本形状.md)的弧与圆形家族：本页讲三组对象——强调/标签圆点与椭圆、饼图式的扇环与圆环、以及手绘三次贝塞尔与"顶点间用弧连"的多边形。

走**原生**通道的有：

- `Ellipse`（`Circle` 子类，核心类已实渲染验证，2026-10-11）；
- `AnnotationDot` / `LabeledDot`（`Dot` 子类，`arc.py:826/846` → 原生 `_send_dot`）；
- 扇环家族 `AnnularSector` / `Sector` / `Annulus`（`Arc` / `Circle` 子类 → 原生 `_send_arc`，专项 `tests/test_arc_fill.py`、`tests/test_passing_flash_and_fill.py`）。

`CubicBezier` / `ArcPolygon` / `ArcPolygonFromArcs` 是 `VMobject` 直系、走通用回退，但已随本页样例正确出片。本页两条样例均已在 RTM 实测出片。

## 参数

### AnnotationDot（随 `01b-基本形状进阶-dots_ellipse.mp4`）、LabeledDot（随 `01b-基本形状进阶-dots_ellipse.mp4`）、Ellipse

```python
def __init__(self, radius: float = 0.104, stroke_width: float = 5,
             stroke_color: ParsableManimColor = WHITE,
             fill_color: ParsableManimColor = BLUE,
             **kwargs: Any) -> None:  # AnnotationDot

def __init__(self, label: str | SingleStringMathTex | Text | Tex,
             radius: float | None = None, buff: float = 0.1,
             **kwargs: Any) -> None:  # LabeledDot

def __init__(self, width: float = 2, height: float = 1,
             **kwargs: Any) -> None:  # Ellipse
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `radius` | `float` | `0.104` | （`AnnotationDot`）半径——比 `Dot` 默认值大 1.3 倍；**能填**任意正数 |
| `stroke_width` | `float` | `5` | （`AnnotationDot`）描边宽度，`0` 去掉白圈 |
| `stroke_color` | `ManimColor` | `WHITE` | （`AnnotationDot`）描边颜色 |
| `fill_color` | `ManimColor` | `BLUE` | （`AnnotationDot`）填充颜色，**能填**任意颜色字符串/`ManimColor` |
| `label` | `str \| MathTex \| Text \| Tex` | 必填 | （`LabeledDot`）点中心的标签；字符串自动按 `MathTex` 渲染（数学斜体），要普通字体就直接传 `Text` 对象 |
| `radius` | `float \| None` | `None` | （`LabeledDot`）半径；`None` 时按标签大小自适应 |
| `buff` | `float` | `0.1` | （`LabeledDot`）标签与点边缘的间距，仅 `radius=None` 自适应时生效 |
| `width` | `float` | `2` | （`Ellipse`）水平轴长 |
| `height` | `float` | `1` | （`Ellipse`）垂直轴长 |

> **返回**：圆点/椭圆对象（`Dot`、`Circle` 子类）。`AnnotationDot` 与 `Dot` 的差别就是"白描边 + 蓝底 + 大一圈"；`LabeledDot` 会把 `label` 放进点中央并自动缩放。

#### 样例：强调点、标签点与两种椭圆

左起先对比 `AnnotationDot` 和默认 `Dot`（谁是"圈重点"的点一目了然）；中间放一个按标签自适应半径、一个手动 `radius` 的 `LabeledDot`；右侧用 `width`/`height` 画一扁一瘦两个椭圆。

```python
from real_time_manim import Scene, AnnotationDot, LabeledDot, Ellipse, Dot, Text, \
    PURPLE, TEAL, YELLOW, GREY_B, UP, DOWN, Create, FadeIn, Write
from real_time_manim.vulkan_bind import MLWindow, Wait

class DotsEllipseDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("01b-AnnotationDot / LabeledDot / Ellipse", font_size=30, color=YELLOW)
        title.to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        # —— AnnotationDot：带白描边的强调圆点（对照默认 Dot）——
        ad = AnnotationDot().move_to([-4.2, 0.6, 0])   #默认：蓝底、白描边 5、半径 0.104（无位置参数，画完再挪）
        d = Dot([-2.7, 0.6, 0])   #对照：默认白色小点（半径 0.08、无描边）
        l1 = Text("AnnotationDot vs Dot", font_size=22, color=GREY_B)
        l1.move_to([-3.45, -0.15, 0])   #标签放在两点下方居中
        win.play(FadeIn(ad), FadeIn(d), run_time=0.5)   #两个点一起淡入
        win.play(FadeIn(l1), run_time=0.3)   #标签淡入

        # —— LabeledDot：中心带标签的圆点（字符串自动按 MathTex 渲染）——
        ld1 = LabeledDot("x").shift([0, 0.7, 0])   #半径按标签自适应
        ld2 = LabeledDot("42", radius=0.55).shift(DOWN * 1.15)   #半径手动指定
        l2 = Text("LabeledDot(label, radius)", font_size=22, color=GREY_B)
        l2.move_to([0, -2.35, 0])   #标签放在两个标签点下方
        win.play(FadeIn(ld1), run_time=0.5)   #自适应半径的标签点
        win.play(FadeIn(ld2), run_time=0.5)   #手动半径的标签点
        win.play(FadeIn(l2), run_time=0.3)   #标签淡入

        # —— Ellipse：width / height 两轴长 ——
        e1 = Ellipse(width=4.2, height=1.6, color=PURPLE).shift([4.3, 0.9, 0])   #扁椭圆
        e2 = Ellipse(width=1.6, height=3.0, color=TEAL).shift([4.3, -1.4, 0])   #瘦椭圆
        l3 = Text("Ellipse(width=, height=)", font_size=22, color=GREY_B)
        l3.move_to([4.3, -3.4, 0])   #标签放在两个椭圆下方
        win.play(Create(e1), run_time=0.6)   #画出扁椭圆
        win.play(Create(e2), run_time=0.6)   #画出瘦椭圆
        win.play(FadeIn(l3), run_time=0.3)   #标签淡入
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：画面从左到右分三块。

- 左边一蓝一白两个点并排：`AnnotationDot` 蓝底带白描边，比旁边的默认 `Dot` 大一圈，谁是"强调点"一眼分清。
- 中间先出现半径随标签自适应的 `LabeledDot("x")`，再出现手动 `radius=0.55` 的 `LabeledDot("42")`。
- 右侧先后画出"扁"和"瘦"两个椭圆，直观展示 `width`/`height` 分别拉哪个轴。

<video src="assets/RTM output/01b-基本形状进阶-dots_ellipse.mp4" controls width="560"></video>

> 提醒：
>
> - `LabeledDot` 的字符串标签走 `MathTex`（数学斜体样式）；想用普通字体（比如正文中文字）就直接传 `Text("标签")` 对象。
> - `AnnotationDot` 构造器**没有位置参数**——第一个位置参数是 `radius`。把坐标写进 `AnnotationDot([-4.2, 0.6, 0])` 会被当成半径，在原点画出一个巨大的怪圆（本页样例实测踩过）；挪位置请用 `.move_to(...)` / `.shift(...)`。
> - `AnnotationDot` 默认蓝底可能和蓝色系图形撞色，图里已有主色调时记得改 `fill_color=`。

### AnnularSector / Sector / Annulus（原生 `_send_arc`，随 `01b-基本形状进阶-sectors.mp4`）、CubicBezier / ArcPolygon / ArcPolygonFromArcs（通用回退，随同一视频）

```python
def __init__(self, inner_radius: float = 1, outer_radius: float = 2,
             angle: float = TAU / 4, start_angle: float = 0,
             fill_opacity: float = 1, stroke_width: float = 0,
             color: ParsableManimColor = WHITE,
             **kwargs: Any) -> None:  # AnnularSector

def __init__(self, radius: float = 1, **kwargs: Any) -> None:  # Sector

def __init__(self, start_anchor: Point3DLike, start_handle: Point3DLike,
             end_handle: Point3DLike, end_anchor: Point3DLike,
             **kwargs: Any) -> None:  # CubicBezier

def __init__(self, *vertices: Point3DLike, angle: float = TAU / 4,
             radius: float | None = None, arc_config: list[dict] | None = None,
             **kwargs: Any) -> None:  # ArcPolygon

def __init__(self, *arcs: Arc | ArcBetweenPoints, **kwargs: Any) -> None:  # ArcPolygonFromArcs
```

扇环家族（`Sector`、`Annulus` 均与 `AnnularSector` 共用下列参数）：

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `inner_radius` | `float` | `1` | 内半径；`Sector` 无此参数（它就是 `inner_radius=0` 的特例，只有 `radius`） |
| `outer_radius` | `float` | `2` | 外半径（`Annulus` 同）；**能填**任意大于内半径的正数 |
| `radius` | `float` | `1` | （`Sector`）扇形半径 |
| `angle` | `float` | `TAU/4`（90°） | 张角（弧度），负值反向 |
| `start_angle` | `float` | `0` | 起始角（弧度） |
| `fill_opacity` | `float` | `1` | 填充不透明度，默认纯色实心 |
| `stroke_width` | `float` | `0` | 描边宽度，默认**无描边**；要勾边自己设 |
| `color` | `ManimColor` | `WHITE` | 颜色（默认白色，图表场景记得换色） |
| `mark_paths_closed` | `bool` | `False` | （`Annulus`）路径闭合标记，**不建议改** |

手绘曲线与弧多边形：

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `start_anchor` / `end_anchor` | `Point3DLike` | 必填 | （`CubicBezier`）曲线的起点/终点（锚点在曲线上） |
| `start_handle` / `end_handle` | `Point3DLike` | 必填 | （`CubicBezier`）起点/终点处的控制柄（点不在曲线上，只"拉"曲线） |
| `*vertices` | `Point3DLike...` | 必填 | （`ArcPolygon`）顶点坐标，**每个参数是一组？不是——每个位置参数就是一个顶点** |
| `angle` | `float` | `TAU/4` | （`ArcPolygon`）所有边统一的弯曲角（弧度） |
| `radius` | `float \| None` | `None` | （`ArcPolygon`）按固定半径弯，给了 `angle` 就失效 |
| `arc_config` | `list[dict] \| None` | `None` | （`ArcPolygon`）逐边定制弯曲（每边一个 `{"radius":..., "arc_center":...}` 字典），与 `angle` 二选一 |
| `*arcs` | `Arc \| ArcBetweenPoints...` | 必填 | （`ArcPolygonFromArcs`）已经画好的弧，要求**首尾相接**（前一段 `end` == 后一段 `start`） |

> **返回**：填色块 / 曲线对象。`Sector` ≡ `AnnularSector(inner_radius=0)`；`CubicBezier` 继承 `VMobject`，端点可用 `get_start()`/`get_end()` 读取。

#### 样例：扇环三件套、贝塞尔与弧边多边形

上排三块填色形状从左到右：内外半径可调的 `AnnularSector`、饼图切块 `Sector`、甜甜圈 `Annulus`；下排三条"线"：四点拉出的 S 形 `CubicBezier`、三顶点边弯 `PI/6` 的 `ArcPolygon`、以及两段弧首尾相接的 `ArcPolygonFromArcs`。

```python
from real_time_manim import Scene, AnnularSector, Sector, Annulus, CubicBezier, \
    ArcPolygon, ArcPolygonFromArcs, ArcBetweenPoints, Text, \
    ORANGE, RED, GREEN, BLUE, TEAL, PURPLE, YELLOW, GREY_B, \
    UP, DOWN, LEFT, RIGHT, PI, TAU, Create, FadeIn, Write
from real_time_manim.vulkan_bind import MLWindow, Wait

class SectorsDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("01b-AnnularSector / Sector / Annulus / Bezier / ArcPolygon",
                     font_size=24, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        # —— 第一排：三种"扇环/圆环"填色块 ——
        asec = AnnularSector(inner_radius=0.5, outer_radius=1.2, angle=2.0,
                             start_angle=PI / 2, color=ORANGE).shift(LEFT * 4.4 + UP * 0.9)   #环形扇区
        cap1 = Text("AnnularSector", font_size=20, color=GREY_B).next_to(asec, DOWN, buff=0.3)
        win.play(Create(asec), FadeIn(cap1), run_time=0.6)   #画出环形扇区

        sec = Sector(radius=0.95, angle=TAU / 3, color=RED).shift(UP * 0.9)   #实心扇形（饼图一块）
        cap2 = Text("Sector", font_size=20, color=GREY_B).next_to(sec, DOWN, buff=0.3)
        win.play(Create(sec), FadeIn(cap2), run_time=0.6)   #画出实心扇形

        ann = Annulus(inner_radius=0.4, outer_radius=1.0, color=GREEN).shift(RIGHT * 4.4 + UP * 0.9)   #圆环（甜甜圈）
        cap3 = Text("Annulus", font_size=20, color=GREY_B).next_to(ann, DOWN, buff=0.3)
        win.play(Create(ann), FadeIn(cap3), run_time=0.6)   #画出圆环

        # —— 第二排：手绘贝塞尔、顶点间用弧连的多边形 ——
        cb = CubicBezier([-6.2, -2.6, 0], [-4.9, -0.9, 0], [-3.9, -3.5, 0], [-2.7, -1.8, 0],
                         color=PURPLE, stroke_width=6)   #两个锚点 + 两个控制柄
        cap4 = Text("CubicBezier(4 pts)", font_size=20, color=GREY_B).move_to([-4.45, -3.7, 0])
        win.play(Create(cb), FadeIn(cap4), run_time=0.6)   #画出 S 形贝塞尔曲线

        ap = ArcPolygon([-1.7, -2.9, 0], [0, -1.5, 0], [1.7, -2.9, 0],
                        angle=PI / 6, color=BLUE, stroke_width=6)   #三顶点、边用弧连
        cap5 = Text("ArcPolygon(angle=PI/6)", font_size=20, color=GREY_B).move_to([0, -3.7, 0])
        win.play(Create(ap), FadeIn(cap5), run_time=0.6)   #画出弧边三角

        a1 = ArcBetweenPoints([2.7, -2.9, 0], [4.4, -1.6, 0], angle=-PI / 3, color=TEAL)   #上拱的第一段弧
        a2 = ArcBetweenPoints([4.4, -1.6, 0], [6.1, -2.9, 0], angle=PI / 3, color=TEAL)   #下凹的第二段弧
        apa = ArcPolygonFromArcs(a1, a2)   #两段弧首尾相接拼成一个对象
        cap6 = Text("ArcPolygonFromArcs", font_size=20, color=GREY_B).move_to([4.4, -3.7, 0])
        win.play(Create(a1), run_time=0.4)   #先画第一段
        win.play(Create(a2), run_time=0.4)   #再画第二段
        win.play(FadeIn(cap6), run_time=0.3)   #标签淡入
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：上排依次画出三块填色形状，每个都配了小字幕。

- 橙色环形扇区：`inner_radius=0.5` 把中心挖空。
- 红色饼图切块：`Sector`，实心到圆心。
- 绿色圆环：内 0.4 外 1.0 的甜甜圈。

下排依次画出三条"线"：先用四个点拉出一条紫色 S 形三次贝塞尔，再画"三个顶点、边按 `angle=PI/6` 弯曲"的弧边三角，最后把两段 `ArcBetweenPoints`（上拱 + 下凹）用 `ArcPolygonFromArcs` 拼成一个连续对象。

<video src="assets/RTM output/01b-基本形状进阶-sectors.mp4" controls width="560"></video>

> 提醒：
>
> - `Sector` 就是"挖到圆心"的扇形，想要环形中心挖空必须用 `AnnularSector`；扇环家族默认 `fill_opacity=1、stroke_width=0`（纯色无线条），要网格感自己补 `stroke_width=2`。
> - `ArcPolygonFromArcs` 要求相邻弧**严格首尾相接**（第一段 `end` 与第二段 `start` 同一点），差一点就会拼出断口。
> - `CubicBezier` 四个位置参数的顺序是"起点锚 → 起点柄 → 终点柄 → 终点锚"，别把锚和柄写反——写反了曲线会飞出预期范围。
> - `ArcPolygon` 每条边的凹向由**顶点书写顺序与 `angle` 正负共同决定**：本例按"上→左→右"给点得到的是向内凹的弧边（像三尖星），换顶点顺序或 `angle` 符号即可翻转凹凸。
