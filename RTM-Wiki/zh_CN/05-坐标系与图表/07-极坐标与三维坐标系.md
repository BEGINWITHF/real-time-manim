# 极坐标与三维坐标系

非直角坐标与 3D：`PolarPlane` 极坐标平面（`plot_polar_graph` 按 `r=f(θ)` 画线），`ThreeDAxes` 三维坐标系（`c2p(x,y,z)` 换算、`move_camera` 转视角），`Axes.plot_surface` 参数方程曲面。三个样例都已实渲染并（`surface` 见下节）。

> 提醒：3D 场景必须用 `ThreeDScene` 且**先** `self.play = win.play` 再 `move_camera`——`move_camera` 内部调 `self.play`，不接上会直接报错或画面不动。

## PolarPlane

```python
def __init__(
    self,
    radius_max: float = 4.0,
    size: float | None = None,
    radius_step: float = 1,
    azimuth_step: int | None = None,
    azimuth_units: str = "PI radians",
    azimuth_compact_fraction: bool = True,
    azimuth_offset: float = 0,
    azimuth_direction: str = "CCW",
    azimuth_label_buff: float = 0.1,
    azimuth_label_font_size: int = 24,
    radius_config: dict[str, Any] | None = None,
    background_line_style: dict[str, Any] | None = None,
    faded_line_style: dict[str, Any] | None = None,
    faded_line_ratio: int = 1,
    make_smooth_after_applying_functions: bool = True,
    **kwargs: Any,
):
```

极坐标平面：同心圆 = 半径刻度、放射线 = 角度刻度，支持 `add_coordinates()`（半径数字 + 角度标签）。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `radius_max` | `float` | `4.0` | 最大半径 |
| `size` | `float \| None` | `None` | 平面直径（给定后覆盖半径自动定标） |
| `radius_step` | `float` | `1` | 同心圆间隔 |
| `azimuth_units` | `str` | `"PI radians"` | 角度标注单位：`"PI radians"`/`"radians"`/`"degrees"` |
| `azimuth_step` | `int \| None` | `None` | 放射线间隔（π 分数个数） |
| `azimuth_direction` | `str` | `"CCW"` | 角度正方向（`CCW`/`CW`） |
| `azimuth_label_font_size` | `int` | `24` | 角度标签字号 |
| `background_line_style` | `dict \| None` | `None` | 同心圆与放射线样式（`stroke_color`/`stroke_width`…） |
| `faded_line_ratio` | `int` | `1` | 细分淡化线密度（`0` 关闭） |

#### 样例：`plot_polar_graph` 画五瓣玫瑰线

`PolarPlane(size=6)` 按 π 分数标角度、`add_coordinates()` 加刻度数字，`plot_polar_graph(lambda th: 2*sin(5θ))` 画出五瓣玫瑰线。

```python
import os
import subprocess
import sys
from real_time_manim import (
    Scene, ThreeDScene, ThreeDAxes, PolarPlane, Dot, Text, np,
    YELLOW, TEAL, BLUE, ORANGE, RED, GREEN, GREY_B, UP, DOWN, UR, TAU,
    Create, FadeIn, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim.record import fast_record_scene

class PolarDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("07-PolarPlane", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        plane = PolarPlane(size=5,   #参数 “size”：平面直径
                           azimuth_units="PI radians",   #参数 “azimuth_units”：方位角按 π 分数标注
                           background_line_style={"stroke_color": TEAL, "stroke_width": 2},   #同心圆与放射线样式
                           ).add_coordinates()   #“add_coordinates”：半径数字 + 角度标签
        rose = plane.plot_polar_graph(lambda th: 2 * np.sin(th * 5),   #“plot_polar_graph”：按 r=f(θ) 画极坐标曲线
                                      theta_range=[0, TAU], color=ORANGE)   #五瓣玫瑰线
        lab = Text("plot_polar_graph(2*sin(5*theta))",
                   font_size=18, color=GREY_B).to_edge(DOWN, buff=0.3)   #参数说明标签
        win.play(Create(plane), FadeIn(lab), run_time=1.0)   #极坐标平面（含标签）与说明一起出场
        win.play(Create(rose), run_time=1.2)   #画出玫瑰线
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口


# ===== 样例 2：ThreeDAxes 三维坐标系 ======================================
```

这段代码在做什么：`PolarPlane` 的同心圆与放射线是 `background_line_style` 统一样式的网格；`plot_polar_graph` 接受 `r(θ)` 标量函数（不是 `(x,y)` 向量），内部按 `theta_range=[0, TAU]` 采样后转成直角坐标连线，`2*sin(5θ)` 是经典的五瓣玫瑰线。

<video src="assets/RTM output/07-极坐标与三维坐标系-polar.mp4" controls width="560"></video>

> 提醒：`plot_polar_graph` 的函数返回**半径**（标量）不是坐标；RTM 与 CE 的 `Create(PolarPlane)` 中间帧绘制顺序略有差异（最终画面一致），逐帧比对时按最终帧验收。

## ThreeDAxes

```python
def __init__(
    self,
    x_range: Sequence[float] | None = (-6, 6, 1),
    y_range: Sequence[float] | None = (-5, 5, 1),
    z_range: Sequence[float] | None = (-4, 4, 1),
    x_length: float | None = 10.5,
    y_length: float | None = 10.5,
    z_length: float | None = 6.5,
    z_axis_config: dict[str, Any] | None = None,
    z_normal: Vector3DLike = array([0.0, -1.0, 0.0]),
    num_axis_pieces: int = 20,
    light_source: Point3DLike = array([-7.0, -9.0, 10.0]),
    depth: Any = None,
    gloss: float = 0.5,
    **kwargs,
):
```

三维坐标系（`Axes` 的 3D 版）：x/y/z 三轴 + `c2p(x, y, z)` 三维换算，`add_coordinates(x, y, z)` 分轴加刻度。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `x_range` / `y_range` / `z_range` | `Sequence[float] \| None` | `(-6,6,1)`/`(-5,5,1)`/`(-4,4,1)` | 各轴数据范围与刻度步长 |
| `x_length` / `y_length` / `z_length` | `float \| None` | `10.5`/`10.5`/`6.5` | 各轴屏幕长度 |
| `z_axis_config` | `dict \| None` | `None` | z 轴样式 |
| `z_normal` | `Vector3DLike` | `[0,-1,0]` | z 轴朝向 |
| `gloss` | `float` | `0.5` | **上游参数，RTM 的 Vulkan 渲染路径不读取（无视觉效果）**——它只出现在 manim 自带的 OpenGL shader 里（`manim/renderer/shaders/**/*.glsl`），RTM 不走那条链路，改这个值不会有任何变化 |

#### 样例：`ThreeDAxes` + `move_camera` 看深度

`ThreeDAxes` 配刻度后放两个空间点 `c2p(1,1,2)`/`c2p(-2,2,-3)`，`move_camera(theta=-0.6, phi=1.1)` 转到 3D 视角，两个点的深度差立刻可见。

```python
import os
import subprocess
import sys
from real_time_manim import (
    Scene, ThreeDScene, ThreeDAxes, PolarPlane, Dot, Text, np,
    YELLOW, TEAL, BLUE, ORANGE, RED, GREEN, GREY_B, UP, DOWN, UR, TAU,
    Create, FadeIn, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim.record import fast_record_scene

class ThreeDAxesDemo(ThreeDScene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        self.play = win.play   #move_camera 内部会调 self.play，必须先接上
        title = Text("07-ThreeDAxes", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        ax = ThreeDAxes(x_range=(-3, 3, 1), y_range=(-3, 3, 1), z_range=(-4, 4, 1),   #三轴数据范围
                        x_length=7, y_length=7, z_length=5)   #各轴屏幕长度
        ax.add_coordinates(range(-2, 3), None, range(-4, 5, 2))   #“add_coordinates”：x/z 轴给定刻度，y 轴默认
        d1 = Dot(ax.c2p(1, 1, 2), color=RED)   #“c2p”：三维数据坐标 -> 场景点
        d2 = Dot(ax.c2p(-2, 2, -3), color=GREEN)
        lab = Text("ThreeDAxes + c2p(1,1,2) / c2p(-2,2,-3)",
                   font_size=24, color=GREY_B).to_edge(DOWN)   #方法说明标签
        win.play(Create(ax), FadeIn(lab), run_time=0.8)   #三维坐标系与说明一起出场
        win.play(FadeIn(d1), FadeIn(d2), run_time=0.4)   #两个空间点淡入
        self.move_camera(theta=-0.6, phi=1.1, run_time=1.0)   #“move_camera”：转到 3D 视角看深度
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口


# ===== 样例 3：Axes.plot_surface 曲面 ======================================
```

这段代码在做什么：`self.play = win.play` 把 manim 的 `self.play` 接到 RTM 窗口上（`move_camera` 内部会调它）；`c2p(1,1,2)` 把三维数据坐标换成场景点直接喂 `Dot`；`move_camera(theta=-0.6, phi=1.1)` 旋转相机——初始视角下红绿两点重叠区看不出深度，转过之后 z 方向的距离立刻拉开。

<video src="assets/RTM output/07-极坐标与三维坐标系-threed.mp4" controls width="560"></video>

> 提醒：**顺序**是先 `win.scene = self` 再 `self.play = win.play`，`move_camera` 才生效；`add_coordinates` 三个参数分别对应 x/y/z 轴（`None` = 默认刻度）。

## plot_surface

`Axes.plot_surface(function, u_range, v_range, resolution)` 把 `f(u, v)` 采成一张参数曲面（`resolution=(u 段数, v 段数)`），返回一个 `Surface`，可以像普通 mobject 一样 `FadeIn` / `Create` / 变换。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `function` | `Callable[[float, float], float]` | 必填 | 参数方程高度函数 `f(u, v)` |
| `u_range` / `v_range` | `Sequence[float]` | `(0,1)` | 两个参数区间 |
| `resolution` | `Sequence[int]` | `(32,32)` | u/v 方向各切几段（段数越小面片越粗） |

#### 样例：`plot_surface(sin(u)·cos(v))` 看曲面起伏

在同一套 `ThreeDAxes` 上画 `sin(u)*cos(v)`，`resolution=(12, 12)` 让面片清晰可见，最后 `move_camera` 转到 3D 视角看起伏。

```python
import os
import subprocess
import sys
from real_time_manim import (
    Scene, ThreeDScene, ThreeDAxes, PolarPlane, Dot, Text, np,
    YELLOW, TEAL, BLUE, ORANGE, RED, GREEN, GREY_B, UP, DOWN, UR, TAU,
    Create, FadeIn, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim.record import fast_record_scene

class SurfaceDemo(ThreeDScene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        self.play = win.play   #move_camera 内部会调 self.play，必须先接上
        title = Text("07-plot_surface", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        ax = ThreeDAxes(x_range=(-3, 3, 1), y_range=(-3, 3, 1), z_range=(-2, 2, 1))   #三轴数据范围
        surf = ax.plot_surface(lambda u, v: np.sin(u) * np.cos(v),   #“plot_surface”：参数方程曲面
                               u_range=(-3, 3), v_range=(-3, 3), resolution=(12, 12))   #u/v 范围与网格分辨率
        lab = Text("plot_surface(sin(u)*cos(v))",
                   font_size=24, color=GREY_B).to_edge(DOWN)   #方法说明标签
        win.play(Create(ax), FadeIn(lab), run_time=0.6)   #坐标系与说明一起出场
        win.play(FadeIn(surf), run_time=0.6)   #曲面淡入
        self.move_camera(theta=-0.6, phi=1.1, run_time=1.0)   #转到 3D 视角看曲面起伏
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：`plot_surface` 先按 `resolution` 把 `u_range × v_range` 切成参数网格，每个网格单元取四个角 `c2p(u, v, f(u,v))` 连成一个面片再交给渲染器；`resolution=(12, 12)` 一共 144 个面片，`FadeIn` 之后每张面片各自按自己的法线着色，所以转过视角后能看到 `sin(u)·cos(v)` 的波峰波谷。这是**参数曲面**——`u`/`v` 不经过 `c2p`，直接喂 `plot_surface` 自己的高度函数。

<video src="assets/RTM output/07-极坐标与三维坐标系-surface.mp4" controls width="560"></video>

> 提醒：`plot_surface` **参数曲面**（`(u,v) → f(u,v)`）与 `plot` （`x → f(x)`）不是一回事；`resolution` 是**段数**不是点数，`(12, 12)` 出 12×12 = 144 个面片，段数太低曲面会呈多边形。本页 RTM 版与 ManimCE 版逐帧对齐（198 帧 / 3.30s，`frames>4.0: 0`，`tests/test_plot_surface.py` 覆盖）。
