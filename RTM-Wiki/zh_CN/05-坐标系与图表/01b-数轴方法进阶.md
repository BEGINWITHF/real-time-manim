# 数轴方法进阶（换算、标签与刻度）

`NumberLine` 构造参数之外的全部常用方法：数值 ⇄ 场景点双向换算（`n2p`/`p2n`）、事后挂数字与任意标签（`add_numbers`/`add_labels`）、补刻度与统一改色（`add_ticks`/`get_tick_marks`）、绕数值旋转（`rotate_about_number`）。

## 方法

### n2p / p2n（数值 ⇄ 场景点）

```python
def number_to_point(number: float | np.ndarray) -> np.ndarray:   #别名 n2p
def point_to_number(point: Point3DLike) -> float:                #别名 p2n
```

数轴上"数值 ↔ 场景坐标"的双向换算，摆放一切元素（`Dot`、`Text`、`next_to`）的唯一正确途径；缩放型数轴（`LogBase`）会先经过 `scaling.inverse_function`。也支持 `数轴 @ 数值` 写法。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `number` | `float \| np.ndarray` | 必填 | 数轴上的值；可传数组一次换算多个 |
| `point` | `Point3DLike` | 必填 | 场景坐标点 `[x, y, z]`，可传点数组 |

> **返回**：`n2p` → `np.ndarray` 场景点；`p2n` → `float`（数组输入返回 `np.ndarray`）。

#### 样例：`n2p`/`p2n`/`@` 双向换算

红点先用 `n2p(1.5)` 落位、再沿轴移动，到站后用 `p2n` 把场景坐标回读成数值文字；黄点演示 `数轴 @ 数值` 的 `@` 写法。

```python
from real_time_manim import Scene, NumberLine, Dot, Text, \
    YELLOW, RED, GREEN, GREY_B, UP, DOWN, Create, FadeIn, Write
from real_time_manim.vulkan_bind import MLWindow, Wait

class N2PP2NDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("01b-n2p-p2n", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        line = NumberLine(x_range=[-2.5, 3, 0.5], length=10)   #半格步长数轴
        line.add_numbers(x_values=[-2, 0, 2])   #只在 -2/0/2 处挂数字
        lab = Text("n2p/p2n  value <-> point", font_size=28,
                   color=GREY_B).next_to(line, DOWN, buff=0.6)   #方法说明标签
        win.play(Create(line), run_time=0.8)   #画出数轴
        win.play(FadeIn(lab), run_time=0.3)   #标签淡入

        red = Dot(line.n2p(1.5), color=RED)   #“n2p”：数值 1.5 -> 场景点
        readout = Text("p2n=0.00", font_size=28, color=GREEN).next_to(lab, DOWN, buff=0.35)
        win.play(FadeIn(red), FadeIn(readout), run_time=0.4)   #红点与回读标签淡入
        win.play(red.animate.move_to(line.n2p(-1.5)), run_time=1.0)   #红点移到数值 -1.5
        point = red.get_center()   #取红点当前场景坐标
        readout.become(Text("p2n=%.2f" % line.p2n(point),   #“p2n”：场景点 -> 数值，回读成文字
                            font_size=28, color=GREEN).next_to(lab, DOWN, buff=0.35))
        win.play(Wait(0.6))   #停 0.6s 看回读结果

        yel = Dot(line @ 3, color=YELLOW)   #“@” 写法：等价于 n2p(3)
        tag = Text("line @ 3", font_size=28, color=YELLOW).next_to(yel, UP, buff=0.3)
        win.play(FadeIn(yel), FadeIn(tag), run_time=0.4)   #黄点与标签淡入
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：红点出生在 `n2p(1.5)`（数值 1.5 对应的场景点），平移到 -1.5 后，`p2n(red.get_center())` 把它的场景坐标反算回数值，`-1.50` 直接显示在屏幕下方——两个方法互为逆运算。黄点用 `line @ 3` 摆到数值 3，效果与 `n2p(3)` 完全一样。

<video src="assets/RTM output/01b-数轴方法进阶-n2p_p2n.mp4" controls width="560"></video>

> 提醒：`数轴 @ 数值` 只接受标量数值；反过来 `点 @ 数轴` 只能传普通 `list`/`tuple`——`np.ndarray` 会被 numpy 抢先解释成矩阵乘法而报错，稳妥就用 `p2c`/`p2n`。

### add_numbers / add_labels

```python
def add_numbers(self, x_values: Iterable[float] | None = None, excluding: Iterable[float] | None = None,
                font_size: float | None = None, label_constructor: type | None = None,
                **kwargs) -> Self
def add_labels(self, dict_values: dict[float, str | float | VMobject], direction: Point3DLike | None = None,
               buff: float | None = None, font_size: float | None = None,
               label_constructor: type | None = None) -> Self
```

`add_numbers` 在指定数值位置挂 `DecimalNumber` 标签（`x_values=None` 时使用 `get_tick_range()` 的全部刻度值），创建后通过 `self.numbers` 访问；`add_labels` 用 `{数值: 标签}` 字典在指定位置放任意标签（`Axes.add_coordinates(dict)` 内部就是调它），标签组存入 `self.labels`。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `x_values` | `Iterable[float] \| None` | `None` | 要标注的数值，默认全部刻度 |
| `excluding` | `Iterable[float] \| None` | `numbers_to_exclude` | 排除的数值 |
| `dict_values` | `dict[float, str \| float \| VMobject]` | 必填 | 如 `{1: "Monday"}`；`str` 交给 `label_constructor` |
| `direction` | `Point3DLike \| None` | `label_direction` | 标签相对数轴的摆放方向 |
| `buff` | `float \| None` | `line_to_number_buff` | 与数轴的距离 |
| `font_size` | `float \| None` | `font_size` | 字号（标签须有 `font_size` 属性，否则抛 `AttributeError`） |
| `label_constructor` | `type \| None` | 数轴的 `label_constructor` | 生成 `str` 标签的类 |
| `**kwargs` | — | — | `add_numbers` 透传给 `get_number_mobject`（如 `num_decimal_places`） |

> **返回**：`Self`（链式调用）。

#### 样例：`add_numbers` 指定数值 + `add_labels` 任意标签

同一条半格步长数轴：`add_numbers([-2,0,2], num_decimal_places=1)` 只标三个一位小数，`add_labels({0:"start", 3:"end"}, direction=UP)` 在轴上方放两个文字标签。

```python
from real_time_manim import Scene, NumberLine, Text, \
    YELLOW, GREY_B, UP, DOWN, Create, FadeIn, Write
from real_time_manim.vulkan_bind import MLWindow, Wait

class AddNumbersLabelsDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("01b-add_numbers-labels", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        line = NumberLine(x_range=[-2.5, 3, 0.5], length=10)   #半格步长数轴
        line.add_numbers(x_values=[-2, 0, 2], num_decimal_places=1)   #“add_numbers”：只标指定数值，保留一位小数
        line.add_labels({0: "start", 3: "end"}, direction=UP, font_size=28)   #“add_labels”：数值换成任意文字标签
        lab = Text("add_numbers([-2,0,2]) + add_labels({0:start,3:end})",
                   font_size=24, color=GREY_B).next_to(line, DOWN, buff=0.6)   #方法说明标签
        win.play(Create(line), run_time=0.8)   #画出数轴
        win.play(FadeIn(lab), run_time=0.4)   #标签淡入
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：数轴的刻度是 0.5 一格，但 `add_numbers(x_values=[-2, 0, 2], num_decimal_places=1)` 只在 -2.0、0.0、2.0 三处挂数字——数字位置不必与刻度一一对应，`num_decimal_places` 通过 `**kwargs` 透传给数字生成器。`add_labels({0: "start", 3: "end"}, direction=UP)` 再在轴**上方**放两个自定义文字，字典的键决定位置、值就是显示内容。

<video src="assets/RTM output/01b-数轴方法进阶-addnumbers.mp4" controls width="560"></video>

> 提醒：`add_labels` 的 `str` 值默认走 `MathTex`（数学斜体），想要正体观感可以传 `Text` 对象当值或改 `label_constructor=Text`；`font_size` 要求标签对象有同名属性，传 `Text`/`MathTex`/`DecimalNumber` 都有，裸 `VMobject` 没有会抛 `AttributeError`。

### 刻度与旋转：get_tick_range / add_ticks / get_tick_marks / rotate_about_number / get_unit_size

```python
def get_tick_range(self) -> np.ndarray                  #按 x_range 算出应有刻度的数值数组
def add_ticks(self) -> None                             #按 x_range 补画刻度
def get_tick(self, x: float, size: float | None = None) -> Line
def get_tick_marks(self) -> VGroup                      #全部刻度组
def rotate_about_number(self, number: float, angle: float, axis: Vector3D = OUT, **kwargs) -> Self
def get_unit_size(self) -> float                        #1 个数值单位 = 多少 Manim 长度
def get_unit_vector(self) -> Vector3D                   #每单位的有向步长
```

`get_tick_range()` 考虑 `exclude_origin_tick` 与 `scaling`，是 `include_numbers`/`add_ticks` 的幕后计算；`get_tick(x)` 造单根刻度，`get_tick_marks()` 取回全部刻度组统一改色/做动画；`rotate_about_number` 绕某个数值对应的点旋转整条轴（`ThreeDAxes` 摆放 z 轴也用它）。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `x` / `number` | `float` | 必填 | 刻度所在数值 / 旋转中心对应的数值 |
| `size` | `float \| None` | `tick_size` | 单根刻度的缩放系数（仅 `get_tick`） |
| `angle` | `float` | 必填 | 旋转角（弧度） |
| `axis` | `Vector3D` | `OUT` | 旋转轴 |

> **返回**：见签名；`rotate_about_number` 返回 `Self`（可链式调用）。

#### 样例：`add_ticks`/`get_tick_marks` 补刻度改色，`rotate` 绕零旋转

先造一条不带刻度的数轴，`add_ticks()` 事后补刻度、`get_tick_marks()` 取全部刻度统一染黄，再显示 `get_unit_size()` 的值并把整条轴绕数值 0 旋转 0.5 弧度。

```python
from real_time_manim import Scene, NumberLine, Text, VGroup, \
    YELLOW, GREEN, GREY_B, UP, DOWN, Create, FadeIn, Write
from real_time_manim.vulkan_bind import MLWindow, Wait

class TicksRotateDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("01b-ticks-rotate", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        line = NumberLine(x_range=[-2, 2, 1], length=6, include_ticks=False)   #先不画刻度
        line.add_ticks()   #“add_ticks”：事后按 x_range 补齐刻度
        line.get_tick_marks().set_color(YELLOW)   #“get_tick_marks”：取全部刻度统一改色
        lab1 = Text("add_ticks() + get_tick_marks().set_color(YELLOW)",
                    font_size=24, color=GREY_B).next_to(line, DOWN, buff=0.6)   #方法说明标签
        lab2 = Text("unit_size=%.2f" % line.get_unit_size(),   #“get_unit_size”：1 个数值单位的屏幕长度
                    font_size=26, color=GREEN).next_to(lab1, DOWN, buff=0.3)
        win.play(Create(line), run_time=0.8)   #画出数轴（含补的黄色刻度）
        win.play(FadeIn(VGroup(lab1, lab2)), run_time=0.4)   #两行标签淡入
        win.play(Wait(0.4))   #停留看刻度颜色
        win.play(line.animate(run_time=1.0).rotate(0.5, about_point=line.n2p(0)))   #绕数值 0 对应点整体旋转
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：`include_ticks=False` 造一条光杆轴，`add_ticks()` 按 `x_range` 事后把刻度补回来，`get_tick_marks()` 把它们一把抓出来染成黄色（`get_tick(2.0)` 也可以单独造/改某一根）。屏幕下方显示 `get_unit_size()`——本例 `length=6`、跨度 4，正好每数值单位 1.5。最后 `rotate(0.5, about_point=line.n2p(0))` 绕数值 0 对应的场景点把整条轴转起来，效果与 `rotate_about_number(0, 0.5)` 相同。

### 数字 mobject：get_number_mobject / get_number_mobjects / get_labels（只留表格）

```python
def get_number_mobject(self, x: float, direction: Vector3D | None = None, buff: float | None = None,
                       font_size: float | None = None, label_constructor: type | None = None,
                       **number_config) -> VMobject
def get_number_mobjects(self, *numbers: float, **kwargs) -> VGroup
def get_labels(self) -> VGroup
```

生成"摆好位置"的数字 mobject 而**不立即加入**数轴，适合单独对某个数字做动画；`get_labels()` 等价于无参的 `get_number_mobjects()`。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `x` | `float` | 必填 | 要生成标签的数值 |
| `direction` | `Vector3D \| None` | `label_direction` | 摆放方向 |
| `buff` | `float \| None` | `line_to_number_buff` | 与轴的距离 |
| `font_size` | `float \| None` | `font_size` | 字号 |
| `label_constructor` | `type \| None` | 数轴的设置 | 文本构造类 |
| `**number_config` | — | — | 合并进 `decimal_number_config`，如 `num_decimal_places=2` |
