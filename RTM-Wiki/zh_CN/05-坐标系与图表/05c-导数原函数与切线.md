# 导数、原函数与切线

曲线上的坐标换算与微积分三件套：`input_to_graph_point`/`input_to_graph_coords` 把 x 值换成曲线上的屏幕点/数据坐标，`plot_derivative_graph` 数值求导画 `f'`，`plot_antiderivative_graph` 数值积分画 `F`，`slope_of_tangent`/`angle_of_tangent` 给出任意点的切线斜率与角度。隐式曲线与割线组在[曲线标注与辅助线](05b-曲线标注与辅助线.md)。

> 提醒：全部是**数值**方法——导数用差分、原函数用梯形法，不解析求导；`graph` 参数必须是 `ax.plot` 的返回值（内部要读它的采样函数）。

## Axes.input_to_graph_point（别名 i2gp）

```python
def input_to_graph_point(
    self,
    x: float,
    graph: ParametricFunction | VMobject,
) -> Point3D:
```

返回曲线上 x 处的**屏幕点**（场景坐标），常用来放 `Dot`、算间距。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `x` | `float` | 必填 | 输入的 x 值 |
| `graph` | `ParametricFunction \| VMobject` | 必填 | `ax.plot` 的返回值 |

#### 样例：`i2gp` / `i2gc` 曲线上取点

带网格的 `NumberPlane` 里画 `y=x²`：`input_to_graph_point(x=PI)` 拿屏幕点放黄点与标签，`input_to_graph_coords(x=2.0)` 拿数据坐标并回读显示 `(2.0, 4.0)`。

```python
from real_time_manim import (
    Scene, Axes, NumberPlane, Dot, Line, Text, PI,
    YELLOW, PURPLE_B, GREEN, ORANGE, GREY_B, UP, DOWN, UR, DL, DR,
    Create, FadeIn, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait

class TakePointDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("05c-input_to_graph", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        ax = NumberPlane(x_range=[-2, 5, 1], y_range=[-1, 7, 1],   #带网格的坐标系
                         background_line_style={"stroke_opacity": 0.4})   #网格线压暗免得抢戏
        curve = ax.plot(lambda x: x**2, color=PURPLE_B)   #抛物线 y=x²
        lab = Text("i2gp(x) -> screen point   i2gc(x) -> data coords",
                   font_size=24, color=GREY_B).to_edge(DOWN)   #方法说明标签
        win.play(Create(ax), FadeIn(lab), run_time=0.6)   #坐标系与标签一起出场
        win.play(Create(curve), run_time=0.8)   #画出抛物线

        pos = ax.input_to_graph_point(x=PI, graph=curve)   #“input_to_graph_point”（别名 i2gp）：x 处的屏幕点
        dot = Dot(pos, color=YELLOW)   #拿到屏幕点后直接放 Dot
        tag = Text("i2gp(PI)", font_size=24, color=YELLOW).next_to(dot, UR, buff=0.2)
        win.play(FadeIn(dot), FadeIn(tag), run_time=0.4)   #黄点与标签淡入

        coords = ax.input_to_graph_coords(x=2.0, graph=curve)   #“input_to_graph_coords”（别名 i2gc）：x 处的数据坐标
        tag2 = Text("i2gc(2.0)=(%.1f, %.1f)" % coords,   #把回读到的数据坐标显示出来
                    font_size=24, color=GREEN).next_to(ax.c2p(2, 4), DR, buff=0.3)
        win.play(FadeIn(tag2), run_time=0.4)   #数据坐标回读淡入
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：`i2gp(PI)` 直接在曲线上"钉点"——内部用 `PI` 的曲线采样值经 `c2p` 得到屏幕坐标，返回值可以喂给 `Dot`/`next_to`；`i2gc(2.0)` 走相反方向，把屏幕点反算回**数据坐标** `(2, 4)`，样例用 `%.1f` 格式化后显示在点旁边，验证 `2²=4`。

<video src="assets/RTM output/05c-导数原函数与切线-takepoint.mp4" controls width="560"></video>

> 提醒：`i2gp` 返回场景坐标（可直接 `Dot(pos)`），`i2gc` 返回数据坐标（`(x, y)` 元组）；两者别搞反。

## Axes.input_to_graph_coords（别名 i2gc）

```python
def input_to_graph_coords(
    self, x: float, graph: ParametricFunction
) -> tuple[float, float]:
```

返回曲线上 x 处的**数据坐标** `(x, y)`（不是屏幕点），用于回读曲线上的真实数值。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `x` | `float` | 必填 | 输入的 x 值 |
| `graph` | `ParametricFunction` | 必填 | `ax.plot` 的返回值 |

## Axes.plot_derivative_graph

```python
def plot_derivative_graph(
    self,
    graph: ParametricFunction,
    color: ParsableManimColor = GREEN,
    **kwargs: Any,
) -> ParametricFunction:
```

对曲线做数值差分求导，返回导函数曲线（与原曲线同取景）。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `graph` | `ParametricFunction` | 必填 | 被求导的曲线 |
| `color` | `ParsableManimColor` | `GREEN` | 导函数曲线颜色 |
| `**kwargs` | — | — | 传给 `ParametricFunction` |

#### 样例：导函数与原函数曲线

同坐标系画三条线：原函数 `x²`（紫）、数值导数 `2x`（绿，过原点的直线）、数值原函数 `x³/3`（橙，梯形法从 0 积到 x，`y_intercept=0`）。

```python
from real_time_manim import (
    Scene, Axes, NumberPlane, Dot, Line, Text, PI,
    YELLOW, PURPLE_B, GREEN, ORANGE, GREY_B, UP, DOWN, UR, DL, DR,
    Create, FadeIn, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait

class DerivativeDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("05c-derivative_antiderivative", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        ax = Axes(x_range=[-1, 2.5, 1], y_range=[-2, 7, 1],
                  x_length=9, y_length=5.5)   #取景包住三条曲线
        c1 = ax.plot(lambda x: x**2, color=PURPLE_B)   #原曲线 y=x²
        lab = Text("f=x^2   f'=2x   F=x^3/3 (y_intercept=0)",
                   font_size=24, color=GREY_B).to_edge(DOWN)   #方法说明标签
        win.play(Create(ax), FadeIn(lab), run_time=0.6)   #坐标系与标签一起出场
        win.play(Create(c1), run_time=0.7)   #画出原曲线

        c2 = ax.plot_derivative_graph(c1, color=GREEN)   #“plot_derivative_graph”：数值求导，画出 2x
        win.play(Create(c2), run_time=0.7)   #画出导函数（过原点的直线）

        c3 = ax.plot_antiderivative_graph(c1, y_intercept=0,   #“plot_antiderivative_graph”：梯形法从 0 积到 x
                                           color=ORANGE)   #参数 “y_intercept”：积分常数（y 轴截距）
        win.play(Create(c3), run_time=0.9)   #画出原函数 x³/3
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：`plot_derivative_graph(c1)` 在 `c1` 的采样点上做中心差分 `(f(x+h)-f(x-h))/2h`，`x²` 的导数正好是过原点的直线 `2x`；`plot_antiderivative_graph(c1, y_intercept=0)` 用梯形法从 0 积到每个 x，`y_intercept` 是积分常数——换 `0.5` 整条橙线平行上移 0.5。

<video src="assets/RTM output/05c-导数原函数与切线-deriv.mp4" controls width="560"></video>

> 提醒：导数/原函数都是**数值**结果，陡峭或间断处会有误差；`plot_antiderivative_graph` 的积分起点固定是 x 最小值，`y_intercept` 只管竖直平移。

## Axes.plot_antiderivative_graph

```python
def plot_antiderivative_graph(
    self,
    graph: ParametricFunction,
    y_intercept: float = 0,
    samples: int = 50,
    use_vectorized: bool = False,
    **kwargs: Any,
) -> ParametricFunction:
```

用梯形法对曲线数值积分，返回原函数曲线。

| 参数 | 类型 | 默认值 | 说明 |

| `graph` | `ParametricFunction` | 必填 | 被积分的曲线 |
| `y_intercept` | `float` | `0` | 积分常数（y 轴截距） |
| `samples` | `int` | `50` | 积分采样数，越大越准越慢 |
| `use_vectorized` | `bool` | `False` | 函数支持数组输入时置 `True` 提速 |
| `**kwargs` | — | — | 传给 `ParametricFunction` |

## Axes.slope_of_tangent

```python
def slope_of_tangent(
    self, x: float, graph: ParametricFunction, **kwargs: Any
) -> float:
```

返回曲线在 x 处的切线斜率（数值差分），可直接喂给 `Line` 画切线。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `x` | `float` | 必填 | 切点 x |
| `graph` | `ParametricFunction` | 必填 | 目标曲线 |
| `**kwargs` | — | — | 传给底层差分（如 `dx`） |

#### 样例：`slope_of_tangent` + `angle_of_tangent` 动态切线

缓坡抛物线 `f=0.25x²+1` 上在 x=-2/0/2 三处画切线：`slope_of_tangent` 求斜率并按半长 1.6 外推两端点连成绿色切线段，`angle_of_tangent` 的读数（弧度）与斜率一起显示在切点旁。

```python
from real_time_manim import (
    Scene, Axes, NumberPlane, Dot, Line, Text, PI,
    YELLOW, PURPLE_B, GREEN, ORANGE, GREY_B, UP, DOWN, UR, DL, DR,
    Create, FadeIn, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait

class TangentDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("05c-slope_of_tangent", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        ax = Axes(x_range=[-3, 3, 1], y_range=[-1, 7, 1],
                  x_length=9, y_length=5.5)   #缓坡抛物线取景
        f = lambda x: 0.25 * x**2 + 1   #缓一点的抛物线，切线不至于太陡
        curve = ax.plot(f, color=PURPLE_B)   #原曲线
        lab = Text("slope_of_tangent(x) + angle_of_tangent(x)",
                   font_size=24, color=GREY_B).to_edge(DOWN)   #方法说明标签
        win.play(Create(ax), FadeIn(lab), run_time=0.6)   #坐标系与标签一起出场
        win.play(Create(curve), run_time=0.8)   #画出曲线

        for x0, side in ((-2, DL), (0, UP), (2, DR)):   #在三个位置画切线
            s = ax.slope_of_tangent(x=x0, graph=curve)   #“slope_of_tangent”：数值求切线斜率
            ang = ax.angle_of_tangent(x=x0, graph=curve)   #“angle_of_tangent”：切线与 x 轴夹角（弧度）
            p = ax.c2p(x0, f(x0))   #切点
            half = 1.6   #切线半长（数据单位）
            pa = ax.c2p(x0 - half, f(x0) + s * (-half))   #按斜率外推两端点
            pb = ax.c2p(x0 + half, f(x0) + s * half)
            tline = Line(pa, pb, color=GREEN)   #切线段
            tag = Text("x=%+d  slope=%.1f  ang=%.2frad" % (x0, s, ang),   #斜率与夹角一起显示
                       font_size=20, color=GREY_B).next_to(p, side, buff=0.25)
            win.play(Create(tline), FadeIn(tag), run_time=0.5)   #切线与读数出场
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：切线段是**手工构造**的——`slope_of_tangent` 给出斜率 `s` 后，在数据坐标里以切点为中心向左右各外推 `half=1.6`（`y = f(x0) + s·Δx`），再 `c2p` 转屏幕点连成 `Line`；`angle_of_tangent` 返回弧度（`atan(s)`），和斜率一起打进读数文本。x=0 处斜率为 0，切线水平；x=±2 处对称相反。

<video src="assets/RTM output/05c-导数原函数与切线-tangent.mp4" controls width="560"></video>

> 提醒：`slope_of_tangent` 返回的是**数据斜率**（dy/dx），直接拿来外推数据坐标没问题，但别当屏幕斜率用（x/y 比例尺不等时会歪）；`angle_of_tangent` 单位是弧度。

## Axes.angle_of_tangent

```python
def angle_of_tangent(
    self,
    x: float,
    graph: ParametricFunction,
    dx: float = 1e-8,
) -> float:
```

返回曲线在 x 处切线与 x 轴的夹角（弧度），`atan(slope_of_tangent(x))`。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `x` | `float` | 必填 | 切点 x |
| `graph` | `ParametricFunction` | 必填 | 目标曲线 |
| `dx` | `float` | `1e-8` | 差分步长 |
