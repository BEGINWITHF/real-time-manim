# 绘制函数曲线（plot 与参数曲线）

`y = f(x)` 与参数方程两类曲线的画法：`ax.plot` 在坐标系上采样作图（支持 `discontinuities` 声明间断点），`FunctionGraph` 脱离坐标系直接画，`plot_parametric_curve` 画李萨如这类参数曲线。面积/黎曼矩形在[面积与黎曼矩形](06-面积与黎曼矩形.md)，曲线标注在 05b/05c。

> 提醒：源码里**没有** `ax.get_graph(...)`、`plot_area` 这些旧教程别名，唯一入口是 `ax.plot(...)`。

## Axes.plot

```python
def plot(self, function: Callable[[float], float], x_range: Sequence[float] | None = None,
         use_vectorized: bool = False, colorscale=None, colorscale_axis: int = 1,
         **kwargs) -> ParametricFunction
```

按 `x_range` 采样、经 `coords_to_point` 转成屏幕点，返回 `ParametricFunction`。`**kwargs` 传给 `ParametricFunction`，最常用的是下表后 5 行。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `function` | `Callable[[float], float]` | 必填 | 如 `lambda x: np.sin(x)` |
| `x_range` | `Sequence[float] \| None` | `None` = 整个 x 轴 | `[x_min, x_max]` 或 `[x_min, x_max, x_step]`；`x_step` 是**采样步长**（不是刻度），越小越平滑越慢 |
| `use_vectorized` | `bool` | `False` | 函数支持数组输入时置 `True`，显著提速 |
| `colorscale` | 颜色序列 / `(color, pivot)` 序列 \| `None` | `None` | 按 y 值渐变上色；**必须与 `x_range` 同时传**，否则抛 `TypeError` |
| `colorscale_axis` | `int` | `1` | 渐变依据的轴：`0`=x，`1`=y |
| `color` | `ParsableManimColor` | `PURE_YELLOW` | 曲线颜色（`**kwargs`） |
| `discontinuities` | `Iterable[float] \| None` | `None` | 间断点的 x 值，如 `[-2, 2]`；不给会连出竖直线 |
| `dt` | `float` | `1e-8` | 间断点左右的容差，常用 `0.1` |
| `use_smoothing` | `bool` | `True` | 是否平滑（点少或函数很陡时关掉更真实） |
| `stroke_width` | `float` | 继承 | 线宽 |

> **返回**：`ParametricFunction`；`graph.underlying_function`（原始函数）、`graph.t_min`/`graph.t_max`（采样区间，`get_area` 等会用到）。

#### 样例：`discontinuities`/`dt` 声明间断点

同一条有垂直渐近线的函数画两遍：不声明间断点的红色版会在 `-2`、`2` 处被一条竖线"连起来"（错误画法），声明 `discontinuities=[-2, 2], dt=0.1` 的绿色版在间断处断开（正确画法）。

```python
from real_time_manim import (
    Scene, Axes, NumberPlane, FunctionGraph, Text, np,
    YELLOW, RED, GREEN, BLUE, ORANGE, GREY_B, UP, DOWN, TAU,
    Create, FadeIn, FadeOut, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait

class PlotDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("05-plot", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        ax = NumberPlane(x_range=[-3, 3, 1], y_range=[-4, 4, 1])   #带网格的坐标系
        f = lambda x: max(-60, min(60, (x**2 - 2) / (x**2 - 4)))   #在 -2、2 处有垂直渐近线；y 先钳到 ±60：极点附近浮点会算出 1e14 巨值，画不出来
        lab = Text("plot(discontinuities=[-2,2], dt=0.1)",
                   font_size=24, color=GREY_B).to_edge(DOWN)   #参数说明标签
        win.play(Create(ax), run_time=0.7)   #画出坐标网格
        win.play(FadeIn(lab), run_time=0.3)   #说明标签淡入

        bad = ax.plot(f, color=RED)   #不标间断点：-2、2 处会被一条竖线“连起来”
        win.play(Create(bad), run_time=1.0)   #先看错误画法
        win.play(FadeOut(bad), run_time=0.4)   #撤掉错误画法

        good = ax.plot(f, discontinuities=[-2, 2], dt=0.1,   #参数 “discontinuities”/“dt”：声明间断点与容差
                       color=GREEN, use_smoothing=False)   #参数 “use_smoothing”：陡峭段关平滑更真实
        win.play(Create(good), run_time=1.2)   #再看正确画法
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：先画"不声明间断点"的红色版——采样点在渐近线两侧一正一负，被直线连成穿过画面的竖线，这就是典型的错误画法。`FadeOut` 撤掉后再画绿色版：`discontinuities=[-2, 2]` 声明两个间断点，`dt=0.1` 给出跳过容差，间断处就真的断开了；陡峭段再加 `use_smoothing=False`，避免贝塞尔平滑把尖角抹圆。

<video src="assets/RTM output/05-函数曲线-plot.mp4" controls width="560"></video>

> 提醒：
>
> - **渐近线函数必须给 y 值设上限**（样例里的 `max(-60, min(60, ...))`）——极点附近浮点会算出 `1e14` 量级巨值，直接画都会翻车。
> - `dt` 默认 `1e-8` 太小，实际写 `0.1`。

## FunctionGraph

```python
def __init__(self, function: Callable[[float], Any], x_range: tuple | None = None,
             color: ParsableManimColor = PURE_YELLOW, **kwargs) -> None:
```

脱离坐标系直接画 `y = f(x)`（默认横跨整个画面宽度），适合"两条函数对比"这类不显示坐标轴的场景。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `function` | `Callable[[float], Any]` | 必填 | `lambda t: np.cos(t)` |
| `x_range` | `tuple \| None` | `None` → `(-frame_x_radius, frame_x_radius)` | 采样区间（第三项为步长） |
| `color` | `ParsableManimColor` | `PURE_YELLOW` | 曲线颜色 |
| `**kwargs` | — | — | 透传 `ParametricFunction`（`discontinuities`、`use_smoothing`…） |

#### 样例：余弦 vs 正弦对比

不建坐标系，两条 `FunctionGraph` 直接叠画：蓝色 `cos(3t)` 与绿色 `sin(3t)`，肉眼可见相差半格相位。

```python
from real_time_manim import (
    Scene, Axes, NumberPlane, FunctionGraph, Text, np,
    YELLOW, RED, GREEN, BLUE, ORANGE, GREY_B, UP, DOWN, TAU,
    Create, FadeIn, FadeOut, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait

class FunctionGraphDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("05-FunctionGraph", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        g1 = FunctionGraph(lambda t: np.cos(3 * t), x_range=[-4, 4], color=BLUE)   #余弦曲线
        g2 = FunctionGraph(lambda t: np.sin(3 * t), x_range=[-4, 4], color=GREEN)   #正弦曲线
        lab = Text("FunctionGraph(cos 3t) vs FunctionGraph(sin 3t)",
                   font_size=24, color=GREY_B).to_edge(DOWN)   #方法说明标签
        win.play(Create(g1), run_time=0.9)   #画出余弦曲线
        win.play(Create(g2), run_time=0.9)   #画出正弦曲线（相差半格相位）
        win.play(FadeIn(lab), run_time=0.4)   #说明标签淡入
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：`FunctionGraph` 不需要坐标系，直接给一个 `t → y` 的函数就画线；`x_range=[-4, 4]` 限定采样区间（不给就是整个画面宽）。两条线用不同颜色依次 `Create`，相位差半格一眼可见。

<video src="assets/RTM output/05-函数曲线-functiongraph.mp4" controls width="560"></video>

> 提醒：`FunctionGraph` 的 `x_range` 是**采样区间**，不是数据坐标（它根本不知道坐标系）；要刻度、网格请改用 `ax.plot`。

## ParametricFunction（只留表格）

```python
def __init__(self, function: Callable[[float], Point3DLike], t_range: tuple = (0, 1),
             scaling: _ScaleBase = LinearBase(), dt: float = 1e-8,
             discontinuities: Iterable[float] | None = None, use_smoothing: bool = True,
             use_vectorized: bool = False, **kwargs) -> None:
```

参数曲线底层类：`function(t) -> (x, y, z)`，既可独立画李萨茹等参数曲线，也是 `Axes.plot` 的返回类型。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `function` | `Callable[[float], Point3DLike]` | 必填 | `lambda t: (x(t), y(t), z(t))` |
| `t_range` | `tuple` | `(0, 1)` | `(t_min, t_max)` 或 `(t_min, t_max, step)`，缺 step 补 `0.01` |
| `scaling` | `_ScaleBase` | `LinearBase()` | 参数缩放（对数轴会自动继承轴的 scaling） |
| `dt` | `float` | `1e-8` | 间断点容差 |
| `discontinuities` | `Iterable[float] \| None` | `None` | 参数 t 上的间断点 |
| `use_smoothing` | `bool` | `True` | 是否平滑 |
| `use_vectorized` | `bool` | `False` | 是否把 t 数组整体传入函数（输出形状 `[[x…],[y…],[z…]]`） |
| `**kwargs` | — | — | 传给 `VMobject`（`color`、`stroke_width`…） |

## CoordinateSystem.plot_parametric_curve

```python
def plot_parametric_curve(self, function: Callable[[float], np.ndarray],
                          use_vectorized: bool = False, **kwargs) -> ParametricFunction
```

在坐标系里画参数曲线：函数返回**数据坐标**，内部自动 `c2p`；心形线、李萨如等参数方程用它。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `function` | `Callable[[float], np.ndarray]` | 必填 | `lambda t: np.array([x(t), y(t), 0])` |
| `use_vectorized` | `bool` | `False` | 函数是否支持向量化 |
| `**kwargs` | — | — | 传给 `ParametricFunction`，**`t_range` 也从这里传**（如 `t_range=[0, 2*PI]`） |

#### 样例：`t_range` 参数方程画李萨如曲线

正方形取景的坐标系里，用 `np.array([sin(3t), sin(4t), 0])` 画一条李萨如曲线，`t_range=[0, TAU]` 经 `**kwargs` 传入。

```python
from real_time_manim import (
    Scene, Axes, NumberPlane, FunctionGraph, Text, np,
    YELLOW, RED, GREEN, BLUE, ORANGE, GREY_B, UP, DOWN, TAU,
    Create, FadeIn, FadeOut, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait

class ParametricCurveDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("05-parametric_curve", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        ax = Axes(x_range=[-2, 2, 1], y_range=[-2, 2, 1],
                  x_length=6, y_length=6)   #正方形取景，李萨如不变形
        curve = ax.plot_parametric_curve(   #“plot_parametric_curve”：按参数方程画曲线
            lambda t: np.array([np.sin(3 * t), np.sin(4 * t), 0]),   #x=sin(3t)、y=sin(4t)
            t_range=[0, TAU], color=ORANGE)   #参数 “t_range” 经 **kwargs 传入
        lab = Text("plot_parametric_curve(sin(3t), sin(4t))",
                   font_size=24, color=GREY_B).to_edge(DOWN)   #参数说明标签
        win.play(Create(ax), run_time=0.6)   #画出坐标系
        win.play(Create(curve), run_time=1.4)   #画出李萨如曲线
        win.play(FadeIn(lab), run_time=0.4)   #说明标签淡入
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：`x_length=y_length=6` 配 `[-2,2]²` 的范围让 x/y 比例尺相等，这是李萨如图形不变形的关键。函数返回的是**数据坐标** `np.array([sin(3t), sin(4t), 0])`，`plot_parametric_curve` 内部自动 `c2p`；`t_range=[0, TAU]` 走 `**kwargs` 透传给 `ParametricFunction`。

<video src="assets/RTM output/05-函数曲线-parametric.mp4" controls width="560"></video>

> 提醒：
>
> - `plot_parametric_curve` 的函数返回**数据坐标**（`np.array` 三项），与 `ParametricFunction` 直接返回场景坐标不同。
> - `t_range` 别写进函数参数，走 `**kwargs`。
