# 刻度与缩放 scaling

RTM 走通用矢量回退出图（2026-10-11 实渲染验证，回退能正确画出）。`scaling=` 参数接受 `_ScaleBase` 子类，决定数轴刻度的非线性映射方式。

## LogBase

`LogBase(base=10, custom_labels=True)`

对数刻度对象，传给 `NumberLine(scaling=...)` 或 `Axes(y_axis_config={"scaling": LogBase(...)})`，把线性步长变成 `base**k` 的十倍频刻度，并生成 `10^2` 形式的 LaTeX 标签。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `base` | `float` | `10` | 对数底 |
| `custom_labels` | `bool` | `True` | 是否用 `10^k` 形式的自定义标签（`False` 则显示普通数字） |

三个核心方法（均会被系统自动调用，也可手动调用）：

| 方法 | 签名 | 说明 |
| --- | --- | --- |
| `function` | `(value) -> float` | `base ** value`，把"指数"变成真实值 |
| `inverse_function` | `(value) -> float` | 真实值 → 指数；**`value <= 0` 抛 `ValueError`** |
| `get_custom_labels` | `(val_range, unit_decimal_places=0, **base_config) -> list[Integer]` | 生成 `10^k` 标签 |

## LinearBase

`LinearBase(scale_factor=1.0)`

默认线性刻度（`function = scale_factor * value`），所有坐标轴的默认 `scaling`；只有想给刻度整体乘一个系数时才需要显式传。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `scale_factor` | `float` | `1.0` | 斜率；方法同 `LogBase`（`function`/`inverse_function`），`custom_labels=False` |

## _ScaleBase（自定义刻度扩展点）

```python
class _ScaleBase:
    def __init__(self, custom_labels: bool = False)
    def function(self, value) -> float            # 必须覆写
    def inverse_function(self, value) -> float    # 必须覆写
    def get_custom_labels(self, val_range, **kw_args) -> Iterable[VMobject]   # 可选覆写
```

名字带下划线但它是**公开扩展点**：任何 `scaling=` 参数都接受它的子类（手册未收录 `SqrtBase`，开方/平方刻度请继承它自定义）。

- `function`：数值 → 轴上的"逻辑位置"（`NumberLine` 内部把 `x_range` 全部过一遍它）。
- `inverse_function`：`function` 的逆，`n2p`/`p2c` 用它还原真实数值。
- `get_custom_labels(val_range)`：返回与 `val_range` 一一对应的标签；配合 `custom_labels=True` 才走自定义标签分支。

## 样例 1：`Axes` 的 y 轴换成 `LogBase`

页面 `示例` 的实际出图版：`Axes` 只把 **y 轴** 改对数刻度，`plot` 一条 `y=x²` —— 在线性 y 轴上它飞得很快，在对数 y 轴上被压成一条平缓上升的曲线。

```python
from real_time_manim import (
    Axes, Create, DOWN, FadeIn, GREY_B, LEFT, LinearBase, LogBase,
    NumberLine, Scene, Text, UP, YELLOW, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait

class LogBaseDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("10-LogBase", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        ax = Axes(x_range=[0, 10, 1], y_range=[-2, 6, 1], tips=False,   #两轴数据范围
                  axis_config={"include_numbers": True},   #两轴都带刻度数字
                  y_axis_config={"scaling": LogBase(custom_labels=True)})   #参数 “scaling”：y 轴改对数刻度
        graph = ax.plot(lambda x: x**2,   #画 y=x^2：在对数 y 轴上会被“压扁”成一条上升曲线
                        x_range=[0.001, 10],   #x_min 必须 > 0（LogBase 的 inverse_function 对 ≤0 抛 ValueError）
                        use_smoothing=False)
        lab = Text("y_axis_config={'scaling': LogBase()}",
                   font_size=24, color=GREY_B).to_edge(UP).shift(DOWN * 0.9)   #参数说明放标题下
        win.play(Create(ax), FadeIn(lab), run_time=0.8)   #坐标系与说明一起出场
        win.play(Create(graph), run_time=0.8)   #画出曲线
        win.play(Wait(0.8))   #进行 0.8s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：`scaling=` 是轴对象的参数（`axis_config` / `x_axis_config` / `y_axis_config` 都能传），`LogBase(custom_labels=True)` 把线性步长变成 `base**k` 的十倍频刻度，并生成 `10^2` 形式的标签；`plot` 的每个 x 先过 `function` 得到轴上的位置。注意 `LogBase.inverse_function(value<=0)` 会抛 `ValueError: log(0) is undefined`，所以 `plot` / `x_range` 的**下界必须 > 0**。

<video src="assets/RTM output/10-刻度与缩放-logbase.mp4" controls width="560"></video>

> **`LogBase` 别直接用在 `NumberLine` 上**：`NumberLine(x_range=[0, 6, 1], scaling=LogBase(base=10), include_numbers=True)` 会崩（`x_range` 含 0，等价于对 0 求 log）；即便改成 `x_range=[1, 6, 1]`，manim 也会把刻度摆到线外（实测 `length=9` 时刻度落在 x≈-6.3…-4.9、`include_numbers` 生成 0 个标签）。要演示对数刻度就用 `Axes(y_axis_config={"scaling": LogBase(...)})`，那是可用的那条路。

## 样例 2：`LinearBase` 给刻度整体乘一个系数

`LinearBase(scale_factor)` 就是 `function(v) = scale_factor * v`；不传参数时是 `1.0`，也就是所有坐标轴的默认刻度。样例把两条 `NumberLine` 上下摆开，第二条传 `1.5`，刻度间距整体变化。

```python
from real_time_manim import (
    Axes, Create, DOWN, FadeIn, GREY_B, LEFT, LinearBase, LogBase,
    NumberLine, Scene, Text, UP, YELLOW, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait

class LinearBaseDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("10-LinearBase", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        base = NumberLine(x_range=[0, 6, 1], length=9,   #默认刻度：LinearBase(scale_factor=1.0)
                          include_numbers=True).shift(UP * 0.9 + LEFT * 0.6)
        wide = NumberLine(x_range=[0, 6, 1], length=9,   #参数 “scale_factor”：刻度整体乘 1.5
                          scaling=LinearBase(scale_factor=1.5),
                          include_numbers=True).shift(DOWN * 0.9)
        la = Text("LinearBase(scale_factor=1.0)  # 默认", font_size=22,
                  color=GREY_B).next_to(base, UP, buff=0.25)
        lb = Text("LinearBase(scale_factor=1.5)", font_size=22,
                  color=GREY_B).next_to(wide, DOWN, buff=0.25)
        win.play(Create(base), Create(wide), FadeIn(la), FadeIn(lb), run_time=0.8)   #两条数轴一起出场
        win.play(Wait(0.8))   #进行 0.8s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：`NumberLine` 的刻度位置 = `scaling.function(值)` 再映射到轴上，所以 `scale_factor=1.5` 会把每个刻度往外推 1.5 倍（0 点不动），标签数值不变——视觉上就是"刻度被拉伸"。`inverse_function` 是它的逆，`n2p`/`p2c` 用它还原真实数值。

<video src="assets/RTM output/10-刻度与缩放-linearbase.mp4" controls width="560"></video>

> 两条数轴是**同一套 `x_range` 只换 `scaling`**：`scale_factor ≠ 1` 时刻度不再铺满整条线（manim 不会自动重新归一化），这是上游行为、两引擎一致。想自定义刻度（如开方/平方轴）就继承 `_ScaleBase` 覆写 `function` / `inverse_function`（可选 `get_custom_labels`）。
