# 引导线与折线图

`Axes` 上"读图标注"与"离散数据折线"的方法：给曲线/点补横竖引导线（`get_vertical_line` 等），按离散数据点画折线图（`plot_line_graph`）。

## 方法

### get_vertical_line / get_horizontal_line / get_lines_to_point

```python
def get_vertical_line(self, point: Point3DLike, **kwargs) -> Line
def get_horizontal_line(self, point: Point3DLike, **kwargs) -> Line
def get_lines_to_point(self, point: Point3DLike, **kwargs) -> VGroup
```

从 x 轴 / y 轴向某个场景点画引导线（默认 `DashedLine`），做"读图"标注最常用；`get_lines_to_point` 同时给出横竖两条。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `point` | `Point3DLike` | 必填 | 目标点（通常来自 `ax.c2p(...)`） |
| `**kwargs` | — | — | 透传 `get_line_from_axis_to_point`：`line_func`（如 `Line`）、`line_config`（如 `{"dashed_ratio": 0.85}`）、`color`、`stroke_width` |

> **返回**：`Line` / `VGroup`（交给 `play` 播放或 `add` 进场景）。

### get_line_from_axis_to_point

```python
def get_line_from_axis_to_point(self, index: int, point: Point3DLike, line_func: type[Line] = DashedLine,
                                line_config: dict | None = None, color: ParsableManimColor | None = None,
                                stroke_width: float = 2) -> Line
```

上面两个方法的通用版：从第 `index` 根轴向 `point` 连线，可自定义线型类。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `index` | `int` | 必填 | `0`=x 轴，`1`=y 轴 |
| `point` | `Point3DLike` | 必填 | 目标点 |
| `line_func` | `type[Line]` | `DashedLine` | 线类，如 `Line`、`Arrow` |
| `line_config` | `dict \| None` | `None` | 传给 `line_func` 的参数 |
| `color` | `ParsableManimColor \| None` | 默认 mobject 色 | 线色 |
| `stroke_width` | `float` | `2` | 线宽 |

> **返回**：`Line`。

#### 样例：竖直虚线 / 横竖两条 / 指定线型的通用版

同一条坐标系上依次画三种引导线：x 轴到点的蓝色竖直虚线、横竖两条的灰色组合、y 轴到点的绿色**实线**（通用版换 `line_func=Line`）。

```python
from real_time_manim import Scene, Axes, Dot, Line, Text, \
    YELLOW, RED, BLUE, GREEN, GREY, GREY_B, UP, DOWN, Create, FadeIn, Write
from real_time_manim.vulkan_bind import MLWindow, Wait

class GuideLinesDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("02b-guide-lines", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        ax = Axes(x_range=[-4, 4, 1], y_range=[-3, 3, 1],
                  x_length=9, y_length=5.5).add_coordinates()   #带刻度数字的坐标系
        p = ax.c2p(2, 1.5)   #目标点：数据坐标 (2, 1.5)
        dot = Dot(p, color=RED)   #目标点圆点
        vline = ax.get_vertical_line(p, color=BLUE)   #“get_vertical_line”：x 轴 -> 点的竖直虚线
        both = ax.get_lines_to_point(ax.c2p(-3, -1), color=GREY)   #“get_lines_to_point”：横竖两条引导线
        solid = ax.get_line_from_axis_to_point(   #“get_line_from_axis_to_point”：通用版，指定线型类
            1, ax.c2p(3, -2), line_func=Line, color=GREEN)   #从 y 轴（index=1）拉一条实线到点
        lab = Text("vertical / lines_to_point / from_axis(1, Line)",
                   font_size=24, color=GREY_B).to_edge(DOWN)   #方法说明标签
        win.play(Create(ax), run_time=0.8)   #画出坐标系
        win.play(FadeIn(lab), run_time=0.3)   #说明标签淡入
        win.play(FadeIn(dot), run_time=0.3)   #目标点淡入
        win.play(Create(vline), run_time=0.6)   #蓝色竖直虚线从 x 轴长到点
        win.play(Create(both), run_time=0.6)   #灰色横竖两条引导线
        win.play(Create(solid), run_time=0.6)   #绿色实线从 y 轴连到点
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：红点钉在数据坐标 (2, 1.5)，`get_vertical_line` 从 **x 轴**垂一条虚线上去；`get_lines_to_point` 在 (-3, -1) 处一次给出横竖两条；最后通用版 `get_line_from_axis_to_point(1, ...)` 从 **y 轴**（`index=1`）拉一条**实线**（`line_func=Line`）到 (3, -2)。三个方法的产物都是普通 `Line` 系对象，直接 `Create` 就能画出来。

> 提醒：
>
> - 引导线的锚点是**场景点**不是数据坐标，先 `ax.c2p(...)` 再传进去。
> - `get_vertical_line` 永远从 x 轴出发，想要从 y 轴出发请用通用版传 `index=1`。

### plot_line_graph

```python
def plot_line_graph(self, x_values: Iterable[float], y_values: Iterable[float],
                    z_values: Iterable[float] | None = None, line_color: ParsableManimColor = PURE_YELLOW,
                    add_vertex_dots: bool = True, vertex_dot_radius: float = 0.08,
                    vertex_dot_style: dict | None = None, **kwargs) -> VDict
```

按**离散数据点**画折线图（不是函数采样）：逐点 `c2p` 后连线，默认在每个顶点放一个 `Dot`。返回 `VDict`，折线在 `line_graph["line_graph"]`，圆点在 `line_graph["vertex_dots"]`。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `x_values` | `Iterable[float]` | 必填 | x 数据 |
| `y_values` | `Iterable[float]` | 必填 | y 数据（长度须与 x 一致） |
| `z_values` | `Iterable[float] \| None` | `None`（全 0） | 3D 数据 |
| `line_color` | `ParsableManimColor` | `PURE_YELLOW` | 折线颜色 |
| `add_vertex_dots` | `bool` | `True` | 是否画顶点圆点 |
| `vertex_dot_radius` | `float` | `0.08` | 圆点半径 |
| `vertex_dot_style` | `dict \| None` | `None` | 传给 `Dot` 的样式 |
| `**kwargs` | — | — | 传给折线 `VGroup`（如 `stroke_width=4`） |

> **返回**：`VDict`（键 `"line_graph"` 折线、`"vertex_dots"` 圆点）。

#### 样例：`plot_line_graph` 离散折线图

四个离散数据点连成金黄色折线（加粗 4），顶点圆点随后淡入——两条线段的"拐点"就是数据点本身。

```python
from real_time_manim import Scene, Axes, Text, \
    YELLOW, GREY_B, UP, DOWN, GOLD_E, Create, FadeIn, Write
from real_time_manim.vulkan_bind import MLWindow, Wait

class LineGraphDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("02b-plot_line_graph", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        ax = Axes(x_range=[0, 5, 1], y_range=[0, 5, 1],
                  x_length=8, y_length=5).add_coordinates()   #第一象限坐标系
        lg = ax.plot_line_graph(x_values=[0, 1.5, 2.8, 4],   #“plot_line_graph”：按离散数据点连线（不是函数采样）
                                y_values=[1, 3, 4, 2.5],
                                line_color=GOLD_E, stroke_width=4)   #参数 “line_color”/“stroke_width”：折线颜色与线宽
        lab = Text("plot_line_graph(x=[0,1.5,2.8,4], y=[1,3,4,2.5])",
                   font_size=24, color=GREY_B).to_edge(DOWN)   #参数说明标签
        win.play(Create(ax), run_time=0.7)   #画出坐标系
        win.play(FadeIn(lab), run_time=0.3)   #说明标签淡入
        win.play(Create(lg["line_graph"]), run_time=1.0)   #折线本体（返回 VDict 的 “line_graph” 键）
        win.play(FadeIn(lg["vertex_dots"]), run_time=0.5)   #顶点圆点（“vertex_dots” 键）
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：`plot_line_graph` 把 `(0,1) (1.5,3) (2.8,4) (4,2.5)` 四个数据点逐个 `c2p` 后用直线段连起来——它画的是**离散折线**，点与点之间不做任何插值，所以"拐点"就是数据点本身。返回值是 `VDict`：折线从 `lg["line_graph"]` 取、顶点圆点从 `lg["vertex_dots"]` 取，两者可以分开做动画（样例里先画线后亮点）。

> 提醒：`x_values`/`y_values` 长度必须一致（内部 `zip(strict=True)`，不齐直接 `ValueError`）；想要平滑曲线请用 [`ax.plot`](05-函数曲线.md) 而不是它。
