# 面积与黎曼矩形

这一节讲曲线下方的面积与积分逼近：

- `get_area` 生成曲线到 x 轴（或到另一条曲线）的填充面积；
- `get_riemann_rectangles` 生成黎曼和矩形组（左端点 / 右端点 / 中点取样）。

切线与导数在[导数原函数与切线](05c-导数原函数与切线.md)。

> 提醒：
>
> - 两个方法都要求 `graph` 是 `ax.plot` 的返回值，内部读它的采样函数与 `t_min` / `t_max`。
> - 面积的正负自动处理——曲线在 x 轴下方时，`get_riemann_rectangles` 会反色显示负面积。

## Axes.get_area

```python
def get_area(
    self,
    graph: ParametricFunction,
    x_range: tuple[float, float] | None = None,
    color: ParsableManimColor | Iterable[ParsableManimColor] = (BLUE, GREEN),
    opacity: float = 0.3,
    bounded_graph: ParametricFunction | None = None,
    **kwargs: Any,
) -> Polygon:
```

返回一个 `Polygon`，表示曲线在 `x_range` 内下方面积（或两条曲线之间的面积）。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `graph` | `ParametricFunction` | 必填 | 目标曲线 |
| `x_range` | `tuple[float, float] \| None` | `None` → 曲线完整范围 | 面积的 x 区间 |
| `color` | 单色 / 颜色序列 | `(BLUE, GREEN)` | 列表则沿 x 方向做渐变 |
| `opacity` | `float` | `0.3` | 填充不透明度 |
| `bounded_graph` | `ParametricFunction \| None` | `None` | 上边界曲线；给定后面积是两曲线**之间** |
| `**kwargs` | — | — | 传给 `Polygon` |

#### 样例：`get_area` 曲线下方面积

在抛物线 `0.5x²-0.5` 上先后演示两种面积：

- 先演示 `[0,2]` 到 x 轴的绿色渐变面积；
- 撤掉后加画 `y=3` 直线，再演示 `bounded_graph` 的两曲线之间面积。

```python
from real_time_manim import (
    Scene, Axes, Text,
    YELLOW, BLUE, BLUE_C, RED, GREEN, GREEN_B, GREEN_D, GREY_B, UP, DOWN,
    Create, FadeIn, FadeOut, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait

class AreaDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("06-get_area", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        ax = Axes(x_range=[-3, 3, 1], y_range=[-2, 6, 1],
                  x_length=9, y_length=5.5).add_coordinates()   #带刻度数字的坐标系
        quad = ax.plot(lambda x: 0.5 * x**2 - 0.5, color=BLUE)   #抛物线
        lab = Text("get_area(x_range=(0,2)) + bounded_graph",
                   font_size=24, color=GREY_B).to_edge(DOWN)   #参数说明标签
        win.play(Create(ax), FadeIn(lab), run_time=0.6)   #坐标系与标签一起出场
        win.play(Create(quad), run_time=0.7)   #画出抛物线

        area = ax.get_area(quad, x_range=(0, 2),   #“get_area”：曲线下方到 x 轴的面积
                           color=(GREEN_B, GREEN_D), opacity=1)   #参数 “color”/“opacity”：单色、渐变列表与不透明度
        win.play(FadeIn(area), run_time=0.6)   #渐变绿面积淡入
        win.play(FadeOut(area), run_time=0.3)   #撤掉，腾地方演示两曲线之间

        bound = ax.plot(lambda x: 3, color=RED)   #第二条曲线 y=3
        area2 = ax.get_area(quad, x_range=(-1.5, 1.5),   #“get_area” 加 “bounded_graph”：两曲线之间的面积
                            bounded_graph=bound, color=(BLUE_C, GREEN), opacity=0.6)
        win.play(Create(bound), run_time=0.4)   #画出上边界直线
        win.play(FadeIn(area2), run_time=0.6)   #两线之间的面积淡入
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：

- 第一次 `get_area` 不给 `bounded_graph`，面积就是曲线到 x 轴之间；`color=(GREEN_B, GREEN_D)` 传颜色列表，就沿 x 方向渐变，`opacity=1` 实心。
- 第二次先画上边界 `y=3`，再 `bounded_graph=bound` 把积分区域换成两曲线之间（曲线在下方、直线在上方），`opacity=0.6` 留一点透感。

<video src="assets/RTM output/06-面积与黎曼矩形-area.mp4" controls width="560"></video>

> 提醒：
>
> - `bounded_graph` 必须在 `graph` **上方**，否则面积为负、方向翻转。
> - `get_area` 返回的是 `Polygon`，可以再套 `FadeIn` / `Transform` 动画。

## Axes.get_riemann_rectangles

```python
def get_riemann_rectangles(
    self,
    graph: ParametricFunction,
    x_range: Sequence[float] | None = None,
    dx: float = 0.1,
    input_sample_type: str = "left",
    stroke_width: float = 1,
    stroke_color: ParsableManimColor = BLACK,
    fill_opacity: float = 1,
    color: Iterable[ParsableManimColor] | ParsableManimColor = (BLUE, GREEN),
    show_signed_area: bool = True,
    bounded_graph: ParametricFunction | None = None,
    blend: bool = False,
    width_scale_factor: float = 1.001,
) -> VGroup:
```

生成黎曼和矩形组（`VGroup`），按 `dx` 分格、按 `input_sample_type` 取样定高度。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `graph` | `ParametricFunction` | 必填 | 被逼近的曲线 |
| `x_range` | `Sequence[float] \| None` | `None` → 曲线完整范围 | 矩形分布区间 |
| `dx` | `float` | `0.1` | 矩形宽度（数据单位） |
| `input_sample_type` | `str` | `"left"` | 取样点：`"left"`/`"right"`/`"center"` |
| `stroke_width` | `float` | `1` | 矩形描边宽度 |
| `stroke_color` | `ParsableManimColor` | `BLACK` | 描边颜色 |
| `fill_opacity` | `float` | `1` | 填充不透明度 |
| `color` | 颜色 / 颜色序列 | `(BLUE, GREEN)` | 单色或渐变（按位置插值） |
| `show_signed_area` | `bool` | `True` | 曲线在 x 轴下方时反色显示负面积 |
| `bounded_graph` | `ParametricFunction \| None` | `None` | 两曲线之间的黎曼矩形 |
| `blend` | `bool` | `False` | 相邻矩形颜色是否混合过渡 |
| `width_scale_factor` | `float` | `1.001` | 矩形宽微调因子（消除描边缝隙） |

#### 样例：`get_riemann_rectangles` 黎曼和逼近

同一条抛物线画两版矩形：

- `dx=0.25` 左端取样（黄色，负面积自动反色）；
- 撤掉后换 `dx=0.5` 中点取样 + `(BLUE, GREEN)` 渐变。

```python
from real_time_manim import (
    Scene, Axes, Text,
    YELLOW, BLUE, BLUE_C, RED, GREEN, GREEN_B, GREEN_D, GREY_B, UP, DOWN,
    Create, FadeIn, FadeOut, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait

class RiemannDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("06-get_riemann_rectangles", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        ax = Axes(x_range=[-3, 3, 1], y_range=[-2, 6, 1],
                  x_length=9, y_length=5.5).add_coordinates()   #带刻度数字的坐标系
        quad = ax.plot(lambda x: 0.5 * x**2 - 0.5, color=BLUE)   #被逼近的抛物线
        lab = Text("dx=0.25 left  ->  dx=0.5 center",
                   font_size=24, color=GREY_B).to_edge(DOWN)   #参数说明标签
        win.play(Create(ax), FadeIn(lab), run_time=0.6)   #坐标系与标签一起出场
        win.play(Create(quad), run_time=0.7)   #画出抛物线

        rects = ax.get_riemann_rectangles(quad, x_range=[-2.5, 2.5],   #“get_riemann_rectangles”：黎曼和矩形组
                                          dx=0.25,   #参数 “dx”：矩形宽
                                          input_sample_type="left",   #参数 “input_sample_type”：左端点取样
                                          color=YELLOW)   #参数 “color”：单色填充（负面积自动反色）
        win.play(FadeIn(rects), run_time=0.6)   #左端取样矩形淡入
        win.play(FadeOut(rects), run_time=0.3)   #撤掉，换中点取样

        rects2 = ax.get_riemann_rectangles(quad, x_range=[-2.5, 2.5],
                                           dx=0.5,   #宽一点，少几个矩形
                                           input_sample_type="center",   #中点取样
                                           color=(BLUE, GREEN))   #多色列表：自动做渐变
        win.play(FadeIn(rects2), run_time=0.6)   #中点取样 + 渐变矩形淡入
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：

- `dx=0.25` 在 `[-2.5, 2.5]` 上切 20 个矩形；左端取样意味着高度取每个小区间**左端点**的函数值——曲线在 x 轴下方的区间高度为负，`show_signed_area=True` 自动把它们反色（蓝绿）。
- 第二版 `dx=0.5` 数量减半，`input_sample_type="center"` 取中点（逼近更准）；`color=(BLUE, GREEN)` 让矩形颜色按位置从蓝渐变到绿。

<video src="assets/RTM output/06-面积与黎曼矩形-riemann.mp4" controls width="560"></video>

> 提醒：
>
> - `dx` 越小逼近越好，但矩形越多越慢。
> - `input_sample_type` 要写全称 `"left"` / `"right"` / `"center"`，不接受缩写。
> - 负面积反色由 `show_signed_area` 控制。
