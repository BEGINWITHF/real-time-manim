# 网格与复平面（NumberPlane / ComplexPlane）

`Axes` 上铺一层背景网格线就是最常用的"画布"坐标系：`NumberPlane` 负责方格纸，`ComplexPlane` 是它的复数版（y 轴标签自带 `i`）。两者 `c2p`/`n2p`/`plot`/`add_coordinates` 全部可用，参数详见[二维坐标系](02-Axes.md)。

## NumberPlane

```python
def __init__(self, x_range: Sequence[float] | None = None, y_range: Sequence[float] | None = None,
             x_length: float | None = None, y_length: float | None = None,
             background_line_style: dict | None = None, faded_line_style: dict | None = None,
             faded_line_ratio: int = 1, make_smooth_after_applying_functions: bool = True,
             **kwargs: Any) -> None:
```

默认不显示刻度数字、不带箭头，轴标签朝右下；`c2p`/`plot`/`add_coordinates` 全部继承自 `Axes`。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `x_range` / `y_range` | `Sequence[float] \| None` | `±frame_x_radius` / `±frame_y_radius`，步长 1 | 同 `Axes`；默认用**未取整**的 frame 半径 |
| `x_length` / `y_length` | `float \| None` | `None` | `None` ⇒ 1 数据单位 = 1 Manim 单位（网格铺满屏幕） |
| `background_line_style` | `dict \| None` | `{"stroke_color": BLUE_D, "stroke_width": 2, "stroke_opacity": 1}` | 主网格线样式（`stroke_color`/`stroke_width`/`stroke_opacity` 都能改） |
| `faded_line_style` | `dict \| None` | 主样式的数值减半 | 淡色细分线样式 |
| `faded_line_ratio` | `int` | `1` | 细分密度：`2` → 每格 4 份，`3` → 9 份，`0` 不画淡线 |
| `make_smooth_after_applying_functions` | `bool` | `True` | 目前无实际作用，保持默认即可 |
| `**kwargs` | — | — | 透传 `Axes`（`axis_config`、`y_axis_config`、`tips`…） |

> **返回**：`NumberPlane` 实例。构造后 `background_lines`、`faded_lines`（`VGroup`）可单独取用。

#### 样例：`background_line_style` / `faded_line_ratio` 网格画布

主网格线换成半透明青色粗线（`stroke_opacity=0.6`、`stroke_width=4`），`faded_line_ratio=2` 让每个方格再细分成 2×2 份淡线，整屏就是一张细分均匀的方格纸。

```python
from real_time_manim import (
    Scene, NumberPlane, ComplexPlane, Dot, MathTex, Text,
    YELLOW, TEAL, BLUE_E, GREEN, GREY_B, UP, DOWN, UR,
    Create, FadeIn, GrowArrow, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait

class NumberPlaneDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("04-NumberPlane", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        plane = NumberPlane(
            background_line_style={"stroke_color": TEAL, "stroke_width": 4, "stroke_opacity": 0.6},   #参数 “background_line_style”：主网格线样式
            faded_line_ratio=2,   #参数 “faded_line_ratio”：每格细分成 2x2 份淡色线
        )
        lab = Text("faded_line_ratio=2  (each cell -> 4)",
                   font_size=24, color=GREY_B).to_edge(DOWN)   #参数说明标签
        win.play(Create(plane), run_time=1.2)   #画出主网格 + 淡色细分线
        win.play(FadeIn(lab), run_time=0.3)   #说明标签淡入
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：`NumberPlane()` 不传范围就是"铺满屏幕的默认方格纸"，只用 `background_line_style` 改主网格的颜色/线宽/透明度，用 `faded_line_ratio` 控制每格的细分密度（设 `0` 就只画主网格）。`Create` 会按顺序把主网格和淡色细线一起画出来。

<video src="assets/RTM output/04-网格与复平面-numberplane.mp4" controls width="560"></video>

> 提醒：`NumberPlane` 默认 `x_length=None`（1 数据单位 = 1 Manim 单位），所以改 `x_range` 会直接改变网格疏密；想固定屏幕比例请像 `Axes` 一样显式传 `x_length`/`y_length`。

## ComplexPlane

```python
def __init__(self, **kwargs: Any) -> None:
```

为复数定制的 `NumberPlane`：y 轴标签自动带 `i`（`1i, 2i, -1i…`），参数全部继承 `NumberPlane`（`x_range`、`y_range`、`background_line_style`…）。

| 方法 | 签名 | 说明 |
| --- | --- | --- |
| `number_to_point` / `n2p` | `(number: float \| complex) -> np.ndarray` | `n2p(2 + 1j)` → 场景点，复数直接定位 |
| `point_to_number` / `p2n` | `(point) -> complex` | 场景点 → 复数（`n2p` 的逆） |
| `get_coordinate_labels` | `(*numbers, **kwargs) -> VGroup` | 默认生成 x 轴实数、y 轴 `1i, 2i…` 标签 |
| `add_coordinates` | `(*numbers, **kwargs) -> Self` | 加坐标标签；可传 `[2, 1j, -3, -2j]` 自定义 |

#### 样例：`n2p` 复数落点 + `get_vector` 向量

蓝色复平面上：黄点用 `n2p(2+1j)` 直接落位并配 `MathTex` 标签，绿色箭头用 `get_vector([1, -2])` 从原点指到 `1-2i`。

```python
from real_time_manim import (
    Scene, NumberPlane, ComplexPlane, Dot, MathTex, Text,
    YELLOW, TEAL, BLUE_E, GREEN, GREY_B, UP, DOWN, UR,
    Create, FadeIn, GrowArrow, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait

class ComplexPlaneDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("04-ComplexPlane", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        cplane = ComplexPlane(
            x_range=[-3, 3, 1], y_range=[-3, 3, 1],   #范围/步长参数与 NumberPlane 相同
            background_line_style={"stroke_color": BLUE_E, "stroke_width": 2},   #网格线换成蓝色系
        ).add_coordinates()   #y 轴标签自动带 i（1i、2i…）
        d1 = Dot(cplane.n2p(2 + 1j), color=YELLOW)   #“n2p”：复数 2+i 直接换算成场景点
        label = MathTex("2+i").next_to(d1, UR, buff=0.2)   #复数标签
        vec = cplane.get_vector([1, -2], color=GREEN)   #“get_vector”：原点 -> (1,-2) 的箭头
        lab = Text("n2p(2+1j) + get_vector([1,-2])",
                   font_size=24, color=GREY_B).to_edge(DOWN)   #方法说明标签
        win.play(Create(cplane), run_time=1.0)   #画出复平面（含 i 标签）
        win.play(FadeIn(lab), run_time=0.3)   #说明标签淡入
        win.play(FadeIn(d1), Write(label), run_time=0.6)   #黄点与 “2+i” 标签出场
        win.play(GrowArrow(vec), run_time=0.6)   #绿色箭头从原点长出来
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：`ComplexPlane` 就是加了复数语义的 `NumberPlane`——`add_coordinates()` 后 y 轴标签自动变成 `1i/2i`，`n2p(2+1j)` 把复数直接换算成场景坐标放黄点，`get_vector([1, -2])` 从原点拉一支箭头到 `1-2i`（坐标按 x/y 顺序传）。

<video src="assets/RTM output/04-网格与复平面-complexplane.mp4" controls width="560"></video>

> 提醒：`get_vector` 接收的是 **x/y 数值序列** `[1, -2]`，不是复数；复数请先 `n2p` 再手动连箭头。y 轴的 `i` 标签走 `MathTex`，字体与 RTM/CE 排版引擎有关，属正常差异。

## NumberPlane.get_vector（只留表格）

```python
def get_vector(self, coords: Sequence[float], **kwargs) -> Arrow
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `coords` | 序列 | 必填 | 数据坐标（x, y 顺序），返回从**原点**指向该点的 `Arrow`（`buff=0`） |
| `**kwargs` | — | — | 传给 `Arrow`（`color`、`stroke_width`、`max_stroke_width_to_length_ratio`…） |

> **返回**：`Arrow`；样例见上面的 ComplexPlane 小节（`GrowArrow` 长出来）。

## NumberPlane.prepare_for_nonlinear_transform（只留表格）

def prepare_for_nonlinear_transform(self, num_inserted_curves: int = 50) -> Self

| 参数 | 类型 | 默认值 | 说明 |
