# 曲线标注与辅助线

这一节讲怎么在 `ax.plot` 画出的曲线上做标注与辅助：

- `plot_implicit_curve` 画 `f(x,y)=0` 的隐式曲线；
- `get_graph_label` / `get_T_label` 在曲线上放标签与三角标记；
- `get_vertical_lines_to_graph` 从 x 轴向曲线拉竖直虚线；
- `get_secant_slope_group` 生成 Δx / Δy / 割线一组。

切线与导数在[导数原函数与切线](05c-导数原函数与切线.md)。

> 提醒：这些方法都挂在 `Axes`（以及 `NumberPlane` 等子类）上，先有坐标系才能用。另外，`graph` 参数必须传 `ax.plot(...)` 的返回值，内部要读它的采样函数。

## Axes.plot_implicit_curve

```python
def plot_implicit_curve(
    self,
    func: Callable[[float, float], float],
    min_depth: int = 5,
    max_quads: int = 1500,
    **kwargs: Any,
) -> ImplicitFunction:
```

按 `f(x, y) = 0` 求等值线，返回 `ImplicitFunction`。四叉树递归细分采样区域，`min_depth` 是递归最小深度、`max_quads` 是最大细分块数。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `func` | `Callable[[float, float], float]` | 必填 | 如 `lambda x, y: x**2 + y**2 - 4`，求零等值线 |
| `min_depth` | `int` | `5` | 四叉树最小深度，越小越快越粗糙 |
| `max_quads` | `int` | `1500` | 最大细分块数，防止病态函数爆算 |
| `**kwargs` | — | — | 传给曲线（`color`、`stroke_width`…） |

#### 样例：`plot_implicit_curve` 画隐式圆

坐标系取景与半径 2 匹配（`x_range=[-3,3]`、`y_range=[-2,2]`），`x²+y²-4=0` 的等值线就是半径 2 的圆。

```python
from real_time_manim import (
    Scene, Axes, Text,
    YELLOW, TEAL, PURPLE_B, GREEN, GREY, GREY_B, UP, DOWN, DL,
    Create, FadeIn, FadeOut, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait

class ImplicitDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("05b-plot_implicit_curve", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        ax = Axes(x_range=[-3, 3, 1], y_range=[-2, 2, 1],
                  x_length=8, y_length=5)   #范围与半径 2 匹配
        circle = ax.plot_implicit_curve(lambda x, y: x**2 + y**2 - 4,   #“plot_implicit_curve”：f(x,y)=0 的等值线
                                        color=TEAL)   #x²+y²=4 即半径 2 的圆
        lab = Text("plot_implicit_curve(x^2+y^2-4=0)",
                   font_size=24, color=GREY_B).to_edge(DOWN)   #参数说明标签
        win.play(Create(ax), FadeIn(lab), run_time=0.6)   #坐标系与标签一起出场
        win.play(Create(circle), run_time=1.2)   #画出隐式圆
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：`plot_implicit_curve` 不需要给 x 范围。它在取景区域内对 `f(x,y)` 做四叉树细分，把符号变化的块不断二分直到 `min_depth`，再把边界点连成等值线。注意取景（`x_range` / `y_range`）要能框住整条曲线，否则只会画出可见的那一段。

<video src="assets/RTM output/05b-曲线标注与辅助线-implicit.mp4" controls width="560"></video>

> 提醒：
>
> - `plot_implicit_curve` 只在坐标系取景范围内求值，曲线超出取景的部分不会绘制。
> - 它返回的是 `ImplicitFunction`，**不能**再传给 `get_area` / `plot_derivative_graph` 这些需要解析函数的方法。

## Axes.get_graph_label

```python
def get_graph_label(
    self,
    graph: ParametricFunction,
    label: float | str | VMobject = "f(x)",
    x_val: float | None = None,
    direction: Sequence[float] = RIGHT,
    buff: float = MED_SMALL_BUFF,
    color: ParsableManimColor | None = None,
    dot: bool = False,
    dot_config: dict[str, Any] | None = None,
) -> Mobject:
```

在曲线指定 `x_val` 处放一个标签（默认 `MathTex` 渲染），可选同时在曲线上加圆点。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `graph` | `ParametricFunction` | 必填 | `ax.plot` 的返回值 |
| `label` | `float \| str \| VMobject` | `"f(x)"` | 标签内容（字符串经 `MathTex` 渲染） |
| `x_val` | `float \| None` | `None` → 曲线中点 | 标签所在的 x |
| `direction` | `Sequence[float]` | `RIGHT` | 标签相对圆点的方向，如 `DL`（左下） |
| `buff` | `float` | `MED_SMALL_BUFF` | 标签与圆点的间距 |
| `color` | `ParsableManimColor \| None` | `None` → 曲线颜色 | 标签颜色 |
| `dot` | `bool` | `False` | 是否同时在曲线上加圆点 |
| `dot_config` | `dict \| None` | `None` | 圆点配置（`radius`、`color`…） |

#### 样例：`get_graph_label` + `get_T_label` 曲线标注

在抛物线 `y=x²` 上演示两种标注：

- `get_graph_label(x_val=-2, direction=DL, dot=True)` 在左下放 "x²" 标签，并加上圆点；
- `get_T_label(x_val=4, label="x-value")` 在 x=4 处生成三角形 + 竖直线 + 文字的标记组。

```python
from real_time_manim import (
    Scene, Axes, Text,
    YELLOW, TEAL, PURPLE_B, GREEN, GREY, GREY_B, UP, DOWN, DL,
    Create, FadeIn, FadeOut, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait

class LabelsDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("05b-graph_label_T_label", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        ax = Axes(x_range=[-4, 4, 1], y_range=[-1, 7, 1],
                  x_length=9, y_length=5.5)   #抛物线取景
        curve = ax.plot(lambda x: x**2, color=PURPLE_B)   #抛物线 y=x²
        lab = Text("get_graph_label(x_val=-2) + get_T_label(x_val=4)",
                   font_size=24, color=GREY_B).to_edge(DOWN)   #参数说明标签
        win.play(Create(ax), FadeIn(lab), run_time=0.6)   #坐标系与标签一起出场
        win.play(Create(curve), run_time=0.8)   #画出抛物线

        label = ax.get_graph_label(curve, "x^2", x_val=-2,   #“get_graph_label”：在曲线 x=-2 处放标签
                                   direction=DL, dot=True)   #参数 “dot”：同时在曲线上加圆点
        win.play(FadeIn(label), run_time=0.5)   #标签与圆点淡入

        t_label = ax.get_T_label(x_val=4, graph=curve,   #“get_T_label”：x=4 处的标记组合
                                 label="x-value")   #三角形 + 竖直线 + 文字标签
        win.play(FadeIn(t_label), run_time=0.5)   #T 标记组淡入
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：两个标注都是"先构造、后播放"。

- `get_graph_label` 用 `MathTex("x^2")` 生成标签，再 `next_to` 曲线上 x=-2 的点；`direction=DL` 指定摆位方向，`dot=True` 顺带在曲线上钉一个圆点。
- `get_T_label` 返回一个 `VGroup`（三角形 + 从 x 轴拉到曲线的竖直线 + 文字），一次 `FadeIn` 整组出场。

<video src="assets/RTM output/05b-曲线标注与辅助线-labels.mp4" controls width="560"></video>

> 提醒：
>
> - `get_graph_label` 的 `label` 走 `MathTex`（默认真实 LaTeX；装了 `real-time-manim[typst]` extra 且未设 `RTM_TYPST=0` 时由 Typst 后端编译），所以写 `x^2` 而不是 `x²`。
> - `get_T_label` 的三角形在 x 轴上，文字在线旁；两者的 `color` 分开，用 `triangle_color` / `label_color` 控制。

## Axes.get_T_label

```python
def get_T_label(
    self,
    x_val: float,
    graph: ParametricFunction,
    label: float | str | Mobject | None = None,
    label_color: ParsableManimColor | None = None,
    triangle_size: float = MED_SMALL_BUFF,
    triangle_color: ParsableManimColor | None = WHITE,
    line_func: type[Line] = Line,
    line_color: ParsableManimColor = PURE_YELLOW,
) -> VGroup:
```

生成"x 轴上的三角形 + 竖直线 + 文字标签"整组标记，常用于指示某个 x 值对应的曲线点。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `x_val` | `float` | 必填 | 标记所在的 x |
| `graph` | `ParametricFunction` | 必填 | 竖直线拉到的曲线 |
| `label` | `float \| str \| Mobject \| None` | `None` → 不带文字 | 文字标签（字符串经 `MathTex`） |
| `label_color` | `ParsableManimColor \| None` | `None` | 文字颜色 |
| `triangle_size` | `float` | `MED_SMALL_BUFF` | 三角形大小 |
| `triangle_color` | `ParsableManimColor \| None` | `WHITE` | 三角形颜色 |
| `line_func` | `type[Line]` | `Line` | 竖直线类型，可换 `DashedLine` |
| `line_color` | `ParsableManimColor` | `PURE_YELLOW` | 竖直线颜色 |

## Axes.get_secant_slope_group

```python
def get_secant_slope_group(
    self,
    x: float,
    graph: ParametricFunction,
    dx: float | None = None,
    dx_line_color: ParsableManimColor = PURE_YELLOW,
    dy_line_color: ParsableManimColor | None = None,
    dx_label: float | str | None = None,
    dy_label: float | str | None = None,
    include_secant_line: bool = True,
    secant_line_color: ParsableManimColor = GREEN,
    secant_line_length: float = 10,
) -> VGroup:
```

在 `(x, f(x))` 处生成一组：Δx 横线段 + Δy 竖线段 + 可选的文字标签 + 割线，讲解"割线斜率 = Δy/Δx"时直接用。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `x` | `float` | 必填 | 割线起点 x |
| `graph` | `ParametricFunction` | 必填 | 目标曲线 |
| `dx` | `float \| None` | `None` → x 轴长度的 10% | 横向增量 |
| `dx_line_color` | `ParsableManimColor` | `PURE_YELLOW` | Δx 线段颜色 |
| `dy_line_color` | `ParsableManimColor \| None` | `None` → 同 `dx` | Δy 线段颜色 |
| `dx_label` / `dy_label` | `float \| str \| None` | `None` | 线段旁的文字标签 |
| `include_secant_line` | `bool` | `True` | 是否包含割线本身 |
| `secant_line_color` | `ParsableManimColor` | `GREEN` | 割线颜色 |
| `secant_line_length` | `float` | `10` | 割线长度（场景单位） |

#### 样例：`get_vertical_lines_to_graph` + 割线组

先用 `get_vertical_lines_to_graph(x_range=[0,4], num_lines=9)` 在曲线上方均匀拉 9 条灰色竖直虚线，展示采样位置；再用 `FadeOut` 撤掉它们，最后在 x=2 处生成 Δx=1 的割线组。

```python
from real_time_manim import (
    Scene, Axes, Text,
    YELLOW, TEAL, PURPLE_B, GREEN, GREY, GREY_B, UP, DOWN, DL,
    Create, FadeIn, FadeOut, Write,
)
from real_time_manim.vulkan_bind import MLWindow, Wait

class SecantDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("05b-secant_slope_group", font_size=34, color=YELLOW).to_edge(UP)   #页面标题
        win.play(Write(title), run_time=0.5)   #写出标题

        ax = Axes(x_range=[-1, 5, 1], y_range=[-1, 7, 1],
                  x_length=9, y_length=5.5)   #抛物线取景
        curve = ax.plot(lambda x: x**2, color=PURPLE_B)   #抛物线 y=x²
        lab = Text("get_vertical_lines_to_graph(9) + secant(dx=1)",
                   font_size=24, color=GREY_B).to_edge(DOWN)   #参数说明标签
        win.play(Create(ax), FadeIn(lab), run_time=0.6)   #坐标系与标签一起出场
        win.play(Create(curve), run_time=0.8)   #画出抛物线

        vlines = ax.get_vertical_lines_to_graph(curve, x_range=[0, 4],   #“get_vertical_lines_to_graph”：曲线上均匀拉竖直虚线
                                                num_lines=9, color=GREY)   #参数 “num_lines”：虚线条数
        win.play(Create(vlines), run_time=0.6)   #画出竖直虚线组
        win.play(FadeOut(vlines), run_time=0.3)   #撤掉虚线组，给割线组腾地方

        group = ax.get_secant_slope_group(x=2.0, graph=curve, dx=1.0,   #“get_secant_slope_group”：Δx 横线 + Δy 竖线 + 割线一组
                                          dx_label="dx", dy_label="dy",   #参数 “dx_label”/“dy_label”：线旁标签
                                          secant_line_color=GREEN, secant_line_length=4)   #参数 “secant_line_color”/“secant_line_length”：割线样式
        win.play(FadeIn(group), run_time=0.8)   #割线组淡入
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：

- `get_vertical_lines_to_graph` 在 `x_range=[0,4]` 内等距取 `num_lines=9` 条线，每条从 x 轴竖直拉到曲线（`**kwargs` 传样式，如 `color=GREY`）。
- `get_secant_slope_group(x=2.0, dx=1.0)` 生成一组 `VGroup`——横线段 [2,3]、竖线段 [f(2),f(3)]、"dx"/"dy" 文字和绿色割线，`FadeIn` 整组出现。

<video src="assets/RTM output/05b-曲线标注与辅助线-secant.mp4" controls width="560"></video>

> 提醒：
>
> - `get_secant_slope_group` 的 `secant_line_length` 是**场景单位**，不是数据单位；要给小值（如 4）才不会戳出画面。
> - `dx_label` / `dy_label` 走 `MathTex`。

## Axes.get_vertical_lines_to_graph

```python
def get_vertical_lines_to_graph(
    self,
    graph: ParametricFunction,
    x_range: Sequence[float] | None = None,
    num_lines: int = 20,
    **kwargs: Any,
) -> VGroup:
```

从 x 轴向曲线均匀拉竖直虚线，用于标记采样位置。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `graph` | `ParametricFunction` | 必填 | 目标曲线 |
| `x_range` | `Sequence[float] \| None` | `None` → 曲线完整范围 | `[x_min, x_max]` 线段分布区间 |
| `num_lines` | `int` | `20` | 线条数量 |
| `**kwargs` | — | — | 传给每条 `DashedLine`（`color`、`stroke_width`…） |
