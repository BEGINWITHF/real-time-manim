# 线性变换场景（LinearTransformationScene）

自带网格（灰色背景网格 + 会被变换的青色前景网格）、基向量 `î`/`ĵ` 与标签体系的教学场景，用 `apply_*` 系列方法播矩阵/函数变换动画；只画向量、不改网格请用 [向量场景](04-向量场景VectorScene.md)。RTM 下全部实测可用（含构造参数开关、四类 `apply_*`、自动改写的变换标签）。

## 参数

#### 样例：构造参数改动

四段各改一档构造参数：默认布景、`show_coordinates=True`、两个平面全关（只剩基向量）、`leave_ghost_vectors=True`（配一次剪切看残影）。

```python
from real_time_manim import LinearTransformationScene, Text, \
    Wait
from real_time_manim.vulkan_bind import MLWindow, Wait

class CtorBase(LinearTransformationScene):
    KW = {}            #子类填要传给 LinearTransformationScene.__init__ 的构造参数
    LABEL = ""         #子类填本段的标题文字
    TRANSFORM = False  #True 的子类在结尾播一次剪切

    def __init__(self, **kwargs):
        super().__init__(**self.KW, **kwargs)   #把 “KW” 里的键传给 LinearTransformationScene.__init__

    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        self.play = win.play   #apply_* 内部会调 self.play，先接到窗口上
        cap = Text(self.LABEL, font_size=26, color=YELLOW)   #顶部标题显示当前构造参数
        cap.to_edge(UP)   #标题挪到画面顶端
        self.add(cap)   #放进场景（网格与基向量由 setup 自动加好）
        win.play(Wait(1.3))   #停 1.3s 看清默认布景
        if self.TRANSFORM:
            self.apply_matrix([[1, 1], [0, 1]], run_time=1.2)   #一次水平剪切：残影开关的效果才看得见
            win.play(Wait(0.6))   #停 0.6s 看残影
        win.close()   #关闭 RTM 窗口


class LtsPlain(CtorBase):
    LABEL = "defaults (bg+fg plane, i_hat/j_hat)"   #默认布景
    KW = {}                                          #空字典 = 用 manim 的默认值


class LtsCoords(CtorBase):
    LABEL = "show_coordinates=True"                 #背景网格显示刻度数字
    KW = {"show_coordinates": True}


class LtsBgOff(CtorBase):
    LABEL = "include_background/foreground_plane=False"   #两个网格平面都不要
    KW = {"include_background_plane": False,              #关掉背景平面
          "include_foreground_plane": False}              #关掉前景平面：画面只剩基向量


class LtsGhost(CtorBase):
    LABEL = "leave_ghost_vectors=True"              #变换后保留基向量残影
    KW = {"leave_ghost_vectors": True}
    TRANSFORM = True                                #本段要播一次变换
```

这段代码在做什么：基类把构造参数收进 `KW` 字典统一传给 `LinearTransformationScene.__init__`，四个子类各换一档 —— 第一段什么都不传看默认布景（灰背景网格 + 青前景网格 + 绿 `î`/红 `ĵ`）；第二段 `show_coordinates=True` 背景网格多出刻度数字；第三段两个平面都关，画面上只剩两个基向量（对比最狠）；第四段 `leave_ghost_vectors=True`，结尾播一次水平剪切后基向量旧位置留下残影。

> 提醒：**只关背景平面画面仍有网格**（青色前景平面自带网格线），想彻底清空要两个参数一起关 —— 这是第三段存在的原因。残影只对**基向量**生效（网格不留影），且只在"变换发生"时才出现，静态摆着看不到效果。`show_coordinates` 的数字画在背景平面上，关掉背景平面它自然也没了。

### apply_matrix / apply_inverse / apply_transposed_matrix / apply_inverse_transpose

四个线性变换入口，都对前景网格、基向量、`moving_vectors`（含单位方块）生效：`apply_matrix` 施加矩阵 M；`apply_inverse` 施加 M 的逆（撤销）；`apply_transposed_matrix` 传入 M、实际施加 M 的转置；`apply_inverse_transpose` 施加转置之逆。

```python
def apply_matrix(self, matrix: np.ndarray | list | tuple, **kwargs: Any) -> None:
def apply_inverse(self, matrix: np.ndarray | list | tuple, **kwargs: Any) -> None:
def apply_transposed_matrix(self, transposed_matrix: np.ndarray | list | tuple, **kwargs: Any) -> None:
def apply_inverse_transpose(self, t_matrix: np.ndarray | list | tuple, **kwargs: Any) -> None:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `matrix` | `np.ndarray \\| list \\| tuple` | — | 2×2 矩阵（列表即可），**能填**任意可逆矩阵；`apply_inverse` 要求矩阵可逆（奇异矩阵会报错） |
| `transposed_matrix` / `t_matrix` | `np.ndarray \\| list \\| tuple` | — | 同上；传入的是"转置前"的原矩阵 —— 实际施加的是它的转置（样例里传 `[[1,1],[0,1]]` 实际是竖直剪切） |
| `**kwargs` | `Any` | — | 透传给 `self.play`：`run_time`（样例用 `1.2`）、`path_arc` 等。`path_arc` 走的是 **play 级**传播（manim `apply_transposed_matrix` 内部这么写），2026-10-17 前 RTM 的 `win.play()` 只转发 `run_time`/`rate_func`、会把它吞掉，现已补上（`Transform.path_arc` 的 setter 会重建 `path_func`） |

> **返回**：无（内部 `self.play` 播动画，RTM 里必须先 `self.play = win.play`）。

#### 样例：apply 系列改动

同一个剪切矩阵走四步：施加（水平剪切）→ 求逆还原 → 转置（变成竖直剪切）→ 转置之逆还原。四步连播，网格的变化方向肉眼可辨。

```python
from real_time_manim import LinearTransformationScene, Text, \
    UP, YELLOW, Wait
from real_time_manim.vulkan_bind import MLWindow, Wait

def say(cap, text):   #瞬间换掉顶部说明文字，不占动画时间
    cap.become(Text(text, font_size=26, color=YELLOW).to_edge(UP))

class ApplyDemo(LinearTransformationScene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        self.play = win.play   #apply_* 内部都会调 self.play，先接到窗口上
        cap = Text("", font_size=26, color=YELLOW)   #顶部说明文字（内容后面换）
        cap.to_edge(UP)   #标题挪到画面顶端
        self.add(cap)   #放进场景

        say(cap, "apply_matrix([[1, 1], [0, 1]])")
        self.apply_matrix([[1, 1], [0, 1]], run_time=1.2)   #水平剪切：整格向右上斜
        win.play(Wait(0.5))   #停 0.5s

        say(cap, "apply_inverse([[1, 1], [0, 1]])")
        self.apply_inverse([[1, 1], [0, 1]], run_time=1.2)   #求 M 的逆并施加：撤销上一步
        win.play(Wait(0.5))   #停 0.5s

        say(cap, "apply_transposed_matrix([[1, 1], [0, 1]])")
        self.apply_transposed_matrix([[1, 1], [0, 1]], run_time=1.2)   #传入 M，实际施加 M 的转置（竖直剪切）
        win.play(Wait(0.5))   #停 0.5s

        say(cap, "apply_inverse_transpose([[1, 1], [0, 1]])")
        self.apply_inverse_transpose([[1, 1], [0, 1]], run_time=1.2)   #施加转置之逆：又回到原网格
        win.play(Wait(0.6))   #停 0.6s 收工
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：用同一个矩阵 `[[1, 1], [0, 1]]` 走完整闭环 —— ① `apply_matrix` 把网格水平剪切（x 方向拉斜）；② `apply_inverse` 求逆还原回正交网格；③ `apply_transposed_matrix` 施加转置，网格变成竖直剪切（方向和①明显不同）；④ `apply_inverse_transpose` 施加转置之逆，再次回到原网格。四个方法各自的"作用方向"在同一屏里依次可比。

<video src="assets/RTM output/05-线性变换场景-apply.mp4" controls width="560"></video>

> 提醒：`apply_transposed_matrix` / `apply_inverse_transpose` 的参数是**原矩阵**（方法内部自己转置），别把转置后的矩阵再传进去。`apply_inverse` 对奇异矩阵（行列式为 0）会直接 `LinAlgError`。`run_time` 透传给 `self.play`，四个方法都可传。

### apply_nonlinear_transformation / apply_function

两个非线性入口：前者会先细分前景网格（`prepare_for_nonlinear_transform`）再施加函数（弯曲处线条平滑），后者直接逐点施加函数（适合简单拉伸）。

```python
def apply_nonlinear_transformation(self, function: Callable[[np.ndarray], np.ndarray], **kwargs: Any) -> None:
def apply_function(self, function: MappingFunction, added_anims: list[Animation] = [], **kwargs: Any) -> None:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `function` | `Callable[[np.ndarray], np.ndarray]` | — | 点变换函数：输入 `[x, y, z]`，**必须返回三元** `np.array([x', y', z'])`（`p[2]` 别丢）；**能填**任意逐点函数 |
| `added_anims` | `list[Animation]` | `[]` | 仅 `apply_function`：与变换同时播的其它动画 |
| `**kwargs` | `Any` | — | 透传给 `self.play`：`run_time`（样例用 `1.6`）等 |

> **返回**：无（内部 `self.play` 播动画）。

#### 样例：非线性变换改动

两个逐点函数连播：`swirl`（离原点越远转得越多）和 `squash`（用 `tanh` 纵向压扁、保证有界）。

```python
import math
import numpy as np

from real_time_manim import LinearTransformationScene, Text, \
    UP, YELLOW, Wait
from real_time_manim.vulkan_bind import MLWindow, Wait

def say(cap, text):   #瞬间换掉顶部说明文字，不占动画时间
    cap.become(Text(text, font_size=26, color=YELLOW).to_edge(UP))

class NonlinearDemo(LinearTransformationScene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        self.play = win.play   #apply_* 内部都会调 self.play，先接到窗口上
        cap = Text("", font_size=26, color=YELLOW)   #顶部说明文字（内容后面换）
        cap.to_edge(UP)   #标题挪到画面顶端
        self.add(cap)   #放进场景
        self.add_unit_square(animate=False)   #放个单位正方形，弯曲效果更直观

        def swirl(p):   #按到原点的距离旋转：离原点越远转得越多
            x, y = p[0], p[1]
            a = 0.5 * math.hypot(x, y)   #每单位半径多转 0.5 弧度
            c, s = math.cos(a), math.sin(a)
            return np.array([x * c - y * s, x * s + y * c, p[2]])

        def squash(p):   #纵向压扁：离 x 轴越远压得越狠
            return np.array([p[0], 3.0 * math.tanh(p[1] / 3.0), p[2]])   #tanh 保证有界

        say(cap, "apply_nonlinear_transformation(swirl)")
        self.apply_nonlinear_transformation(swirl, run_time=1.6)   #先细分平面再施加函数
        win.play(Wait(0.6))   #停 0.6s

        say(cap, "apply_function(squash)")
        self.apply_function(squash, run_time=1.6)   #直接对每个点施加函数
        win.play(Wait(0.6))   #停 0.6s 收工
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：先摆一个单位方块当参照物，然后 ① `apply_nonlinear_transformation(swirl)` —— 每个点绕原点多转 `0.5 × 半径` 弧度，整个网格旋成漩涡、方块被拧成弧边；② `apply_function(squash)` —— y 坐标过一遍 `3·tanh(y/3)`，离 x 轴越远压得越狠（远处的网格线挤成密条带、中心保持原样），方块被横向压扁。

<video src="assets/RTM output/05-线性变换场景-nonlinear.mp4" controls width="560"></video>

> 提醒：函数签名是 `p -> np.array([x', y', z'])`，返回值**必须三元**（`p[2]` 是 z 分量，照抄搬走即可），返回二元会报形状错。`apply_nonlinear_transformation` 会先细分网格（线条更平滑、帧更重），`apply_function` 直接逐点（适合 squash 这类温和变换）。两者都会同时作用于前景网格、基向量、单位方块和 `moving_vectors`。

#### 样例：组合编排改动

把上面的方法串成一段完整的"线性代数课堂"：标题 → 单位方块 → 向量 → 坐标矩阵 → 可改写标签 → 旋转 90° 全部联动。

```python
from real_time_manim import LinearTransformationScene, Text, \
    UP, DOWN, YELLOW, Wait
from real_time_manim.vulkan_bind import MLWindow, Wait

def say(cap, text):   #瞬间换掉顶部说明文字，不占动画时间
    cap.become(Text(text, font_size=26, color=YELLOW).to_edge(UP))

def say_low(cap, text):   #ComposeDemo 专用：说明放底部，给顶部的 add_title 让位
    cap.become(Text(text, font_size=26, color=YELLOW).to_edge(DOWN))

class ComposeDemo(LinearTransformationScene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        self.play = win.play   #add_title / add_unit_square / add_vector 内部会调 self.play，先接到窗口上
        cap = Text("", font_size=26, color=YELLOW)   #说明文字放底部，给顶部的标题让位
        cap.to_edge(DOWN)   #标题挪到画面底端
        self.add(cap)   #放进场景

        say_low(cap, "add_title('Linear Transformation', animate=True)")
        self.add_title("Linear Transformation",   #顶部大标题（自动加背景条、进前景层）
                       scale_factor=0.9, animate=True)   #animate=True 时内部播 Write
        win.play(Wait(0.7))   #停 0.7s

        say_low(cap, "add_unit_square(animate=True)")
        self.add_unit_square(animate=True)   #画出单位正方形（DrawBorderThenFill）
        win.play(Wait(0.5))   #停 0.5s

        say_low(cap, "add_vector([2, 1], color=YELLOW, animate=True)")
        v = self.add_vector([2, 1], color=YELLOW, animate=True)   #放一个向量并登记进 moving_vectors
        win.play(Wait(0.6))   #停 0.6s

        say_low(cap, "write_vector_coordinates(v)")
        self.write_vector_coordinates(v)   #写出列矩阵坐标
        win.play(Wait(0.6))   #停 0.6s

        say_low(cap, "add_transformable_label(v, 'w', ...)")
        self.add_transformable_label(v, "w",   #变换时会自动改写的标签
                                     transformation_name="L",
                                     label_scale_factor=0.8)
        win.play(Wait(0.6))   #停 0.6s

        say_low(cap, "apply_matrix([[0, -1], [1, 0]])  rotate 90°")
        self.apply_matrix([[0, -1], [1, 0]], run_time=1.4)   #旋转 90°：方块变竖、标签随矩阵改写
        win.play(Wait(0.7))   #停 0.7s 收工
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：① `add_title(..., animate=True)` 在顶部 `Write` 出大标题（自动带背景条）；② `add_unit_square(animate=True)` 画单位方块；③ `add_vector([2, 1], animate=True)` 让黄色向量 `GrowArrow` 长出来并登记进 `moving_vectors`；④ `write_vector_coordinates(v)` 在旁边写出列矩阵 `★[2, 1]`；⑤ `add_transformable_label(v, "w", ...)` 放一个会随变换改写的标签；⑥ `apply_matrix` 旋转 90° —— 方块转竖、向量指向左上、`w` 标签自动改写成 `L(w)`，坐标矩阵停在原地（前景层不参与变换）。整段演示"一套教学元素如何联动"。

<video src="assets/RTM output/05-线性变换场景-compose.mp4" controls width="560"></video>

> 提醒：`add_title` 固定钉在画面**顶部**，所以本样例的说明文字放到了底部（`say_low`）——你自己写场景时给标题让位即可。`add_vector` 在 `LinearTransformationScene` 里**默认 `animate=False`**（和 `VectorScene` 的默认 `True` 相反），要出场动画得显式传。标签改写发生在 `apply_*` 播放期间（视频末尾 `w` → `L(w)`）；列矩阵在前景层、**不随变换移动**，这是刻意行为（坐标值写的是变换前的量）。
