# 内容上屏：add / remove 与层次

把对象放上画面、拿下来、调遮挡顺序。RTM 逐帧照着 `scene.mobjects` 的顺序绘制，所以加入顺序就是绘制顺序：先加的在下面，后加的盖在上面。前景名单（`foreground_mobjects`）永远画在最上层。

## 参数

### `Scene.add` 

```python
def add(self, *mobjects: Mobject | OpenGLMobject) -> Self:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `*mobjects` | `Mobject` | — | 要上屏的对象，可一次传多个。**能填**任意 `Mobject`；按加入顺序从背景到前景绘制（先加的在下面），返回 `Scene` 自身可链式调用。已经在场景里的对象再 `add` 一次会被挪到最上层 |

#### 样例：`Scene.add`

三个形状依次加入，谁盖住谁一眼可见；动画里新加的对象（小绿方块）直接盖在最上层。

```python
from real_time_manim import (
    Scene,
    Square, Circle, Triangle, Text,
    BLUE, RED, GREEN, YELLOW, WHITE,
    UP, RIGHT,
    FadeIn,
)
from real_time_manim.vulkan_bind import MLWindow, Wait

class AddDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 场景，绑定给名为 “win” 的 RTM 窗口
        back = Square(color=BLUE, side_length=2.5)   #第一个加入的方块
        mid = Circle(color=RED, radius=1.6)   #第二个加入的圆
        top = Triangle(color=YELLOW).scale(1.3).shift(RIGHT * 2.2)   #第三个加入的三角
        self.add(back)   #先加的画在最下面
        self.add(mid, top)   #后加的盖在上面；一次可传多个
        self.add(Text("add order = paint order", font_size=36, color=WHITE).to_edge(UP))   #最后加的文字在最上层
        win.play(Wait(0.5))   #保持 0.5s，看清谁盖住谁
        win.play(FadeIn(Square(color=GREEN, side_length=1.2)), run_time=0.5)   #动画新加的对象直接盖在最上层
        win.play(Wait(0.5))   #再等 0.5s
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：先加一个蓝色方块、再加一个红色圆、最后加一个黄色三角，然后放一行标题。因为按加入顺序从下往上画，圆压着方块、三角压着圆、标题压在所有形状上面。

接着用 `FadeIn` 播一个小绿方块进来，它属于"动画新加的对象"，同样直接盖在最上层。整个过程没有任何层次调整调用，全靠 `add` 的顺序。

<video src="assets/RTM output/02-内容上屏-add.mp4" controls width="560"></video>

> 提醒：动画新增对象时也遵守这条规则：`win.play(FadeIn(x))` 里的 `x` 若不在场景中会被登记并追加到列表末尾（最上层）；已经在场景里的对象（哪怕是某个 Group 的子对象）不会被重新排序，它留在原位。

### `Scene.remove` 

```python
def remove(self, *mobjects: Mobject) -> Self:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `*mobjects` | `Mobject` | — | 要下屏的对象，可一次传多个；返回 `Scene` 自身。会连带处理子对象：从 `Group` 里删一个子对象会把组"拆解"、其余成员保留为顶层对象 |

#### 样例：`Scene.remove`

圆压着方块；把圆 `remove` 掉，下面的方块就露出来了。

```python
from real_time_manim import Scene, Square, Circle, BLUE, RED
from real_time_manim.vulkan_bind import MLWindow, Wait

class RemoveDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 场景，绑定给名为 “win” 的 RTM 窗口
        back = Square(color=BLUE, side_length=2.5)   #被盖住的方块
        front = Circle(color=RED, radius=1.6)   #压在上面的圆
        self.add(back, front)   #圆盖着方块上屏
        win.play(Wait(0.5))   #先看清“圆盖住方块”
        self.remove(front)   #把圆拿下屏，露出下面的方块
        win.play(Wait(0.5))   #再等 0.5s 看效果
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：先把方块和圆放进场景（圆后加、压在方块上），等 0.5 秒让你看清遮挡关系；然后 `remove` 把圆拿下屏——被盖住的蓝色方块立刻完整露出来，再等 0.5 秒收工。

`remove` 是立即生效的，不需要配任何动画。

<video src="assets/RTM output/02-内容上屏-remove.mp4" controls width="560"></video>

> 提醒：`remove` 的对象必须在场景里（不在就等于没干任何事）。RTM 内部也走同一个入口：`Uncreate`、`FadeOut` 这类"消失"动画收尾时就是调 `scene.remove` 把对象摘掉的。

### `Scene.clear` 

```python
def clear(self) -> Self:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| （无参数） | — | — | 一键下屏：`mobjects` 和 `foreground_mobjects` 两个列表全部清空。返回 `Scene` 自身。常用于"翻页"式切换画面 |

#### 样例：`Scene.clear`

画面清空后重新放一个新标题，就像翻了一页。

```python
from real_time_manim import Scene, Square, Circle, Text, BLUE, RED, YELLOW, GREEN, LEFT, RIGHT, UP
from real_time_manim.vulkan_bind import MLWindow, Wait

class ClearDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 场景，绑定给名为 “win” 的 RTM 窗口
        self.add(Square(color=BLUE, side_length=2).shift(LEFT * 2))   #放一个方块
        self.add(Circle(color=RED, radius=1.2).shift(RIGHT * 2))   #再放一个圆
        self.add(Text("before clear", font_size=40, color=YELLOW).to_edge(UP))   #加个标题
        win.play(Wait(0.5))   #先看清屏幕上的内容
        self.clear()   #一键清空：mobjects 和 foreground_mobjects 全部下屏
        self.add(Text("after clear", font_size=40, color=GREEN).to_edge(UP))   #再放一个新标题
        win.play(Wait(0.5))   #画面里只剩新标题
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：先摆一个方块、一个圆和一个黄色标题，等 0.5 秒看清内容；然后 `clear()` 一次性把所有东西下屏（连前景名单也一起清），再放一个绿色的新标题，等 0.5 秒——画面里从"三个对象"变成"一个标题"，就是一次翻页。

<video src="assets/RTM output/02-内容上屏-clear.mp4" controls width="560"></video>

> 提醒：`clear()` 只是把对象从场景摘掉，不销毁对象本身；想回来接着用就再 `add` 一次。它连 `foreground_mobjects` 一起清，所以清屏后要重新登记前景。

### 层次调整：`bring_to_front` / `bring_to_back` / `add_foreground_mobject(s)` / `remove_foreground_mobject(s)`

```python
def bring_to_front(self, *mobjects: Mobject) -> Scene:
def bring_to_back(self, *mobjects: Mobject) -> Scene:
def add_foreground_mobjects(self, *mobjects: Mobject) -> Scene:
def add_foreground_mobject(self, mobject: Mobject) -> Scene:
def remove_foreground_mobjects(self, *to_remove: Mobject) -> Scene:
def remove_foreground_mobject(self, mobject: Mobject) -> Scene:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `*mobjects` / `mobject` | `Mobject` | — | 要调整层次的对象。`bring_to_front` 重新 `add` 到最上层；`bring_to_back` 挪到最底层；均返回 `Scene` 自身 |
| `*to_remove` / `mobject` | `Mobject` | — | 前景登记/注销的对象。前景对象永远画在最上层（哪怕别的对象后加、动画对象进出），适合标题、图例、放大窗边框 |

#### 样例：层次调整

方块换层、大圆扫过标题：先看"谁在上层"随 `bring_to_front` / `bring_to_back` 变化，再看标题登记为前景后如何压着大圆、注销后又被大圆盖住。

```python
from real_time_manim import Scene, Square, Circle, Text, BLUE, RED, GREEN, YELLOW, UP, LEFT, RIGHT
from real_time_manim.vulkan_bind import MLWindow, Wait

class ZorderDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 场景，绑定给名为 “win” 的 RTM 窗口
        self.play = win.play   #置顶规则会在 win.play 内部重排对象，先接上
        blue = Square(color=BLUE, side_length=2.2).shift(LEFT * 0.6)   #先加的蓝方块
        red = Square(color=RED, side_length=2.2).shift(RIGHT * 0.6)   #后加的红方块，压在蓝上
        title = Text("z-order", font_size=40, color=YELLOW).to_edge(UP)   #要置顶的标题
        self.add(blue, red)   #红上蓝下
        win.play(Wait(0.5))
        self.bring_to_front(blue)   #蓝方块提到最上层
        win.play(Wait(0.5))
        self.bring_to_back(blue)   #蓝方块压回最底层
        win.play(Wait(0.5))
        self.add(title)   #标题先按普通对象上屏
        sweep = Circle(color=GREEN, radius=2.8, fill_opacity=1).shift(LEFT * 9 + UP * 3.5)   #一个实心大圆，会横扫过标题
        self.add(sweep)   #大圆后加，压在标题上面
        win.play(sweep.animate.shift(RIGHT * 8), run_time=0.8)   #大圆横扫过标题，把标题盖住
        self.add_foreground_mobject(title)   #标题登记为前景：立刻浮到最上层
        win.play(Wait(0.5))   #停 0.5s：标题压在圆上
        self.remove_foreground_mobject(title)   #取消前景；但标题已被 add 挪到列表末尾，仍在最上层
        self.bring_to_back(title)   #想回到下层还得自己压回去
        win.play(Wait(0.5))   #停 0.5s：标题又被圆盖住了
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：两个方块重叠摆放，`bring_to_front(blue)` 让蓝方块盖住红方块，`bring_to_back(blue)` 又把它压回红方块下面——重叠部分的归属随之翻转。

接着一个实心绿圆从左往右横扫过标题，把标题盖住；此时 `add_foreground_mobject(title)` 把标题登记为前景，它立刻浮到绿圆之上。最后 `remove_foreground_mobject(title)` 注销前景、再 `bring_to_back(title)` 把它压回底层，标题重新被绿圆盖住。

<video src="assets/RTM output/02-内容上屏-zorder.mp4" controls width="560"></video>

> 提醒：两个坑。
>
> ① `add_foreground_mobject` 内部会把对象再 `add` 一遍（`Scene.add` 的前景规则顺手把它挪到列表末尾），所以它常常"顺带"变到最上层；`remove_foreground_mobject` **只是退出前景名单**，对象还留在列表末尾、依然画在最上层——真想让它回下层得自己 `bring_to_back`（样例最后一段演的就是这一步）。
>
> ② 每次 `win.play` 都会按前景名单把前景对象拉回最上层，所以前景标题不会被后加的动画对象盖住。

### `Scene.replace` / 场景查询工具 

```python
def replace(self, old_mobject: Mobject, new_mobject: Mobject) -> None:
def get_attrs(self, *keys: str) -> list[Any]:
def get_top_level_mobjects(self) -> list[Mobject]:
def get_mobject_family_members(self) -> list[Mobject]:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `old_mobject` | `Mobject` | — | 被顶替的对象，必须已在场景中；找不到时抛 `ValueError`。若它是某 `Group` 的子对象，则在组内原位替换 |
| `new_mobject` | `Mobject` | — | 顶上去的新对象，不能已经在场景中。无返回值；保持绘制顺序不变，只换这一格 |

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `*keys` | `str` | — | 属性名（仅 `get_attrs`）。三个查询函数分别返回属性值列表、顶层对象列表、全部对象及子对象的展平列表 |

#### 样例：`Scene.replace`

三角原位换成方块，旁边红点纹丝不动——保持绘制顺序只换一格。

```python
from real_time_manim import Scene, Square, Triangle, Dot, GREEN, ORANGE, RED, LEFT, RIGHT
from real_time_manim.vulkan_bind import MLWindow, Wait

class ReplaceDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 场景，绑定给名为 “win” 的 RTM 窗口
        tri = Triangle(color=GREEN).scale(1.3).shift(LEFT * 2.5)   #将被顶替的三角
        dot = Dot(color=RED, radius=0.35).shift(RIGHT * 2.5)   #旁边的红点，作对照
        self.add(tri, dot)   #两个对象上屏
        print("replace之前：top-level = %d" % len(self.get_top_level_mobjects()))   #查询工具 get_top_level_mobjects
        win.play(Wait(0.5))
        self.replace(tri, Square(color=ORANGE, side_length=1.8).shift(LEFT * 2.5))   #三角原位换成方块
        print("replace 之后：top-level = %d" % len(self.get_top_level_mobjects()))   #数量不变，只是原位顶替
        win.play(Wait(0.5))
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：屏幕左边放一个绿三角、右边放一个红点做对照，先用 `get_top_level_mobjects()` 数一下顶层对象（2 个）。等 0.5 秒后用 `replace` 把三角原位换成橙色方块，再数一次——还是 2 个，说明只是顶替、没有增删，旁边的红点也完全不受影响。

<video src="assets/RTM output/02-内容上屏-replace.mp4" controls width="560"></video>

> 提醒：`replace` 之后记得别再引用旧对象（它已不在场景里）。
>
> 计数时留意：`self.wait(...)` 这类走 manim `Wait` 的等待会在 `scene.mobjects` 里留一个空 `Mobject`（上游行为），让 `len(self.mobjects)` 多 1；用 `win.play(Wait(...))` 则不会（详见 [播放与等待](03-播放与等待.md)）。
