# 路径与窗口

`config` 里管**输出路径**（`media_dir` 那批目录模板）和**窗口**（OpenGL 预览窗口的位置/尺寸/全屏）的键，在 RTM 里**成片路径一个都不接线**：RTM 的输出就是你给的那一个文件路径（`out_path`），窗口由 `MLWindow(w, h, hidden)` 管。

**例外**：`tex_dir` / `text_dir` / `assets_dir` 对**中间产物**（LaTeX/Typst 编译目录、`Text` 的 svg、图片/音频查找目录）仍然生效，`tex_template` / `tex_template_file` 实际生效（2026-10-17 实测，见下表）。

想要的效果都能做到，只是入口换了——对照关系见本页最后的样例，参数细节见 [05-RTM的录制与窗口参数](05-RTM的录制与窗口参数.md)。

## 参数

### `config` 输出路径键（速查表 C；成片未接线，中间产物见 `tex_dir` / `text_dir` / `assets_dir`）

**作用**：这批键在 ManimCE 里拼出 `media/videos/...`、`media/Tex` 这些目录模板；RTM 的**成片**不走这套模板，产物只有 `out_path` 一个文件（外加临时的 manim `media/` 目录，录完自动清）。

但 manim 自己的 LaTeX / Text / 图片管线还在跑，它们读的目录键依然生效。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `media_dir` | `str` | `./media` | 成片不接线：输出根目录模板没用，RTM 直接给文件路径 `out_path`。但 `tex_dir` / `text_dir` 默认是它的子目录，改它会连带移动 LaTeX / Text 中间产物；另注意清理用的 `util.clear_media()` 只删 `<cwd>/media`（`real_time_manim/util.py:144-166`），**不跟随** `config.media_dir` |
| `video_dir` | `str` | `{media_dir}/videos/{module_name}/{quality}` | 不接线：同上 |
| `sections_dir` | `str` | `{video_dir}/sections` | 不接线：想分段输出就拆场景分别录 |
| `images_dir` | `str` | `{media_dir}/images/{module_name}` | 不接线 |
| `partial_movie_dir` | `str` | `{video_dir}/partial_movie_files/{scene_name}` | 不接线：RTM 没有片段缓存，不会生成 partial movie |
| `tex_dir` | `str` | `{media_dir}/Tex` | **对中间产物生效**：LaTeX/Typst 编译目录就是 `config.get_dir("tex_dir")`（`manim/utils/tex_file_writing.py:105,202,277`、`manim/utils/typst_file_writing.py:84`），改了 `.tex`/`.svg` 中间文件就换地方（2026-10-17 实测：设成临时目录后 `Tex('a + b')` 的 `.tex`/`.svg` 真落在那里）；**不接线的只是成片输出路径**（RTM 只用 `out_path`）。默认在 `media/` 下，随 `cleanup=True` 一起清掉 |
| `text_dir` | `str` | `{media_dir}/texts` | **对中间产物生效**：`Text` 的 svg 缓存目录就是 `config.get_dir("text_dir")`（`manim/mobject/text/text_mobject.py:841,1388`；2026-10-17 实测 `Text('hello rtm')` 落在改后的目录），同上 |
| `log_dir` | `str` | `{media_dir}/logs` | 不接线：RTM 不写日志文件，输出都在终端 |
| `assets_dir` | `str` | `./` | **对查找目录生效**：`get_full_raster_image_path` / `get_full_svg_image_path`（`manim/utils/images.py:27-38`，音频 `manim/utils/sounds.py:24` 同）把 `config.get_dir("assets_dir")` 当默认搜索目录之一——先试你给的原样相对路径，再试 `assets_dir` 下的同名文件（2026-10-17 实测：改了之后新目录里的同名 png 能被 `ImageMobject` 找到）。**不接线的只是成片输出路径** |
| `input_file` | `str \| Path` | — | 不接线：RTM 没有「被渲染的脚本」这个概念 |
| `scene_names` | `list[str]` | `[]` | 不接线：渲哪个场景 = 在自己的脚本里调哪个 `fast_record_scene` |
| `custom_folders` | `str` | `False` | 不接线（自定义目录结构随 `media_dir` 一起失效） |
| `tex_template` | `TexTemplate` | 默认模板 | **实际生效**：`config.tex_template` 是真的 `TexTemplate` 对象（2026-10-17 实测 `type(...) == TexTemplate`、`hasattr(..., "add_to_preamble") == True`），RTM 走 manim 自己的 LaTeX 管线（`manim/utils/tex_file_writing.py:56-57,98-99` 直接读 `config["tex_template"]`）——实测给模板加一行自定义注释后，写出的 `.tex` 里就带这行 |
| `tex_template_file` | `Path` | `""` | **实际生效**：`tex_template` 的 getter 会在该键非空时 `TexTemplate.from_file(...)` 载入（`manim/_config/utils.py:1811-1820`），设了它等于换掉整个模板 |
| `plugins` | `list[str]` | `[]` | 不接线：插件由 manim 命令行加载，RTM 不走命令行 |
| `log_to_file` | `bool` | `False` | 不接线 |
| `ffmpeg_loglevel` | `str` | `ERROR` | 不接线：RTM 自己起 ffmpeg（stderr 直接丢弃），这个键管不到 |
| `notify_outdated_version` | `bool` | `True` | 不接线 |
| `no_latex_cleanup` | `bool` | `False` | 不接线：注意 RTM 的 `cleanup` 是反着的——默认把 manim 的 `media/` **整个删掉**，`cleanup=False` 才保留 |
| `preview_command` | `str` | `""` | 不接线：渲完想看自己打开播放器 |

> 提醒：
>
> - 最常踩的坑：把输出文件「安排」在 `media_dir` 模板里，然后去找 `media/videos/xxx/1080p60/`——RTM 根本不会生成这个路径，文件就在你 `out_path` 给的那个位置（不存在的子目录会自动创建）。
> - 反过来，manim 自己的 `media/` 临时目录**会被 RTM 删掉**（`cleanup=True` 默认），想留着研究就传 `cleanup=False`。

### `config` 窗口键（速查表 D，全部未接线）

**作用**：这批键在 ManimCE 里配置 OpenGL 预览窗口（位置、尺寸、全屏、调试开关）；RTM 的窗口由 `MLWindow(w, h, hidden)` 创建，尺寸还只能是 1920×1080。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `enable_gui` | `bool` | `False` | 不接线（DearPyGUI 控制面板，RTM 没有） |
| `gui_location` | `tuple[int,...]` | `(0,0)` | 不接线 |
| `fullscreen` | `bool` | `False` | 不接线：录出来的永远是 1920×1080 的帧，跟窗口全不全屏无关 |
| `window_position` | `str` | `UR` | 不接线：窗口位置 RTM 不管（弹出位置随系统） |
| `window_size` | `str \| tuple` | `default` | 不接线：窗口尺寸 = `MLWindow(w, h)` 的两个参数，而且只能 1920×1080 |
| `window_monitor` | `int` | `0` | 不接线（用哪块显示器渲染） |
| `force_window` | `bool` | `False` | 不接线：想开窗口用 `fast_record_scene(hidden=False)` 或 `record_scene` |
| `enable_wireframe` | `bool` | `False` | 不接线（线框调试） |
| `use_projection_fill_shaders` | `bool` | `False` | 不接线（OpenGL 着色器兼容开关，RTM 用自己的渲染管线） |
| `use_projection_stroke_shaders` | `bool` | `False` | 不接线（同上） |
| `media_embed` | `bool \| None` | `False` | 不接线（Jupyter 内嵌视频） |
| `media_width` | `str` | `60%` | 不接线（同上） |

> 提醒：`hidden` 是 RTM 窗口唯一的显隐开关（构造参数或 `fast_record_scene(hidden=...)`），它只影响**你的桌面**上弹不弹窗，录出来的视频内容完全一样——这一点有出片对比，见 [05-RTM的录制与窗口参数](05-RTM的录制与窗口参数.md) 的 `MLWindow` 样例。

### RTM 侧对照：路径给 `out_path`，窗口给 `MLWindow`

| 想做什么 | RTM 里用 | 详见 |
| --- | --- | --- |
| 指定输出文件 | `fast_record_scene(..., out_path="my.mp4")` | [05](05-RTM的录制与窗口参数.md) 的 `out_path` 样例 |
| 输出到子目录 | `out_path="clips/my.mp4"`（自动建目录） | 同上 |
| 窗口尺寸 | `MLWindow(w, h)`（只能 1920×1080） | [05](05-RTM的录制与窗口参数.md) 的 `MLWindow` 样例 |
| 窗口显隐 | `fast_record_scene(..., hidden=...)` | 同上 |
| 边渲边看 / 实时录制 | `record_scene(...)` | [05](05-RTM的录制与窗口参数.md) 的 `record_scene` 样例 |
| 保留 manim 临时目录 | `fast_record_scene(..., cleanup=False)` | [05](05-RTM的录制与窗口参数.md) |

#### 样例：config → RTM 对照

这条样例不演示单个参数，而是把上面两张表的「谁管」关系做成动画上屏：一行 `config` 键、一行 RTM 真正的入口。

```python
from real_time_manim import Scene, Text, VGroup, ORANGE, GREY_B, UP, DOWN, LEFT, Write, FadeIn
from real_time_manim.vulkan_bind import MLWindow, Wait

class ConfigToRtmDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        title = Text("config  ->  RTM", font_size=42, color=ORANGE).to_edge(UP, buff=0.7)   #标题行
        rows = VGroup(
            Text("media_dir / video_dir  ->  out_path = my.mp4", font_size=30, color=GREY_B),
            Text("window_size / window_position  ->  MLWindow(w, h)", font_size=30, color=GREY_B),
            Text("fullscreen / force_window  ->  hidden", font_size=30, color=GREY_B),
            Text("preview  ->  hidden=False", font_size=30, color=GREY_B),
        ).arrange(DOWN, buff=0.3, aligned_edge=LEFT).next_to(title, DOWN, buff=0.7)   #四行对照排好
        self.add(title)   #把标题放进场景
        win.play(Write(title), run_time=0.7)   #写出标题
        for row in rows:   #对照行一行一行上屏
            win.play(FadeIn(row, shift=UP * 0.15), run_time=0.4)   #淡入一行对照
        win.play(Wait(0.5))   #进行 0.5s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：先写出「config -> RTM」的标题，然后把四组对照一行一行淡入上屏：

- 目录模板换成 `out_path`；
- 窗口尺寸/位置换成 `MLWindow(w, h)`；
- 全屏/强制开窗换成 `hidden`；
- 渲染完预览换成 `hidden=False`。

最后等 0.5 秒收工。视频就是本页内容的浓缩版：左边这些 `config` 键都不接线，右边才是 RTM 真正的入口。

> 提醒：对照关系记不住时，想一句就行——「路径 = `out_path`，窗口 = `MLWindow`，其余 config 键当它不存在」。
>
> 另外注意 RTM 渲完会**主动删** manim 的 `media/` 临时目录（`cleanup=True` 默认），别把重要东西放在那里面。
