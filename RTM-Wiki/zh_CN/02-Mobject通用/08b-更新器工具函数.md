# 更新器工具函数（模块级）

`manim.animation.updaters` 提供的模块级便捷函数：一键重绘、匀速平移/旋转、把动画变成 updater。

## 参数

### always_redraw

```python
def always_redraw(func: Callable[[], M]) -> M
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `func` | 无参可调用 | — | 返回一个新 `Mobject` 的工厂函数 |

> **返回**：已挂好 updater 的 `Mobject`（即 `func()` 的第一次结果），直接 `self.add(...)` 即可。`ValueTracker` 驱动「依赖当前值的图形」的标准写法——每帧重新执行工厂函数并 `become` 它的结果。

#### 样例：轨道上的圆点

`ValueTracker` 沿轨道走，`always_redraw` 每帧按当前值重画一个圆点——圆点位置实时跟随数值。

```python
from real_time_manim import Scene, Line, Dot, ValueTracker, \
    RED, GREY, LEFT, RIGHT
from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim import always_redraw

class AlwaysRedrawDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        alpha = ValueTracker(0.0)   #数值追踪器
        track = Line(LEFT * 3.0, RIGHT * 3.0, color=GREY)   #一段轨道
        self.add(track)   #进场景
        bead = always_redraw(lambda: Dot(color=RED, radius=0.12).move_to(LEFT * 3.0 + alpha.get_value() * RIGHT))   #每帧按当前值重画圆点
        self.add(bead)   #进场景（返回的就是挂好 updater 的对象）
        win.play(alpha.animate.set_value(6.0), run_time=1.0)   #驱动 tracker：圆点沿轨道匀速走
        win.play(Wait(0.4))   #进行 0.4s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：灰色轨道从 `x=-3` 到 `x=+3`；`ValueTracker` 从 0 动画到 6 的同时，`always_redraw(lambda: Dot(...))` **每帧**重新造一个新圆点——位置按 `alpha.get_value()` 计算，`become` 到旧圆点上。

效果就是红点沿轨道匀速滑行：数值在变，图形永远「现算现画」。这是「图形依赖某个可变数值」的标准姿势。

<video src="assets/RTM output/08b-更新器工具函数-always_redraw.mp4" controls width="560"></video>

> 提醒：工厂函数必须返回**新对象**且每帧都要执行——里面别放重操作（比如每次 `Text`）。
>
> `always_redraw` 的对象也可以直接放进 `play` 动画（如 `TransformFromCopy`）；它内部就是 `add_updater` + `become`。

### always / f_always（模块级函数）

```python
def always(method: Callable, *args, **kwargs) -> Mobject
def f_always(method: Callable[[M], None], *arg_generators, **kwargs) -> M
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `method` | 绑定方法 | — | 必须是 `Mobject` 实例上的方法，否则断言失败 |
| `*args` | 任意 | — | 固定参数，挂载时求值一次（仅 `always`） |
| `*arg_generators` | 无参可调用 | — | 每帧调用一次再传给目标方法的参数生成器（仅 `f_always`） |

> **返回**：该方法所属的 `Mobject`。与 `Mobject.always` 属性**同名但不同东西**；`always` 的参数只在挂载时求值一次，`f_always` 的参数每帧求值——两者的唯一区别。

#### 样例：一行一个跟随标签

`always(tag.next_to, sq, UP, ...)` 让黄标签永远在方块上方；`f_always(tag2.next_to, lambda: sq, lambda: DOWN, ...)` 用参数生成器让绿标签在下方。

```python
from real_time_manim import Scene, Square, Text, \
    BLUE, YELLOW, GREEN, UP, DOWN, LEFT, RIGHT
from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim import always, f_always

class AlwaysFnDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        sq = Square(color=BLUE, side_length=1.2).shift(LEFT * 3.0)   #蓝色方块
        self.add(sq)   #进场景
        tag = Text("always", font_size=24, color=YELLOW)   #上方标签
        always(tag.next_to, sq, UP, buff=0.3)   #always：参数挂载时求值一次（引用照用）
        self.add(tag)   #进场景
        tag2 = Text("f_always", font_size=24, color=GREEN)   #下方标签
        f_always(tag2.next_to, lambda: sq, lambda: DOWN, buff=0.3)   #f_always：参数生成器每帧重求值
        self.add(tag2)   #进场景
        win.play(sq.animate.shift(RIGHT * 2.5), run_time=0.8)   #两个标签一上一下全程跟随
        win.play(Wait(0.4))   #进行 0.4s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：蓝方块上方的黄标签用 `always(tag.next_to, sq, UP, buff=0.3)` 挂——参数 `sq` 是引用，挂载时求值一次就够（每次执行都重读它的位置）。

下方的绿标签用 `f_always`，参照物写成 `lambda: sq`、方向写成 `lambda: DOWN`，每帧各调用一次再传参。

方块右移的 0.8 秒里，两个标签一上一下全程跟随——日常用哪个都行，需要「每帧换参照物/换方向」时只有 `f_always` 能胜任。

<video src="assets/RTM output/08b-更新器工具函数-always_fn.mp4" controls width="560"></video>

> 提醒：
>
> - `always` 传的必须是**绑定方法**（`tag.next_to` 而不是 `Tag.next_to`），传错由 `assert_is_mobject_method` 抛 `AssertionError`。
> - 参数里放的是「挂载那一刻」的值——要变的值请走 `f_always`。
> - 它与 `Mobject.always` 属性（见 [08-更新器](08-更新器.md)）是两套实现、行为几乎一致。

### always_shift / always_rotate

```python
def always_shift(mobject: M, direction: Vector3DLike = RIGHT, rate: float = 0.1) -> M
def always_rotate(mobject: M, rate: float = 20 * DEGREES, **kwargs) -> M
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `Mobject` | — | 被移动 / 被旋转的对象 |
| `direction` | 向量 | `RIGHT` | 平移方向（会归一化，模长无所谓） |
| `rate` | `float` | `0.1` / `20 * DEGREES` | 每秒移动的距离 / 每秒转过的弧度 |
| `**kwargs` | `Any` | — | 仅 `always_rotate`：透传给 `Mobject.rotate`（如 `about_point=`） |

> **返回**：该对象。各挂一个时间型 updater——对象**自己不知道地**匀速移动/旋转，不进 `play`，随场景时间推进；停用 `clear_updaters()`。样例顺带演示 `assert_is_mobject_method`（入参校验辅助，确认传的是 `Mobject` 绑定方法，返回 `None`）。

#### 样例：边走边转

绿三角同时挂 `always_shift`（每秒右移 1）与 `always_rotate`（每秒 90°），1.2 秒里边走边转，`clear_updaters()` 一起停。

```python
from real_time_manim import Scene, Triangle, \
    GREEN, UP, DOWN, LEFT, RIGHT, PI
from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim import always_shift, always_rotate, assert_is_mobject_method

class AlwaysShiftRotateDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        tri = Triangle(color=GREEN).set_fill(GREEN, opacity=1).scale(0.8).shift(DOWN * 1.5 + LEFT * 3.0)   #绿色三角
        self.add(tri)   #进场景
        assert_is_mobject_method(tri.shift)   #入参校验辅助：确认是 Mobject 上的绑定方法（返回 None）
        print("assert_is_mobject_method -> None")
        always_shift(tri, direction=RIGHT, rate=1.0)   #匀速右移：每秒 1.0 单位
        always_rotate(tri, rate=PI / 2)   #匀速自转：每秒 90°
        win.play(Wait(1.2))   #边走边转
        tri.clear_updaters()   #两个 updater 一起停
        win.play(Wait(0.4))   #进行 0.4s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：绿色实心三角挂上 `always_shift(direction=RIGHT, rate=1.0)` 和 `always_rotate(rate=PI / 2)`——两条**独立**的时间型 updater 同时驱动它，1.2 秒的 `Wait` 里边向右滑行 1.2 个单位、边顺时针转了约 108°。

没有 `play`、没有动画类，全靠渲染循环每帧驱动；`clear_updaters()` 把两个一起停掉。`assert_is_mobject_method(tri.shift)` 演示了这几个函数内部用的入参校验（返回 `None`）。

<video src="assets/RTM output/08b-更新器工具函数-always_shift_rotate.mp4" controls width="560"></video>

> 提醒：多个 `always_*` 可以叠加（各是各的 updater）；`always_rotate` 默认绕自身中心转，绕别处加 `about_point=`。
>
> 想要「走一段停一段」，就得自己挂/清 updater，或者改用 `animate` 动画。

### turn_animation_into_updater / cycle_animation

```python
def turn_animation_into_updater(animation: Animation, cycle: bool = False,
                                delay: float = 0, **kwargs) -> Mobject
def cycle_animation(animation: Animation, **kwargs) -> Mobject
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `animation` | `Animation` | — | 要转成 updater 的动画（**不进 `play`**） |
| `cycle` | `bool` | `False` | 是否无限循环（`cycle_animation` 即 `cycle=True` 的简写） |
| `delay` | `float` | `0` | 开始前延迟的秒数 |

> **返回**：动画对应的 `Mobject`。不进 `play`，随场景时间自动推进，播完自动移除 updater（`cycle=True` 时永远转下去，手动 `clear_updaters()` 停）。

#### 样例：转一圈 vs 永远转

左块 `turn_animation_into_updater(Rotate(..., angle=TAU), cycle=False)` 自己转完一圈就停；右块 `cycle_animation(...)` 一直转，最后手动停掉。

```python
from real_time_manim import Scene, Square, \
    BLUE, ORANGE, UP, LEFT, RIGHT, TAU, Rotate
from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim import turn_animation_into_updater, cycle_animation

class AnimUpdaterDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        sq = Square(color=BLUE, side_length=1.0).shift(LEFT * 3.5 + UP * 1.5)   #左边：转一圈就结束
        self.add(sq)   #进场景
        turn_animation_into_updater(Rotate(sq, angle=TAU), cycle=False, delay=0)   #动画变 updater：随场景时间推进
        win.play(Wait(0.9))   #看它自己转完一圈
        sq2 = Square(color=ORANGE, side_length=1.0).shift(RIGHT * 3.5 + UP * 1.5)   #右边：无限循环
        self.add(sq2)   #进场景
        cycle_animation(Rotate(sq2, angle=TAU))   #cycle=True 的简写：永远转下去
        win.play(Wait(0.9))   #看它一直转
        sq2.clear_updaters()   #停掉
        win.play(Wait(0.4))   #进行 0.4s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：左右两个方块各领一种「动画变 updater」。

左块的 `Rotate` 动画**没有**交给 `play`，而是 `turn_animation_into_updater(...)` 变成 updater——随场景时间自己转，转满一整圈（`TAU`）后自动结束。右块用 `cycle_animation(...)`（即 `cycle=True`）无限循环，同样的 0.9 秒里它转到哪儿算哪儿，最后由 `clear_updaters()` 手动停。

适合「背景里持续自转/闪烁」这类不想占用 `play` 的效果。

<video src="assets/RTM output/08b-更新器工具函数-anim_updater.mp4" controls width="560"></video>

> 提醒：动画对象传进去就**别再自己 play 它**了（会重复驱动）；`cycle=True` 的动画要手动停。
>
> `delay=` 可以错峰启动多个动画 updater。
