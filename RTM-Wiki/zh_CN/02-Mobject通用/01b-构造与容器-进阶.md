# 构造、容器与增删（进阶）

家族树遍历、属性批量设置与构造钩子——自定义子类和写工具函数时才会用到的 API，普通动画脚本了解即可。

## 参数

### get_family / family_members_with_points / split

```python
def get_family(recurse: bool = True) -> list[Mobject]
def family_members_with_points() -> list[Mobject]
def split() -> list[Mobject]
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `recurse` | `bool` | `True` | 仅为与 OpenGL 版签名一致而保留，填什么都一样 |
| （另两个无参数） | — | — | — |

> **返回**：`get_family` 给出**自身 + 全部后代**的扁平列表（深度优先、去重）；`family_members_with_points` 只留**真正有顶点**的对象（容器本身、空组都被剔掉）；`split` 给出「自身（有点时）+ **直接**子对象」，是索引与迭代的底层。

#### 样例：家族树三种遍历

外层 `Group` 里套一个两方块的 `VGroup`、一个空 `Group`、一个独立方块：三种遍历各返回什么一目了然，最后按 `family_members_with_points` 逐个染色——只有三个真方块被染到。

```python
from real_time_manim import Scene, Group, VGroup, Square, \
    RED, BLUE, GREEN, ORANGE, YELLOW, PURPLE, RIGHT, UP, FadeIn
from real_time_manim.vulkan_bind import MLWindow, Wait

class FamilyDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        inner = VGroup(Square(color=RED, side_length=1.0), Square(color=BLUE, side_length=1.0))   #里层：两个方块
        inner.arrange(RIGHT, buff=0.4)   #里层排成一行
        empty = Group()   #空容器：一个顶点都没有
        solo = Square(color=GREEN, side_length=1.0)   #独立方块
        outer = Group(inner, empty, solo)   #外层：里层组、空组、一个方块
        inner.shift(LEFT * 2.2)   #里层组放左边（别用 arrange：空组宽度为 0，会挤到一起）
        solo.shift(RIGHT * 2.2)   #独立方块放右边
        outer.shift(UP * 1.0)   #整棵树抬高一点
        self.add(outer)   #整棵树进场景
        print("get_family =", len(outer.get_family()), [type(m).__name__ for m in outer.get_family()])   #自身+全部后代
        print("family_members_with_points =", [type(m).__name__ for m in outer.family_members_with_points()])   #只留有顶点的
        print("split =", [type(m).__name__ for m in outer.split()])   #自身(有点时)+直接子对象
        for i, m in enumerate(outer.family_members_with_points()):   #真正会被 shift/scale 作用的对象
            m.set_color([ORANGE, YELLOW, PURPLE][i])   #逐个染色：只有三个方块被染到
        win.play(Wait(0.6))   #进行 0.6s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：搭一棵三层的对象树（外层 `Group` → 里层 `VGroup` 两方块 + 空 `Group` + 独立方块），进场景后分别用三种遍历打印结果：`get_family` 把整棵树摊平（含所有容器自身），`family_members_with_points` 只剩三个有顶点的方块，`split` 只看一层。最后按 `family_members_with_points` 的顺序把三个方块染成橙、黄、紫——画面上变色的正好就是「真正有几何数据」的那三个。

<video src="assets/RTM output/01b-构造与容器-进阶-family.mp4" controls width="560"></video>

> 提醒：`shift` / `scale` / `rotate` 这些几何变换实际作用的对象集合就是 `family_members_with_points()`，所以空容器不会被拉伸、文字整体移动但字形点集跟着走。`get_family` 的 `recurse` 参数是摆设（OpenGL 版才用），别指望传 `False` 能只拿一层。

### has_points / has_no_points / get_num_points

```python
def has_points() -> bool
def has_no_points() -> bool
def get_num_points() -> int
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| （均无参数） | — | — | 空容器（刚建的 `Group`）点数为 0；`Square` 这类几何对象自带顶点；`Text` 本身点数为 0，点都在字形子对象里 |

> **返回**：`has_points` / `has_no_points` 返回 `bool`，`get_num_points` 返回 `int`。

#### 样例：空容器 / 方块 / 文字的点数

三个对象各查一遍点数：空 `Group` 全是「空」，`Square` 自带 16 个顶点，`Text` 本身点数为 0、点分散在字形子对象里。

```python
from real_time_manim import Scene, Group, Square, Text, \
    BLUE, YELLOW, LEFT, RIGHT, FadeIn
from real_time_manim.vulkan_bind import MLWindow, Wait

class PointsDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        g = Group()   #空容器
        sq = Square(color=BLUE, side_length=1.6)   #有顶点的方块
        txt = Text("points", font_size=36, color=YELLOW)   #文字：点在字形子对象里
        sq.shift(LEFT * 3.2)   #方块放左边
        txt.shift(RIGHT * 2.4)   #文字放右边
        self.add(sq, txt)   #两个对象进场景
        print("空 Group：has_points =", g.has_points(), "has_no_points =", g.has_no_points(), "get_num_points =", g.get_num_points())   #全是“空”
        print("Square：has_points =", sq.has_points(), "get_num_points =", sq.get_num_points())   #方块自带顶点
        print("Text 本身 get_num_points =", txt.get_num_points(), "| 字形 =", [m.get_num_points() for m in txt.submobjects])   #点在字形里
        win.play(FadeIn(sq), FadeIn(txt), run_time=0.5)   #淡入两个对象
        win.play(Wait(0.5))   #进行 0.5s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：把空 `Group`、`Square`、`Text("points")` 三个对象的点数查一遍打到控制台——空组 `has_points=False` / `has_no_points=True` / 点数 0；方块点数 16（形状采样点）；文字**本身**点数为 0，每个字母字形子对象里才有顶点。画面里淡入方块和文字，方便把控制台里的数字和实物对上。

<video src="assets/RTM output/01b-构造与容器-进阶-points.mp4" controls width="560"></video>

> 提醒：想统计一个复杂对象的顶点总量，用 `get_all_points().shape[0]`（见 [03-测量](03-测量.md)）而不是对 `Text` 直接 `get_num_points`——后者只会告诉你 0。这三个方法是纯查询，不改任何状态。

### set

```python
def set(**kwargs: Any) -> Self
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `**kwargs` | 任意 | — | 「属性名=值」，等价于逐个写 `mob.foo = v`；**能填**对象上真实存在的属性，如 `width=`、`color=`、`fill_opacity=` |

> **返回**：自身，可链式调用。主要配合 `.animate` 用（见 [07-animate语法](07-animate语法.md)）：`win.play(rect.animate.set(width=7))`。兼容层 `mob.get_foo()` / `mob.set_foo(v)` 仍然能用，但会发 `DeprecationWarning`，优先用属性访问或 `set`。

#### 样例：`set` 配合 `.animate`

`rect.animate.set(width=..., color=...)` 一次改多个属性并播放过渡；不带 `animate` 的 `set` 是瞬间改；再用兼容层 `set_width` 看一眼 `DeprecationWarning`。

```python
import warnings

from real_time_manim import Scene, Rectangle, \
    BLUE, ORANGE
from real_time_manim.vulkan_bind import MLWindow, Wait

class SetDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        rect = Rectangle(width=3.0, height=1.4, color=BLUE, fill_opacity=0.6)   #一个矩形
        self.add(rect)   #进场景
        win.play(rect.animate.set(width=5.0, color=ORANGE), run_time=0.7)   #“set” 配合 animate：一次改多个属性
        rect.set(fill_opacity=1.0)   #不加 “animate” 就是瞬间改
        print("rect.width =", rect.width, "| rect.color =", rect.color)   #属性读取验证
        with warnings.catch_warnings(record=True) as w:   #兼容层的 get_foo / set_foo 会发警告
            warnings.simplefilter("always")
            rect.set_width(4.0)   #兼容层写法：能用但会发 DeprecationWarning
            print("兼容层警告 =", [str(x.message)[:24] for x in w])   #看一眼警告内容
        win.play(Wait(0.5))   #进行 0.5s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：一个半透明蓝色矩形进场景，`rect.animate.set(width=5.0, color=ORANGE)` 把「变宽」和「变橙」合成**一个**过渡动画播放；随后 `rect.set(fill_opacity=1.0)` 不带 `animate`，是瞬间生效的直接赋值；控制台打印读回的 `width` / `color` 验证改动。最后用兼容层 `rect.set_width(4.0)` 改一次宽度，捕获并打印它发出的 `DeprecationWarning` 文案。

<video src="assets/RTM output/01b-构造与容器-进阶-set.mp4" controls width="560"></video>

> 提醒：`.animate.set(...)` 里的属性要能在起止状态间插值（数值、颜色都行），塞个字符串属性就只能瞬间跳变。`set` 不做任何合法性检查，属性名写错就是普通的动态赋值，画面毫无反应还查不出错——不确定有没有这个属性先 `dir(mob)` 看一眼。

### set_default（类方法）

```python
def set_default(**kwargs: Any) -> None
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `**kwargs` | 任意 | — | 要覆盖的 `__init__` 关键字参数，如 `side_length=1.0` |

> **返回**：`None`。修改**该类**后续构造的默认值；只影响之后新建的对象，不改已存在的对象。不带参数调用**恢复原始默认值**。

#### 样例：`set_default` 改默认边长

建一个方块 → 把 `Square` 的默认边长改成 1、颜色改成黄 → 再建一个（用上新默认值）→ 不带参数调用恢复默认 → 又建一个，三个方块排一行对比。

```python
from real_time_manim import Scene, VGroup, Square, \
    YELLOW, RIGHT, FadeIn
from real_time_manim.vulkan_bind import MLWindow, Wait

class SetDefaultDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        before = Square()   #默认方块：边长 2、白色
        Square.set_default(side_length=1.0, color=YELLOW)   #把 “Square” 的默认边长改成 1、默认颜色改成黄
        after = Square()   #新建对象用新默认值
        Square.set_default()   #不带参数调用：恢复原始默认值
        back = Square()   #再建一个：又回到默认
        trio = VGroup(before, after, back)   #三个方块一组
        trio.arrange(RIGHT, buff=0.8)   #排成一行，大小差别一眼看出
        self.add(trio)   #进场景
        print("边长：", before.width, after.width, back.width)   #2.0 1.0 2.0
        win.play(FadeIn(trio), run_time=0.6)   #整组淡入
        win.play(Wait(0.5))   #进行 0.5s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：先按默认值建一个白色方块（`Square` 默认边长是 **2**），然后 `Square.set_default(side_length=1.0, color=YELLOW)` 改掉 `Square` 的构造默认值，紧接着新建的方块就成了黄色小方块；再不带参数调用 `Square.set_default()` 一键恢复原始默认，第三个方块回到白色大方块。三个方块排成一行淡入，控制台打印的边长是 `2.0 1.0 2.0`——已经建好的对象不受影响，只有「之后新建」的才用新默认。

<video src="assets/RTM output/01b-构造与容器-进阶-set_default.mp4" controls width="560"></video>

> 提醒：`set_default` 是**类级别全局改动**，会一直影响后面所有代码，用完记得 `set_default()` 恢复或手动传回原值。它对已存在的对象无效，想批量改现存对象用 `set` 或 `set_color` 这类实例方法；另外 `Square` 的默认边长是 2 不是 1，别按想当然的尺寸排版。

### reset_points / generate_points / init_colors

```python
def reset_points() -> Self
def generate_points() -> Self
def init_colors(propagate_colors: bool = True) -> Self
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `propagate_colors` | `bool` | `True` | 仅 `init_colors`：是否把颜色下发给家族 |

> **返回**：都返回自身。这是构造函数里依次调用的三个钩子：清空 `points` → 生成形状 → 按 `color` 初始化样式。**只有自定义 `Mobject` 子类时才需要覆写**，普通脚本不调用。

#### 样例：自定义子类与三个钩子

自定义 `WideCircle` 覆写 `generate_points` 把圆拉宽成椭圆；对照的普通圆手动走一遍「清空 → 重新生成 → 重新上色」，看着它消失再在原点重现。

```python
from real_time_manim import Scene, VGroup, Circle, \
    GREEN, BLUE, DOWN, FadeIn
from real_time_manim.vulkan_bind import MLWindow, Wait

class WideCircle(Circle):   #自定义子类：在构造钩子里改形状
    def generate_points(self):   #构造函数调它生成形状
        super().generate_points()   #先按 “Circle” 的默认形状生成
        self.stretch(1.6, 0)   #再横向拉宽，得到“宽椭圆”


class HooksDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        wc = WideCircle(radius=0.9, color=GREEN)   #自定义子类：生成后被拉宽
        c = Circle(radius=0.9, color=BLUE)   #普通圆对照
        duo = VGroup(wc, c)   #两个圆一组
        duo.arrange(DOWN, buff=0.6)   #上下排好
        self.add(duo)   #进场景
        win.play(FadeIn(duo), run_time=0.5)   #淡入：上面是宽椭圆
        c.reset_points()   #清空所有顶点：圆消失
        win.play(Wait(0.5))   #停 0.5s 看消失
        c.generate_points()   #重新生成形状：默认圆在原点又出现
        c.init_colors()   #按 “color” 重新初始化样式
        win.play(Wait(0.5))   #停 0.5s 看结果
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：自定义的 `WideCircle` 覆写 `generate_points`，先按默认圆生成再横向拉宽 1.6 倍，所以画面里上面那个是宽椭圆、下面的普通圆是对照。然后对普通圆依次调用三个钩子：`reset_points()` 清空顶点（圆当场消失）、`generate_points()` 重新生成形状、`init_colors()` 按 `color` 重新上色——圆在**原点**重新出现（`generate_points` 生成的是围绕原点的形状，不会记住原来的位置）。

<video src="assets/RTM output/01b-构造与容器-进阶-hooks.mp4" controls width="560"></video>

> 提醒：`generate_points` 只有子类**真正覆写**才有用——`Circle` / `Arc` 这类在钩子里生成形状，覆写、重调都有效；而 `Square` / `Triangle` / `Polygon` 系在 `__init__` 里直接给点，基类的 `generate_points` 是空操作，对它们调 `reset_points()` 后再 `generate_points()` **不会**把形状变回来（0.21 实测）。另外重新生成的形状在原点、顶点布局也可能变，要保持位置和样式就自己补 `move_to` / `init_colors`。
