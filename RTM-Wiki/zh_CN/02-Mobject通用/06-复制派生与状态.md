# 复制、派生与状态

复制对象、让它变成另一个对象、保存/还原状态，以及 `Transform` 背后的插值与对齐接口；除 `copy`（返回新对象）与 `generate_target`（返回 `self.target`）外均返回自身，可链式调用。

## 参数

### copy

```python
def copy() -> Self
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| （无参数） | — | — | 深拷贝（含所有子对象与样式） |

> **返回**：新的独立对象。新副本**不会自动出现在场景里**，需手动 `self.add(...)` 或交给动画；对原件的后续改动不影响副本。

#### 样例：深拷贝后互不影响

蓝方块拷出红副本，原件再变绿——副本停在红色，证明两者已彻底独立。

```python
from real_time_manim import Scene, Square, \
    BLUE, RED, GREEN, LEFT, RIGHT, FadeIn
from real_time_manim.vulkan_bind import MLWindow, Wait

class CopyDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        sq = Square(color=BLUE, side_length=1.4, fill_opacity=0.6).shift(LEFT * 3.5)   #原件
        self.add(sq)   #进场景
        twin = sq.copy()   #深拷贝：独立副本，不会自动进场景
        twin.set_color(RED).shift(RIGHT * 2.0)   #副本改色、挪走：与原件互不影响
        self.add(twin)   #副本进场景
        win.play(FadeIn(twin), run_time=0.5)   #副本淡入
        win.play(sq.animate.set_color(GREEN), run_time=0.5)   #改原件颜色：副本纹丝不动
        win.play(Wait(0.4))   #进行 0.4s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：左边的蓝方块先 `copy()` 出一个副本，副本立刻改红、挪到右边再进场景（`copy` 本身不进场景）；然后给**原件**播放变绿动画——右边的副本纹丝不动，停在红色。这就是「深拷贝」的含义：顶点、颜色、子对象全部独立，改谁都不影响另一个。

<video src="assets/RTM output/06-复制派生与状态-copy.mp4" controls width="560"></video>

> 提醒：`copy` 是**深**拷贝，副本连 updater（有的话）也会一起复制，记得 `clear_updaters` 一下再用；要「两份一模一样且同步变化」用引用/`VGroup`，要独立改动才用 `copy`。

### become

```python
def become(mobject: Mobject, match_height: bool = False, match_width: bool = False,
           match_depth: bool = False, match_center: bool = False,
           stretch: bool = False) -> Self
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `Mobject` | — | 目标形态 |
| `match_height` / `match_width` / `match_depth` | `bool` | `False` | 保留**自己**的高/宽/深（对目标做等比缩放） |
| `match_center` | `bool` | `False` | 保留自己的中心位置（否则连位置一起搬成目标的） |
| `stretch` | `bool` | `False` | 无视三个 `match_*`，把目标**按三维分别拉伸**到自己的高宽深（会变形） |

> **返回**：自身。`become` 本身是**瞬间**改形，直接调用没有过渡；配合 `.animate` 才有动画。

#### 样例：`become` 的位置与 `stretch`

圆先直接 `become` 右边的矩形（形态和位置一起搬过去）；再 `become` 左边的小圆并同时给 `match_center=True, stretch=True`——小圆被拉成 3.0×1.4 的椭圆、位置留在原地。

```python
from real_time_manim import Scene, Circle, Rectangle, \
    ORANGE, PURPLE, TEAL, RIGHT, LEFT, FadeIn
from real_time_manim.vulkan_bind import MLWindow, Wait

class BecomeDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        circ = Circle(radius=0.9, color=ORANGE, fill_opacity=0.7)   #圆形
        self.add(circ)   #进场景
        rect = Rectangle(width=3.0, height=1.4, color=PURPLE, fill_opacity=0.7).shift(RIGHT * 3.2)   #目标矩形在右边
        win.play(circ.animate.become(rect), run_time=0.6)   #形态与位置一起变成目标的样子
        print("become 后：width =", round(circ.width, 2), "位置 =", circ.get_center().round(2))   #3.0，跑到右边
        dot = Circle(radius=0.3, color=TEAL).shift(LEFT * 3.2)   #目标小圆在左边
        win.play(circ.animate.become(dot, match_center=True, stretch=True),
                 run_time=0.5)   #stretch 把目标拉成自己的 3.0×1.4（小圆→椭圆），match_center 位置不动
        print("stretch+center 后：", round(circ.width, 2), round(circ.height, 2), circ.get_center().round(2))   #3.0 1.4 位置不变
        win.play(Wait(0.4))   #进行 0.4s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：橙色圆第一次 `become(rect)`——顶点、颜色全部换成右边紫色矩形的样子，连**位置**也搬了过去（控制台 `width=3.0`、中心跑到右边）；第二次同时给 `match_center=True, stretch=True`：`stretch` 把目标小圆按**自己当前的 3.0×1.4** 三维拉伸成椭圆，`match_center` 则把位置钉在原地——于是左边的小圆目标变成了一个停在右上方的青色椭圆。

<video src="assets/RTM output/06-复制派生与状态-become.mp4" controls width="560"></video>

> 提醒：`stretch=True` 时**三个维度**都会被拉到与自己一致，三个 `match_*` 不再生效（源码里 `stretch` 分支直接覆盖它们）；`match_*` 不带 `stretch` 时是**等比**缩放目标。`become` 直接调用是瞬间跳变，想要过渡写 `animate.become(...)` 或 `Transform`。

### save_state / restore

```python
def save_state() -> Self
def restore() -> Self
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| （均无参数） | — | — | 前者把位置/大小/颜色/结构存进 `self.saved_state`；后者 `become(saved_state)` 还原 |

> **返回**：自身。没存过就 `restore` 会抛异常；可多次 `save_state` 覆盖存档。

#### 样例：存档与还原

左上的方块先 `save_state`，再放大改绿右移，`animate.restore()` 一路回到存档状态。

```python
from real_time_manim import Scene, Square, \
    BLUE, GREEN, LEFT, RIGHT
from real_time_manim.vulkan_bind import MLWindow, Wait

class SaveRestoreDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        sq = Square(color=BLUE, side_length=1.4, fill_opacity=0.7).shift(LEFT * 3.0)   #蓝色方块
        self.add(sq)   #进场景
        sq.save_state()   #把位置/大小/颜色/结构存进 saved_state
        win.play(sq.animate.scale(1.8).set_color(GREEN).shift(RIGHT * 3.0), run_time=0.7)   #放大、改绿、右移
        win.play(sq.animate.restore(), run_time=0.6)   #还原到存档时的状态
        win.play(Wait(0.4))   #进行 0.4s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：左边的蓝方块先 `save_state()` 把「位置、大小、颜色、顶点结构」整套存档；然后一口气放大 1.8 倍、变绿、右移 3（三个改动叠在同一个 `animate` 链上）；最后 `sq.animate.restore()` 播放还原动画——尺寸、颜色、位置全部回到存档瞬间。这是「先出去浪、再一键回家」的标准写法。

<video src="assets/RTM output/06-复制派生与状态-save_restore.mp4" controls width="560"></video>

> 提醒：`save_state` 是**引用式快照**（`become` 语义），结构变化也能还原；`restore()` 没存档直接抛异常，别放在条件分支里赌。多次 `save_state` 会覆盖旧档，想要多档位自己存多个副本。

### generate_target

```python
def generate_target(use_deepcopy: bool = False) -> Self
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `use_deepcopy` | `bool` | `False` | `True` 用 `deepcopy`，默认用 `copy()` |

> **返回**：`self.target` 快照本身（不是自身！）。配合 `MoveToTarget` 动画把本体「变过去」——目标态改什么都行：位置、大小、颜色、子对象。

#### 样例：`generate_target` + `MoveToTarget`

黄方块生成目标快照，把快照右移放大改色，`MoveToTarget` 播放本体变过去的动画。

```python
from real_time_manim import Scene, Square, \
    YELLOW, TEAL, LEFT, RIGHT, MoveToTarget
from real_time_manim.vulkan_bind import MLWindow, Wait

class TargetDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        sq = Square(color=YELLOW, side_length=1.2).shift(LEFT * 3.5)   #黄色方块
        self.add(sq)   #进场景
        sq.generate_target(use_deepcopy=False)   #生成 self.target 快照（本体不消失）
        sq.target.shift(RIGHT * 3.0).scale(1.6).set_color(TEAL)   #在快照上摆出目标形态
        win.play(MoveToTarget(sq), run_time=0.7)   #本体动画到目标形态
        win.play(Wait(0.4))   #进行 0.4s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：黄方块 `generate_target()` 后手里多了一份 `self.target` 快照（本体还在画面里）；直接对**快照**做任何改动——右移 3、放大 1.6、改青色；最后 `MoveToTarget(sq)` 播放本体「向目标态过渡」的动画。它比 `Transform(本体, 副本)` 更直观：目标态就是随便改一份快照。

<video src="assets/RTM output/06-复制派生与状态-target.mp4" controls width="560"></video>

> 提醒：`generate_target` 返回的是 `self.target` 不是自身（直接赋值会把对象换掉），链式写法要小心。`use_deepcopy=True` 会更彻底（含不可变属性），一般默认的 `copy()` 就够。

### interpolate

```python
def interpolate(mobject1: Mobject, mobject2: Mobject, alpha: float,
                path_func: PathFuncType = straight_path()) -> Self
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject1` / `mobject2` | `Mobject` | — | 起点状态 / 终点状态 |
| `alpha` | `float` | — | 0 = 起点，1 = 终点 |
| `path_func` | 可调用 | `straight_path()` | 插值路径；走弧线可用 `arc_path` 类 |

> **返回**：自身。`Transform` 的底层：把本体**瞬间**变成两状态在 `alpha` 处的插值态。三者**点数须一致**（一般用 `copy` 出状态）。

#### 样例：手动取插值态

绿色方块的起点/终点各存一份副本，`interpolate(s1, s2, 0.5)` 瞬间取中间态，再 `become(s2)` 对照终点。

```python
from real_time_manim import Scene, Square, \
    GREEN, RIGHT, PI, straight_path
from real_time_manim.vulkan_bind import MLWindow, Wait

class InterpolateDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        sq = Square(color=GREEN, side_length=1.2)   #绿色方块
        self.add(sq)   #进场景
        win.play(Wait(0.4))   #看清起点状态
        s1 = sq.copy()   #起点状态
        s2 = sq.copy().shift(RIGHT * 2.5).scale(1.5).rotate(PI / 4)   #终点状态
        sq.interpolate(s1, s2, 0.5, path_func=straight_path())   #直接取 alpha=0.5 的插值态（瞬间）
        win.play(Wait(0.5))   #看清中间状态
        win.play(sq.animate.become(s2), run_time=0.4)   #再动到终点状态对照
        win.play(Wait(0.3))   #进行 0.3s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：画面中央的绿色方块先停 0.4 秒（起点），然后用两份 `copy` 定义起点态和终点态（右移 2.5、放大 1.5、转 45°），`interpolate(s1, s2, 0.5, straight_path())` **瞬间**把它摆到正中间——位置/尺寸/角度都恰好处在一半；最后 `animate.become(s2)` 播放动画走到终点，好对照「中间态」和「终点态」的位置差。

<video src="assets/RTM output/06-复制派生与状态-interpolate.mp4" controls width="560"></video>

> 提醒：`interpolate` 是**瞬间**函数（一帧到位），想要连续过渡就交给 `Transform` / `MoveToTarget`，它们内部逐帧调它。三者点数不一致时会抛错——跨形状插值前先 `align_points`（见下）。`alpha` 可以超过 0~1（外插），一般不建议。

### match_dim_size / match_width / match_height / match_depth

```python
def match_dim_size(mobject: Mobject, dim: int, **kwargs: Any) -> Self
def match_width(mobject: Mobject, **kwargs: Any) -> Self
def match_height(mobject: Mobject, **kwargs: Any) -> Self
def match_depth(mobject: Mobject, **kwargs: Any) -> Self
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `Mobject` | — | 参照对象 |
| `dim` | `int` | — | 仅 `match_dim_size`：`0`宽、`1`高、`2`深 |
| `**kwargs` | `Any` | — | 透传给 `rescale_to_fit`，如 `stretch=True` |

> **返回**：自身。默认**等比**缩放到与参照同尺寸（`match_width` = 宽高一起变）；`stretch=True` 只调这一维。

#### 样例：等比匹配与拉伸匹配

灰矩形当尺子：蓝方块 `match_width` 等比放到同宽（高也跟着变 2.6）；红方块 `match_dim_size(ref, 1, stretch=True)` 只把高压到同高。

```python
from real_time_manim import Scene, Rectangle, Square, \
    BLUE, RED, GREY, UP, LEFT
from real_time_manim.vulkan_bind import MLWindow, Wait

class MatchSizeDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        ref = Rectangle(width=2.6, height=1.0, color=GREY, fill_opacity=0.5).shift(UP * 1.6)   #参照矩形
        m1 = Square(color=BLUE, side_length=1.0).shift(LEFT * 3.0)   #等比对照
        m2 = Square(color=RED, side_length=1.8).shift(LEFT * 1.0)   #拉伸对照
        self.add(ref, m1, m2)   #进场景
        win.play(m1.animate.match_width(ref), run_time=0.5)   #等比缩到与参照同宽
        print("match_width 后：", round(m1.width, 2), round(m1.height, 2))   #2.6 2.6
        win.play(m2.animate.match_dim_size(ref, 1, stretch=True), run_time=0.5)   #match_dim_size：dim=1，只压这一维
        print("match_dim_size 后：", round(m2.width, 2), round(m2.height, 2))   #1.8 1.0
        m2.match_depth(ref)   #match_depth：平面对象安全 no-op（维度长度都是 0）
        print("match_depth 后：", round(m2.width, 2), round(m2.height, 2))   #不变
        win.play(Wait(0.4))   #进行 0.4s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：灰色矩形（2.6×1.0）当尺子。蓝方块 `match_width(ref)`——**等比**放到宽 2.6，于是高也变 2.6（控制台 `2.6 2.6`）；红方块 `match_dim_size(ref, 1, stretch=True)`——`dim=1` 指高度、`stretch=True` 只压这一维，1.8 的方块变成 1.8×1.0 的扁条；最后 `match_depth` 对平面对象是安全 no-op（宽度不变）。

<video src="assets/RTM output/06-复制派生与状态-match_size.mp4" controls width="560"></video>

> 提醒：这族方法 = `rescale_to_fit` 的「拿别人当尺子」版本——`match_width` 等价于 `rescale_to_fit(参照.width, 0)`。`match_width` / `match_height` 默认等比，想单维硬调必须显式传 `stretch=True`。

### match_coord / match_x / match_y / match_z / match_points / align_points

```python
def match_coord(mobject: Mobject, dim: int, direction: Vector3DLike = ORIGIN) -> Self
def match_x(mobject: Mobject, direction: Vector3DLike = ORIGIN) -> Self
def match_y(mobject: Mobject, direction: Vector3DLike = ORIGIN) -> Self
def match_z(mobject: Mobject, direction: Vector3DLike = ORIGIN) -> Self
def match_points(mobject: Mobject, copy_submobjects: bool = True) -> Self
def align_points(mobject: Mobject) -> Self
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `Mobject` | — | 参照对象 |
| `dim` | `int` | — | 仅 `match_coord`：`0`/`1`/`2` |
| `direction` | 向量 | `ORIGIN` | 用自己哪个关键点去对齐（`DOWN` = 下边缘对齐） |
| `copy_submobjects` | `bool` | `True` | 签名保留参数 |

> **返回**：自身。`match_coord` 把自己某一维的关键点坐标设成参照的（`match_x` 等是它的糖）；`match_points` **照抄顶点**（形状大小一起变成参照的样子）；`align_points` 只对齐**顶点数**（`Transform` 插值的前提），不改可见外观。

#### 样例：坐标匹配、顶点照抄与对齐点数

灰圆当参照：蓝方块 `match_x`（x 对齐）、红方块 `match_coord(ref, 1, direction=DOWN)`（下边缘对齐）；小圆 `match_points(ref)` 变成与参照一样的圆，再 `align_points` 打印两边点数。

```python
from real_time_manim import Scene, Circle, Square, \
    BLUE, RED, TEAL, GREY, UP, DOWN, LEFT, RIGHT
from real_time_manim.vulkan_bind import MLWindow, Wait

class MatchPosDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        ref = Circle(radius=0.8, color=GREY, fill_opacity=0.5).shift(UP * 1.5 + RIGHT * 2.0)   #参照圆
        m1 = Square(color=BLUE, side_length=1.0).shift(LEFT * 3.5 + DOWN * 1.5)   #x 对齐对照
        m2 = Square(color=RED, side_length=1.0).shift(LEFT * 1.5 + DOWN * 1.5)   #y 边缘对齐对照
        self.add(ref, m1, m2)   #进场景
        win.play(m1.animate.match_x(ref), run_time=0.5)   #match_x：x 对齐到参照中心
        win.play(m2.animate.match_coord(ref, 1, direction=DOWN), run_time=0.5)   #match_coord：dim=1，按下边缘对齐
        print("ref 中心 =", ref.get_center().round(2), "| m1 中心 =", m1.get_center().round(2))   #x 相同
        mp = Circle(color=TEAL, radius=0.4).shift(LEFT * 3.5 + UP * 1.5)   #待变形的圆
        self.add(mp)   #进场景
        win.play(mp.animate.match_points(ref), run_time=0.5)   #match_points：顶点照抄参照（形状大小一起变）
        print("match_points 后 width =", round(mp.width, 2))   #1.6 与参照一致
        mp.align_points(ref)   #align_points：把顶点数对齐（插值的前提）
        print("align_points 后点数 =", mp.get_num_points(), ref.get_num_points())   #两边一致
        win.play(Wait(0.4))   #进行 0.4s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：右上的灰圆当参照。蓝方块 `match_x(ref)` 只把 x 挪到与圆心相同（y 不动）；红方块 `match_coord(ref, 1, direction=DOWN)` 用 `DOWN` 关键点做 y 对齐——**下边缘**与圆的下沿齐平（控制台打印两者中心的 x/y 供核对）。左上的小圆半径只有参照的一半，`match_points(ref)` 把参照的**顶点数组**整个照抄过来，于是小圆瞬间变成与参照一样的圆（宽 1.6）；`align_points(ref)` 把两边顶点数对齐，打印显示同为 32 点——这正是 `Transform` 跨形状插值前要做的事。

<video src="assets/RTM output/06-复制派生与状态-match_pos.mp4" controls width="560"></video>

> 提醒：`match_coord` 是「**某一维**的坐标对齐」，不是整体位移；`match_points` 会连颜色结构外的**全部顶点**照抄，圆对方就直接变成对方的圆。`align_points` 只保证点数一致、外观可能中间会闪一下填充错位，一般只在动画前置里用。
