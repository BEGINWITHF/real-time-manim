# 样式与颜色（Mobject 层）

Mobject 自己提供的样式入口；`set_fill` / `set_stroke` / `set_opacity` 定义在 `VMobject` 上，见 [04-图形与文本](../04-图形与文本/07-VMobject样式.md)。以下方法均返回自身。

## 参数

### set_color

```python
def set_color(color: ParsableManimColor = PURE_YELLOW, alpha: Any = None,
              family: bool = True) -> Self
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `color` | 颜色字符串 / `ManimColor` | `PURE_YELLOW` | **能填** `"red"`、`"#ff0000"`、`RED`、`ManimColor("#83c167")` |
| `alpha` | 任意 | `None` | 只存在于 `Mobject` 基类签名；`VMobject.set_color` **没有这个参数**，矢量对象传了直接 `TypeError` |
| `family` | `bool` | `True` | `False` 只改自己的属性，**不递归**子对象 |

> **返回**：自身。默认递归到所有子对象；`color=` 同时更新 `self.color`（后面 `to_original_color` 用它复位）。

#### 样例：`set_color` 的 `family`

蓝色大方块里嵌一个黄色小方块（子对象）：`set_color(ORANGE)` 默认把整组连子对象全改；`set_color(GREEN, family=False)` 只改组自身的属性——子对象停在橙色（组本身不绘制，画面无变化）。

```python
from real_time_manim import Scene, Group, Square, \
    BLUE, YELLOW, ORANGE, GREEN
from real_time_manim.vulkan_bind import MLWindow, Wait

class SetColorDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        sq = Square(color=BLUE, side_length=2.2, fill_opacity=0.7)   #蓝色方块
        kid = Square(color=YELLOW, side_length=0.8, fill_opacity=0.9)   #黄色小方块
        g = Group(sq, kid)   #小方块作为子对象放进组
        self.add(g)   #进场景
        win.play(g.animate.set_color(ORANGE), run_time=0.6)   #默认 family=True：整组连子对象全改
        win.play(g.animate.set_color(GREEN, family=False), run_time=0.6)   #family=False：只改组自身属性
        print("sq =", sq.get_color(), "| kid =", kid.get_color())   #子对象停在橙色：family=False 不下放
        win.play(Wait(0.4))   #进行 0.4s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：一组「大方块套小方块」，第一次 `set_color(ORANGE)` 用默认 `family=True`，整组从蓝一起变橙（小方块也变）；第二次 `set_color(GREEN, family=False)` 只把 `Group` 自身的颜色属性改绿——但容器自己不绘制，画面上两个方块纹丝不动，控制台打印 `sq = #FF862F | kid = #FF862F` 证明子对象停在橙色、`family=False` 的改动没下放。

<video src="assets/RTM output/05-样式与颜色-set_color.mp4" controls width="560"></video>

> 提醒：`alpha` 参数只在 `Mobject` 基类签名里，`VMobject.set_color` **没有它**——给方块传 `set_color(RED, alpha=0.5)` 会直接 `TypeError`（0.21 实测）。要改不透明度用 `set_fill(opacity=...)` / `fade_to`。对容器（`Group`）用 `family=False` 基本等于没改——改的东西根本不参与绘制。

### set_color_by_gradient / set_submobject_colors_by_gradient / 径向渐变

```python
def set_color_by_gradient(*colors: ParsableManimColor) -> Self
def set_submobject_colors_by_gradient(*colors: ParsableManimColor) -> Self
def set_colors_by_radial_gradient(center: Point3DLike | None = None, radius: float = 1,
                                  inner_color: ParsableManimColor = WHITE,
                                  outer_color: ParsableManimColor = BLACK) -> Self
def set_submobject_colors_by_radial_gradient(center=None, radius=1,
                                             inner_color=WHITE, outer_color=BLACK) -> Self
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `*colors` | 颜色 | — | 线性渐变端点色，至少 1 个，常用 2–3 个 |
| `center` | 点或 `None` | `None` | 渐变中心，`None` 取自身中心（仅径向） |
| `radius` | `float` | `1` | 到达外色的距离（仅径向） |
| `inner_color` / `outer_color` | 颜色 | `WHITE` / `BLACK` | 径向渐变的内色 / 外色 |

> **返回**：自身。两个 `set_*` 版本都是在**有顶点的子孙**之间按顺序/距离分配纯色——颜色是**逐对象**的，不是单个形状内部的真渐变。`set_color_by_gradient` 内部就是调 `set_submobject_colors_by_gradient`；径向两个方法同理。

#### 样例：线性渐变与径向渐变

四排小图形各领一个方法：线性渐变（蓝→红、绿→紫）、径向渐变（内白外蓝、内黄外红）——每排按子对象离中心的距离/顺序取色。

```python
from real_time_manim import Scene, VGroup, Square, Circle, \
    BLUE, RED, GREEN, PURPLE, WHITE, YELLOW, UP, DOWN, RIGHT
from real_time_manim.vulkan_bind import MLWindow, Wait

class GradientDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        r1 = VGroup(*[Square(side_length=0.8) for _ in range(4)])   #一排四个方块
        r1.arrange(RIGHT, buff=0.25).shift(UP * 2.2)
        self.add(r1)   #进场景
        win.play(r1.animate.set_color_by_gradient(BLUE, RED), run_time=0.5)   #整组渐变：四个方块依次取中间色
        r2 = VGroup(*[Square(side_length=0.8) for _ in range(4)])   #第二排
        r2.arrange(RIGHT, buff=0.25).shift(UP * 0.7)
        self.add(r2)   #进场景
        win.play(r2.animate.set_submobject_colors_by_gradient(GREEN, PURPLE), run_time=0.5)   #直接对子对象逐个上色（等价实现）
        r3 = VGroup(*[Circle(radius=0.2 + 0.15 * i) for i in range(3)])   #第三排：大小不一的圆
        r3.arrange(RIGHT, buff=0.35).shift(DOWN * 1.0)
        self.add(r3)   #进场景
        win.play(r3.animate.set_colors_by_radial_gradient(radius=1.6, inner_color=WHITE, outer_color=BLUE), run_time=0.5)   #径向：按离中心的距离取色
        r4 = VGroup(*[Circle(radius=0.2 + 0.15 * i) for i in range(3)])   #第四排
        r4.arrange(RIGHT, buff=0.35).shift(DOWN * 2.4)
        self.add(r4)   #进场景
        win.play(r4.animate.set_submobject_colors_by_radial_gradient(radius=1.6, inner_color=YELLOW, outer_color=RED), run_time=0.5)   #同上
        win.play(Wait(0.4))   #进行 0.4s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：四排小图形演示渐变四件套。第一排四个方块 `set_color_by_gradient(BLUE, RED)`，从左到右依次取蓝→红之间的中间色（实测 `#58C4DD → #8EA3AF → #C58282 → #FC6255`）；第二排用 `set_submobject_colors_by_gradient` 得到一模一样的效果——前者内部就是调后者。第三排三个大小不一的圆 `set_colors_by_radial_gradient`，按各子对象**离中心的距离**在内白/外蓝之间取色（中间的圆最白）；第四排是对应的 `set_submobject_colors_by_radial_gradient` 版本，内黄外红。

<video src="assets/RTM output/05-样式与颜色-gradient.mp4" controls width="560"></video>

> 提醒：这是**逐个子对象**分配纯色，不是单个形状内部的真渐变——组里只有一个子对象时，你只会看到一个纯色。想在**一个形状内部**做渐变用 `set_fill(color1, opacity).set_style(...)` 之外的写法（VMobject 的 per-vertex 颜色）或改用纹理/图案填充，Mobject 层没有提供。`radius` / `center` 只对径向版本有意义。

### fade_to / fade

```python
def fade_to(color: ParsableManimColor, alpha: float, family: bool = True) -> Self
def fade(darkness: float = 0.5, family: bool = True) -> Self
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `color` | 颜色 | — | 目标色（仅 `fade_to`） |
| `alpha` | `float` | — | 混合比例 0~1（仅 `fade_to`） |
| `darkness` | `float` | `0.5` | 变暗/变淡程度（仅 `fade`） |
| `family` | `bool` | `True` | 是否递归子对象 |

> **返回**：自身。`fade_to` 把颜色向目标色混合 `alpha` 比例（`alpha=0.7` = 七成新色）；`fade` 的真正逻辑由 `VMobject.fade` 实现——**动的是不透明度不是颜色**，矢量对象有效、裸 `Mobject` 无效。

#### 样例：`fade_to` 混色与 `fade` 变淡

两个蓝色方块：左边 `fade_to(RED, 0.7)` 混成偏红；右边 `fade(darkness=0.6)` 变淡（`get_color` 仍是蓝）。

```python
from real_time_manim import Scene, Square, \
    BLUE, RED, LEFT, RIGHT
from real_time_manim.vulkan_bind import MLWindow, Wait

class FadeDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        f1 = Square(color=BLUE, side_length=1.4, fill_opacity=0.8).shift(LEFT * 2.5)   #左侧：混色
        f2 = Square(color=BLUE, side_length=1.4, fill_opacity=0.8).shift(RIGHT * 2.5)   #右侧：变淡
        self.add(f1, f2)   #进场景
        win.play(f1.animate.fade_to(RED, 0.7), run_time=0.6)   #向红色混合 70%
        win.play(f2.animate.fade(darkness=0.6), run_time=0.6)   #矢量对象变淡 60%
        print("f1 =", f1.get_color(), "| f2 =", f2.get_color())   #颜色读数验证
        win.play(Wait(0.4))   #进行 0.4s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：两个一模一样的蓝方块各走一个方法。左边 `fade_to(RED, 0.7)` 把颜色向红混合 70%，控制台读数 `#CA7F7D`（约七成红三成蓝）；右边 `fade(darkness=0.6)`，画面里方块明显变淡，但 `get_color` 读出来**仍是蓝色** `#58C4DD`——因为 `VMobject.fade` 调的是不透明度通道，颜色属性没动。

<video src="assets/RTM output/05-样式与颜色-fade.mp4" controls width="560"></video>

> 提醒：`fade_to` 改的是颜色、`fade` 改的是透明度，两者不对称，别混用；想淡出动画请直接用 `FadeOut`。`darkness` 越大越淡（`1.0` = 完全消失）；对没有填充/描边颜色概念的裸 `Mobject`，`fade` 是空操作。

### get_color / match_color / to_original_color

```python
def get_color() -> ManimColor
def match_color(mobject: Mobject) -> Self
def to_original_color() -> Self
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `Mobject` | — | 参照对象（仅 `match_color`） |

> **返回**：`get_color` 返回 `ManimColor`，另两个返回自身。`match_color` 把 `self.color` 和颜色都设成参照对象的（**原来的 `self.color` 一并被覆盖**）；`to_original_color` 把 `self.color` 重新下发到整个家族——真正的用途是清掉 `Text` 这类对象**子对象各自**的颜色。

#### 样例：读取、照抄与清子对象颜色

红方块 `match_color` 照抄绿方块的颜色；白字只给前两个字母染红，`to_original_color()` 一次性清掉字形的单独颜色。

```python
from real_time_manim import Scene, Square, Text, \
    RED, GREEN, WHITE, UP, DOWN, LEFT, RIGHT, FadeIn
from real_time_manim.vulkan_bind import MLWindow, Wait

class GetMatchDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        a = Square(color=RED, side_length=1.4).shift(LEFT * 3.0 + UP * 1.2)   #红方块
        b = Square(color=GREEN, side_length=1.4).shift(RIGHT * 3.0 + UP * 1.2)   #绿方块
        self.add(a, b)   #进场景
        print("a =", a.get_color())   #读取当前颜色
        win.play(a.animate.match_color(b), run_time=0.6)   #把 a 的颜色设成 b 的
        print("match 后：a =", a.get_color(), "b =", b.get_color())
        w = Text("color", font_size=38, color=WHITE).shift(DOWN * 1.6)   #白色文字：字形各自能染色
        w[0:2].set_color(RED)   #只把前两个字母染红
        self.add(w)   #进场景
        win.play(FadeIn(w), run_time=0.4)   #文字淡入
        win.play(Wait(0.5))   #看清前两个字母是红的
        w.to_original_color()   #整体按 self.color 重置：字形的单独颜色被清掉
        print("reset 后 w =", w.get_color())   #属性打印是黑色（Text 的 color 默认黑）
        win.play(Wait(0.5))   #看清字形全部恢复
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：上排红方块先 `get_color()` 读出自己是红（`#FC6255`），`match_color(b)` 后与绿方块同色（`#83C167`）。注意这一步把 `a` 的 `self.color` 一并覆盖了，之后调 `to_original_color()` 并不会变回红。

下排是 `to_original_color` 的真正用途：白色文字 `color` 只把前两个字母染红（字形是子对象、各有自己的颜色），`to_original_color()` 一次性把所有字形按整体颜色重置——画面里红色的 "co" 变回白色、整词恢复一致。控制台打印的 `self.color` 是 `#000000`（`Text` 的 `color` 属性默认黑，与字形画成白色是两回事，字形的实际颜色由 `Text` 自己的 `font_color` 管理）。

<video src="assets/RTM output/05-样式与颜色-get_match.mp4" controls width="560"></video>

> 提醒：`match_color` 之后别指望 `to_original_color` 能恢复旧色——原色已被覆盖，想恢复先 `save_state()`（见 [06-复制派生与状态](06-复制派生与状态.md)）。`to_original_color` 用在「给 `Text` / `MathTex` 的部分字形上了色、想一键还原」这类场景。

### set_z_index / set_z_index_by_z_Point3D

```python
def set_z_index(z_index_value: float, family: bool = True) -> Self
def set_z_index_by_z_Point3D() -> Self
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `z_index_value` | `float` | — | 任意数值，越大越靠上 |
| `family` | `bool` | `True` | 是否同时设置所有子对象 |

> **返回**：自身。**渲染顺序由 `z_index` 决定，与 `add` 先后无关**（`z_index` 相同才按加入顺序）；后者把 `z_index` 设成**中心的 z 坐标**，用于 3D 场景按远近遮挡。

#### 样例：`set_z_index` 反转叠放

红蓝两个重叠方块：默认后加的蓝色在上；`zA.set_z_index(2)` 后红色反超；给蓝色 `set_z(3.0)` 再 `set_z_index_by_z_Point3D()`，蓝色按 z 坐标设层级 3，又盖回去。

```python
from real_time_manim import Scene, Square, \
    RED, BLUE, LEFT
from real_time_manim.vulkan_bind import MLWindow, Wait

class ZIndexDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        zA = Square(color=RED, side_length=2.2, fill_opacity=0.85).shift(LEFT * 2.2)   #红方块
        zB = Square(color=BLUE, side_length=2.2, fill_opacity=0.85).shift(LEFT * 1.3)   #蓝方块
        self.add(zA, zB)   #后加的蓝色在上（同层级时按加入顺序）
        win.play(Wait(0.5))   #先看默认叠放
        zA.set_z_index(2)   #红色层级设为 2：瞬间反超到上层
        win.play(Wait(0.5))   #停一下看红色盖住蓝色
        zB.set_z(3.0)   #给蓝色一个 z 坐标（2D 画面看不出位置变化）
        zB.set_z_index_by_z_Point3D()   #蓝色层级 = 中心 z 坐标 = 3：又盖回去
        print("z_index:", zA.z_index, zB.z_index)   #2 3
        win.play(Wait(0.5))   #停一下看蓝色盖住红色
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：两个半透明方块错位重叠，第一段 `Wait` 展示默认规则——`z_index` 都是 0，**后 add 的蓝色在上**；然后 `zA.set_z_index(2)` 瞬间把红色的层级抬到 2，下一段画面里红色反超盖住蓝色；最后给蓝色 `set_z(3.0)` 挪个 z 坐标（2D 画面看不出位置变化），`set_z_index_by_z_Point3D()` 把它的 `z_index` 设成中心 z=3，于是蓝色又盖了回来。控制台打印 `z_index: 2 3.0`。

<video src="assets/RTM output/05-样式与颜色-z_index.mp4" controls width="560"></video>

> 提醒：
>
> - `set_z_index` 是**瞬间**改层级，没有过渡；要渐变的层级变化得自己写 updater。
> - 两个对象 `z_index` 相同才看 `add` 顺序，所以「后加的在上」只是默认值相同的巧合。
> - `set_z_index_by_z_Point3D` 只有 3D 场景才有意义（2D 下 z 都是 0）。

### add_background_rectangle（及两个递归变体）

```python
def add_background_rectangle(color: ParsableManimColor | None = None,
                             opacity: float = 0.75, **kwargs: Any) -> Self
def add_background_rectangle_to_submobjects(**kwargs: Any) -> Self
def add_background_rectangle_to_family_members_with_points(**kwargs: Any) -> Self
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `color` | 颜色或 `None` | `None` | 背景色 |
| `opacity` | `float` | `0.75` | 背景不透明度 |
| `**kwargs` | `Any` | — | 透传给 `BackgroundRectangle`（后两个变体直接吃这组参数） |

> **返回**：自身。垫底的矩形被加到子对象列表（绘制在下层），让文字/图形在花哨背景上更易读。三个版本分别是：给自己垫一块 / 给每个直接子对象各垫一块 / 给家族里每个有顶点的成员各垫一块。

#### 样例：文字与图形的衬底

彩条背景上放白字：整字垫一块 `add_background_rectangle`；`A B` 两个字用变体二各垫一块；两个圆用变体三各垫一块——花哨背景上的内容全部读得清。

```python
from real_time_manim import Scene, VGroup, Square, Circle, Text, Rectangle, \
    RED, BLUE, GREEN, WHITE, BLACK, UP, DOWN, FadeIn
from real_time_manim.vulkan_bind import MLWindow, Wait

class BgRectDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        bg = VGroup(*[Rectangle(width=2.0, height=6.0, color=c, fill_opacity=1.0) for c in (RED, BLUE, GREEN)])   #三条彩色竖条
        bg.arrange(RIGHT, buff=0)
        self.add(bg)   #花哨背景
        txt = Text("READABLE", font_size=44, color=WHITE).shift(UP * 1.6)   #白字
        txt.add_background_rectangle(color=BLACK, opacity=0.75)   #背后垫一块半透明黑
        self.add(txt)
        win.play(FadeIn(bg), FadeIn(txt), run_time=0.6)   #背景与文字一起淡入
        duo = VGroup(Text("A", font_size=36), Text("B", font_size=36)).arrange(RIGHT, buff=0.9)
        duo.shift(UP * 0.1)
        duo.add_background_rectangle_to_submobjects(color=BLACK, opacity=0.7)   #给每个字母各垫一块
        self.add(duo)
        rings = VGroup(Circle(radius=0.35), Circle(radius=0.35)).arrange(RIGHT, buff=0.4).shift(DOWN * 1.8)
        rings.add_background_rectangle_to_family_members_with_points(color=BLACK, opacity=0.7)   #给每个有顶点的成员垫一块
        self.add(rings)
        win.play(FadeIn(duo), FadeIn(rings), run_time=0.5)   #两组元素淡入
        win.play(Wait(0.4))   #进行 0.4s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：先铺红蓝绿三条彩色竖条当「花哨背景」，再在上面放白字 `READABLE`——它背后垫了一块半透明黑（`add_background_rectangle`），跨过亮色条纹的部分依旧清晰可读；中间的 `A B` 用变体二，**每个字母**背后各垫一块；底部两个圆用变体三，给家族里每个有顶点的成员垫一块。三种垫法一次演示完，效果都是「深色底让前景浮出来」。

<video src="assets/RTM output/05-样式与颜色-background.mp4" controls width="560"></video>

> 提醒：垫底矩形是**对象的子对象**，会跟着对象一起 `shift` / `scale`；给 `Text` 垫整块时矩形包住**全部字形**，只给部分字母上色想局部垫就对字形切片用变体二。`opacity` 默认 0.75，在纯色背景上可能嫌深，按需调小。
