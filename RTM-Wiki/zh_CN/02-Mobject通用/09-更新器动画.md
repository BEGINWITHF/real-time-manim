# 更新器动画类（Scene.play 直接播放）

三个可以交给 `Scene.play` 的更新器动画：有始有终的「回调式」动画。

## 参数

### UpdateFromFunc

```python
def UpdateFromFunc(mobject: Mobject, update_function: Callable[[Mobject], Any],
                   suspend_mobject_updating: bool = False, **kwargs: Any) -> Animation
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `Mobject` | — | 被驱动的对象（动画期间它会出现在场景里） |
| `update_function` | `Callable[[Mobject], Any]` | — | 每帧接收 `mobject` 的函数 `f(mob)` |
| `suspend_mobject_updating` | `bool` | `False` | 是否在动画期间暂停该对象**已有的** updater |
| `**kwargs` | `Any` | — | 透传给 `Animation`（`run_time=`、`rate_func=` 等） |

> **返回**：`Animation`。在 `play` 的**整个时长内**反复调用 `update_function(mobject)`。与 `add_updater` 的差别：它是**一段有始有终的动画**（`run_time` 结束就停），updater 则是永久挂载。

#### 样例：跟着点走的读数

黄点横穿画面；第二段播放时点往回走，`UpdateFromFunc(lab, follow)` 让标签**贴着点上方**、实时显示它的 x 坐标——动画一结束回调就停。

```python
from real_time_manim import Scene, Dot, DecimalNumber, \
    WHITE, YELLOW, UP, LEFT, RIGHT
from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim import UpdateFromFunc

class UpdateFromFuncDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        dot = Dot(color=YELLOW, radius=0.12).shift(LEFT * 4.0)   #黄点
        lab = DecimalNumber(0, num_decimal_places=2, color=WHITE).scale(0.7)   #读数标签
        lab.to_edge(UP, buff=0.5)   #先放到顶部
        self.add(dot, lab)   #进场景

        def follow(m):   #动画期间每帧被调用：标签贴到点上方并显示点的 x 坐标
            m.move_to(dot.get_center() + UP * 1.2)
            m.set_value(round(float(dot.get_x()), 2))

        win.play(dot.animate.shift(RIGHT * 8.0), run_time=1.2)   #点横穿画面（标签还没挂）
        win.play(UpdateFromFunc(lab, follow), dot.animate.shift(LEFT * 8.0), run_time=1.2)   #动画的整个时长里每帧驱动标签
        win.play(Wait(0.3))   #进行 0.3s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：黄点先自己横穿一次画面（此时标签还钉在顶部不动）；第二段 `play` 里同时播两个动画——点往回走、`UpdateFromFunc(lab, follow)` 在**整个 1.2 秒**里每帧调用 `follow`，把标签挪到点上方并写出它的 x 坐标（数字实时滚动）；`run_time` 一到回调自动停止，标签停在最后一帧的位置。

<video src="assets/RTM output/09-更新器动画-update_func.mp4" controls width="560"></video>

> 提醒：和 `add_updater` 二选一——要「永久跟随」用 updater，要「只在某段动画里跟随」用 `UpdateFromFunc`。被驱动的对象会自动加入场景（不需要先 `add`）；`suspend_mobject_updating=True` 可以在回调期间压制它自己的 updater，避免打架。

### UpdateFromAlphaFunc

```python
def UpdateFromAlphaFunc(mobject: Mobject, update_function: Callable[[Mobject, Any], Any],
                        suspend_mobject_updating: bool = False, **kwargs: Any) -> Animation
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `Mobject` | — | 被驱动的对象 |
| `update_function` | `Callable[[Mobject, Any], Any]` | — | 签名是 `func(mobject, alpha)`，`alpha` 为经 `rate_func` 处理后的 0→1 进度 |
| `suspend_mobject_updating` | `bool` | `False` | 是否在动画期间暂停该对象已有的 updater |
| `**kwargs` | `Any` | — | 透传给 `Animation` |

> **返回**：`Animation`。`UpdateFromFunc` 的子类，用于「按进度精确插值」的自定义动画——回调多拿一个 `alpha`，可以做颜色渐变、位置映射这类**确定性**变换。

#### 样例：按进度插值

蓝方块在 1 秒内从中心走向右边，颜色按 `alpha` 从蓝插到红——进度本身由 `alpha` 参数给出，每帧都是确定值。

```python
from real_time_manim import Scene, Square, \
    BLUE, RED, RIGHT
from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim import UpdateFromAlphaFunc, interpolate_color

class UpdateAlphaDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        sq = Square(color=BLUE, side_length=1.2, fill_opacity=0.7)   #蓝色方块
        self.add(sq)   #进场景
        start = sq.get_center().copy()   #记住起点

        def morph(m, alpha):   #按进度插值：颜色蓝→红、向右移动
            m.set_color(interpolate_color(BLUE, RED, alpha))
            m.move_to(start + alpha * RIGHT * 3.0)

        win.play(UpdateFromAlphaFunc(sq, morph, suspend_mobject_updating=False), run_time=1.0)   #alpha 经 rate_func 处理后 0→1
        win.play(Wait(0.3))   #进行 0.3s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：方块的 `morph(m, alpha)` 拿到的 `alpha` 是**经过 `rate_func` 处理的进度**（默认缓入缓出，0→1）——颜色按 `interpolate_color(BLUE, RED, alpha)` 线性插值、位置按 `start + alpha * RIGHT * 3.0` 线性映射。1 秒的动画里两件事严格同步：走到一半时颜色也正好是一半的紫。这是「一个回调里同时驱动多个属性」的最短路径。

<video src="assets/RTM output/09-更新器动画-update_alpha.mp4" controls width="560"></video>

> 提醒：`alpha` 已经过 `rate_func`——要匀速请传 `rate_func=linear`。回调里做的事**必须是 alpha 的纯函数**（同样的 alpha 得到同样的状态），否则重复帧之间会跳。瞬时的累计变换（如每帧转 5°）应该用 `UpdateFromFunc` + `dt` 或 updater。

### MaintainPositionRelativeTo

```python
def MaintainPositionRelativeTo(mobject: Mobject, tracked_mobject: Mobject,
                               **kwargs: Any) -> Animation
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject` | `Mobject` | — | 要保持相对位置的对象 |
| `tracked_mobject` | `Mobject` | — | 被跟踪的参照对象 |
| `**kwargs` | `Any` | — | 透传给 `Animation` |

> **返回**：`Animation`。动画期间保持 `mobject` 相对 `tracked_mobject` 的位置（初始差值被记录，每帧跟随）。

#### 样例：卫星与参照

紫色小圆先贴在绿方块上方，播放 `MaintainPositionRelativeTo(sat, ref)` + 方块右移——小圆像卫星一样保持偏移量一起走。

```python
from real_time_manim import Scene, Square, Circle, \
    GREEN, PURPLE, UP, LEFT, RIGHT
from real_time_manim.vulkan_bind import MLWindow, Wait
from real_time_manim import MaintainPositionRelativeTo

class MaintainDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        ref = Square(color=GREEN, side_length=1.0, fill_opacity=0.6).shift(LEFT * 3.5)   #参照方块
        sat = Circle(color=PURPLE, radius=0.35)   #卫星
        sat.next_to(ref, UP, buff=0.25)   #先贴在参照上方：这就是要保持的相对位置
        self.add(ref, sat)   #进场景
        win.play(MaintainPositionRelativeTo(sat, ref), ref.animate.shift(RIGHT * 7.0), run_time=1.2)   #相对位置不变：一起走
        win.play(Wait(0.3))   #进行 0.3s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：紫圆先用 `next_to` 贴在绿方块正上方——这个初始偏移就是被记住的「相对位置」；同一次 `play` 里方块右移 7 个单位，`MaintainPositionRelativeTo(sat, ref)` 让紫圆每帧同步这个偏移量，看起来就像卫星钉着方块一起飞。`run_time` 结束绑定解除，紫圆停在原地。

<video src="assets/RTM output/09-更新器动画-maintain.mp4" controls width="560"></video>

> 提醒：相对位置在**动画开始时**记录——要先摆好位置再播。动画结束后绑定自动解除（不是永久跟随）；要永久跟随用 `add_updater(lambda m: m.move_to(ref.get_center() + offset))` 或 `always`。
