# 摆放位置

把对象放到画面里想去的位置：平移、对齐、贴边、贴角。以下方法均返回自身，可链式调用。

## 参数

### shift

```python
def shift(*vectors: Vector3DLike) -> Self
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `*vectors` | `np.ndarray` / 坐标元组 | — | 位移向量。**能填** `RIGHT * 2`、`UP + LEFT` 这类向量常量组合；**可传多个**，内部求和后一次平移 |

> **返回**：自身。作用于自身及全部子对象（真正移动的是 `family_members_with_points()` 那批顶点）。这是最基础的摆放方法，`next_to` / `to_edge` 等最终都落到它头上。

#### 样例：`shift` 单向量与多向量

方块先沿一个向量右移，再一次性传两个向量（内部求和走向左 4、向上 1.2），最后不带 `animate` 瞬间平移一步。

```python
from real_time_manim import Scene, Square, \
    BLUE, UP, DOWN, LEFT, RIGHT
from real_time_manim.vulkan_bind import MLWindow, Wait

class ShiftDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        sq = Square(color=BLUE, side_length=1.4, fill_opacity=0.6)   #蓝色方块
        self.add(sq)   #进场景
        win.play(sq.animate.shift(RIGHT * 2.0), run_time=0.5)   #沿一个向量平移：向右 2
        win.play(sq.animate.shift(UP * 1.2, LEFT * 4.0), run_time=0.6)   #传多个向量：内部求和，走向左 4、向上 1.2
        sq.shift(DOWN * 2.4, RIGHT * 1.2)   #不加 “animate” 是瞬间平移：下 2.4 + 右 1.2
        win.play(Wait(0.5))   #进行 0.5s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：一个蓝色方块先沿 `RIGHT * 2` 平滑右移；然后 `shift(UP * 1.2, LEFT * 4.0)` 一次传两个向量，内部把它们加起来（等于 `LEFT * 4 + UP * 1.2`）再移动；最后一步不加 `.animate`，是瞬间到位的直接平移。三步的起点都是上一步的终点——`shift` 是相对移动，多次调用会累积。

<video src="assets/RTM output/02-摆放位置-shift.mp4" controls width="560"></video>

> 提醒：`shift` 是**相对量**，写 `shift(RIGHT * 2)` 是「再往右 2」而不是「移到 x=2」；要绝对坐标用 `move_to` 或 `set_x` / `set_y`。多个向量参数和 `a + b` 一个向量等价，挑好读的写法就行。

### move_to

```python
def move_to(point_or_mobject: Point3DLike | Mobject,
            aligned_edge: Vector3DLike = ORIGIN,
            coor_mask: Vector3DLike = [1, 1, 1]) -> Self
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `point_or_mobject` | 点坐标 / `Mobject` | — | 目标点。**能填** `[2, 1, 0]`、`RIGHT * 2` 这类坐标，或另一个对象（取它的基准点） |
| `aligned_edge` | 向量 | `ORIGIN` | 用**自己**哪个基准点去对齐：`ORIGIN`=中心、`UR`=右上角、`UP`=上边缘中点…… |
| `coor_mask` | 向量 | `[1, 1, 1]` | 只在掩码为 1 的轴上生效。**能填** `np.array([1, 0, 0])`（只对齐 x）之类 |

> **返回**：自身。「对齐到某物」的通用入口：把自己 `aligned_edge` 处的关键点挪到目标点，再按 `coor_mask` 过滤掉不想动的轴。

#### 样例：`move_to` 三种对齐方式

方块对准左上的目标点：先默认中心对中心，再用右上角对到右上目标点，最后 `coor_mask` 只对齐 x、y 保持不动。

```python
import numpy as np

from real_time_manim import Scene, Square, Dot, \
    RED, YELLOW, UP, DOWN, LEFT, RIGHT, UR
from real_time_manim.vulkan_bind import MLWindow, Wait

class MoveToDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        dot = Dot(color=YELLOW, radius=0.12)   #目标点
        dot.move_to(LEFT * 3.0 + UP * 1.6)   #把目标点放到画面左上
        sq = Square(color=RED, side_length=1.2, fill_opacity=0.6)   #要移动的方块
        self.add(dot, sq)   #都进场景
        win.play(sq.animate.move_to(dot), run_time=0.6)   #默认中心对中心
        win.play(sq.animate.move_to(RIGHT * 3.0 + UP * 1.6, aligned_edge=UR), run_time=0.6)   #用自己右上角对到目标点
        win.play(sq.animate.move_to(RIGHT * 3.0 + DOWN * 1.8, coor_mask=np.array([1, 0, 0])), run_time=0.6)   #只对齐 x，y 保持不动
        win.play(Wait(0.5))   #进行 0.5s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：画面左上放一个小黄点当目标，红方块分三步走。第一步 `move_to(dot)` 什么都不加，方块**中心**对到目标点；第二步 `aligned_edge=UR`，改成把方块**右上角**对到右上目标点，所以方块整体落在目标点的左下方；第三步 `coor_mask=np.array([1, 0, 0])` 把 y 轴掩掉，虽然目标点在下方，方块只在 x 方向移过去、高度保持不变。

<video src="assets/RTM output/02-摆放位置-move_to.mp4" controls width="560"></video>

> 提醒：`aligned_edge` 用的是**自己**的关键点（`UR` = 把自己的右上角放上去），传 `Mobject` 时取的才是对方的关键点。`coor_mask` 是逐轴相乘的掩码，`[1, 0, 0]` 就是「只管 x」，做「x 跟随、y 不动」这类效果很方便。

### next_to

```python
def next_to(mobject_or_point: Mobject | Point3DLike,
            direction: Vector3DLike = RIGHT, buff: float = 0.25,
            aligned_edge: Vector3DLike = ORIGIN,
            submobject_to_align: Mobject | None = None,
            index_of_submobject_to_align: int | None = None,
            coor_mask: Vector3DLike = [1, 1, 1]) -> Self
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mobject_or_point` | `Mobject` / 点坐标 | — | 参照物。**能填**另一个对象或一个点 |
| `direction` | 向量 | `RIGHT` | 放在参照物的哪一侧。**能填** `UP` / `DOWN` / `LEFT` / `RIGHT` 及对角方向 |
| `buff` | `float` | `0.25` | 两者之间的间距 |
| `aligned_edge` | 向量 | `ORIGIN` | 用自己哪个基准点贴上去。对位点是「参照物的 `aligned_edge+direction` 关键点」对「自己的 `aligned_edge-direction` 关键点」——如 `aligned_edge=DOWN` + `direction=RIGHT` 就是自己左下角对参照物右下角（下边缘对齐） |
| `submobject_to_align` | `Mobject` 或 `None` | `None` | 指定**自己**的某个子对象去对齐，父对象整体平移 |
| `index_of_submobject_to_align` | `int` 或 `None` | `None` | 按下标取「自己第 i 个子对象」去对齐；参照物是 `Mobject` 时**同样**取它的第 i 个子对象当目标 |
| `coor_mask` | 向量 | `[1, 1, 1]` | 只在掩码为 1 的轴上生效 |

> **返回**：自身。标签与排列最常用：内部按「参照物关键点 - 自己关键点 + buff×方向」算位移，再交给 `shift`。

#### 样例：`next_to` 的方向、间距与对齐

中心一个蓝色方块：右侧邻居给 `buff=0.3`（垂直居中），上侧邻居 `direction=UP`（水平居中），另一个右侧邻居 `aligned_edge=DOWN` 演示下边缘对齐；左侧的一组用 `submobject_to_align` 指定第二个子对象去贴；底部再演示 `index_of_submobject_to_align` 两边同时按下标取子对象。

```python
from real_time_manim import Scene, Square, VGroup, \
    BLUE, RED, GREEN, PURPLE, ORANGE, TEAL, YELLOW, WHITE, \
    UP, DOWN, LEFT, RIGHT, FadeIn
from real_time_manim.vulkan_bind import MLWindow, Wait

class NextToDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        box = Square(color=BLUE, side_length=1.6, fill_opacity=0.6)   #参照物
        self.add(box)   #进场景
        right = Square(color=RED, side_length=0.8).next_to(box, RIGHT, buff=0.3)   #direction / buff：垂直居中贴右侧
        up = Square(color=GREEN, side_length=0.8).next_to(box, UP, buff=0.2)   #direction=UP：水平居中贴上侧
        low = Square(color=ORANGE, side_length=0.8).next_to(box, RIGHT, buff=1.2, aligned_edge=DOWN)   #aligned_edge=DOWN：下边缘对齐，不垂直居中
        duo = VGroup(Square(color=PURPLE, side_length=0.5), Square(color=TEAL, side_length=0.5))   #两个小方块一组
        duo.arrange(DOWN, buff=0.2)   #上下排好
        duo.next_to(box, LEFT, buff=0.3, submobject_to_align=duo[1])   #用自己第二个子对象去对齐
        self.add(right, up, low, duo)   #四个邻居进场景
        win.play(FadeIn(right), FadeIn(up), run_time=0.5)   #右侧、上方的邻居淡入
        win.play(FadeIn(low), FadeIn(duo), run_time=0.5)   #下对齐的、左侧的一组淡入
        ref = VGroup(Square(color=TEAL, side_length=0.6), Square(color=TEAL, side_length=0.6))   #参照组：两个子对象
        ref.arrange(RIGHT, buff=0.2).shift(DOWN * 2.3)   #放到底部
        self.add(ref)   #进场景
        tag = VGroup(Square(color=YELLOW, side_length=0.3), Square(color=WHITE, side_length=0.3))   #两段标记
        tag.arrange(RIGHT, buff=0.1)   #排成一行
        tag.next_to(ref, UP, buff=0.25, index_of_submobject_to_align=1)   #自己和参照物都用第 2 个子对象对齐
        self.add(tag)   #进场景
        win.play(FadeIn(ref), FadeIn(tag), run_time=0.5)   #参照组与标记淡入
        win.play(Wait(0.5))   #进行 0.5s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：中心放一个蓝色方块当参照物，四周演示 `next_to` 的参数——右边的红方块只给 `direction` 和 `buff`，与参照物垂直居中；上边的绿方块 `direction=UP`，水平居中；橙色方块同样贴右侧但给 `aligned_edge=DOWN`，于是它**下边缘**与参照物对齐而不是垂直居中；左边一组两个小方块用 `submobject_to_align=duo[1]`，是让**第二个子对象**去贴，整组随之左移。底部的参照组有两个子对象，`index_of_submobject_to_align=1` 让标记组和参照物**都**取第 2 个子对象来对位，所以黄白标记正对参照组的右半边上方。

<video src="assets/RTM output/02-摆放位置-next_to.mp4" controls width="560"></video>

> 提醒：`aligned_edge` 不是「自己哪个角贴上去」这么简单——实际对位的是「参照物 `aligned_edge+direction`」和「自己 `aligned_edge-direction`」两个关键点，方向会参与进来，写之前按这个公式推一遍才不会贴歪。`submobject_to_align` 优先于 `index_of_submobject_to_align`；`index_of_submobject_to_align` 是**同一个下标**同时用在自己和参照物上，两边子对象数量对不上就容易取错位。`buff` 是沿 `direction` 的间距，方向换成对角线时间距也按对角方向算。

### to_edge / to_corner

```python
def to_edge(edge: Vector3DLike = LEFT, buff: float = 0.5) -> Self
def to_corner(corner: Vector3DLike = DL, buff: float = 0.5) -> Self
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `edge` | 向量 | `LEFT` | **只能填** `UP` / `DOWN` / `LEFT` / `RIGHT` 四个边方向 |
| `corner` | 向量 | `DL` | **只能填** `UL` / `UR` / `DL` / `DR` 四个角方向 |
| `buff` | `float` | `0.5` | 距边/角的留白 |

> **返回**：自身。`to_edge` 只改贴边那条轴的坐标，另一轴保持不动（内部就是 `align_on_border`，见 [02b-摆放位置-进阶](02b-摆放位置-进阶.md)）。

#### 样例：`to_edge` / `to_corner` 贴边贴角

四个小方块分别贴上、下、左三条边和右上角；贴左边那个先抬高 1.2 再贴边，验证 y 坐标不被改动。

```python
from real_time_manim import Scene, Square, ScreenRectangle, \
    RED, BLUE, GREEN, YELLOW, GREY, UP, LEFT, DOWN, UR, FadeIn
from real_time_manim.vulkan_bind import MLWindow, Wait

class EdgeCornerDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        frame = ScreenRectangle(height=6.8, color=GREY)   #示意画面边界
        self.add(frame)   #进场景
        top = Square(color=RED, side_length=0.9)   #贴上边的方块
        bottom = Square(color=BLUE, side_length=0.9)   #贴下边的方块
        side = Square(color=GREEN, side_length=0.9)   #贴左边的方块
        corner = Square(color=YELLOW, side_length=0.9)   #贴右上角的方块
        top.to_edge(UP, buff=0.3)   #贴上边，留白 0.3
        bottom.to_edge(DOWN, buff=0.3)   #贴下边
        side.shift(UP * 1.2)   #先往上挪一点
        side.to_edge(LEFT, buff=0.3)   #贴左边：y 坐标不受影响
        corner.to_corner(UR, buff=0.5)   #贴右上角，留白 0.5
        self.add(top, bottom, side, corner)   #都进场景
        win.play(FadeIn(top), FadeIn(bottom), FadeIn(side), FadeIn(corner), run_time=0.6)   #四个方块淡入
        win.play(Wait(0.5))   #进行 0.5s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：先画一个灰色 `ScreenRectangle` 示意画面边界（真正贴的是整个画面的边，不是这个框），然后四个小方块各就各位——红的贴上边、蓝的贴下边、黄的贴右上角，都按留白拉开距离；绿色的**先抬高 1.2** 再 `to_edge(LEFT)`，可以看到它贴到左边后仍然保持抬高的高度，证明 `to_edge` 只动贴边那条轴。

<video src="assets/RTM output/02-摆放位置-edge_corner.mp4" controls width="560"></video>

> 提醒：贴边参照的是**画面**（`config` 的 frame 宽高），不是 `self.camera.frame` 之类的取景框——用 MovingCamera 推镜头时，贴边对象是贴在世界坐标系的屏幕上，镜头一推就可能出画。想要「钉在屏幕上」的效果得挂在相机 frame 上（见 [01-MovingCameraScene](../01-场景与相机/专用场景/01-MovingCameraScene.md)）。

### center / align_to

```python
def center() -> Self
def align_to(mobject_or_point: Mobject | Point3DLike,
             direction: Vector3DLike = ORIGIN) -> Self
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| （`center` 无参数） | — | — | 把中心移到原点 `(0, 0, 0)` |
| `mobject_or_point` | `Mobject` / 点坐标 | — | 对齐目标 |
| `direction` | 向量 | `ORIGIN` | 只调整这个方向**非零分量**对应的轴：`UP`/`DOWN` 对齐 y、`LEFT`/`RIGHT` 对齐 x、`ORIGIN` 完全重合 |

> **返回**：自身。`align_to` 是「沿指定方向齐平」：`mob1.align_to(mob2, UP)` 让两者上边缘齐平，只动 y 轴。

#### 样例：`center` 回中与 `align_to` 齐平

蓝方块从左上回到原点；黄方块与红色大方块 `align_to(big, UP)` 上边缘齐平，x 坐标保持不变。

```python
from real_time_manim import Scene, Square, \
    BLUE, RED, YELLOW, UP, LEFT, RIGHT
from real_time_manim.vulkan_bind import MLWindow, Wait

class CenterAlignDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        sq = Square(color=BLUE, side_length=1.2, fill_opacity=0.6)   #蓝色方块
        sq.shift(LEFT * 3.2 + UP * 1.4)   #先挪到左上
        self.add(sq)   #进场景
        win.play(sq.animate.center(), run_time=0.6)   #center：回到原点 (0, 0, 0)
        big = Square(color=RED, side_length=2.0, fill_opacity=0.4)   #参照大方块
        big.shift(RIGHT * 3.2)   #放右边
        small = Square(color=YELLOW, side_length=1.0)   #待对齐的小方块
        small.shift(RIGHT * 3.2 + UP * 1.8)   #先放高一点
        self.add(big, small)   #进场景
        win.play(small.animate.align_to(big, UP), run_time=0.6)   #align_to：上边缘齐平，x 不动
        win.play(Wait(0.5))   #进行 0.5s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：先把蓝色方块挪到左上角，然后播放 `center()` 让它回到画面正中——不管之前在哪，`center` 一步归零。右边的红色大方块和黄色小方块起初一高一低，`align_to(big, UP)` 只把小方块的 y 调到与大方块上边缘齐平，x 方向纹丝不动；这就是 `align_to` 和 `move_to` 的区别：它只动 `direction` 里非零的那些轴。

<video src="assets/RTM output/02-摆放位置-center_align.mp4" controls width="560"></video>

> 提醒：`center()` 是**画面正中**不是「自身中心」——对象自己的中心永远是自己的中心，不需要搬。`align_to` 想对齐多个轴就传对角方向，如 `align_to(other, UR)` 会把 x、y 都对齐到右上角齐平。
