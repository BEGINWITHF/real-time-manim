# 构造、容器与增删

Mobject 是所有可视对象的基类。本页讲它的构造参数、`Group` 容器，以及子对象的增删与索引访问——这四个入口，任何动画脚本都绕不开。

## 参数

### class Mobject

```python
def __init__(self, color: ParsableManimColor | list[ParsableManimColor] = WHITE,
             name: str | None = None, dim: int = 3,
             target: Mobject | None = None, z_index: float = 0) -> None:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `color` | 颜色字符串 / `ManimColor` / 颜色列表 | `WHITE` | 对象颜色。**能填**：`"red"`、`"#ff0000"`、`RED`、`ManimColor("#83c167")`；也接受颜色列表（部分子类按列表逐子对象上色）。子类在 `init_colors()` 里用它初始化描边与填充 |
| `name` | `str \| None` | `None` | 对象名。**能填**任意字符串，缺省取类名（如 `Square`）；只影响 `repr` 之类的调试输出，可以随便改 |
| `dim` | `int` | `3` | 顶点坐标的维度。**不建议改**：实际只有 `3` 能用，改了点数组维度对不上，纯属自定义子类的内部参数 |
| `target` | `Mobject \| None` | `None` | `.target` 缓存槽。 **不建议手动设置**：它由 `generate_target()`（见 [06-复制派生与状态](06-复制派生与状态.md)）填充，手动塞值容易和 `MoveToTarget` 打架 |
| `z_index` | `float` | `0` | 渲染叠放顺序。**能填**任意数值，越大显示越靠上；与 `add` 先后无关（`z_index` 相同才按加入顺序） |

> **返回**：无（构造实例）。这 5 个参数会被每个子类（`Square`、`Text`、`Circle`……）通过 `**kwargs` 原样透传，所以在**任何**子类的构造函数里都能写。

#### 样例：`color` / `name` / `z_index` 改动

两个同样大小的方块错开重叠：后加进场景的是蓝色，但红色 `z_index=2` 更大，所以重叠处红色永远压住蓝色——这就是 `z_index` 的作用。`name` 不改画面，只改控制台打印里的对象名。`dim` / `target` 属于内部参数，样例只把它们的当前值打出来看一眼。

```python
from real_time_manim import Scene, Square, \
    BLUE, RED, RIGHT, FadeIn
from real_time_manim.vulkan_bind import MLWindow, Wait

class CtorDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        front = Square(color=RED, side_length=2.4, fill_opacity=0.8, name="hero", z_index=2)   #名字 “hero”、叠放层级 2
        back = Square(color=BLUE, side_length=2.4, fill_opacity=0.8)   #其余全走默认：name 取类名、z_index=0
        back.shift(RIGHT * 1.2)   #向右错开一点，让两个方块有重叠
        self.add(front, back)   #先加 “front” 后加 “back”，但层级大的仍然显示在上
        print("color =", back.color, "| name =", back.name, "| dim =", back.dim)   #颜色、名字、点坐标维度
        print("target =", front.target, "| z_index =", front.z_index, back.z_index)   #target 缓存默认为空
        win.play(FadeIn(front), FadeIn(back), run_time=0.6)   #两个方块一起淡入
        win.play(Wait(0.5))   #进行 0.5s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：先开一个 RTM 窗口绑上场景，再造两个一样的方块——红色的叫 `hero`、叠放层级 2，蓝色的什么都不传、全走默认。把蓝色的往右错开 1.2，让它们有一段重叠，然后按「先红后蓝」的顺序加进场景。

控制台会打印 `color` / `name` / `dim` / `target` / `z_index` 这几个构造参数的实际取值。画面里则能看到：蓝色虽然是后加进场景的，重叠处却**没有**盖住红色——因为 `z_index` 大的渲染在上层。

<video src="assets/RTM output/01-构造与容器-ctor.mp4" controls width="560"></video>

> 提醒：
>
> - `Square` 默认只有描边没有填充，样例显式给了 `fill_opacity=0.8`；否则两个方块都是空心的，重叠处根本看不出谁压谁。
> - `z_index` 只在相同时才用加入顺序定先后，所以「后 add 的在上」只是默认 `z_index` 全为 0 时的巧合。
> - `target` 别手动赋值，它是 `generate_target()` 的地盘。

### class Group

```python
def Group(*mobjects: Mobject, **kwargs: Any) -> None:
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `*mobjects` | 任意 `Mobject` | — | 要放进组里的对象，**什么类型都能装**（含 `Text`、`ImageMobject` 这类非纯几何对象） |
| `**kwargs` | `Any` | — | 透传给 `Mobject.__init__`，所以 [上一小节](#class-mobject) 的 5 个参数（如 `color=`、`z_index=`）在这里也能填 |

> **返回**：新的 `Group`，自身没有新增方法（用的还是 `Mobject` 的那套）。与 `VGroup` 的区别：`VGroup` 只收矢量对象（`VMobject` 子类），塞别的会直接 `TypeError`；`Group` 什么都能装。组里重复添加同一个对象会被忽略（想要两份先 `.copy()`）。

#### 样例：`Group` 混装不同类型

方块、文字、圆点三种不同类型的对象装进一个 `Group`，整组当成一个对象摆放、淡入；再演示重复添加会被忽略，以及 `VGroup` 拒收非矢量对象。

```python
from real_time_manim import Scene, Mobject, Group, VGroup, Square, Circle, Text, Dot, \
    BLUE, YELLOW, GREEN, RIGHT, FadeIn
from real_time_manim.vulkan_bind import MLWindow, Wait

class GroupDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        sq = Square(color=BLUE, side_length=1.2)   #方块
        label = Text("G", font_size=48, color=YELLOW)   #文字：和方块不同类
        dot = Dot(color=GREEN, radius=0.35)   #圆点：又一种类型
        g = Group(sq, label, dot, z_index=1)   #“Group” 什么类型都能装，“z_index” 透传给 Mobject
        g.arrange(RIGHT, buff=0.6)   #三个子对象排成一行
        self.add(g)   #整组进场景
        print("len(g) =", len(g), "| 类型 =", [type(m).__name__ for m in g])   #三个子对象都在
        g.add(sq)   #重复添加同一个对象：被忽略，只留一份
        print("重复 add 后 len(g) =", len(g))   #仍然是 3
        try:
            VGroup(Mobject())   #“VGroup” 只收矢量对象
        except TypeError as exc:   #裸 “Mobject” 没有矢量数据
            print("VGroup 拒收非矢量对象 ->", exc)
        win.play(FadeIn(g), run_time=0.6)   #整组淡入
        win.play(Wait(0.5))   #进行 0.5s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：把方块、文字 `G`、圆点三种不同类型的对象装进同一个 `Group`，`arrange` 排成一行后整组进场景、整组淡入。控制台打印组里有 3 个子对象、各自的类型。接着把方块再 `add` 一遍——组里仍然只有 3 份，重复项被忽略。最后用一个裸 `Mobject` 去构造 `VGroup`，被 `TypeError` 拒收，证明 `VGroup` 只收矢量对象。

<video src="assets/RTM output/01-构造与容器-group.mp4" controls width="560"></video>

> 提醒：`Group.arrange` 这类摆放方法用的是每个子对象的包围盒，文字和几何对象混排没问题；但 `Group` 切片（`g[1:3]`）返回的也是 `Group`，不会变成 `VGroup`。想对整组做 `set_fill` 这类矢量样式操作，还是用 `VGroup` 更顺手。

### add / remove / add_to_back / insert

```python
def add(*mobjects: Mobject) -> Self
def remove(*mobjects: Mobject) -> Self
def add_to_back(*mobjects: Mobject) -> Self
def insert(index: int, mobject: Mobject) -> Self
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `*mobjects` | `Mobject` | — | 要增删的对象（`add` / `remove` / `add_to_back`）；`add` 的重复项被忽略并打印警告，`remove` 不存在的对象被静默忽略 |
| `index` | `int` | — | `insert` 的插入位置，负数按 Python 列表规则 |
| `mobject` | `Mobject` | — | `insert` 要插入的对象 |

> **返回**：都返回自身，可链式调用。**渲染顺序 = `submobjects` 列表顺序**：列表头部先画（垫底）、尾部后画（盖上）。
>
> - `add` 追加到尾部（显示最上）。
> - `add_to_back` 插到头部（显示最下）。
> - `insert` 精确指定位置。
>
> 父对象已在场景里时，新加的子对象自动跟着显示。

#### 样例：`add` / `remove` / `add_to_back` / `insert`

红方块和蓝圆盘反复调整叠放关系：加到尾部就盖住方块，`remove` 退场只剩方块，`add_to_back` 插到头部就垫到方块下面，`insert(1, ...)` 又插回尾部。

```python
from real_time_manim import Scene, Group, Square, Circle, \
    RED, BLUE, FadeIn
from real_time_manim.vulkan_bind import MLWindow, Wait

class AddRemoveDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        box = Square(color=RED, side_length=2.6, fill_opacity=0.8)   #红色方块（带填充）
        disc = Circle(color=BLUE, radius=1.25, fill_opacity=0.8)   #蓝色圆盘（带填充）
        g = Group(box)   #先把方块放进 “Group”
        g.add(disc)   #add：圆盘加到列表尾部，显示在方块上面
        self.add(g)   #整组进场景
        win.play(FadeIn(g), run_time=0.5)   #淡入：圆盘盖住方块中心
        g.remove(disc)   #remove：圆盘退出组，画面里只剩方块
        win.play(Wait(0.4))   #停 0.4s 看结果
        g.add_to_back(disc)   #add_to_back：圆盘插到列表头部，显示在方块下面
        win.play(Wait(0.4))   #停 0.4s 看结果
        g.remove(disc)   #先拿走：insert 不去重，已存在时会多出一份引用
        g.insert(1, disc)   #insert：按索引插入到尾部，圆盘又盖住方块
        win.play(Wait(0.4))   #停 0.4s 看结果
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：一个红方块和一个蓝圆盘放进 `Group`，靠几次「改列表顺序」看叠放关系怎么变。

- `add` 把圆盘追加到列表尾部，它盖住方块。
- `remove` 把它拿走，画面只剩方块。
- `add_to_back` 把它插回列表头部，于是垫到方块底下（被红方块盖住中心）。
- 最后先 `remove` 再 `insert(1, disc)`，按索引把它插到尾部，圆盘又回到方块上面。

三段 `Wait` 各停 0.4 秒，就是给你看清每一步的结果。

<video src="assets/RTM output/01-构造与容器-add_remove.mp4" controls width="560"></video>

> 提醒：
>
> - 这几个方法是**瞬间生效**的，没有过渡动画；想让「加进来」有过程，用 `FadeIn` / `Write` 等动画类。
> - `remove` 只是解除从属关系，对象本身还在，随时能 `add` 到别处。
> - `add` 同一个对象两次会被忽略，`insert` 则**不会去重**——对象已在列表里时会多出一份引用，想挪位置先 `remove` 再 `insert`。

### 索引、切片与迭代

```python
def __getitem__(value: int | slice) -> Mobject | Group
def __iter__() -> Iterator[Mobject]
def __len__() -> int
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `int` / `slice` | — | 子对象下标或切片；负数下标按 Python 列表规则 |

> **返回**：`int` 返回子 `Mobject`，`slice` 返回**同类型**新组（`VGroup` 切出来还是 `VGroup`），`len()` 返回子对象个数，`for` 循环依次给出直接子对象。底层是 `split()`（「自身 + 直接子对象」），不会自动展开更深层。

#### 样例：`mob[i]` / `mob[a:b]` / 迭代

五个方块排成一行：索引取出第 3 个往上挪，切片取出中间两个改色，最后把整组遍历一遍打印类型。

```python
from real_time_manim import Scene, VGroup, Square, \
    RED, BLUE, GREEN, YELLOW, PURPLE, ORANGE, RIGHT, UP
from real_time_manim.vulkan_bind import MLWindow, Wait

class IndexingDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        colors = (RED, BLUE, GREEN, YELLOW, PURPLE)   #五个颜色
        g = VGroup(*[Square(color=c, side_length=0.9) for c in colors])   #五个方块装进 “VGroup”
        g.arrange(RIGHT, buff=0.35)   #排成一行
        self.add(g)   #整组进场景
        print("len(g) =", len(g))   #子对象个数
        print("g[0] =", type(g[0]).__name__, "| g[1:3] =", type(g[1:3]).__name__)   #切片返回同类型新组
        win.play(g[2].animate.shift(UP * 1.2), run_time=0.5)   #索引取出的子对象可以直接动画
        part = g[1:3]   #切片出中间两个方块
        win.play(part.animate.set_color(ORANGE), run_time=0.5)   #只改这两个的颜色
        print("迭代 =", [type(m).__name__ for m in g])   #for 循环依次取出子对象
        win.play(Wait(0.5))   #进行 0.5s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：五个不同颜色的方块排成一行进场景。先打印 `len(g)` 看子对象个数、`type(g[1:3])` 看切片返回的是不是同类型新组。然后 `g[2]` 索引取出第 3 个方块，直接播放它的 `animate` 往上挪；再用 `g[1:3]` 切出中间两个（它们是原组里子对象的引用，不是复制品），把这两个一起改成橙色。最后 `for` 循环把整组遍历一遍打印类型。

<video src="assets/RTM output/01-构造与容器-indexing.mp4" controls width="560"></video>

> 提醒：切片拿到的是**子对象引用**而不是副本，`part.animate.set_color(...)` 改的就是原组里那两个方块；想要独立副本用 `.copy()`。另外切片/迭代只看「直接子对象」这一层——`VGroup` 里套的 `VGroup` 不会被自动展开，它的下标仍是整体一个。
