# 屏幕框架与品牌横幅

版面示意矩形与 Manim 官方 logo 横幅——`frame.py` / `logo.py` 里的低频可视化对象。

## 参数

### ScreenRectangle

```python
def ScreenRectangle(aspect_ratio: float = 16.0 / 9.0, height: float = 4,
                    **kwargs: Any) -> None
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `aspect_ratio` | `float` | `16/9` | 宽高比 |
| `height` | `float` | `4` | 高度 |
| `**kwargs` | `Any` | — | 透传给 `Rectangle`（`color=`、`fill_opacity=` 等） |

> **返回**：新的 `ScreenRectangle`（继承 `Rectangle` 全部方法）。按「屏幕比例」构造的矩形，常代表「一块屏幕/一个版面」并配合 `arrange`、`to_edge` 排版。**特有可读写属性 `aspect_ratio`**：赋值时自动 `stretch_to_fit_width`，改比例不改变高度。

#### 样例：16:9 示意屏幕与 `aspect_ratio`

两个 16:9 的屏幕矩形并排，把右边的 `aspect_ratio` 设为 1.0——高度不变、宽度收到与高度相等。

```python
from real_time_manim import Scene, ScreenRectangle, \
    BLUE, GREEN, LEFT, RIGHT, FadeIn
from real_time_manim.vulkan_bind import MLWindow, Wait

class ScreenRectDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        s1 = ScreenRectangle(height=2.6, color=BLUE)   #按 16:9 生成的示意屏幕
        s1.shift(LEFT * 3.4)   #放左边
        s2 = ScreenRectangle(height=2.6, color=GREEN).next_to(s1, RIGHT, buff=0.5)   #右边一个对照
        self.add(s1, s2)   #进场景
        print("s1 宽高 =", round(s1.width, 2), round(s1.height, 2))   #16:9
        win.play(FadeIn(s1), FadeIn(s2), run_time=0.5)   #淡入
        s2.aspect_ratio = 1.0   #特有可读写属性：变正方形，高度不变（瞬间生效）
        print("改后 s2 =", round(s2.aspect_ratio, 2), round(s2.width, 2), round(s2.height, 2))   #1.0 2.6 2.6
        win.play(Wait(0.5))   #停一下看结果
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：两个高 2.6 的屏幕矩形并排淡入——`s1` 的宽高是 4.62 : 2.6 = 16 : 9（控制台可验证）；随后 `s2.aspect_ratio = 1.0` 直接赋值，setter 会 `stretch_to_fit_width` 把宽收到 2.6 而**高度保持不变**，画面里绿色的屏幕变成了正方形。这就是「按屏幕比例排版」的基本件。

<video src="assets/RTM output/11-屏幕框架与横幅-screen_rect.mp4" controls width="560"></video>

> 提醒：`aspect_ratio` 的赋值是**瞬间**的（想过渡写 `animate.set(aspect_ratio=...)`）；它只改宽，不会动 `height`。示意矩形是**世界坐标**里的一块区域，别指望它自动跟随相机推拉（见 [02-摆放位置](02-摆放位置.md) 的贴边提醒）。

### FullScreenRectangle

```python
def FullScreenRectangle(**kwargs: Any) -> None
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `**kwargs` | `Any` | — | 透传给 `ScreenRectangle`（如 `fill_opacity=`、`color=`） |

> **返回**：新的 `FullScreenRectangle`。铺满整个画面的矩形（高取 `config.frame_height`），常做遮罩、变暗背景：`FullScreenRectangle(fill_opacity=0.7, color=BLACK)`。

#### 样例：全屏变暗遮罩

白字+方块的画面上盖一层半透明黑遮罩，整体变暗；`remove` 摘掉遮罩恢复。

```python
from real_time_manim import Scene, Square, Text, FullScreenRectangle, \
    BLUE, WHITE, BLACK, DOWN, FadeIn
from real_time_manim.vulkan_bind import MLWindow, Wait

class FullScreenDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        txt = Text("SCENE", font_size=48, color=WHITE)   #白字
        sq = Square(color=BLUE, side_length=1.5).shift(DOWN * 1.5)   #蓝方块
        self.add(txt, sq)   #进场景
        win.play(FadeIn(txt), FadeIn(sq), run_time=0.4)   #内容淡入
        mask = FullScreenRectangle(fill_opacity=0.7, color=BLACK)   #铺满整个画面的变暗遮罩
        self.add(mask)   #进场景
        win.play(FadeIn(mask), run_time=0.5)   #遮罩淡入：画面整体变暗
        win.play(Wait(0.4))   #停一下看遮罩效果
        self.remove(mask)   #摘掉遮罩
        win.play(Wait(0.3))   #进行 0.3s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：白字和蓝方块先淡入，然后一张 `FullScreenRectangle(fill_opacity=0.7, color=BLACK)` 淡入——它自动铺满整个画面（不需要自己算尺寸），画面里所有内容立刻压暗到 30% 亮度；停 0.4 秒看清效果后 `self.remove(mask)` 摘掉遮罩恢复原样。这就是「转场压暗」的标准写法。

<video src="assets/RTM output/11-屏幕框架与横幅-fullscreen.mp4" controls width="560"></video>

> 提醒：遮罩按**画面尺寸**生成（`frame_height`/`frame_width`），与 `ScreenRectangle` 不同；`remove` 是瞬间摘除，想要渐隐就动画它的 `fill_opacity`。多个遮罩叠 `add` 的话，后加的画在最上面。

### ManimBanner

```python
def ManimBanner(dark_theme: bool = True)
def create(run_time: float = 2) -> AnimationGroup
def expand(run_time: float = 1.5, direction: str = "center") -> Succession
def scale(scale_factor: float, **kwargs: Any) -> Self
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `dark_theme` | `bool` | `True` | `True` 深色主题（浅色字），`False` 浅色主题（深色字） |
| `run_time` | `float` | `2` / `1.5` | `create` / `expand` 的动画时长 |
| `direction` | `str` | `"center"` | `expand` 的图标让位方向。**只能填** `"left"` / `"right"` / `"center"`，其它值抛 `ValueError` |
| `scale_factor` | `float` | — | 缩放倍数 |

> **返回**：`create` 返回 `AnimationGroup`（logo 图形旋转飞入 + 字母 `M` 淡入的组合动画，是 `Create` 的 override，`banner.create()` 与 `Create(banner)` 均可）；`expand` 返回 `Succession`（把只有图标的 logo 展开成完整「manim」横幅，展开后 `anim` 字母组才被 `add` 进来）；`scale` 是覆写版本：额外记录 `self.scale_factor` 并同步缩放尚未挂载的 `anim` 字母组，保证 `expand()` 间距正确——**必须用这个版本，不要绕开**。常用属性：`M`、`circle`、`square`、`triangle`、`shapes`、`anim`（展开后才出现）、`font_color`、`scale_factor`。

#### 样例：create → expand → 非法 direction

深色主题横幅缩放 0.8 放到底部：`create` 播 logo 入场，`expand` 展开成完整字样；再用 `try` 演示非法 `direction` 抛 `ValueError`，最后打印 `anim` 属性确认展开后已挂载。

```python
from real_time_manim import Scene, ManimBanner, \
    DOWN, FadeIn
from real_time_manim.vulkan_bind import MLWindow, Wait

class BannerDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        banner = ManimBanner(dark_theme=True)   #深色主题横幅
        banner.scale(0.8)   #必须用覆写的 scale：会同步缩放尚未挂载的字母组
        banner.to_edge(DOWN, buff=0.8)   #放到下方
        print("font_color =", banner.font_color, "| scale_factor =", banner.scale_factor)   #常用属性
        self.add(banner)   #进场景
        win.play(banner.create(run_time=1.2))   #logo 图形旋转飞入 + 字母 M 淡入
        win.play(banner.expand(run_time=1.0, direction="center"))   #展开成完整 “manim” 横幅
        try:
            banner.expand(direction="up")   #非法 direction 抛 ValueError
        except ValueError as exc:
            print("expand 非法 direction ->", str(exc)[:50])
        print("anim 属性 =", getattr(banner, "anim", None) is not None)   #展开后才挂上 anim
        win.play(Wait(0.4))   #进行 0.4s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：深色主题的 `ManimBanner` 先 `scale(0.8)`（必须走覆写版，否则 `expand` 的间距会错）、放到画面底部；`banner.create(run_time=1.2)` 播放入场——logo 图形旋转飞入 + 字母 `M` 淡入；接着 `expand(run_time=1.0, direction="center")` 把图标让位、展开成完整「manim」字样。最后 `try` 一次非法的 `expand(direction="up")`，控制台打印出 `ValueError` 文案（只认 `left/right/center`）；`anim` 属性打印 `True`——展开后字母组才被挂进来。

<video src="assets/RTM output/11-屏幕框架与横幅-banner.mp4" controls width="560"></video>

> 提醒：`create` 之后再 `expand` 是官方推荐顺序（`expand` 假设 logo 已在画面里）；反过来先 expand 会看到图标还没入场就让位。`banner.scale(...)` 必须用横幅自己的覆写版本（它会同步缩放还没挂载的 `anim` 组）；直接 `Mobject.scale(banner, ...)` 会让展开时字母间距错位。
