# 测量：尺寸与位置读取

读取包围盒尺寸与各类关键点坐标——摆放、对齐和写 updater 的基础。全部是只读查询（`width` 等三个属性除外），不改对象状态。

## 参数

### width / height / depth（属性，可读可写）

```python
mob.width / mob.height / mob.depth -> float
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| （读取） | `float` | — | 返回包围盒的宽 / 高 / 深；平面对象 `depth` 为 `0` |
| （赋值） | `float` | — | 赋值等价于 `scale_to_fit_width(...)` 等——**等比缩放**到目标尺寸，语句无返回值 |

> **返回**：读取得 `float`。想要「宽变 x 但不变形」用 `stretch_to_fit_width`（见 [04b-缩放旋转与变形-进阶](04b-缩放旋转与变形-进阶.md)）。

#### 样例：读取与赋值

一个 4×2 矩形：先打印三个尺寸，再把 `width` 赋成 2.0（高度等比变 1.0），再把 `height` 赋成 3.0（宽度等比变 6.0）。

```python
from real_time_manim import Scene, Rectangle, \
    BLUE
from real_time_manim.vulkan_bind import MLWindow, Wait

class SizeDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        rect = Rectangle(width=4.0, height=2.0, color=BLUE, fill_opacity=0.4)   #4×2 的矩形
        self.add(rect)   #进场景
        print("初始：width =", rect.width, "height =", rect.height, "depth =", rect.depth)   #4.0 2.0 0.0
        win.play(rect.animate.set(width=2.0), run_time=0.6)   #给 “width” 赋值 = 等比缩放
        print("width=2.0 后：width =", rect.width, "height =", rect.height)   #2.0 1.0：高度等比跟着变
        win.play(rect.animate.set(height=3.0), run_time=0.6)   #给 “height” 赋值：等比放大
        print("height=3.0 后：width =", rect.width, "height =", rect.height)   #6.0 3.0
        win.play(Wait(0.4))   #进行 0.4s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：4×2 的矩形进场景，先打印 `width=4.0 height=2.0 depth=0.0`；播放 `set(width=2.0)` 让宽度变成 2——注意高度**等比**缩到 1.0，长宽比不变；再播放 `set(height=3.0)`，宽度跟着涨到 6.0。控制台两行打印就是「赋值是等比缩放」的证据。

<video src="assets/RTM output/03-测量-size.mp4" controls width="560"></video>

> 提醒：属性赋值是**等比**缩放（底层走 `scale_to_fit_*`），想单独拉宽不改高要用 `stretch_to_fit_width` 或 `stretch`。读取永远拿的是包围盒尺寸——`Text` 连行距空隙一起量进去，做贴合排版时留意。

### get_center / get_top / get_bottom / get_left / get_right

```python
def get_center() -> Point3D
def get_top() -> Point3D   # get_bottom / get_left / get_right 同构
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| （均无参数） | — | — | — |

> **返回**：`np.ndarray`，形状 `(3,)`。分别是包围盒中心与四边中点的坐标；配合 `next_to(..., UP, buff=0)` 可严丝合缝贴合。

#### 样例：中心与四边中点打点

2.4 见方的方块，五个红点分别打在 `get_center` / `get_top` / `get_bottom` / `get_left` / `get_right` 上，坐标同步打印。

```python
from real_time_manim import Scene, VGroup, Square, Dot, \
    BLUE, RED, FadeIn
from real_time_manim.vulkan_bind import MLWindow, Wait

class EdgesDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        sq = Square(color=BLUE, side_length=2.4, fill_opacity=0.4)   #2.4 见方的方块
        self.add(sq)   #进场景
        marks = VGroup()   #关键点标记
        for name, p in (
            ("center", sq.get_center()),
            ("top", sq.get_top()),
            ("bottom", sq.get_bottom()),
            ("left", sq.get_left()),
            ("right", sq.get_right()),
        ):   #中心与四边中点
            marks.add(Dot(color=RED, radius=0.08).move_to(p))   #在关键点上打一个红点
            print(name, "=", p.round(2))   #打印坐标验证
        self.add(marks)   #标记进场景
        win.play(FadeIn(marks), run_time=0.5)   #五个红点淡入
        win.play(Wait(0.5))   #进行 0.5s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：把 2.4 见方的方块的五个关键点各打一个红点——正中、上边中点、下边中点、左边中点、右边中点，一眼看清每个方法返回的是哪个位置；控制台同步打印坐标（如 `top = [0. 1.2 0.]`），与画面互相印证。

<video src="assets/RTM output/03-测量-edges.mp4" controls width="560"></video>

> 提醒：这些是**包围盒**的边中点，不是形状轮廓上的点——圆的 `get_top()` 是圆最上沿的切点没问题，但斜线的 `get_left()` 是包围盒左中点而非线的左端点（端点用 `get_start` / `get_end`，见 [11b-低频其余API](11b-低频其余API.md)）。

### get_x / get_y / get_z / get_coord / get_corner / get_edge_center / get_critical_point

```python
def get_x(direction: Vector3DLike = ORIGIN) -> float   # get_y / get_z 同构
def get_coord(dim: int, direction: Vector3DLike = ORIGIN) -> float
def get_corner(direction: Vector3DLike) -> Point3D
def get_edge_center(direction: Vector3DLike) -> Point3D
def get_critical_point(direction: Vector3DLike) -> Point3D
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `direction` | 向量 | `ORIGIN`（`get_corner` 等必填） | 由各分量**符号**决定取哪个关键点（0 分量取中值），如 `UR`=右上角、`DOWN`=下边中点 |
| `dim` | `int` | — | **只能填** `0`=x、`1`=y、`2`=z（仅 `get_coord`） |

> **返回**：`get_x` / `get_y` / `get_z` / `get_coord` 返回 `float`；后三个返回 `np.ndarray`。`get_corner` / `get_edge_center` 是 `get_critical_point` 的语义化别名（同一实现）；`get_coord` 是 `get_x` / `get_y` / `get_z` 的通用版。写 updater 时 `get_x()` 这类单分量读数最常用。

#### 样例：单坐标与角点读取

右移 1.5 的方块：打印 `get_x` / `get_x(LEFT)` / `get_y` / `get_z` / `get_coord`，再把 `get_corner(UR)` / `get_edge_center(DOWN)` / `get_critical_point(LEFT)` 三个点打上红点。

```python
from real_time_manim import Scene, VGroup, Square, Dot, \
    GREEN, RED, UR, DOWN, LEFT, RIGHT, FadeIn
from real_time_manim.vulkan_bind import MLWindow, Wait

class CoordsGetDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        sq = Square(color=GREEN, side_length=2.0).shift(RIGHT * 1.5)   #右移 1.5 的方块
        self.add(sq)   #进场景
        print("get_x =", sq.get_x(), "| get_x(LEFT) =", sq.get_x(direction=LEFT))   #1.5 0.5
        print("get_y =", sq.get_y(), "| get_z =", sq.get_z())   #0.0 0.0
        print("get_coord(0, UR) =", sq.get_coord(0, UR))   #UR 角点的 x
        marks = VGroup()   #关键点标记
        for name, p in (
            ("corner(UR)", sq.get_corner(UR)),
            ("edge_center(DOWN)", sq.get_edge_center(DOWN)),
            ("critical_point(LEFT)", sq.get_critical_point(LEFT)),
        ):   #角点 / 边中点 / 通用关键点
            marks.add(Dot(color=RED, radius=0.08).move_to(p))   #在关键点上打一个红点
            print(name, "=", p.round(2))   #打印坐标验证
        self.add(marks)   #标记进场景
        win.play(FadeIn(marks), run_time=0.5)   #红点淡入
        win.play(Wait(0.4))   #进行 0.4s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：边长 2 的方块右移 1.5，中心 x=1.5、左边缘 x=0.5——`get_x()` 不带参数读中心、`get_x(direction=LEFT)` 读左边缘，正是 `set_x(..., direction=...)` 的读数版。然后三个红点分别打在右上角、下边中点、左边缘中点上，`get_corner` / `get_edge_center` / `get_critical_point` 三个名字各归其位；`get_coord(0, UR)` 与 `get_x(UR)` 等价，打印验证。

<video src="assets/RTM output/03-测量-coords.mp4" controls width="560"></video>

> 提醒：`direction` 只看符号不看大小，`UR` 和 `UP + RIGHT` 一回事；`get_critical_point` 是底层通用版本，`get_corner` / `get_edge_center` 只是好记的别名，性能没有差别。`get_z` 对平面对象恒为 0，3D 场景才用得上。

### length_over_dim / get_all_points

```python
def length_over_dim(dim: int) -> float
def get_all_points() -> Point3D_Array
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `dim` | `int` | — | **只能填** `0`=宽、`1`=高、`2`=深 |

> **返回**：`length_over_dim` 返回该维长度（`width` / `height` 的底层实现），空对象返回 `0`；`get_all_points` 返回形状 `(N, 3)` 的数组——自身及**全部后代**的顶点深度优先拼接，可能含重复。

#### 样例：维度长度与顶点云

半径 1.2 的圆：打印三维长度（2.4 / 2.4 / 0.0），再把 `get_all_points()` 的 32 个顶点各打一个小红点——贝塞尔控制点的分布看得清清楚楚。

```python
from real_time_manim import Scene, VGroup, Circle, Dot, \
    YELLOW, RED, FadeIn
from real_time_manim.vulkan_bind import MLWindow, Wait

class MeasurePointsDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        circ = Circle(radius=1.2, color=YELLOW)   #半径 1.2 的圆
        self.add(circ)   #进场景
        print("length_over_dim(0/1/2) =", [float(circ.length_over_dim(i)) for i in range(3)])   #2.4 2.4 0.0
        pts = circ.get_all_points()   #自身及全部后代的所有顶点
        print("get_all_points =", pts.shape)   #(32, 3)
        cloud = VGroup(*[Dot(color=RED, radius=0.03).move_to(p) for p in pts])   #每个顶点打一个小红点
        self.add(cloud)   #顶点云进场景
        win.play(FadeIn(cloud), run_time=0.6)   #顶点云淡入：贝塞尔控制点
        win.play(Wait(0.4))   #进行 0.4s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：半径 1.2 的圆，`length_over_dim` 三个维度依次是宽 2.4、高 2.4、深 0.0（平面对象）；`get_all_points()` 把圆的 32 个贝塞尔控制点全部取出（形状 `(32, 3)`），每个点上打一颗小红点——画面上能看到锚点落在圆上、控制柄略在圆外，这就是「顶点」的真实含义。

<video src="assets/RTM output/03-测量-points.mp4" controls width="560"></video>

> 提醒：`get_all_points` 拼的是**整个家族树**的顶点（含子对象），对象嵌套深时 N 会很大；只是想量尺寸用 `width` / `length_over_dim`，别拿数组算包围盒。控制点 ≠ 描边上的点，想取曲线上的位置用 `point_from_proportion`（见 [11b-低频其余API](11b-低频其余API.md)）。

### 重心与边界点族 + 底层统计

```python
def get_center_of_mass() -> Point3D   # 顶点均值
def get_midpoint() -> Point3D          # 路径 50% 处的点
def get_boundary_point(direction: Vector3DLike) -> Point3D
def get_zenith() / get_nadir() -> Point3D   # 3D 下 OUT / IN 面中心
def get_z_index_reference_point() -> Point3D
def get_points_defining_boundary() -> Point3D_Array
def get_merged_array(array_attr: str) -> np.ndarray
def get_extremum_along_dim(points=None, dim=0, key=0) -> float
def reduce_across_dimension(reduce_func, dim) -> float | None
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `direction` | 向量 | — | 仅 `get_boundary_point`：沿方向取最远顶点 |
| `array_attr` | `str` | — | 属性名字符串，如 `"points"`，把家族树上该数组拼接 |
| `points` | 点数组或 `None` | `None` | 取值用的点集，`None` 用自身点 |
| `dim` | `int` | `0` | 维度 |
| `key` | `int` | `0` | `1` 取最大、`-1` 取最小、`0` 取中值 |
| `reduce_func` | 可调用 | — | 归约函数，如 `max` |

> **返回**：前几个返回 `np.ndarray`（`get_midpoint` 等价 `point_from_proportion(0.5)`）；`get_points_defining_boundary` 基类默认同 `get_all_points`，`VMobject` 系只取轮廓采样点（圆实测 16 点 vs 全部 32）；`get_extremum_along_dim` / `reduce_across_dimension` 返回 `float`（空对象 `None`）。**绝大多数用户不需要直接调用**（`get_top` / `length_over_dim` 已封装）。

#### 样例：重心、边界点与统计

半径 1.4 的圆：五个红点打在顶点均值、路径中点、UR 方向最远点、zenith、排序参考点上；再把 `get_extremum_along_dim` / `reduce_across_dimension` / `get_merged_array` / `get_points_defining_boundary` 的数值打到控制台。

```python
from real_time_manim import Scene, VGroup, Circle, Dot, \
    BLUE, RED, UR, FadeIn
from real_time_manim.vulkan_bind import MLWindow, Wait

class StatsDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        c = Circle(radius=1.4, color=BLUE)   #半径 1.4 的圆
        self.add(c)   #进场景
        marks = VGroup()   #关键点标记
        for name, p in (
            ("center_of_mass", c.get_center_of_mass()),
            ("midpoint", c.get_midpoint()),
            ("boundary_point(UR)", c.get_boundary_point(UR)),
            ("zenith", c.get_zenith()),
            ("z_index_ref", c.get_z_index_reference_point()),
        ):   #重心与边界点族（平面对象的 zenith 落在中心）
            marks.add(Dot(color=RED, radius=0.07).move_to(p))   #在关键点上打一个红点
            print(name, "=", p.round(2))   #打印坐标验证
        self.add(marks)   #标记进场景
        print("get_extremum_along_dim(key=1/-1) =", c.get_extremum_along_dim(dim=0, key=1), c.get_extremum_along_dim(dim=0, key=-1))   #最右 / 最左 x
        print("reduce_across_dimension(max, 0) =", c.reduce_across_dimension(max, 0))   #按 x 归约最大
        print("get_merged_array('points') =", c.get_merged_array("points").shape)   #家族顶点拼接
        print("get_points_defining_boundary =", c.get_points_defining_boundary().shape)   #轮廓采样点
        win.play(FadeIn(marks), run_time=0.5)   #红点淡入
        win.play(Wait(0.4))   #进行 0.4s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：半径 1.4 的圆上打五个红点——`get_center_of_mass`（顶点均值，落在圆心）、`get_midpoint`（路径 50% 处，落在圆**周**上，与前者不同！）、`get_boundary_point(UR)`（UR 方向最远的顶点）、`get_zenith`（平面对象没有 z 厚度，落在圆心）、`get_z_index_reference_point`（排序参考点，也是圆心）。控制台再打出四个底层统计：最右/最左 x、按 x 归约的最大值、`points` 数组的家族拼接形状（32, 3）与轮廓采样点形状（16, 3）。

<video src="assets/RTM output/03-测量-stats.mp4" controls width="560"></video>

> 提醒：`get_center_of_mass` 是**顶点均值**、`get_midpoint` 是**路径中点**，对圆来说一个在圆心一个在圆周，别混用；`get_zenith` / `get_nadir` 只有 3D 对象才有意义。`get_extremum_along_dim` / `reduce_across_dimension` 是给 `get_top` 这类方法垫底的，空对象返回 `None` 而不是 0，直接参与算术前记得判空。
