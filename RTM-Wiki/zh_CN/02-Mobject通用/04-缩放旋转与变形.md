# 缩放、旋转与变形

对对象做等比缩放、旋转、镜像与单维拉伸。以下方法均返回自身，可链式调用。

## 参数

### scale

```python
def scale(scale_factor: float, *, about_point: Point3DLike | None = None,
          about_edge: Vector3DLike | None = None) -> Self
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `scale_factor` | `float` | — | 缩放倍数。**能填** `0<\|a\|<1` 变小、`>1` 变大、**负数带翻转** |
| `about_point` | 点或 `None`（关键字） | `None` | 绕哪个点缩放；`None` 为自身中心 |
| `about_edge` | 向量或 `None`（关键字） | `None` | 绕哪个边缘缩放（如 `DOWN` 表示底边不动） |

> **返回**：自身。`about_point` / `about_edge` **必须用关键字传**，两者同时给时 `about_point` 优先。

#### 样例：`scale` 三种基准

蓝方块先绕自身中心放大 1.6 倍，再绕红点缩小（红点不动），最后绕下边缘放大（底边不动）。

```python
from real_time_manim import Scene, Square, Dot, \
    BLUE, RED, UP, DOWN, RIGHT
from real_time_manim.vulkan_bind import MLWindow, Wait

class ScaleDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        sq = Square(color=BLUE, side_length=1.6, fill_opacity=0.5)   #蓝色方块
        anchor = Dot(color=RED, radius=0.08).move_to(RIGHT * 2.5)   #缩放基准点的标记
        self.add(sq, anchor)   #进场景
        win.play(sq.animate.scale(1.6), run_time=0.6)   #默认绕自身中心放大
        win.play(sq.animate.scale(0.6, about_point=RIGHT * 2.5), run_time=0.6)   #绕红点缩放：红点位置不变
        win.play(sq.animate.scale(1.8, about_edge=DOWN), run_time=0.6)   #绕下边缘缩放：底边不动
        win.play(Wait(0.4))   #进行 0.4s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：蓝色方块分三步缩放，红点是「基准点」的可视化标记。第一步不加参数，绕**自身中心**放大 1.6 倍；第二步 `about_point=RIGHT * 2.5`，绕红点缩小 0.6 倍——红点位置始终不动，方块往红点收拢；第三步 `about_edge=DOWN`，绕下边缘放大 1.8 倍，底边钉在原处、往上长。三种基准的区别在画面上一目了然。

<video src="assets/RTM output/04-缩放旋转与变形-scale.mp4" controls width="560"></video>

> 提醒：`scale_factor` 给负数会「缩放+翻转」，效果等于反向放大，一般想要翻转用 `flip` 更直白。`scale` 是纯几何变换，描边宽度**不**跟着变粗（想连线宽一起缩用 `scale_stroke` 之类或事后调 `stroke_width`）。

### rotate / rotate_about_origin

```python
def rotate(angle: float, axis: Vector3DLike = OUT, *,
           about_point: Point3DLike | None = None,
           about_edge: Vector3DLike | None = None,
           **kwargs: Any) -> Self
def rotate_about_origin(angle: float, axis: Vector3DLike = OUT) -> Self
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `angle` | `float` | — | 弧度。**能填** `PI / 2`、`90 * DEGREES`（两者等价） |
| `axis` | 向量 | `OUT` | 旋转轴方向；2D 平面内旋转用默认 `OUT`，**3D 旋转**才换轴 |
| `about_point` | 点或 `None`（关键字） | `None` | 绕哪个点转，`None` 为自身中心 |
| `about_edge` | 向量或 `None`（关键字） | `None` | 绕哪条边转 |
| `**kwargs` | `Any` | — | 基类 `Mobject.rotate` 忽略这些关键字；但 `Square`/`Circle` 等实际类走的是 `VMobject.rotate`，它**没有 `**kwargs` 形参**，多传一个直接 `TypeError` |

> **返回**：自身。`rotate_about_origin(angle, axis)` 等价 `rotate(angle, axis, about_point=ORIGIN)`——绕**场景原点**转而不是自身中心。

#### 样例：`rotate` 与 `Rotate` 动画的区别

长方形先 `animate.rotate` 转 90°（注意这是插值不是连续转），再绕指定点转 60°，接着用 `Rotate` 动画连续转 180°，最后 `rotate_about_origin` 绕原点转 90°。

```python
from real_time_manim import Scene, Rectangle, \
    GREEN, UP, LEFT, DEGREES, FadeIn, Rotate
from real_time_manim.vulkan_bind import MLWindow, Wait

class RotateDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        rect = Rectangle(width=2.4, height=1.0, color=GREEN, fill_opacity=0.5)   #长方形：转起来看得清
        self.add(rect)   #进场景
        win.play(rect.animate.rotate(90 * DEGREES), run_time=0.6)   #绕自身中心转 90°（弧度 = 90*DEGREES）
        win.play(rect.animate.rotate(60 * DEGREES, about_point=LEFT * 2), run_time=0.6)   #绕指定点转
        win.play(Rotate(rect, angle=180 * DEGREES), run_time=0.8)   #“animate.rotate” 只是插值；连续转要用 Rotate 动画
        win.play(rect.animate.rotate_about_origin(90 * DEGREES), run_time=0.6)   #绕场景原点 (0, 0, 0) 旋转
        win.play(Wait(0.4))   #进行 0.4s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：绿色长方形走四步——`animate.rotate(90°)` 绕自身中心转（画面里看到的是「淡过去」的插值效果，中间帧被压扁，不是转着过去的！）；`about_point=LEFT * 2` 让它绕左边的点转 60°，扫过一段扇形；`Rotate(rect, angle=180°)` 是**动画类**，画面里连续地转半圈；最后 `rotate_about_origin(90°)` 整个绕画面正中的原点公转 90°。

<video src="assets/RTM output/04-缩放旋转与变形-rotate.mp4" controls width="560"></video>

> 提醒：`.animate.rotate(...)` 只是**插值到旋转后的状态**（点对点线性过渡，中间帧会缩塌），不是按角度连续转动；要真转动请用 `Rotate` / `Rotating` 动画类。`axis` 是 3D 参数，2D 里改它通常没有可见效果（绕 `RIGHT` 轴转 180° 例外，等价上下镜像，见 `flip`）。

### flip

```python
def flip(axis: Vector3DLike = UP, *, about_point: Point3DLike | None = None,
         about_edge: Vector3DLike | None = None) -> Self
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `axis` | 向量 | `UP` | 镜像轴（绕它转 180°）。`UP`（竖直轴）= **左右**镜像、`RIGHT`（水平轴）= **上下**镜像，正好和直觉相反 |
| `about_point` | 点或 `None`（关键字） | `None` | 镜像基准点，`None` 为自身中心 |
| `about_edge` | 向量或 `None`（关键字） | `None` | 镜像基准边 |

> **返回**：自身。实现就是 `rotate(PI, axis, ...)`——绕 `axis` 转 180°，所以 `axis` 指的是**旋转轴**而不是「要翻转的那条边」。

#### 样例：`flip` 两种轴的方向

右高左低的斜线：`axis=UP` 翻成左高右低（左右镜像），再 `axis=RIGHT, about_point=RIGHT * 2` 翻回右高左低（上下镜像、绕右侧基准点）。

```python
from real_time_manim import Scene, Line, \
    YELLOW, UP, LEFT, RIGHT
from real_time_manim.vulkan_bind import MLWindow, Wait

class FlipDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        s = Line(LEFT * 2, RIGHT * 2 + UP * 1.2, color=YELLOW)   #右高左低的斜线：镜像看得出来
        self.add(s)   #进场景
        win.play(s.animate.flip(axis=UP), run_time=0.6)   #绕竖直轴转 180° = 左右镜像
        win.play(s.animate.flip(axis=RIGHT, about_point=RIGHT * 2), run_time=0.6)   #绕水平轴转 180° = 上下镜像，基准点在右
        win.play(Wait(0.4))   #进行 0.4s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：一条右高左低的黄色斜线当「箭头」用——`flip(axis=UP)` 绕竖直轴翻 180°，斜线变成左高右低（**左右**互换）；再 `flip(axis=RIGHT, about_point=RIGHT * 2)` 绕水平轴翻 180° 且以右侧点为基准，斜线又翻回右高左低，但整条线的位置因基准点在右而向右偏。两步把「axis 是旋转轴」这件事演示清楚。

<video src="assets/RTM output/04-缩放旋转与变形-flip.mp4" controls width="560"></video>

> 提醒：`axis=UP` 是**左右**镜像、`axis=RIGHT` 是**上下**镜像——别按「axis 指哪条边就翻哪边」理解，它是旋转轴（绕竖直轴转半圈自然是左右换位）。想给文字做倒影（上下翻）用 `flip(axis=RIGHT)`。

### stretch / stretch_about_point

```python
def stretch(factor: float, dim: int, *, about_point: Point3DLike | None = None,
            about_edge: Vector3DLike | None = None) -> Self
def stretch_about_point(factor: float, dim: int, point: Point3DLike) -> Self
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `factor` | `float` | — | 该方向的拉伸倍数（不保持长宽比） |
| `dim` | `int` | — | **只能填** `0`=x、`1`=y、`2`=z |
| `about_point` | 点或 `None`（关键字） | `None` | 参考点，`None` 为自身中心 |
| `about_edge` | 向量或 `None`（关键字） | `None` | 参考边 |
| `point` | 点 | — | 仅 `stretch_about_point`：不动的那个点（位置参数版） |

> **返回**：自身。`stretch_about_point(factor, dim, point)` 就是 `stretch(factor, dim, about_point=point)` 的位置参数写法。它是 `stretch_to_fit_width` 等方法的底层。

#### 样例：`stretch` 单维拉伸

紫方块先拉宽 2.2 倍，再绕原点竖向压扁一半，最后 `stretch_about_point` 左端不动向右拉。

```python
from real_time_manim import Scene, Square, \
    PURPLE, UP, DOWN, ORIGIN
from real_time_manim.vulkan_bind import MLWindow, Wait

class StretchDemo(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #将名为 “self” 的 manim 窗口，绑定给名为 “win” 的 RTM 窗口
        sq = Square(color=PURPLE, side_length=1.4, fill_opacity=0.5)   #紫色方块
        self.add(sq)   #进场景
        win.play(sq.animate.stretch(2.2, 0), run_time=0.6)   #只拉宽：dim=0
        win.play(sq.animate.stretch(0.5, 1, about_point=ORIGIN), run_time=0.6)   #dim=1 压扁，绕原点
        win.play(sq.animate.stretch_about_point(1.8, 0, sq.get_left()), run_time=0.6)   #左端不动向右拉
        win.play(Wait(0.4))   #进行 0.4s 的等待
        win.close()   #关闭 RTM 窗口
```

这段代码在做什么：紫色方块依次被单维拉伸——`stretch(2.2, 0)` 只在 x 方向放大 2.2 倍（变扁长条）；`stretch(0.5, 1, about_point=ORIGIN)` 在 y 方向压扁一半，且以**原点**为基准（方块下边缘往上收）；`stretch_about_point(1.8, 0, sq.get_left())` 用左边缘当不动点向右拉长，方块左端钉在原处。全程只动一个维度，另一维纹丝不动——这就是与 `scale` 的本质区别。

<video src="assets/RTM output/04-缩放旋转与变形-stretch.mp4" controls width="560"></video>

> 提醒：`stretch` **不保持长宽比**，`scale` 才保持；想「宽度变成 5」这类按目标尺寸调的用 `stretch_to_fit_width` / `scale_to_fit_width`（见 [04b-缩放旋转与变形-进阶](04b-缩放旋转与变形-进阶.md)）。`dim` 是绝对轴（`0`/`1`/`2`），旋转过的对象拉伸也是按世界坐标轴拉，会变形。
