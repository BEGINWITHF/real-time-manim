# 快速开始

本文将快速的带你入门 real-time-manim,包括你的第一个scene, transformation，以及在real-time-manim里输出 `Hello, world!`变换到 `Hello, real-time-manim`的动画。我们强烈建议在读完安装流程，并成功安装real-time-manim后再阅读本文，从而在阅读的同时操作。

## 渲染一个圆圈

1. 在有预装好real-time-manim的项目里新建一个文件（示例为`main.py`）
2. 将如下的代码拷贝到你的文件中

```python
from real_time_manim import *

class CreateCircle(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #把场景绑定给窗口
        circle = Circle()#设置circle
        circle.set_fill(PINK, opacity=0.5)  # 设置圆圈的填充以及透明度
        win.play(FadeIn(circle), run_time=1.0)   #淡入这个圆，时长1秒
        win.close()   #关闭窗口

fast_record_scene(CreateCircle)#将视频导出到 ~/Downloads/output.mp4中
```

3. 打开终端，配置虚拟环境 （我们建议在vscode中使用 `source .venv/bin/activate`指令），然后在虚拟环境中运行如下代码：

```bash
python main.py
```

4. 打开`~/Downloads/output.mp4`,就可以看到渲染的视频了。

### 解释

我们先来看一下各个部分的运作机制

```py
from real_time_manim import *
```

```py
class CreateCircle(Scene):
    def construct(self):
        ...
```

在这一段代码中，我们把主要的代码写进了`construct(self)`的代码中，也即覆写`scene`类中的`construct`方法。在`construct`方法内部，你可以添加物品，动画，视觉效果，也就是`real-time-manim`库的主要动画程序编写地点。

```python
win = MLWindow(960, 540)
win.scene = self
```

这两段代码创建了 RTM 的窗口，并把当前场景绑定到窗口上（RTM 固定以 1920×1080 渲染，所以括号里的 960×540 会被自动改为 1920×1080）。在`real-time-manim`中，窗口的渲染都是使用`vulkan`的`MLWindow`来制作，从`python`的`cairo renderer`全部变成了`vulkan`引擎，从而加速了渲染效率。

```python
circle = Circle()#设置circle
circle.set_fill(PINK, opacity=0.5)  # 设置圆圈的填充以及透明度
```

这里我们创建了`circle`的变量名称，从而使我们可以借由变量名来操控动画的效果。同时，每一个物体可以设置特征（例如这里的`.set_fill`指令）来改变物体的具体效果。

```py
win.play(FadeIn(circle), run_time=1.0)   #淡入这个圆，时长1秒
```

这里是我们的主要动画渲染效果指令，为一个`FadeIn`,也即将一个圆圈淡入进画面。其中动画效果可以被改变，时长由后面的参数（例如在这里的`run_time=1.0`）确定。

## 渲染 `Hello, world! Hello, real-time-manim`动画

1. 将如下的代码接在文件末尾

```python
class HelloWorld(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #把场景绑定给窗口
        text = Text("Hello, world!")#设置text
        win.play(FadeIn(text), run_time=1.0)   #淡入文字，时长1秒
        text2 = Text("Hello, real-time-manim!")#设置第二个text
        win.play(Transform(text, text2), run_time=2.0)   #变换到第二个text，时长2秒
        win.play(Wait(0.5))   #等待0.5秒
        win.close()   #关闭窗口

fast_record_scene(HelloWorld, "hello.mp4")#将视频导出到项目目录下的 hello.mp4 中
```

2. 再次在虚拟环境中运行

```bash
python main.py
```

3. 打开项目目录下的`hello.mp4`，就可以看到文字从 `Hello, world!` 变换到 `Hello, real-time-manim!` 的动画了。

### 解释

```python
text = Text("Hello, world!")#设置text
```

这里我们创建了`text`的变量名称，`Text`指令可以把一串字符变成一个文字物体（mobject）。和上一节的`circle`一样，我们可以通过这个变量名来操控文字物体，也可以像`.set_fill`那样为它设置特征。

```python
win.play(Transform(text, text2), run_time=2.0)   #变换到第二个text，时长2秒
```

这里是本节的动画核心，`Transform`指令可以把第一个物体变换成第二个物体的样子。在这里，`text`会从`Hello, world!`平滑地变形到`Hello, real-time-manim!`，变形动画的时长由后面的`run_time=2.0`确定，和上一节一样。
