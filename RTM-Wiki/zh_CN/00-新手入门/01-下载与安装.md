# 下载与安装

本文将带你装好 real-time-manim 的全部依赖。real-time-manim 支持 **Windows 10/11** 和 **macOS**（没有 Linux 版本），需要 Python 3.11 或更高。

装完本文的东西之后，再读 [快速开始](02-快速开始.md) 就能跑出你的第一个动画了。

## 安装列表

| 依赖 | 作用 | 必装？ |
| --- | --- | --- |
| Python 3.11+ | 运行 real-time-manim 的解释器 | 必装 |
| real-time-manim | RTM 本体（自带一套 ManimCE 0.21.0，**不用单独装 manim**） | 必装 |
| Vulkan（macOS 上是 MoltenVK） | RTM 的渲染引擎 | 必装 |
| ffmpeg | 录制视频时把帧合成为 mp4 | 录视频必装 |
| typst | `MathTex` 数学公式的编译后端（装了它就不用装 LaTeX 出公式） | 可选 |
| LaTeX（TeX Live / MacTeX / MiKTeX） | `Tex` 文字公式恒需要；`MathTex` 没装 typst 时也需要 | 可选 |

## 1. 安装 Python

去 [python.org](https://www.python.org/downloads/) 下载并安装 **Python 3.11 或更高版本**，安装时勾选 "Add Python to PATH"（Windows）。

装完在终端里验证：

```bash
python3 --version
```

能打印出版本号（3.11 及以上）就继续。

## 2. 创建虚拟环境（建议）

我们建议每个 real-time-manim 项目都用自己的虚拟环境，避免和其它项目的包打架：

```bash
python3 -m venv .venv   #在项目目录里创建虚拟环境
```

之后每次使用前先激活（vscode 的终端会自动问你要不要激活）：

```bash
# Windows
.venv\Scripts\activate
```

```bash
# macOS
source .venv/bin/activate
```

## 3. 安装 real-time-manim

```bash
pip install real-time-manim            #只装本体
pip install "real-time-manim[typst]"   #本体 + typst（推荐：MathTex 公式不用装 LaTeX）
```

`[typst]` 这一档会顺手装上 `typst>=0.14`，之后 `MathTex` 直接可用。只有当你需要用 `Tex`（整段文字公式）时，才需要再装 LaTeX。

### Windows 的 Vulkan

Windows 的安装包（wheel）自带 `vulkan_core.dll`，**不需要单独装 Vulkan SDK**。Vulkan 的驱动由显卡驱动提供——把 NVIDIA / AMD / Intel 显卡驱动更新到最新即可。只有当你想自己编译 RTM 的 native 部分（`native/build.ps1`）时才需要装 Vulkan SDK。

### macOS 的 Vulkan（MoltenVK）

macOS 没有原生 Vulkan，RTM 通过 **MoltenVK**（Vulkan → Metal 的转换层）跑起来：

```bash
brew install molten-vk   #用 Homebrew 装 MoltenVK
```

pip 安装时 sdist 自带 native 源码和编译好的 `vulkan_core.dylib`，会在本地构建 wheel。Apple Silicon 上如果构建报错，加上这个环境变量重试：

```bash
MACOSX_DEPLOYMENT_TARGET=13 python3 -m pip install real-time-manim
```

从源码编译 native 库则是 `bash native/build_mac.sh`（只在仓库开发时需要）。

## 4. 安装 ffmpeg（录视频需要）

RTM 录制时靠 ffmpeg 把逐帧画面合成 mp4，ffmpeg 必须在 `PATH` 里：

```bash
# macOS
brew install ffmpeg
```

```bash
# Windows：winget 或官网下载后加入 PATH
winget install ffmpeg
```

验证：

```bash
ffmpeg -version
```

## 5.（可选）安装 LaTeX

`MathTex`（行内公式）装了 typst 就不需要 LaTeX；但 `Tex`（整段公式文字）**恒需要** LaTeX：

| 平台 | 装法 | 体积 |
| --- | --- | --- |
| macOS | `brew install --cask mactex-no-gui`（或 BasicTeX 轻量版） | 大（几 GB） |
| Windows | 安装 [TeX Live](https://tug.org/texlive/) 或 MiKTeX | 大 |

不写 `Tex`、只用 `MathTex` + typst 的话，跳过本节即可。

## 6. 验证安装

把下面的代码存成 `main.py` 并运行，能跑出一个 mp4 就说明全链路通了：

```python
from real_time_manim import *

class Hello(Scene):
    def construct(self):
        win = MLWindow(960, 540)   #创建一个 RTM 窗口
        win.scene = self   #把场景绑定给窗口
        text = Text("Hello, real-time-manim!")
        win.play(FadeIn(text), run_time=1.0)   #淡入文字，时长1秒
        win.close()   #关闭窗口

fast_record_scene(Hello, "hello.mp4")#导出到项目目录下的 hello.mp4
```

```bash
python main.py
```

运行成功后项目目录里会出现 `hello.mp4`，控制台打印 `[FastRecord] Saved: ...`。

## 常见报错

| 报错 | 原因 | 修法 |
| --- | --- | --- |
| `FileNotFoundError: vulkan_core.dll not found...` | native 库缺失 | Windows 重装 wheel；macOS 跑 `bash native/build_mac.sh` 后重装 |
| `RuntimeError: Vulkan_Init failed` | Vulkan 设备/驱动初始化失败 | 更新显卡驱动（macOS 确认 `brew install molten-vk` 成功） |
| `[Record] ffmpeg not found` | ffmpeg 不在 PATH | 按第 4 节安装 ffmpeg |
| `latex error converting to dvi` | 用了 `Tex`/`MathTex` 但没有 LaTeX | 装 LaTeX，或给 `MathTex` 装 typst（第 3 节） |

> 提醒：real-time-manim **自带** ManimCE 0.21.0，不要单独 `pip install manim`；也不要先 `import manim` 再 `import real_time_manim`（会让 RTM 用上外部的 manim 拷贝）。正确姿势永远是从 `real_time_manim` 导入。
